Many papers have been written giving divisibility tests for integers. This 
note does not contain any new result, but it gathers previous tests in one 
place and shows how to generate any number of new ones. 
Divisibility tests for 2, 3,4, 5, 8, and 10 are taught as early as elementa- 
ry school but tests for arbitrary prime numbers are not given. Here is a test 
for divisibility by 7. Take the number to be tested and double its last digit. 
Subtract this from the number with its last digit removed. If 7 divides this 
new number, then 7 divides the original. For example, 7 1 294 since
