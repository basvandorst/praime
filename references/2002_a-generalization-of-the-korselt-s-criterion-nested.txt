1 Introduction to Carmichael numbers :
1o) Deﬁnition : A positive composite integer n is called a Carmichael number if
and only if for all integer b we have bn ≡ b [n].
2o) Korselt’s Criterion (1899)
Theorem :
A composite odd number n is a Carmichael number if and only if n is squarefree
and p − 1 divides n − 1 for every prime p dividing n.
2 The generalization :
1o) Deﬁnitions :
Let E = {C1, C2, ..., Cz} be a set of coprime Carmichael numbers.
Let f be a function that returns the product of the elements of a given set.
Let F be the set of prime factors of f (E).
Let P (E) be the set of parts of E without {∅}, and let S ∈ P (E).
Let T be the set of prime factors of f (S).
Let m = lcm {pi − 1 for all pi ∈ F }
Let g = gcd {Cj − 1 for all Cj ∈ E}
2o) Theorem :
(∀S f (S) is a Carmichael number) ⇐ ⇒(m | g)

3 The concept of nested Carmichaels :
When |S| = 1, the previous theorem becomes :
C is a Carmichael number ⇐ ⇒lcm {pi − 1} | C − 1
which is clearly equivalent to :
C is a Carmichael number ⇐ ⇒pi − 1 | C − 1 ∀pi | C
which is exactly the Korselt’s criterion. But Korselt’s criterion is only valid for
a single Carmichael number. The above part gives a generalization for any number
of Carmichael numbers. This leads us to the deﬁnition of a new concept : “a set of
nested Carmichaels”.
1o) Deﬁnition : Using the deﬁnitions of the part 2, a set S is “a set of nested
Carmichaels” if and only if ∀ S f (S) is a Carmichael number.
2o) Example : One of the smallest set S of 2 elements is S = {C1, C2} with
C1 = 1729 = 7 .13.19 and C2 = 294409 = 37 .73.109. Thus, C1, C2, and C1.C2 are
all Carmichael numbers.
