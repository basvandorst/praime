IDEAS - how to crack more puzzles
==================================

General tricks to try first
- Records that are sums or counts of primes up to a huge x (sum of the first k primes, pi(x)): verify them with Lucy's recursion (pi(x) and the prime sum in O(x^(3/4)), writeup/code/p9_lucy.c) instead of a sieve. Resta's 2.2e23 sum (puzzle 9) checks in 4 s. A search still has to visit every prime: Lucy only gives the exact starting sum for a segment.
- Find the remainder. If a property depends only on p mod m, build a formula that always gives that remainder (1230, 1135, 77).
- Use non-residues. Choose constants so that small primes can never divide any value: (D/p) = -1 for many small p (Euler 41, 1139).
- Glue blocks. Primes in arithmetic progression with difference 19# are plentiful. Any formula that can switch between blocks can reach large counts (1097, 1099, 1028).
- Reuse record objects: Mersenne primes, the largest palindromic prime, twin-prime records, AP-27, Dress-Landreau polynomials.
- Fix all but one unknown. Build everything except the last prime, so a linear equation fixes it (435, 325).
- Multiply known solutions. Multiplicative functions (sigma, phi) let two known pairs combine into a new one (1080, 458).
- Check for a covering set before a search. If none exists, a heuristic count usually answers "is it always composite?" (1145, 1257).
- Explain percentages and biases with Hardy-Littlewood, done exactly for the small primes (1204, 1257).
- Prove impossibility with parity, mod 4 and mod 11 first. Many "no answer yet" questions have no answer at all (75, 170, 890).
- Equations in sigma and phi on n = 2^a 3^b: write sigma(phi(n)) in closed form A*B. sigma(AB) - AB >= 1 + A + B kills most cases. Zsigmondy (fact 1509) plus a congruence mod 2^(p+1) kills the rest (489, 490).
- Multiplicative conditions (sigma(n) = q^k, sigma(n) odd, ...): search the prime-power parts, not n. Parts p^a with a >= 2 need only p <= sqrt(X), so X = 10^18 is minutes (542).
- Magic squares of order 4 with extra prime conditions: use entries a_i + b_j on two orthogonal diagonal Latin squares. Every line is magic for free, and the search becomes a K_{4,4} in a bipartite graph (870). Affine digit rules (append/prepend digits) keep magic squares magic.
- Magic squares of palindromes or other digit patterns: make every digit position a small magic square of digits (no carries), so magic and palindromic come for free; then sieve all middle patterns into a bitset and search centers c with c +- a in the set (868: 101 digits). PARI (cypari2) and FLINT (python-flint) in .venv prove primes of hundreds of digits in well under a second.
- Digit-pattern chains (A Z..Z B, near-repdigits): q | N_i is linear in A, so sieve over A for fixed (Z, B). Only ord_q(10) classes per q are lost, and 10^10 candidates take a minute (882). Sieve only the terms the target needs: sieving extra terms silently drops good candidates.
- Digits of 1/p read backwards are the 10-adic expansion of -1/p (carries move forward). Questions about reversed periods become 10-adic identities, which are often cleaner than the forward ones (1238).
- "Only these roots" for equations mixing tau and sigma: tau(m) <= c_e m^e with an exact constant (c_(1/4)^4 = 127401984/25025) and sigma(m) <= m(1 + ln m) turn a heuristic into a proof above some X0; check below X0 exhaustively (1035).
- Two prime factors, equation bilinear in X = p^(a+1), Y = q^(b+1): write it as D*XY - A(X+Y) + C = 0, multiply by D and complete the product, (DX - A)(DY - A) = A^2 - DC. A square or small right side bounds everything (455).
- Conjectured primality tests: work out exactly what the test checks mod p (or p^2) when n = p is prime. If it comes down to "random" residues being 0, a random model gives the failure rate; scan just past the author's range (conjecture 115: first failure 3917, author tested to 3000).
- Before claiming ANY result, list every page that links to the puzzle and is not just the previous/next navigation link:
    grep -l -E "[Pp]uzzles? *$N\b|puzz_0*$N\.htm" data/puzzles/*.txt
  "Redo puzzle N", "Puzzle N revisited" and "Follow up to puzzle N" pages often hold the real record. An audit on 31 Oct 2026 found six cases: 324 (puzzle 1244), 373 (951), 793 (960) and conjecture 19 (problem 33) were rediscoveries and were withdrawn to writeup/; 957 (981) and 172 (914) were cut back to what is new; 374 now credits Volpatti (952).
- Before calling table entries "new", read the editor's notes inside the table rows too. Puzzle 11: Rivera's note in the N = 36 row says Gusev computed N = 21..36 in 2001 and only N = 36 was printed, so our N = 21..35 are first publications of known values, not discoveries. Phrase such results as "published, recomputed, proved minimal" and claim only the new bounds as new. A keyword audit of all results pages (published only / not shown / unpublished / computed all / on his site ...) found no other case (31 Oct 2026).
- Before trusting "checked up to N", test the claim mod 6. A residue class with almost no chances fails almost always (conjecture 55: 305).
- Ratios that tend to ln 2 or ln 3: write the condition as an interval for u = ln p / ln n and integrate du/(u(1-u)). The exact sum over primes then predicts the finite-range values (conjecture 99; also 90).
- Search the literature before computing: a conjecture on the pages may already be a theorem (conjecture 70: Cohen-Oliveira e Silva-Trudgian 2015). Read the abstract itself (arXiv API via curl), not a summary.
- Inequalities "implied by Firoozbakht" often need far less: p_(a+b) <= p_a p_b (Bertrand plus Rosser-Schoenfeld) already proves all six of conjecture 76.
- "True for n large enough" becomes a proof with an explicit theorem: Bennett-Martin-O'Bryant-Rechnitzer (2018) give |theta(x;q,a) - x/phi(q)| < x/(160 ln x) for 3 <= q <= 10^5, x >= 8e9. Add Brun-Titchmarsh (Montgomery-Vaughan) for prime-power moduli and sieve below 8e9 (conjecture 80).
- A greedy process driven by random-looking weights is often a classic model. "Remove neighbours in order of gap" is Flory's dimer adsorption, density e^-2 (conjecture 111).

Method (user tip, 31 Oct 2026): drill down. Write the problem as a chain of claims down to the lowest level; prove or check each link on exact data before using it; only then let a model predict, calibrated link by link (1064: q | G(p) -> 2p | q-1 -> -3 QR -> 6p | q-1 -> mod 8 rule -> p mod 4 rule -> pair model). No brute force.
- Egyptian fractions with restricted denominators (problem 76, puzzles 897/899/1020): a sum of squarefree unit fractions is an integer iff every prime p is 'balanced' (the inverses mod p of the cofactors of the terms containing p sum to 0); then a sum in (0, 2) is exactly 1. Build: bulk of the smallest denominators, repair primes from the largest down (Lagrangian score: d(terms) - lam*X0*d(sum)), close the smallest primes exactly with a DP over their residue states using 'gadgets' (a prime v plus terms v*f, f small, whose inverses cancel mod v). Mask INF before adding negative costs in the DP. Odd semiprimes: 711 (record 2587); 3-prime denominators: 4959 (but 4922 is already on puzzle 897, Oct 2026).
- Mod-3 colourings kill 'neighbour sums prime' puzzles: if all sums are prime, multiples of 3 form an independent set separating the classes 1 and 2 mod 3 (only 1+2 = 3 escapes). A complete search over residue colourings (C, seconds) proves impossibility far beyond direct search (puzzle 120: n = 4, 6, 8, 10).
- Chains defined by a map f (cascades, 857): invert f at the top of the record chain. For f(p) = 2ab+1 with p = a^2+b^2 the predecessors are the coprime splits ab = (T-1)/2; one factorisation gives all of them.
- 'Self-referential' forms f(n) = a(n)^n + b(n) (1022): modulo a prime r = (jn - i)/k both the base and the exponent n mod (r-1) are fixed, so Fermat/Euler reduce r | f(n) to r | D(j,i,k). List the (j,i,k) with D = 0: these are the infinite divisor families (for (n-1)^n + n only n+1 and 2n-1, i.e. base -2 Fermat/Euler tests). Then n = 1 (mod r) usually kills covering sets outright, and the question becomes a calibrated count (sieve + Mertens, calibrate on an OEIS family of the same size).
- 1064 pattern: q | gcd(a^p + 1, b^p + 1) iff q = 1 + dp with -a, -b both d-th power residues. Quadratic characters of -a, -b then force congruences on q (here mod 24) and tie d to p mod 4. The same works for gcd(a^n - 1, b^n - 1) and any pair of bases; pairs of factor types that need opposite p classes never co-occur, which shapes the composite counts.

- Gap inequalities "for all n" (997, conjecture 53): reduce to a bound on one or two consecutive gaps, check below 2e8, then the complete gap table (max gap 1476 below 4e18) proves the rest to 4e18; Jarviniemi 2022 (gaps >= x^0.5 in [x,2x] total x^0.57, gaps >= x^0.45 total x^0.63) bounds the exceptions beyond. Siblings still open: conjectures 38, 42, 52, 57, 60, 78, 106.

- Forcing cascades (360): if a condition makes l | f(d, N) iff N is in a residue set built from divisors d, then once the divisors cover all residues, l must divide N; each forced prime adds divisors, so the cascade accelerates. Count the exact escapes (values equal to l itself) at the first steps; they are usually exactly the known small solutions.

- Many covering sets (problem 92): fix a core of covering primes, then glue disjoint 'tails' that each cover the core's remainder; CRT makes them compatible, so the number of covering sets is unbounded. For a given k, every prime p with ord_p(2) | L covers a determined class (2^r = -s/k mod p): enumerate minimal covers to count a number's covering sets.

- Brier numbers and covering sets (problem 68): a prime in both covering sets has even order m and covers n = a (+1) and a + m/2 (-1); with 3 shared, the others need m = 2 (mod 4) (11, 19, 331, 43, 5419, 281, 211, ...). Split n by parity: both sides become covering problems in t with these primes 'paired' (c and c + 1/2 mod m/2). Minimum-product questions are then an exact 0/1 program over residue classes (scipy.optimize.milp = HiGHS; minimal cover = every member has a private point). T = 360 solves in minutes; T = 1260 only gives good incumbents.

- 'Most objects from a digit budget' (1276, 49): an ILP over digit-count classes is only optimal for the primes it sees. LP duality closes the gap: weights y_d >= 0 give count <= k*sum(y) + sum_{short p} max(0, 1 - y.c(p)); if every long prime has y.c >= 1 (last digit 1/3/7/9, first nonzero, the rest >= min y) the bound covers all primes. ILP = floor(bound) is then a proof of optimality.

- Covering/packing puzzles (963, 896): reduce to the maximal objects (a set can always be replaced by a superset), then exact set cover with HiGHS. For an independent optimality proof, use branch-and-bound with LP dual bounds rounded to fractions and scaled to be exactly feasible; SAT with a cardinality bound was far slower on set cover. SAT (pysat, CaDiCaL) is good for subsequence questions instead: 'string of length L containing all words' proves 896's sets B (11) and C (21) optimal in minutes.

- Grid arrangements with a local cost (1277): first place the 'expensive' items by hand (no friends: border; few friends: exactly their friends around them), freeze them, then anneal the rest. Plain annealing cannot build multi-cell motifs like a prime with its four multiples.

- 'Minimal sum under local gcd/lcm conditions' (764, 766, 767): derive the relaxed cost of every unit (a cell is a multiple of the lcm of its labels), solve the relaxation exactly by DP over subsets, and use it as a completion bound in a search that places real values. The relaxation alone is far from tight; inside the search it beats CP-SAT by orders of magnitude (N = 20: a few seconds vs no answer in 30 minutes). Same recipe for any 'arrangement with labelled edges' puzzle.

- Forms a^n + n^k (1235, like 1022): the density of q | a^n + n^k comes from two subgroups of (Z/q)*, the powers of a and the k-th powers; closed form from their orders, and -1 must lie in their product or q never divides. Condition the densities on the residue classes that the small primes leave (the period of a^n mod q shares factors with the class modulus), otherwise the Euler product does not even converge. n = 0 (mod q) escapes q, so these forms never have covering sets.

- Puzzle 764 rows of 50 and 100: records 4036 and 22062 are only 77 % and 65 % of the cover lower bound (3111, 14382) while proved optima sit at 88-92 %: a construction from the structure (doubling chains, label 1 between two bare primes, large primes at the ends, every cell = lcm of its labels) should beat them.

- Parity-of-index questions about gaps (211, OEIS A008347): the sum of every other gap is open, but sieve upper bounds for prime pairs (Halberstam-Richert Thm 3.11, factor 4) force a positive share in each parity class (1/64). Any 'even vs odd position' gap question gets this bound for free.

Open targets that look reachable
- 1257 Q1: the next n with 2^n - 7 prime. Search only the 8 allowed classes mod 60, sieve deep, then PRP test. This needs days of PRP tests, not days of thinking.
- 1139 variants: other "irregular" rules. Ask which divisor rules give odd values for all n, as we did for halving. Then reuse the two-forms picture.
- Other prime-generating puzzles (232, 782, problem 12): search those polynomial families with the non-residue filter on the discriminant.
- 1272: the next three terms after Resta's 15th term of puzzle 935. First explain how the 15th term was found, then extend that.
- 1247: the 5 missing permutations are 1793, 1937, 1973, 9173, 9713. Each needs the squares 1 and 9 ahead of 3 (and 1937 ahead of 7 too), which Chebyshev bias makes rare. The last solutions on the page are near 5.1e12, inside an excursion where 1 and 9 lead. A plain sieve past 1e13 is hours on 2 cores; first locate the next excursions with the explicit formula (zeros of the mod 10 L-functions), then count exactly there.
- 1286: Crescendo serpents for D = 3, 7, 9. They are blocked by factoring 150-digit numbers. Only try this with ECM or a factoring service.
- 782 Q1 (P + p# prime for 2#..p_n#) and 350: OEIS A115786/A115785 have terms to n = 20/19 (Glickman, Oct 2026), so a new record needs P near 1e22. Q2 has no fixed rules: floor/mod formulas glue any list (1099).
- 'Is a window sum of k-th powers of consecutive primes ever special' (443, 393, 128, 543): build all windows by S_L = S_(L-1) + shifted powers (one numpy addition per length, arrays of 1e6 entries), keep a float copy for the root and a copy mod 2^64 for the test; 3e9 windows in 90 s and 190 MB. Sum the density of the target set over the windows to see at once whether solutions are expected (cubes: 0.06 in total; squares: infinitely many).
- 543 (least prime that is a sum of squares and also a sum of cubes of consecutive primes): not reachable. Below 1e11 there are 2.1e6 square sums and 25803 cube sums with one common value, 23939 = 37 * 647 (23^2 + ... + 67^2, 11 primes, = 17^3 + 19^3 + 23^3); common values grow like X^(1/6) and the prime ones like X^(1/6)/ln^3 X, so the first prime is expected near 1e30. Needs a collision method on C[j] - Q[l] = C[i] - Q[k], not enumeration.
- 'A quadratic form in consecutive primes is a square' (498, 655; 10 November 2026): complete the square to a Pell-type equation U^2 - D z^2 = k with k depending only on the gaps, list fundamental solutions for all k once, walk the orbits modulo two small primorials in numpy, pair with the gap tuples of the same k, sieve, and build exact integers only for survivors (writeup/code/p655_pell.py: 3e9 pairs to 100 digits in 10 core-minutes). First sum the density: if the expected number grows like ln ln p, a sieve over p is hopeless and the orbit walk is the only way (each new solution costs a factor 17 in digits). Same shape: 497 (sqrt(p^2 + q^2 - 9)), 460, 561, 531 (two products of consecutive primes a power), 595.
- Read every page that links to the puzzle before coding: 655 already had the Pell reduction for 498 (van Delden) and its search bounds (40 digits, gaps <= 500); the new solutions sit just outside both.
- Pages with no contributions at all: list them with
    grep -L "contributions came\|wrote:" data/puzzles/puzzle-*.txt
  Then pick the ones with a solved sibling in writeup/.

New puzzles we could pose
- Irregular polynomials with halving: what is the longest run with all values distinct? (Best seen: 53.)
- For which c is 2^p - c composite for every prime p because of a real covering set? That would be a true version of 1257.
- Prime pines and prime spheres (77, 92) with 11 rows or 8 levels, using the same remainder trick.

How to work
- Reason first, then search only a bounded range. State every range in the write-up.
- Re-check each claim with a second script. Mark numbers above 2^64 without a proof as PRP.
- When stuck, ask: which solved puzzle has the same structure?
- Before quoting a record from memory, grep references/web/ (archived copies from 2026) and recompute what you can. Two remembered records were wrong: the largest maximal gap (1854 since 2026, not 1550) and the least CPAP-7 (unknown; 1107819732821 starts 8 consecutive twin pairs instead).

Leads from the facts pass (FACTS.md)
- Puzzle 151: no Euler-Rodriguez chain of 15 is known (none below 10^17, Andersen 2003). Necessary: 1 - 4A is a non-residue mod every odd q <= 29. Mirrored chains L - x(x+1) are equally likely, so search both. A Hardy-Littlewood count calibrated on our chain counts would say where the first 15 should be.
- Mirrored chains as a new table: least L for 13 and 14 primes (we know 12 at 27797667649 below 1.4e11; forward 13 and 14 were found in 2003).

Leads from the second facts pass (FACTS.md, October 2026)
- Fixed classes of affine maps: for any chain rule x -> a x + b (Cunningham, Collatz-like, GPD maps), the classes mod small q that avoid 0 forever are the fixed points and cycles of the map mod q. Search only inside them (fact 6201).
- Prime races: for puzzles about the order of residue classes, the squares (class 1 mod 8, 12, 24; digits 1 and 9) lag behind the non-squares for a very long time (facts 1602, 1603, 1605, 1606).
- Zsigmondy gives a prime = 1 (mod n) dividing a^n - 1 for free; useful for constructions that need a prime of order exactly n (fact 1509).
- Kronecker races: f(5) = 2082927221 (first time primes with (5/q) = 1 lead) is checkable in C with our 1.4e11 sieve; f(-3) = 608981813029 too.

Leads from the third facts pass (October 2026)
- Explicit bounds (Dusart, Rosser-Schoenfeld) often have thresholds that are sharp at a prime gap: when a puzzle needs "a prime in [x, x + f(x)]", test the bound at x just below each prime, not at the primes (fact 2033).
- Minimal primes (fact 6217): any digit-avoidance puzzle can be settled by checking which of the 26 minimal primes survive the digit restriction; the survivors bound what can be prime.
- Covering sets work for k*10^n +- 1 and near-repdigits (fact 6219): before searching a decimal family, test it mod 3, 7, 11, 13, 37 for a cover.
- Kronecker races give a whole table of "first time the squares lead" (fact 1611); mod 3 at 608981813029 is the hardest small case.

Leads from the shared-component pass (30 October 2026)
- Puzzle 151: the chain model predicts E[number of 15-chains below 1e17] = 0.91 (no chain there has chance 40 %), and 3.6 more between 1e17 and 1e18 (97 % chance of one). A forward + mirrored search of 1e17..1e18 with the A mod 210 filter is the natural next step.
- For any "record extreme" (least witness, maximal gap, longest run) use the hybrid model (exact sieve to y = x^0.405, Buchstab-normalised) rather than Cramer; Cramer is 25-30 % too generous at reachable sizes.
- Prime-rich quadratics = small L(1, chi_D) = small h(D)/sqrt|D|. Search discriminants by class number tables, not by brute force.
- To fit a quadratic to a given list of primes, search D in (m^2 - D)/4: the winner is always a D that is a non-residue mod most q <= 23 (53..83: D = 293 hits 7 of 8, unique for |D| <= 1e7).

Leads from the gap-explanation night (31 October 2026; scripts in the session scratch, summary in FINDINGS)
- Pattern counts (CPAP, Euler-Rodriguez, any consecutive-prime pattern): use an EXACT random sieve to Y just above the span (sample p mod q uniformly from the allowed classes for every q <= Y, independent by CRT), a coin rho_Y above Y, and for "exactly k" subtract rho * [next term survives] * (1 - rho)^(survivors before it). Calibrated below 1.4e11 to ~1 %: gaps 2/6 1.0003/1.0001, ER-3..8 0.997-1.014, CPAP-4/5/6 (d = 30) 1.009/0.979/0.998. Two traps: Y far below sqrt x (v ~ 3) adds a Buchstab factor per term; averaging HL factors over p's classes (Jensen) overcounts long spans (CPAP-6 +24 %).
- Puzzle 151 with that model: N(15-chain, at least 15, below 1e17) = 0.71 (no chain 49 %), below 1e18 3.6; first 15-chain expected in (1e17, 1e18) with 95 % given none below 1e17. 16-chain: median ~4e18.
- Least CPAP-7: a 23-digit one is known (71137654873189893604531, Zimmermann; OEIS A006560), so the least has at most 23 digits. The model (writeup/code/facts_pattern_model.py --ap 7 --d 210,420) gives N(1e20) = 0.09, N(1e21) = 3.1, median 3.8e20: most likely 21 digits, 22 possible (CPAP-3 checks up to span 240 within noise once 5 seeds are averaged: 1.001, 0.990, 1.016). Andersen 2014: 22-23 digits. Not checkable here.
- The maximal next-prime hit rate with sight y is rho_y (the next prime is the J-th sieve survivor, J geometric); with a memory of K gaps it is rho_y with y ln y ~ K. No look-back or learned rule can do better; don't spend more searches on gap rules.
- Puzzle 11 (open): an exhaustive two-pointer pass below 1.7e12 gives the first runs of N distinct gaps for N = 21..35 (missing on the page; 33-36 all start at 1625800359439) and confirms Gusev's 14 increasing / 13 decreasing as first. Next targets: 37 distinct, 15 increasing, 14 decreasing; none below 1.01e13 (searched on 31 Oct; a second 36-run at 3668866071389). 15 increasing / 14 decreasing lie above 1e13. Draft write-up and code in the 31 Oct night scratch (p11/), not yet in writeup/.
- Puzzle 58 (k consecutive primes p with 4p^2 + 1 prime): k = 7 at 136145640773 is Andersen 2004 and k = 9 at 1719004000057 is van Delden 2018, both on the page of puzzle 54 (read the sibling first!). We confirmed k = 7 minimal below 2e11 (4p^2+1 proven by Pocklington since N - 1 = 4p^2). Open: the least k = 8 (<= 1719004000057). The HL forecast (A = 2.213, pair factor 0.89) put the median at 1.1e11; k = 8 median ~1.3e13. Draft in the 31 Oct scratch (p58/). Exhaustively searched (sieve of 4p^2+1 by q = 1 mod 4 <= 1e5, runs of >= 8 survivors fully tested): no 8-run below 1.08e12; the range 1.08e12 .. 1.72e12 is left (stopped by request: no brute force). Same recipe fits any "consecutive primes p with f(p) prime" puzzle: measure q = A_f/ln f(x), forecast, search where N_k ~ 1.

- Concatenation sequences "P & f(q) & RP for all q <= p(k)" (788): the digit count d of f(q) varies, so P*10^(L+d) runs through the residues mod 7 (ord 6). Reduce to (P mod 7, RP*10^-L mod 7) and the sets S_d of f(q) mod 7 per d mod 6; the block appears once each d-class has enough residues (788: q = 1009, the first 7-digit square). Check 13 (ord 6) and 37 (ord 3) too for siblings.
- Covering-set searches over k (1279): a block sieve that ORs 64-bit masks for n = 0..63 is an exact necessary test and runs at 1e8 k/s; only 1 odd k in 3250 needs the full test. List ALL minimal covers of each covered k (DFS on the least uncovered n): the counts by size and by number of covers come for free and exposed that the OEIS 'three covering sets' lists (A394518/9) were a restricted search (sets of <= 7 primes, no 673).
- Affine maps on residues (Keller cycle N -> (2N + P) mod 2P, 1280): split by CRT into mod 2 and mod P; the map becomes plain doubling mod P, so cycle lengths are orders and cycle extremes are gaps of the doubling orbit. A reflection x -> 2P - x that commutes with the map (Sierpinski <-> Riesel) turns 'largest member' into 'least member of the mirror'.
- Rare-event questions about gaps (record gaps, "no prime in an interval of length G"): do not sample. Use importance sampling over n mod q for q < G, with the proposal tilted by exp(beta * positions killed), and an exact one-kill-per-prime DP for the larger primes (writeup/code/facts_maxgap_is.py). It costs 1-2 s per point and reaches tail probabilities of 1e-30 and below.
