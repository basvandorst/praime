# Puzzle 1028: Prime generators made of "A·n mod B" terms

> **In short:** A sum of five terms of the form (A·n mod B) produces 49 different primes for n = 1 to 49; the best on the page used five terms for 41. The remainders behave like a sawtooth, which lets the sum jump between blocks of ten primes in arithmetic progression, so adding terms adds blocks (we also have 59 primes with six terms).

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1028.htm)

**Status:** beaten (Q2) · proven primes

## The question

Use functions of the form f(n) = Σᵢ (Aᵢ·n mod Bᵢ) with all Aᵢ, Bᵢ positive whole numbers. Kamenetsky's example (671n mod 2454) + (304n mod 32) + (4373n mod 199) gives 38 different primes for n = 1 … 38. Question 2 asks for a function of the same form with more distinct primes.

## Current record vs ours

| | Terms | Distinct primes |
|---|---|---|
| Current record (D. Kamenetsky, 2021) | 5 | 41 (n = 1 … 41) |
| **Ours** | 5 | **49** (n = 1 … 49) |
| **Ours** | 6 | **59** (n = 1 … 59) |

## How we found it

A term (A·n mod B) is a sawtooth: it grows by A each step and drops by B whenever it passes a multiple of B. Two special cases do all the work:

- **A falling line.** (A·n mod (A + 1)) = A + 1 − n for 1 ≤ n ≤ A + 1, since A·n = (A + 1)·n − n.
- **A step every L values.** With B slightly less than a multiple of A·L, the term rises steadily and drops by a fixed amount exactly when n crosses a multiple of L (or of m·L).

Together they build the same staircase as in [puzzle 1099](1099.md): on each block of 10 consecutive n the sum climbs by 9699690 per step, and at each block boundary it jumps to the start of the next block. We chose the block starts among the progressions of ten primes with difference 9699690, so every value is prime. Stinchcombe already noted on the page that a single arithmetic progression of primes fits this form; the blocks let several progressions be chained.

## The math

Write each term as A·n mod B = A·n − B·⌊A·n/B⌋. For our 5-term function the total slope is

```
35968 + 9481023 + 204182 + 1230 + 13256 − (35968 + 1) = 9699690 = 19#
```

(the first term counts as slope −1, because 35968·n mod 35969 = 35969 − n). The other four terms each drop by a fixed amount at block boundaries, and their drop sizes are chosen so that the value at the start of block j equals the j-th chosen progression start. The resulting values are the blocks starting at 35969, 2268443, 417293, 2612881 and 231529, each followed by +9699690 steps.

## The numbers

```

6 terms, n = 1..59:
g(n) = (35968n mod 35969) + (9189321n mod 91701916) + (417875n mod 8357494) + (48429n mod 1452860)
     + (10880n mod 435176) + (33186n mod 1659256)
```

With more terms the construction keeps going (one block of 10 per extra start): we also built 129 primes with 14 terms and 199 with 21 terms. All values are below 2⁶⁴, where sympy's test is exact: proven primes.

## Verify it yourself

This script evaluates both functions and checks that every value is prime and that no value repeats.

```python
from sympy import isprime

def make(terms):
    # f(n) = sum of (A*n mod B) over the given (A, B) pairs, all positive
    return lambda n: sum((A * n) % B for A, B in terms)

f5 = make([(35968, 35969), (9481023, 94764426), (204182, 4083624), (1230, 36886), (13256, 530202)])
f6 = make([(35968, 35969), (9189321, 91701916), (417875, 8357494), (48429, 1452860),
           (10880, 435176), (33186, 1659256)])

for f, N in ((f5, 49), (f6, 59)):
    values = [f(n) for n in range(1, N + 1)]
    assert all(isprime(v) for v in values)       # prime for n = 1..N
    assert len(set(values)) == N                 # all different
    print(N, "distinct primes; first values:", values[:3])

# the "falling line" building block: 35968*n mod 35969 = 35969 - n
assert all((35968 * n) % 35969 == 35969 - n for n in range(1, 60))
```
