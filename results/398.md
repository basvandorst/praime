# Puzzle 398: A prime that no inserted digit can keep prime

> **In short:** We built a 1057-digit prime where inserting any digit anywhere inside it always gives a composite number. It is proven prime, and it beats the 1000-digit example on the page.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_398.htm)

**Status:** beaten (Q2) · proven prime (Pocklington)

## The question

Take a prime and insert one extra digit somewhere between two of its digits (not at the front or the end). The prime 369293 is the smallest prime where **every** such insertion gives a composite number. Question 2 asks for the largest example you can find.

Example: inserting 5 into 369293 between the 3 and the 6 gives 3569293, which is composite. All 50 interior insertions of 369293 are composite.

## Current record vs ours

| | Prime | Digits |
|---|---|---|
| Current record (G. Resta) | 10⁹⁹⁹ + 33592689 | 1000 |
| **Ours** | N = A·10⁹⁰⁰ + 1 (A below) | **1057** |

## How we found it

A big number has thousands of possible insertions, and for a random prime some of them would be prime. So we chose the shape N = A·10⁹⁰⁰ + 1: a block of digits A, then 899 zeros, then a final 1. Inserting a digit c somewhere in the zero run gives N' = A·10⁹⁰¹ + 1 + c·10ᵏ, which only depends on c and on the position k.

For small primes q with ord₁₀(q) dividing 240 (such as 7, 11, 13, 37, 41), the value 10ᵏ mod q repeats with period 240. So by choosing A with the Chinese remainder theorem we made each of 31 small primes divide the insertions for whole families of (c, k mod 240) at once, covering about 90% of the zero-run insertions. The remaining insertions, and those inside A, we simply tested. The shape also makes N easy to **prove** prime, because N − 1 = A·10⁹⁰⁰ is almost completely factored.

## The math

Inserting digit c at position k (k digits from the right end) of N = A·10ᵐ + 1, inside the zero run, gives

```
N'(c, k) = A·10^(m+1) + c·10^k + 1
```

A small prime q divides N'(c, k) exactly when A·10^(m+1) ≡ −1 − c·10^k (mod q). Since 10^k mod q only depends on k mod ord_q(10), one condition on A mod q kills a whole class of positions. Combining one such condition for each of 31 primes gives A mod ∏q by the Chinese remainder theorem.

**Primality proof (Pocklington).** N − 1 = A·10⁹⁰⁰ = A·2⁹⁰⁰·5⁹⁰⁰, and the fully factored part F = 10⁹⁰⁰ is larger than √N because A < 10⁹⁰⁰. If some base a satisfies

```
a^(N−1) ≡ 1 (mod N),   gcd(a^((N−1)/2) − 1, N) = 1,   gcd(a^((N−1)/5) − 1, N) = 1
```

then N is prime. The base a = 3 works.

All 10,560 interior insertions are composite: each one either has a prime factor below 10⁵ or fails a base-2 Fermat test (which proves it composite).

## Verify it yourself

This script proves N prime with Pocklington's test and then checks every one of the 10,560 interior insertions for compositeness. It takes about a minute.

```python
import gmpy2
from gmpy2 import mpz, powmod, gcd
from sympy import primerange

A = mpz(1057447767801982899810936078986870322855097083184870799512294142679453394807877910422539690997221686644824565309308629748242833059104863529225434120688108130)
N = A * mpz(10) ** 900 + 1
s = gmpy2.digits(N)
assert len(s) == 1057

# Pocklington: F = 10^900 divides N - 1, F^2 > N, and base 3 works for both prime factors 2 and 5 of F
F = mpz(10) ** 900
assert (N - 1) % F == 0 and F * F > N
assert powmod(3, N - 1, N) == 1
assert gcd(powmod(3, (N - 1) // 2, N) - 1, N) == 1
assert gcd(powmod(3, (N - 1) // 5, N) - 1, N) == 1          # so N is proven prime

# product of all primes below 10^5, for a quick small-factor test
small = mpz(1)
for q in primerange(2, 100000):
    small *= q

count = 0
for i in range(1, len(s)):                                   # every position strictly inside N
    for c in "0123456789":                                   # every digit
        x = mpz(s[:i] + c + s[i:])
        count += 1
        if 1 < gcd(x, small) < x:
            continue                                         # has a small prime factor: composite
        assert powmod(2, x - 1, x) != 1                      # fails Fermat base 2: composite
assert count == 10560

print("1057-digit proven prime; all 10,560 interior insertions are composite")
```
