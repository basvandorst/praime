# Puzzle 639: σ(n + 12m) = σ(n) + 12m for every m

> **In short:** The puzzle asks to prove that for every m there is a composite n whose divisor sum grows by exactly 12m when n grows by 12m. We found a recipe that works whenever four numbers P, P + 2, P + 6m, P + 6m + 2 are all prime: take n = P·(P + 6m + 2). Such primes exist for every m we checked (up to 3.3·10⁷), and their existence for every m is a case of the prime k-tuples conjecture. So the answer is "yes" assuming that conjecture, not unconditionally.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_639.htm)

**Status:** first answer · conditional proof (prime k-tuples conjecture), checked for every m ≤ 3.3·10⁷

## The question

σ(n) is the sum of all divisors of n. Farideh Firoozbakht and Jahangeer ask: prove that for every positive integer m there are composite numbers n with

```
σ(n) + 12m = σ(n + 12m)
```

## What the page had vs ours

| | Answer |
|---|---|
| On the page | the question, no contributions |
| **Ours** | an explicit family that works whenever a prime pattern exists; **true for every m if the prime k-tuples conjecture holds**, and checked for every m up to 3.3·10⁷ |

## How we found it

A composite number with the simplest divisor sum is a product of two different primes: σ(a·b) = (a + 1)(b + 1). So we looked for n = a·b where n + 12m is again a product of two primes c·d, and asked what makes (c + 1)(d + 1) − (a + 1)(b + 1) come out at exactly 12m. Pairing a with c = a + 2 and b with d = b − 2 does it, because the two products then differ by a fixed amount that depends only on b − a. That leads to the pattern P, P + 2, P + 6m, P + 6m + 2: two pairs of twin primes, 6m apart.

The family gives one solution for each m (65, 95, 341, 155, 473 for m = 1 to 5), which is all the puzzle asks for. It does not always give the **smallest** one: the least solutions for m = 1 to 5 are 65, 80, 125, 63 and 99, and most of those have a different shape (80 = 2⁴·5, 125 = 5³).

## The math

Let P, P + 2, P + 6m and P + 6m + 2 all be prime, and set n = P·(P + 6m + 2). Then

```
n + 12m = P² + (6m + 2)P + 12m = (P + 2)·(P + 6m)
```

For a product of two different primes, σ(a·b) = (a + 1)(b + 1), so

```
σ(n + 12m) − σ(n) = (P + 3)(P + 6m + 1) − (P + 1)(P + 6m + 3) = 12m
```

and n is composite. So the claim holds for every m for which the pattern {0, 2, 6m, 6m + 2} takes four prime values.

**Why 12.** The same algebra works for any even shift k = 2h with the pattern {0, 2, h, h + 2}. But a prime pattern can only occur infinitely often if it avoids some remainder modulo every prime (it is "admissible"). Modulo 3, the pattern {0, 2, h, h + 2} covers all three remainders unless h ≡ 0 (mod 3), and h must be even, so h is a multiple of 6 and k = 2h a multiple of 12. For h = 6m the pattern is admissible for every m: mod 2 it misses 1, mod 3 it misses 1, and mod any larger prime four values cannot cover everything.

**Why it stays conditional.** The prime k-tuples conjecture (Hardy–Littlewood) says every admissible pattern takes prime values infinitely often; it is unproven even for twin primes. Known unconditional results fall short here: Maynard–Tao finds two primes among many forms, but not four prescribed ones; Pintz shows a positive proportion of even numbers are gaps infinitely often, not every one; and Green–Tao–Ziegler handles linear patterns of finite complexity, which this one-parameter family is not.

## Verify it yourself

This script lists the least solutions for m = 1 to 5 by brute force, checks the family's identity, and finds a working P for every m up to 10⁵. It takes a few seconds.

```python
import numpy as np
from sympy import divisor_sigma, isprime

# the least composite solutions for m = 1..5, by brute force (not all from the family)
for m, least in zip(range(1, 6), [65, 80, 125, 63, 99]):
    k = 12 * m
    first = next(n for n in range(4, 1000) if not isprime(n) and divisor_sigma(n) + k == divisor_sigma(n + k))
    assert first == least

N = 2_000_000
sieve = np.ones(N, dtype=bool)
sieve[:2] = False
for i in range(2, int(N**0.5) + 1):
    if sieve[i]:
        sieve[i * i::i] = False
twins = [int(p) for p in np.flatnonzero(sieve[:-2] & sieve[2:])]   # P with P and P + 2 prime

worst = (0, 0)
for m in range(1, 10**5 + 1):
    h = 6 * m
    P = next(p for p in twins if sieve[p + h] and sieve[p + h + 2])  # the four-prime pattern
    n = P * (P + h + 2)
    assert n + 12 * m == (P + 2) * (P + h)
    assert (P + 3) * (P + h + 1) - (P + 1) * (P + h + 3) == 12 * m  # sigma difference
    worst = max(worst, (P, m))
    if m <= 5:
        assert n == [65, 95, 341, 155, 473][m - 1]               # the family's solution for small m
        assert divisor_sigma(n + 12 * m) - divisor_sigma(n) == 12 * m

print("a working P exists for every m up to 10^5; largest P needed:", worst[0], "at m =", worst[1])
```
