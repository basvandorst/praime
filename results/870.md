# Puzzle 870: Prime nested magic squares II

> **In short:** Rivera asked for a 4×4 prime magic square nested inside another 4×4 prime magic square and could not find one. We built one of each type (R, L and LR), all with 3-digit inner primes. The trick: write every entry as a_i + b_j and place the pairs on two orthogonal diagonal Latin squares. Each line is then magic for free, and the search only has to make 32 numbers prime.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_870.htm) (rules in [Puzzle 869](https://www.primepuzzles.net/puzzles/puzz_869.htm))

**Status:** first answer · proven primes

## The question

Puzzle 869 defines nested magic squares. Take a magic square of primes n. Build the outer square by the rule m = (L·10^LN + n)·10^LR + R, where LN is the number of digits of the largest n. In decimal, m is n with L written in front and R written behind. Either L or R may be absent (types R, L and LR). If the outer square is again a magic square of distinct primes, the pair is a nested prime magic square of grade 2.

Puzzle 870: "Please send one solution of prime nested magic square 4x4, grade 2. Perhaps you'll be luckier than me. I couldn't find a single one." The page has no contributions.

## How we found it

The rule m = (L·10^LN + n)·10^LR + R is affine: m = u·n + v with u = 10^LR and v fixed. Every line of the inner square has the same sum, so every line of the outer square has the same sum too. Magic is automatic, and the only hard part is making 16 inner and 16 outer entries prime at once.

Searching 4×4 prime magic squares directly is hopeless (the space is huge, which is probably why Rivera found none). We impose a structure that makes any square magic:

```
entry(i, j) = a[S(i, j)] + b[T(i, j)]

S = 0 1 2 3      T = 0 1 2 3
    2 3 0 1          3 2 1 0
    3 2 1 0          1 0 3 2
    1 0 3 2          2 3 0 1
```

S and T are diagonal Latin squares and are orthogonal: each of the 16 pairs (S, T) occurs once. Every row, column and diagonal therefore holds each a_k once and each b_k once, and sums to Σa + Σb. The outer entries are u·(a + b) + v, which have the same form.

So we only need sets A = {a₁..a₄} (even) and B = {b₁..b₄} (odd) such that every sum s = a + b is a 3-digit prime with rule(s) also prime, and the 16 sums are distinct. That is a K₄,₄ in a bipartite graph: join a to b when s and rule(s) are both prime. `results/code/p870_search.py` finds one in seconds for each rule (a < 500, 101 ≤ b < 500).

Some rules have no solution in that box. For example R = 1 forces s ≡ 1 (mod 3) for all 16 sums: 10s + 1 ≡ s + 1 (mod 3).

## The math

- Affine maps keep magic squares magic: Σ (u·nᵢ + v) = u·Σ nᵢ + 4v on every line.
- The Graeco-Latin structure makes every line sum Σa + Σb. Our S and T are a standard orthogonal pair of order 4, and both diagonals of each are transversals.
- Primality is the only real constraint: 32 numbers, all below 30,000, so `sympy.isprime` is a proof.

This does not settle Puzzle 869 (3×3, grade 4). A 3×3 prime magic square has no a_i + b_j freedom: it is c + {0, ±a, ±b, ±(a+b), ±(a−b)}, and four nested grades need 36 primes on one fixed pattern. Our estimate is that this needs far more than a few hours of computing.

## Verify it yourself

`results/code/p870_verify.py` rebuilds each outer square from the rule as digit strings, checks that this equals the arithmetic form, and checks that both squares are magic with 16 distinct primes.

```python
from sympy import isprime

def is_prime_magic(sq):
    n = len(sq)
    lines = [list(r) for r in sq] + [[sq[i][j] for i in range(n)] for j in range(n)]
    lines += [[sq[i][i] for i in range(n)], [sq[i][n - 1 - i] for i in range(n)]]
    flat = [x for r in sq for x in r]
    return len({sum(l) for l in lines}) == 1 and len(set(flat)) == n * n and all(isprime(x) for x in flat)

def nest(sq, L, R):
    """Puzzle 869 rule m = (L*10^LN + n)*10^LR + R; L or R may be absent (None)."""
    LN = max(len(str(x)) for r in sq for x in r)
    f = lambda n: int((str(L) if L is not None else '') + str(n).zfill(LN) + (str(R) if R is not None else ''))
    out = [[f(x) for x in r] for r in sq]
    LR = len(str(R)) if R is not None else 0
    assert all(f(x) == ((L or 0) * 10**LN + x) * 10**LR + (R or 0) for r in sq for x in r)
    return out

cases = [  # (inner square, L, R)
    ([[191, 239, 367, 541], [499, 409, 197, 233], [379, 331, 401, 227], [269, 359, 373, 337]], None, 3),
    ([[163, 557, 631, 863], [733, 761, 271, 449], [701, 463, 719, 331], [617, 433, 593, 571]], 3, None),
    ([[139, 281, 577, 859], [727, 709, 191, 229], [593, 409, 547, 307], [397, 457, 541, 461]], 2, 1),
]
for inner, L, R in cases:
    outer = nest(inner, L, R)
    assert is_prime_magic(inner) and is_prime_magic(outer)
print("all checks pass")
```
