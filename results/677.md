# Puzzle 677: Primes in a row with square sums (partial answer)

> **In short:** Can the primes 2, 3, 5, …, P be put in a row so that every two neighbours add up to a perfect square? Nobody found one. We did not either, but we showed why the values tried on the page cannot work, and narrowed down where a solution could be. The key: a square sum forces neighbours to alternate between primes 1 mod 4 and 3 mod 4, and there are almost always too many primes 3 mod 4 (Chebyshev's bias).

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_677.htm)

**Status:** partial answer · proof of impossibility at the tried values, plus narrowed ranges

## The question

Q1: find the smallest prime P such that all primes 2, 3, 5, …, P can be arranged in a row with every two neighbours summing to a perfect square. Q2: the same, arranged in a circle.

## What the page had vs ours

| | On the page | Ours |
|---|---|---|
| Lower bounds | E. Vantieghem: a row needs P ≥ 238373, a circle needs n ≥ 38031 (every prime must have enough possible neighbours) | used as given |
| Tried values | P = 238373 and P = 409271 tried "in vain" | **both impossible**, with a short proof |
| Where a row can exist | unknown | the smallest P lies in **[615721, 634187]** or is **≥ 12305677** |
| Where a circle can exist | unknown | **none for P < 12305753** |

## How we found it

Think of the primes as dots, joined when their sum is a square. A row is then a path through every dot once.

Look at remainders mod 4. Two odd primes add up to an even number, so a square sum must be divisible by 4, which means one prime is 1 mod 4 and the other 3 mod 4. The prime 2 can only pair with q where 2 + q is an odd square, so q ≡ 7 mod 8, and 2 acts like a "1 mod 4" prime. So the dots split into two teams

```
A = {2} ∪ {primes ≡ 1 mod 4},      B = {primes ≡ 3 mod 4}
```

and every edge joins A to B. A path through all dots must alternate teams, so the team sizes can differ by at most one. For a circle they must be equal.

Primes 3 mod 4 are slightly more common than primes 1 mod 4 for almost all x (Chebyshev's bias), so B is usually bigger than A by more than one, and no row exists. That settled the two tried values at once and leaves only short windows where the teams are balanced.

## The math

```
p + q = k², p and q odd  ⇒  k even  ⇒  p + q ≡ 0 (mod 4)  ⇒  {p, q} ≡ {1, 3} (mod 4)
2 + q = k²               ⇒  k odd   ⇒  q ≡ 7 (mod 8)       ⇒  q ≡ 3 (mod 4)

row (path):    |A| − |B| ∈ {−1, 0, 1}
circle:        |A| = |B|
```

Counting the teams for every prime P up to 1.3·10⁷:

- At P = 238373, |A| − |B| = −51; at P = 409271, |A| − |B| = −66. Neither can have a row.
- For P ≥ 238373 (Vantieghem's bound), the teams are within one of each other only for P in [615721, 634187] and again from P = 12305677. So the smallest row, if any exists, has P in that window or P ≥ 12305677.
- For a circle, equal teams first occur again at P = 615869 inside that window, and next at P = 12305753. Inside the window the prime 582451 has at most one possible neighbour, even with every prime up to 634187 available, and a circle needs two at every dot. So there is no circle for P < 12305753.

## Verify it yourself

This script sieves the primes up to 1.3·10⁷, counts the two teams for every P, and checks the claims above, including the degree of 582451. It takes a few seconds.

```python
import numpy as np

N = 13_000_000
is_prime = np.ones(N + 1, dtype=bool)
is_prime[:2] = False
for i in range(2, int(N**0.5) + 1):
    if is_prime[i]:
        is_prime[i * i::i] = False
primes = np.flatnonzero(is_prime)

team = np.where((primes == 2) | (primes % 4 == 1), 1, -1)    # +1 for team A, -1 for team B
balance = np.cumsum(team)                                      # |A| - |B| using all primes up to P

def balance_at(P):
    return int(balance[primes == P][0])

assert balance_at(238373) == -51 and balance_at(409271) == -66  # the tried values cannot work

row_ok = primes[(np.abs(balance) <= 1) & (primes >= 238373)]
assert row_ok.min() == 615721 and row_ok[row_ok < 10**6].max() == 634187
assert row_ok[row_ok > 10**6].min() == 12305677

circle_ok = primes[(balance == 0) & (primes >= 454277)]          # 454277 = p(38031), Vantieghem's bound
assert circle_ok.min() == 615869 and circle_ok[circle_ok > 10**6].min() == 12305753

# in G[634187], the largest graph in the window, 582451 has at most one neighbour
P = 634187
small = primes[primes <= P]
degree = np.zeros(P + 1, dtype=np.int64)
for k in range(2, int((2 * P)**0.5) + 1):
    t = k * k
    a = small[small < t]
    b = t - a
    ok = (b <= P) & is_prime[b] & (b != a)
    np.add.at(degree, a[ok], 1)
assert degree[582451] <= 1                                      # so no circle anywhere in the window
print("row: P in [615721, 634187] or P >= 12305677; circle: P >= 12305753")
```
