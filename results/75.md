# Puzzle 75: Palindromic primes and the number 2000

> **In short:** Question 2 asks to redo four "prime and 2000" claims with palindromic primes. Three of them have no answer at all: a palindrome with 2000 digits is always divisible by 11. For the fourth, the smallest palindromic prime with digit sum 2000 has 223 digits and starts 9889…, found by checking the candidates in increasing order.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_075.htm)

**Status:** first answer (Q2) · probable prime (PRP)

## The question

Carlos Rivera listed six claims about primes and the number 2000. Four of them are:

1. the smallest prime with 2000 digits,
2. the largest prime with 2000 digits,
3. the smallest prime whose digits add up to 2000,
4. the smallest prime with 2000 digits whose digits add up to 2000.

Question 2 asks to redo these four using **palprimes**: primes that read the same forwards and backwards.

## What the page had vs ours

| Claim | On the page | Ours (palprimes) |
|---|---|---|
| 1, 2, 4 (2000 digits) | nothing for palprimes | **impossible**: every 2000-digit palindrome is a multiple of 11 |
| 3 (digit sum 2000) | nothing for palprimes | **10²²³ − 1 − (10²²¹ + 10²²⁰ + 10¹²⁴ + 10¹¹¹ + 10⁹⁸ + 10² + 10)**, 223 digits |

## How we found it

**Claims 1, 2 and 4.** A palindrome with an even number of digits is always divisible by 11, so the only even-length palprime is 11 itself. All three claims ask for 2000 digits, so they have no answer.

**Claim 3.** We first counted digits. 222 nines add up to only 1998, so we need at least 223 digits. With 223 digits, all nines add up to 2007, so the digits must fall 7 short of all-nines in total. That leaves very few shapes:

- The first digit is also the last digit, so it must be 1, 3, 7 or 9. A 1 or 3 costs too much (two copies of a small digit), which leaves 7 or 9.
- A 223-digit palindrome is a 111-digit half, a middle digit m, and the half mirrored. Each unit lost in the half is lost twice, so the middle digit takes the odd remainder: m = 2, 4, 6 or 8.

Starting with 7 gives only 111 candidates, and none of them is prime. Starting with 9, we listed all 234,136 candidates in increasing order and tested them one by one. The 208th is the first prime. Every candidate before it is composite, so it is the smallest.

## The math

Write the palindrome as half + m + reversed half, where the half has 111 digits and starts with 9:

```
digit sum = 2 · (sum of half) + m = 2000
sum of half = 999 − δ   (δ = how far the 110 inner digits fall short of all nines)
⇒  m = 2 + 2δ,   δ = 0, 1, 2, 3   (m = 2, 4, 6, 8)
```

A smaller number has its lost units further to the left, so sorting the candidate strings is the same as sorting the numbers. Our prime has δ = 3 and m = 8: the half is 988 9…9 8 9…9, and the middle digit is 8.

For a leading 7, the half already loses 2 at the front, so the middle digit is 6 (all other digits 9) or 8 (one more 8 in the half): 1 + 110 = 111 candidates.

## The numbers

```
N = 10^223 − 1 − (10^221 + 10^220 + 10^124 + 10^111 + 10^98 + 10^2 + 10)
  = 988(9)95 8(9)12 8(9)12 8(9)95 889   (223 digits, digit sum 2000)
rank 208 of 234,136 candidates starting with 9; all 111 candidates starting with 7 are composite
```

N has 223 digits, far above 2⁶⁴. It passes the BPSW test, which no composite number is known to pass, but it has not been formally proven prime: a probable prime (PRP).

## Verify it yourself

This script builds every 223-digit palindrome with digit sum 2000, in increasing order, and finds the first one that is prime. It takes a few seconds.

```python
from itertools import combinations_with_replacement
from sympy import isprime

def palindrome(half, middle):
    return int(half + middle + half[::-1])

# leading 7: the half is 7 followed by 110 digits; the middle digit absorbs the rest
lead7 = [("7" + "9" * 110, "6")]
for i in range(110):
    inner = ["9"] * 110
    inner[i] = "8"                                    # one more unit lost in the half
    lead7.append(("7" + "".join(inner), "8"))
assert not any(isprime(palindrome(h, m)) for h, m in lead7)   # none of the 111 is prime

# leading 9: lose delta units among the 110 inner digits, the middle digit is 2 + 2*delta
lead9 = []
for delta in range(4):
    for spots in combinations_with_replacement(range(110), delta):
        inner = [9] * 110
        for i in spots:
            inner[i] -= 1
        lead9.append("9" + "".join(map(str, inner)) + str(2 + 2 * delta))
lead9.sort()                                          # same order as the numbers themselves

for rank, key in enumerate(lead9, 1):
    N = palindrome(key[:111], key[111])
    if isprime(N):                                    # BPSW: probable prime above 2^64
        break

s = str(N)
assert len(s) == 223 and sum(map(int, s)) == 2000 and s == s[::-1]
assert N == 10**223 - 1 - (10**221 + 10**220 + 10**124 + 10**111 + 10**98 + 10**2 + 10)
assert 9 * 222 < 2000                                 # 222 digits can never reach digit sum 2000

# claims 1, 2 and 4: a palindrome with an even number of digits is a multiple of 11
assert all(palindrome(h, "")  % 11 == 0 for h in ["1" + "0" * 999, "9" * 1000, "1234567" * 142 + "123456"])

print("smallest palprime with digit sum 2000: rank", rank, "of", len(lead9))
print(s)
```
