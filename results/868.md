# Puzzle 868: Magic squares 3×3 and palprimes

> **In short:** We found five 3×3 magic squares of **101-digit** palindromic primes, against 31 digits on the page. All 45 entries are proven prime by two independent provers, PARI/GP and FLINT. The trick: make each digit position of the nine entries a small magic square of digits. Then no carries happen, every entry stays a palindrome, and the whole square is magic automatically.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_868.htm)

**Status:** beaten · proven primes

## The question

Send a 3×3 magic square of palindromic primes with more digits than the 31-digit square on the page (C. Rivera). The page has no contributions.

## How we found it

**Digitwise magic squares.** Every 3×3 magic square has the form c + αa + βb with α, β ∈ {−1, 0, 1}:

```
c − b       c + a + b   c − a
c − a + b   c           c + a − b
c + a       c − a − b   c + b
```

Take palindromes of L digits: an outer digit d₀ at both ends, m free "half-positions" in the middle (each mirrored), and zeros elsewhere. Suppose c, a and b are digit vectors such that every digit of every entry stays within 0..9. Then no carries happen, each entry is a palindrome, and the square is magic. This is Rivera's structure; his 31-digit square has L = 31 and m = 6.

**Search** (`results/code/p868_search.c`, C with GMP):

1. **Primes.** Sieve all 10^m middle patterns with the first 1000 odd primes ≠ 5, and test the survivors with GMP's probable-prime test. The primes go into a bitset S.
2. **Squares.** For every center c ∈ S, list the vectors a > 0 with c ± a ∈ S. The lowest digit is handled as one bit word, with a bit-reversed read for c − a. Then test the pairs (a, b) whose digit sums stay in range (|aⱼ| + |bⱼ| ≤ min(cⱼ, 9 − cⱼ)), and check c ± (a + b) and c ± (a − b) in S.

The program reproduces Rivera's 31-digit square (L = 31, m = 6, d₀ = 3).

**Runs.**

| L | m | d₀ | prime patterns | squares |
|---|---|---|---|---|
| 61 | 7 | 1, 3, 7, 9 | about 180,000 each | 0, 1, 1, 0 |
| 101 | 8 | 3 | 1,124,096 of 10⁸ | 2 |
| 101 | 8 | 7 | 1,141,401 of 10⁸ | 3 |

The 101-digit runs took about 20 minutes on 2 cores.

## The math

- **Why digitwise squares are enough.** If all nine digits in each position form a magic square of digits (all 0..9), the column sums add up position by position. Each entry is a palindrome because the m free positions are mirrored.
- **How many to expect.** A center digit cⱼ allows 2·min(cⱼ, 9 − cⱼ) + 1 values of aⱼ, which is 5 on average. So there are about 10^m · 25^m / 8 candidate squares. Each needs 9 primes, at density about 2.5/ln(10^L) each. For L = 101, m = 8 this gives a few squares per outer digit, which matches the runs.
- **Proofs.** All 45 entries are proven prime by PARI/GP's `isprime` (APR-CL) and, independently, by FLINT's `fmpz.is_prime`.

## Verify it yourself

`results/code/p868_verify.py` (4 s; needs `pip install cypari2 python-flint`) reads the five squares from the data file. It checks that each is magic (rows, columns, diagonals), has 9 different entries, all 101-digit palindromes, and that each entry is proven prime by both provers.

```python
import cypari2, flint
pari = cypari2.Pari()

blocks = open('results/data/868_squares.txt').read().split('\n\n')
squares = []
for b in blocks:
    nums = [int(x) for x in b.split() if x.isdigit()]
    if nums:
        squares.append([nums[0:3], nums[3:6], nums[6:9]])
assert len(squares) == 5

for sq in squares:
    flat = [x for r in sq for x in r]
    lines = sq + [list(c) for c in zip(*sq)] + [[sq[i][i] for i in range(3)], [sq[i][2 - i] for i in range(3)]]
    assert len({sum(l) for l in lines}) == 1
    assert len(set(flat)) == 9
    assert all(len(str(x)) == 101 and str(x) == str(x)[::-1] for x in flat)
    assert all(pari.isprime(x) for x in flat)
    assert all(flint.fmpz(x).is_prime() for x in flat)
print("all checks pass")
```
