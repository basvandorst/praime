# Puzzle 93: Decimal and hexadecimal reversals, and why 53 divides them

> **In short:** Some numbers have a hexadecimal form that is their decimal form reversed: 53 = 0x35, 371 = 0x173, 5141 = 0x1415, 99481 = 0x18499 and 8520280 = 0x0820258. All of them are multiples of 53. The reason is one line of algebra: 10 · 16 = 160 = 3 · 53 + 1, so 16 is the inverse of 10 modulo 53. The same identity explains every example on the page in other bases, including why 7721 (base 19) is a multiple of 7 but not of 21.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_093.htm)

**Status:** answered · Q2 proved, Q3 explained in general

## The question

Jim Howell noticed decimal/hexadecimal reversals and asked: (1) are there others, (2) is there a reason they are all divisible by 53, (3) does something similar happen in other bases? On the page, Q2 has only an informal remark ("a sum of powers in one base must equal the sum of powers in another base").

## The answer

Let N have the k decimal digits d_(k−1) … d_0, and suppose its base-c digits are the same digits reversed (a leading zero is allowed):

```
N = Σ d_i · 10^i = Σ d_i · c^(k−1−i)
```

Put m = 10c − 1. Then 10c ≡ 1 (mod m), so c ≡ 10⁻¹, and

```
N ≡ Σ d_i · 10^(−(k−1−i)) = 10^(−(k−1)) · N   (mod m)   ⟹   N · (10^(k−1) − 1) ≡ 0   (mod m).
```

So **N is a multiple of m / gcd(m, 10^(k−1) − 1)**. The same holds with any pair of bases b, c and m = bc − 1.

**Hexadecimal (Q2).** m = 159 = 3 · 53. The factor 3 gives nothing, because 10 ≡ 16 ≡ 1 (mod 3). Modulo 53, the order of 10 is 13, so 53 | N unless 13 | k − 1. All reversals have at most 7 digits, so k − 1 ≤ 6, and 53 divides every one of them. A check of all N < 10⁸ finds exactly the five reversals above.

**Other bases (Q3).** The table lists the forced divisor m / gcd(m, 10^(k−1) − 1) for each example on the page:

| base c | m = 10c − 1 | examples | forced divisor |
|---|---|---|---|
| 4 | 39 = 3·13 | 13 | 13 |
| 7 | 69 = 3·23 | 23, 46, 2116, 15226 | 23 |
| 8 | 79 | 1527465 | 79 |
| 9 | 89 | 445, 313725 | 89 |
| 12 | 119 = 7·17 | 315231 | 119 |
| 13 | 129 = 3·43 | 43, 86, 774 | 43 |
| 14 | 139 | 834 | 139 |
| 19 | 189 = 3³·7 | 21, 42, 63, 84 (k = 2), 441, 882 (k = 3) | 21 |
| 19 | 189 | 1540, 3290, 7721, 9471 (k = 4) | 7 |

The last two rows explain the page's remark "7721 = 7·1103 — not a multiple of 21". For k = 4, gcd(189, 999) = 27, so only the factor 7 is forced. For k = 2 and 3, the gcd is 9 and 21 is forced. (The page prints 774 = 2·3²·32; it is 2·3²·43.)

## Verify it yourself

`results/code/p93_verify.py` checks that every example on the page is a reversal and is divisible by its forced divisor. It also lists all decimal/hex reversals below 10⁸ and checks that each is a multiple of 53.

```python
from math import gcd
def digits(n, b):
    d = []
    while n: d.append(n % b); n //= b
    return d[::-1]
def reversal(N, b, c):
    s = digits(N, b)[::-1]
    return max(s) < c and sum(x * c**(len(s) - 1 - i) for i, x in enumerate(s)) == N
def forced(N, b, c):
    m = b * c - 1; k = len(digits(N, b)); return m // gcd(m, b**(k - 1) - 1)
for c, Ns in {16: [53, 371, 5141, 99481, 8520280], 4: [13], 7: [23, 46, 2116, 15226], 8: [1527465],
              9: [445, 313725], 12: [315231], 13: [43, 86, 774], 14: [834],
              19: [21, 42, 63, 84, 441, 882, 1540, 3290, 7721, 9471]}.items():
    for N in Ns:
        assert reversal(N, 10, c) and N % forced(N, 10, c) == 0
print("all examples verified")
```
