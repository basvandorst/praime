# Puzzle 489: Mersenne primes & 0, 23 & 1535

> **In short:** We found every solution of the form q + 1 = 2^a·3^b and proved the list is complete. Besides the Mersenne primes, only 0, 23 and 1535 qualify. Firoozbakht's family q = 3·2^(2p−1) − 1 stops at p = 5, which settles her open remark "next such p, if it exists, is greater than 1278". A C search shows that every solution with q + 1 ≤ 10⁹ is already on the page.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_489.htm)

**Status:** partial answer · proof (all solutions with q + 1 = 2^a·3^b) · exhaustive search to 10⁹

## The question

If q is a Mersenne prime, then σ(σ(φ(q + 1))) = q + 1. Besides the Mersenne primes, three other numbers do the same: 0, 23 and 1535. Are there others?

What the page says:

- Antoine Verroken searched q + 1 ≤ 10⁶ and found 1, 4, 8, 24, 32, 128, 1536, 8192, 131072, 524288. He noticed that every one has the form 2^a·3^b.
- Farideh Firoozbakht gave a family: if 2^p − 1 is prime and σ(2^p + 1) = 3·2^(p−1), then q = 3·2^(2p−1) − 1 works. p = 2 gives 23 and p = 5 gives 1535. She writes: "Next such p, if it exists is greater than 1278."

## Record vs ours

| | Result |
|---|---|
| Page (Verroken; Firoozbakht) | no other q with q + 1 ≤ 10⁶; family open beyond p = 1278 |
| **Ours** | **theorem:** every solution with q + 1 = 2^a·3^b is a Mersenne prime, 0, 23 or 1535. **Family:** only p = 2 and p = 5, for all p. **Search:** no other solution with q + 1 ≤ 10⁹. |

So any new solution must exceed 10⁹ and must have a prime factor of q + 1 that is at least 5. The general question ("are there others at all?") remains open.

## How we found it

Write n = q + 1. Verroken's pattern n = 2^a·3^b suggested computing σ(φ(n)) in closed form for those n, which turned out to be easy. The rest is three small arguments: a size inequality, a 2-adic congruence, and Zsigmondy's theorem on primitive prime divisors of 2^m − 1 (FACTS fact 1509), the same tool kit as Puzzle 490. Then a C search (`results/code/p489_search.c`) checked every n ≤ 10⁹ with a 16-bit smallest-prime-factor table. It took 3 minutes and 1 GB of memory.

## The math

Let n = 2^a·3^b and f(n) = σ(σ(φ(n))). We need f(n) = n.

**Lemma 1 (one 3 at most).** Let N be odd with σ(N) = 2^x or 3·2^x. Then N is squarefree, and every prime r | N has r + 1 = 2^y or r + 1 = 3·2^y. The second kind occurs for at most one r, and only when σ(N) = 3·2^x.

*Proof.* Take r^e ‖ N with e ≥ 2. If e is even, σ(r^e) is odd and at least 13, so it is neither a power of 2 nor 3 times one. If e is odd, σ(r^e) = (1 + r)(1 + r² + … + r^(e−1)). When (e + 1)/2 is odd, the second factor is odd and at least 91. When (e + 1)/2 is even, σ(r^e) has the factor 1 + r² ≡ 2 (mod 4), whose odd part (1 + r²)/2 ≥ 5 is prime to 3 (r² ≢ 2 mod 3). Either way an odd factor other than 3 appears. So e = 1, and then σ(r) = r + 1 must be 2^y or 3·2^y. ∎

**Case b = 0, n = 2^a.** σ(φ(n)) = σ(2^(a−1)) = 2^a − 1 =: M, and we need σ(M) = 2^a. By Lemma 1, M is a product of k distinct Mersenne primes 2^(p_i) − 1, with p₁ < p₂ < …. Suppose k ≥ 2. Products of two terms 2^(p_i) are divisible by 2^(p₁+1), so mod 2^(p₁+1) the product is (−1)^k + (−1)^(k−1)·2^(p₁). That is not ≡ −1 for either parity of k (p₁ ≥ 2). But M = 2^a − 1 with a > p₁ + 1, so M ≡ −1. Contradiction, so k = 1 and **2^a − 1 is prime**. These are the Mersenne primes; a = 0 gives n = 1 (q = 0).

**Case a = 0, b ≥ 1, n = 3^b.** f(3) = 4. For b ≥ 2, σ(φ(n)) = σ(2·3^(b−1)) = 3(3^b − 1)/2 > 3^b, so σ of it is larger than n. **No solutions.**

**Case a ≥ 1, b ≥ 2.** Here φ(n) = 2^a·3^(b−1), so

```
M = σ(φ(n)) = A·B,   A = 2^(a+1) − 1 ≥ 3,   B = (3^b − 1)/2 ≥ 4.
n − M = B + (A + 1)/2.
```

A = B would mean 2^(a+2) = 3^b + 1, which forces b ≤ 1 (3^b + 1 ≡ 2 or 4 mod 8). So 1, A and B are three distinct proper divisors of M, and σ(M) − M ≥ 1 + A + B > B + (A + 1)/2 = n − M. Hence σ(M) > n. **No solutions.**

**Case a ≥ 1, b = 1, n = 3·2^a.** φ(n) = 2^a, so M = 2^m − 1 with m = a + 1, and we need

```
σ(2^m − 1) = 3·2^(m−1).          (*)
```

**Lemma 2.** (*) holds only for m = 4 and m = 10, that is n = 24 and n = 1536.

*Proof.* By Lemma 1, 2^m − 1 is squarefree. All but exactly one of its prime factors are Mersenne primes 2^y − 1. The remaining factor r* has r* + 1 = 3·2^y. A Mersenne prime 2^y − 1 has multiplicative order y (a prime) for 2.

- m = 1 and m = 6 fail: σ(1) = 1 and σ(63) = 104.
- m prime: every prime factor of 2^m − 1 has order m. A Mersenne factor would be 2^m − 1 itself, giving σ = 2^m. Otherwise 2^m − 1 = r* = 3·2^y − 1, which is impossible.
- m composite, m ≠ 6: by Zsigmondy/Bang (fact 1509), for every d > 1, d ≠ 6, 2^d − 1 has a prime of order exactly d. For d = m (composite) that prime cannot be Mersenne, so it is r*. For a proper divisor d > 1 of m with d ≠ 6, the order-d prime is not r*, so it is a Mersenne prime of order d, which makes d prime. If m = 6k with k ≥ 2, then 2k is a composite proper divisor of m other than 6 (for k = 3 take 9 instead). So every proper divisor > 1 of m is prime, and m = p² or m = pq (p < q). For each prime p | m, the order-p prime is Mersenne, so 2^p − 1 is prime. Matching primes by order gives 2^m − 1 = (2^p − 1)(2^q − 1)·r* or (2^p − 1)·r*.
  - m = pq: (*) gives r* = 3·2^e − 1 with e = pq − p − q − 1. If (p − 1)(q − 2) ≥ 4, then e ≥ p + 1 and q ≥ p + 1. Mod 2^(p+1) the product is (2^p − 1)(−1)(−1) = 2^p − 1 ≢ −1. Contradiction. The pairs left over are (2, 3), which is m = 6 and fails, and (2, 5), which is **m = 10**.
  - m = p²: r* = 3·2^(p²−p−1) − 1. For p ≥ 3 the exponent is at least p + 1, and mod 2^(p+1) the product is 1 − 2^p ≢ −1. That leaves p = 2: **m = 4**. ∎

**Theorem.** If n = 2^a·3^b and σ(σ(φ(n))) = n, then n = 1, 24, 1536, or n = 2^p with 2^p − 1 prime. In terms of q: q = 0, 23, 1535, or a Mersenne prime.

**Corollary (Firoozbakht's family).** Her condition, 2^p − 1 prime and σ(2^p + 1) = 3·2^(p−1), gives σ(2^(2p) − 1) = 3·2^(2p−1). That is (*) with m = 2p, so p = 2 or p = 5. **No further p exists**, not just none below 1279.

## The search

`results/code/p489_search.c` computes f(n) for every n ≤ 10⁹. It factors n, φ(n) and σ(φ(n)) with a table of smallest prime factors of odd numbers, and skips n with σ(φ(n)) ≥ n, since σ(M) > M. Output:

```
1 4 8 24 32 128 1536 8192 131072 524288
```

This is Verroken's list, and nothing else up to 10⁹; the next known solution is n = 2³¹. So every solution with q + 1 ≤ 10⁹ has the form 2^a·3^b, and by the theorem the list is complete there.

What remains open: a solution with q + 1 > 10⁹ that has a prime factor ≥ 5. Neither the search nor the theorem rules one out.

## Verify it yourself

`results/code/p489_verify.py` is independent of the C code: plain sympy. It runs in about a minute.

```python
from sympy import divisor_sigma as s, totient as phi, isprime

f = lambda n: s(s(phi(n)))

# 1. Direct search for n = q + 1 <= 2*10^5 reproduces the page's list.
sols = [n for n in range(1, 200001) if f(n) == n]
assert sols == [1, 4, 8, 24, 32, 128, 1536, 8192, 131072], sols

# 2. Theorem on n = 2^a 3^b, checked for a <= 64, b <= 30.
for a in range(0, 65):
    for b in range(0, 31):
        n = 2**a * 3**b
        expected = n in (1, 24, 1536) or (b == 0 and a >= 2 and isprime(2**a - 1))
        assert (f(n) == n) == expected, (a, b)

# 3. Lemma 2: sigma(2^m - 1) = 3 * 2^(m-1) only for m = 4, 10 (m <= 100).
assert [m for m in range(1, 101) if s(2**m - 1) == 3 * 2**(m - 1)] == [4, 10]

# 4. The inequality for a >= 1, b >= 2.
for a in range(1, 40):
    for b in range(2, 25):
        A, B, n = 2**(a+1) - 1, (3**b - 1)//2, 2**a * 3**b
        assert A != B and n - A*B == B + (A + 1)//2 and s(A*B) - A*B >= 1 + A + B

# 5. Firoozbakht's family among Mersenne exponents p <= 127: only p = 2, 5.
mers = [p for p in range(2, 128) if isprime(p) and isprime(2**p - 1)]
assert [p for p in mers if s(2**p + 1) == 3 * 2**(p - 1)] == [2, 5]
print("all checks pass")
```
