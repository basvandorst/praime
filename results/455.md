# Puzzle 455: 1 + σ₀(n)·σ(n) = n·rad(n)

> **In short:** Pebody refuted the twin-prime claim on the page with the family n = p^(p−2), and said these are the only prime-power solutions. We take the next step. **No solution has exactly two prime factors** (proof). A C search shows the family is the only kind of solution up to **10¹⁰**, against 6.3·10⁸ on the page. The key step is a factorisation: with two prime factors the equation becomes (DX − A)(DY − A) = B², which bounds everything.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_455.htm)

**Status:** partial answer · proof for one and two prime factors · exhaustive search to 10¹⁰

## The question

Juan López: prove or refute that if n > 3 and 1 + σ₀(n)·σ(n) = n·rad(n), then n = q^p with p and q = p + 2 twin primes. (σ₀ = τ is the number of divisors; rad(n) is the product of the distinct primes dividing n.)

On the page:

- Antoine Verroken checked the identity for n = q^p with q = p + 2.
- Luke Pebody: "There is no need for q to be prime. For p a prime ≥ 3, p^(p−2) is a solution. In particular, 11⁹ is a solution. It is easy to see that these are the only prime power solutions... The only other numbers n below 630,000,000 for which n is a factor of 1 + σ₀(n)σ(n) are 77 and 128807153."

So the claim is refuted. The natural open question is whether the prime powers p^(p−2) are all the solutions.

## Record vs ours

| | Result |
|---|---|
| Page | p^(p−2) solves it; only prime powers below 6.3·10⁸ (Pebody) |
| **Ours** | **proof:** prime powers give exactly p^(p−2), and no n with two prime factors works. **Search:** no other solution up to 10¹⁰ |

## The math

Write n = ∏ pᵢ^(aᵢ), Xᵢ = pᵢ^(aᵢ+1), A = τ(n) = ∏(aᵢ + 1) and B = ∏(pᵢ − 1). Then σ(n) = ∏(Xᵢ − 1)/B and n·rad(n) = ∏ Xᵢ, so the equation is

```
B + A·∏(Xᵢ − 1) = B·∏ Xᵢ.
```

**One prime factor.** (p − 1) + (a + 1)(X − 1) = (p − 1)X gives (a + 1)(X − 1) = (p − 1)(X − 1), so a = p − 2. The solutions are **n = p^(p−2)** for odd primes p (p = 2 gives n = 1): 3, 5³, 7⁵, 11⁹, 13¹¹, …. López's q^p with q = p + 2 is the special case where p − 2 is also prime.

**Two prime factors: no solutions.** Let n = p^a·q^b, X = p^(a+1), Y = q^(b+1), A = (a+1)(b+1), B = (p−1)(q−1). The equation becomes

```
D·XY − A(X + Y) + (A + B) = 0,      D = A − B.
```

1. **D ≥ 1.** If D ≤ 0, then D·XY ≤ D and the left side is at most D − A(X + Y) + A + B = A(2 − X − Y) < 0.
2. **So (p − 1)(q − 1) = B < A**, hence p, q ≤ A.
3. **Take X ≤ Y.** Then D·XY = A(X + Y) − (A + B) < 2AY, so X < 2A/D ≤ 2A.
4. **The factorisation.** Multiply by D and add A²:

   ```
   (DX − A)(DY − A) = A² − D(A + B) = A² − (A − B)(A + B) = B².
   ```

   If both factors are positive, then DY − A ≤ B² < A², so Y < A + A². If both are negative, then Y < A/D ≤ A.
5. **Bounds on a and b.** X ≥ 2^(a+1) and Y ≥ 2^(b+1), so 2^(a+1) < 2(a+1)(b+1) and 2^(b+1) ≤ A² + A. Only 42 pairs (a, b) satisfy both. For each, every pair of primes p ≠ q with (p − 1)(q − 1) < A was tested exactly. **None works.** ∎

**Three or more prime factors.** The same algebra gives A/B ∈ (1, ∏ Xᵢ/(Xᵢ − 1)). So ∏(aᵢ + 1) is only slightly larger than ∏(pᵢ − 1), but this no longer bounds the exponents, and the question stays open. Mod each pᵢ the equation says τ(n)σ(n) ≡ −1, so τ(n) is prime to every pᵢ.

## The search

`results/code/p455_search.c` factors every n ≤ 10¹⁰ with a segmented sieve and compares 1 + τσ with n·rad(n) in 128-bit arithmetic. It also reports every n that merely divides 1 + τσ. It took 34 s up to 10⁹ and 3.6 minutes for 10⁹ … 10¹⁰ on 2 cores.

```
solutions:           3, 125 = 5³, 16807 = 7⁵, 2357947691 = 11⁹
n | 1 + τ(n)σ(n):    77, 128807153 (Pebody's two, below 10⁹); none in 10⁹ … 10¹⁰
```

So every solution up to 10¹⁰ is a prime power p^(p−2). The next one is 13¹¹ ≈ 1.8·10¹².

## How we found it

With two prime factors the equation is bilinear in X and Y. That suggests the classic trick for D·XY − A(X + Y) = const: multiply by D and complete the product. The right side came out as exactly B², which bounds everything once D ≥ 1 is known.

## Verify it yourself

`results/code/p455_verify.py` (8 s) checks:

- the prime-power case (p < 200, a ≤ 300);
- the 42 cases of the two-prime proof, plus a brute-force box p, q < 80, a, b ≤ 13;
- a direct sympy search for n ≤ 2·10⁵;
- the solutions and near-misses reported by the C search.

```python
import math
from sympy import primerange, divisor_count, divisor_sigma, primefactors, factorint

def holds(fac):
    """1 + tau(n) sigma(n) == n rad(n) for n = prod p^a."""
    n = r = A = S = 1
    for p, a in fac:
        n *= p**a; r *= p; A *= a + 1; S *= (p**(a + 1) - 1) // (p - 1)
    return 1 + A * S == n * r

# 1. Prime powers: p^a works iff a = p - 2.
assert all(holds([(p, a)]) == (a == p - 2) for p in primerange(3, 200) for a in range(1, 301))

# 2. Two prime factors: the finitely many cases left by the proof.
for a in range(1, 80):
    for b in range(1, 80):
        A = (a + 1) * (b + 1)
        if not (2**(a + 1) < 2 * A and 2**(b + 1) <= A * A + A):
            continue
        ps = list(primerange(2, A + 1))
        for p in ps:
            for q in ps:
                if q != p and (p - 1) * (q - 1) < A:
                    assert not holds([(p, a), (q, b)])

# 3. Brute-force box.
assert not any(holds([(p, a), (q, b)]) for p in primerange(2, 80) for q in primerange(2, 80) if p < q
               for a in range(1, 14) for b in range(1, 14))

# 4. Direct sympy search, and the C search's numbers.
direct = [n for n in range(2, 200001) if 1 + divisor_count(n) * divisor_sigma(n) == n * math.prod(primefactors(n))]
assert direct == [3, 125, 16807]
for n in (3, 125, 16807, 2357947691):
    (p, a), = factorint(n).items()
    assert a == p - 2 and holds([(p, a)])
print("all checks pass")
```
