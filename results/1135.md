# Puzzle 1135: Consecutive primes whose digits do not alternate odd/even

> **In short:** The same quartic we used for [puzzle 1230](1230.md) gives 30 primes in a row, and none of them has digits that alternate between odd and even. The longest such run on the page was 23. The reason is simple: every value ends in two odd digits.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1135.htm)

**Status:** beaten · proven primes

## The question

The digits of a number "alternate parity" when odd and even digits take turns all the way through, as in 3412 or 5276. Davide Rotondo noticed that n⁴ + 29n² + 101 gives 19 primes in a row (n = 1 … 19) whose digits do **not** alternate parity. The puzzle asks for polynomials giving more consecutive primes with this property.

## Current record vs ours

| | Polynomial | Consecutive primes, digits not alternating |
|---|---|---|
| On the page (D. Rotondo) | n⁴ + 29n² + 101, n = 1 … 19 | 19 |
| On the page (Kazmenko–Trofimov cubic) | \|−66n³ + 3845n² − 60897n + 251831\|, n = 23 … 45 | 23 (the run is broken at n = 22) |
| **Ours** | 5n⁴ − 330n³ + 9395n² − 130510n + 709337, n = 0 … 29 | **30** |

## How we found it

Checking digits one by one is fragile: a single alternating number breaks the run. So we looked for a reason that rules out alternation for **every** value at once. If the last two digits are both odd, the digits can never alternate. A number leaves remainder 17 when divided by 20 exactly when its last two digits are odd-ten plus 7 (…17, …37, …57, …77, …97).

Our quartic from puzzle 1230 has every value ≡ 17 (mod 40), so in particular ≡ 17 (mod 20). All its 30 consecutive primes therefore end in "odd digit, 7", and the property holds automatically.

## The math

```
P(n) = 5n⁴ − 330n³ + 9395n² − 130510n + 709337 = 40·Q(n) + 17,   Q(n) a whole number
⇒ P(n) ≡ 17 (mod 20)
⇒ last two digits are 17, 37, 57, 77 or 97: two odd digits side by side
⇒ the digits of P(n) never alternate parity
```

For the Kazmenko–Trofimov cubic the run of non-alternating primes stops at n = 22, where the value 70309 alternates (7 odd, 0 even, 3 odd, 0 even, 9 odd).

## Verify it yourself

This script checks that all 30 values are distinct primes whose digits do not alternate parity, and shows the break in the Kazmenko–Trofimov run at n = 22.

```python
from sympy import isprime

def alternates(n):
    # True if odd and even digits take turns all the way through
    s = str(abs(n))
    return all((int(a) + int(b)) % 2 == 1 for a, b in zip(s, s[1:]))

P = lambda n: 5*n**4 - 330*n**3 + 9395*n**2 - 130510*n + 709337
vals = [P(n) for n in range(30)]

assert all(isprime(v) for v in vals) and len(set(vals)) == 30   # 30 different primes
assert all(v % 20 == 17 for v in vals)                          # last two digits: odd, then 7
assert not any(alternates(v) for v in vals)                     # so none alternates
assert not isprime(P(-1)) and not isprime(P(30))                # the run is exactly 30

KT = lambda n: -66*n**3 + 3845*n**2 - 60897*n + 251831
assert KT(22) == 70309 and isprime(KT(22)) and alternates(KT(22))   # breaks their run at n = 22

print("30 consecutive primes, none with alternating digit parity")
```
