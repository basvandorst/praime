# Puzzle 458: Prime factors of σ(n) inside n inside φ(n)

> **In short:** Find n where the prime factors of σ(n) are a strict part of those of n, which are a strict part of those of φ(n). We started from Luke Pebody's number from puzzle 451, where all three sets are equal, and multiplied by 47³. That adds 47 to n, adds 23 (from 47 − 1) to φ(n), and leaves σ(n)'s primes unchanged.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_458.htm)

**Status:** first answer · exact (no primality question)

## The question

For a number x, let P(x) be its set of prime factors. σ(n) is the sum of the divisors of n and φ(n) is Euler's totient. Farideh Firoozbakht asks for an n with

```
P(σ(n)) ⊊ P(n) ⊊ P(φ(n))
```

where ⊊ means "is a subset, but not the whole set".

## How we found it

Puzzle 451 asked for n where n, σ(n) and φ(n) have the **same** prime factors, and Luke Pebody found

```
n₀ = 6534150553412193640795377701190 = 2·3·5·7·11·13³·17²·29²·31³·37²·67²·307³
```

with P(σ(n₀)) = P(n₀) = P(φ(n₀)) = S. That is the perfect starting point: we only need to tip each inclusion by one prime. Multiply n₀ by a new prime power r^e (r not in S). Then

- **n** gains the prime r,
- **φ(n)** gains the prime factors of r − 1 (and r itself if e ≥ 2),
- **σ(n)** gains the prime factors of σ(r^e) = 1 + r + … + r^e.

So we want σ(r^e) to use only primes from S (σ keeps its old primes), and r − 1 to bring in a prime outside S ∪ {r} (φ gets something extra). We tried primes r and exponents e, and r = 47, e = 3 is the first that works.

## The math

```
σ(47³) = 1 + 47 + 47² + 47³ = 106080 = 2⁵ · 3 · 5 · 13 · 17     only primes from S
47 − 1 = 46 = 2 · 23                                            23 is new
φ(47³) = 47² · 46                                               brings 47 and 23
```

With n = n₀·47³:

```
P(σ(n)) = S                       = {2, 3, 5, 7, 11, 13, 17, 29, 31, 37, 67, 307}
P(n)    = S ∪ {47}
P(φ(n)) = S ∪ {23, 47}
```

## The numbers

```
n = 6534150553412193640795377701190 · 47³ = 678395112906914180368298499070649370
  = 2 · 3 · 5 · 7 · 11 · 13³ · 17² · 29² · 31³ · 37² · 47³ · 67² · 307³
```

## Verify it yourself

This script checks Pebody's starting point (all three prime sets equal), then checks the two strict inclusions for n = n₀·47³.

```python
from sympy import primefactors, totient, divisor_sigma

def P(x):
    return set(primefactors(int(x)))

n0 = 6534150553412193640795377701190                   # L. Pebody, puzzle 451
S = P(n0)
assert P(divisor_sigma(n0)) == S == P(totient(n0))     # all three sets are equal

assert P(divisor_sigma(47**3)) <= S                    # sigma(47^3) = 106080 adds no new prime
assert P(46) - S == {23}                               # 47 - 1 = 2 * 23 adds 23 to phi

n = n0 * 47**3
assert n == 678395112906914180368298499070649370
assert P(divisor_sigma(n)) < P(n) < P(totient(n))      # both inclusions strict
print("P(sigma(n)) =", sorted(P(divisor_sigma(n))))
print("P(n)        =", sorted(P(n)))
print("P(phi(n))   =", sorted(P(totient(n))))
```
