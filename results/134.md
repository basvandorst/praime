# Puzzle 134: Carrousel primes

> **In short:** We built a 201-digit prime that stays prime while its single "active" last digit runs through 1, 3, 7 and 9, four times longer than the 50-digit example on the page. We also give the first 100-digit carrousel prime with exactly one "inactive" digit.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_134.htm)

**Status:** beaten (Q3) · first answer (Q4) · PRP (probable primes)

## The question

Apply one "carrousel" step to a number: every digit 1 becomes 3, every 3 becomes 7, every 7 becomes 9, every 9 becomes 1, and the other digits (0, 2, 4, 5, 6, 8, the "inactive" ones) stay the same. A carrousel prime stays prime for three steps in a row, so it gives four primes.

Example: 19 → 31 → 73 → 97.

- **Q3** asks for a very large carrousel prime with only **one** active digit. The page accepts 100, 200, … digit answers as a start.
- **Q4** asks for a 100-digit carrousel prime with only **one** inactive digit.

## Current record vs ours

| | Number | Result |
|---|---|---|
| Current record, Q3 (M. Bell, 2001) | 46060600066600606006·10³⁰ + 1, 3, 7, 9 | 50 digits |
| **Ours, Q3** | 10·B + 1, 3, 7, 9 with B made only of inactive digits | **201 digits** |
| Page, Q4 | no answer | none |
| **Ours, Q4** | a 100-digit prime with a single 0 (below) | **first answer** |

## How we found it

With only one active digit, it is best to make it the **last** digit. Then the carrousel just turns the last digit 1 → 3 → 7 → 9, and the four primes are 10B + 1, 10B + 3, 10B + 7, 10B + 9: a whole decade of primes, with B built only from the digits 0, 2, 4, 5, 6, 8.

A random 201-digit decade almost never holds four primes, so blind trying is hopeless (Bell called a titanic answer "close to impossible"). Instead we sieved: we only kept bases B where none of the four numbers is divisible by any small prime, which the Chinese remainder theorem lets us arrange half by half. Only the few survivors needed a real primality test.

For Q4 the logic is reversed: almost all digits are active, so all four images change everywhere. We kept a single 0 and searched 100-digit numbers made of 1, 3, 7, 9 whose four images all pass the prime test.

## The math

Write the step as a digit map σ with σ(1) = 3, σ(3) = 7, σ(7) = 9, σ(9) = 1 and σ(d) = d for inactive d. For N = 10·B + d with B inactive and d ∈ {1, 3, 7, 9}:

```
σ(N) = 10·B + σ(d)      so the four images are   10B + 1, 10B + 3, 10B + 7, 10B + 9
```

The sieve condition, for each small prime q (we used all q < 8192):

```
10·B + e  ≢  0  (mod q)     for e = 1, 3, 7, 9
```

Each q forbids at most four residues of B, so the surviving fraction of bases is about ∏(1 − 4/q), and the four-prime chance per survivor is far higher than for a random decade.

## Verify it yourself

This script applies the carrousel step three times to each answer and checks that all four numbers are probable primes, with the required count of active or inactive digits.

```python
import gmpy2

# the carrousel step: 1->3, 3->7, 7->9, 9->1, other digits stay
STEP = str.maketrans("1379", "3791")

def four_images(n):
    # n and its three carrousel images
    s = str(n)
    out = [s]
    for _ in range(3):
        s = s.translate(STEP)
        out.append(s)
    return [int(x) for x in out]

# Q3: base made only of inactive digits, one active last digit
B = int("28266822285522252262205200548226688846285220488406648065224005542545688222462886502204488505285626565285254522005586452866085484025260620884668502226056465885558042646664604085455288052024585686255804")
assert set(str(B)) <= set("024568")                 # B uses only inactive digits
q3 = four_images(10 * B + 1)
assert q3 == [10 * B + e for e in (1, 3, 7, 9)]     # the four images are a full decade
assert all(gmpy2.is_prime(x, 25) for x in q3)       # all four are probable primes
assert len(str(q3[0])) == 201                       # 201 digits

# Q4: 100 digits, exactly one inactive digit
p = 9773317917193993331131917339173977131919931391113371131103919313311737119331717179393197317197911119
s = str(p)
assert len(s) == 100
assert sum(c not in "1379" for c in s) == 1         # exactly one inactive digit
assert all(gmpy2.is_prime(x, 25) for x in four_images(p))   # all four images are probable primes

print("Q3: 201-digit carrousel prime decade; Q4: 100-digit carrousel prime with one inactive digit")
```
