# Puzzle 179: An alphametic where every number is prime

> **In short:** In French, TROIS + ONZE = SEPT + SEPT is true as words (3 + 11 = 7 + 7). Replacing letters by digits gives 12689 + 6053 = 9371 + 9371, which is also true, and all three numbers are prime. A second one: CINQ + CINQ + ONZE = SEPT + SEPT + SEPT becomes 2879 + 2879 + 6701 = 4153 · 3.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_179.htm)

**Status:** first answer (Q1) · proven primes

## The question

An **alphametic** is a sum written in words where each letter stands for a digit (different letters, different digits, no leading zeros), and the digits make the sum correct as well. J.-C. Meyrignac studied sums of prime names on both sides, like the Spanish dos + dos + tres = siete (581 + 581 + 9231 = 10393). Question 1 asks for such alphametics where **the numbers are prime too**, not just the words.

## How we found it

The words must balance first: the prime names on the left must add up to the same number as those on the right. For each language we listed every such balanced combination of a few prime names, using at most ten different letters.

Each alphametic is then a single linear equation in the letters: each letter gets a weight (its place values, plus on the left and minus on the right), and the weighted sum must be zero. With at most ten letters there are at most 3.6 million digit assignments, so numpy checks them all at once. Among the solutions we kept the ones where every word's number is prime.

## The math

```
TROIS + ONZE = SEPT + SEPT        3 + 11 = 7 + 7 = 14
letters T R O I S N Z E P (9)     T=1 R=2 O=6 I=8 S=9 N=0 Z=5 E=3 P=7
12689 + 6053 = 18742 = 9371 + 9371
```

This alphametic has 6 digit solutions in total, and the one above is the solution where all numbers are prime.

## Verify it yourself

This script solves each alphametic completely: it tries every assignment of different digits to the letters, keeps those that make the sum correct, and shows which of them use only primes.

```python
from itertools import permutations
import numpy as np
from sympy import isprime

def solve(left, right):
    words = left + right
    letters = sorted(set("".join(words)))
    weight = np.zeros(len(letters), dtype=np.int64)        # place values, + on the left, - on the right
    for side, sign in ((left, 1), (right, -1)):
        for w in side:
            for power, ch in enumerate(reversed(w)):
                weight[letters.index(ch)] += sign * 10**power
    digits = np.array(list(permutations(range(10), len(letters))), dtype=np.int64)
    ok = digits @ weight == 0                              # the sum is correct
    for w in set(words):
        ok &= digits[:, letters.index(w[0])] != 0          # no leading zeros
    solutions = []
    for row in digits[ok]:
        value = {w: int("".join(str(row[letters.index(c)]) for c in w)) for w in set(words)}
        solutions.append(value)
    return solutions

for left, right in [(["TROIS", "ONZE"], ["SEPT", "SEPT"]),
                    (["CINQ", "CINQ", "ONZE"], ["SEPT", "SEPT", "SEPT"])]:
    solutions = solve(left, right)
    prime_ones = [v for v in solutions if all(isprime(x) for x in v.values())]
    print(" + ".join(left), "=", " + ".join(right), ":", len(solutions), "solutions, all-prime:", prime_ones)

assert {"TROIS": 12689, "ONZE": 6053, "SEPT": 9371} in [v for v in solve(["TROIS", "ONZE"], ["SEPT", "SEPT"])]
assert 12689 + 6053 == 2 * 9371 and 2 * 2879 + 6701 == 3 * 4153
assert all(isprime(x) for x in (12689, 6053, 9371, 2879, 6701, 4153))
```
