# Puzzle 438: A larger prime that no inserted digit keeps prime

> **In short:** Puzzle 438 asks the same question as [puzzle 398](398.md): find a large prime where inserting any digit inside it never gives another prime. Our 1057-digit proven prime from puzzle 398 also answers this one, beating the 200-digit example listed here.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_438.htm)

**Status:** beaten · proven prime (Pocklington)

## The question

The Prime Curios site notes that you cannot insert a digit into 1024383257 to form another prime ("insert" means between two existing digits, not at the front or the end). The puzzle asks: can you find a larger prime like this? Rivera himself notes on the page that this repeats puzzle 398.

## Current record vs ours

| | Prime | Digits |
|---|---|---|
| Current record (W. E. Clark) | 99844622…94 1 (listed on the page) | 200 |
| **Ours** | N = A·10⁹⁰⁰ + 1, the prime from [puzzle 398](398.md) | **1057** |

## How we found it

See [puzzle 398](398.md). In short: the shape A·10⁹⁰⁰ + 1 turns every insertion into the zero run into the simple expression A·10⁹⁰¹ + c·10ᵏ + 1. Choosing A with the Chinese remainder theorem makes 31 small primes divide most of these insertions at once. The remaining ones were tested, and the shape lets N − 1 = A·10⁹⁰⁰ be factored completely enough for a Pocklington primality proof.

## The math

The construction, the covering condition and the Pocklington proof are written out in [puzzle 398](398.md). Nothing changes here except the record we compare against.

## Verify it yourself

This is the same check as in puzzle 398: it proves N prime and confirms that all 10,560 interior insertions are composite. It takes about a minute.

```python
import gmpy2
from gmpy2 import mpz, powmod, gcd
from sympy import primerange

A = mpz(1057447767801982899810936078986870322855097083184870799512294142679453394807877910422539690997221686644824565309308629748242833059104863529225434120688108130)
N = A * mpz(10) ** 900 + 1
s = gmpy2.digits(N)
assert len(s) == 1057 > 200                                  # larger than the 200-digit record

# Pocklington with F = 10^900 (F^2 > N) and base 3
F = mpz(10) ** 900
assert (N - 1) % F == 0 and F * F > N and powmod(3, N - 1, N) == 1
assert gcd(powmod(3, (N - 1) // 2, N) - 1, N) == 1 and gcd(powmod(3, (N - 1) // 5, N) - 1, N) == 1

small = mpz(1)
for q in primerange(2, 100000):
    small *= q                                                # product of primes below 10^5

for i in range(1, len(s)):                                    # every interior position
    for c in "0123456789":
        x = mpz(s[:i] + c + s[i:])
        if 1 < gcd(x, small) < x:
            continue                                          # small prime factor: composite
        assert powmod(2, x - 1, x) != 1                       # fails Fermat base 2: composite

print("1057-digit proven prime with no prime interior insertion")
```
