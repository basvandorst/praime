# Puzzle 435: A solution of φ(m) + σ(m) = 5m

> **In short:** No solution of φ(m) + σ(m) = 5m was known. The construction: (1) write m = A·p with p a prime not dividing A; (2) then p = (σ(A) − φ(A))/(5A − σ(A) − φ(A)) is fixed; (3) a depth-first search runs over A with many small prime factors. This gives m = 60493590969525342720 = 2⁹·3⁵·5·7³·13²·31²·41·42577, not claimed least.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_435.htm)

**Status:** first answer · exact (no primality question)

## The question

φ(m) counts the numbers up to m that share no factor with m, and σ(m) is the sum of all divisors of m. Farideh Firoozbakht asked for the next term of OEIS A015704 (1, 312, 23760, …), the smallest m with φ(m) + σ(m) = 5m, and wrote that not even one solution was known for any k > 4.

## What the page had vs ours

| | Solution of φ(m) + σ(m) = 5m |
|---|---|
| On the page | none known (J. López sent congruence conditions only) |
| **Ours** | **m = 60493590969525342720 = 2⁹·3⁵·5·7³·13²·31²·41·42577** |

We do not claim this m is the smallest solution, so the next term of A015704 is still open. We also could not check whether OEIS has listed a solution since the page was written.

## How we found it

Write m = A·p, where p is a prime that does not divide A. Both φ and σ split over coprime factors, so

```
φ(m) + σ(m) = φ(A)·(p − 1) + σ(A)·(p + 1)
```

Setting this equal to 5·A·p and solving for p gives

```
p = (σ(A) − φ(A)) / (5A − σ(A) − φ(A))
```

So once A is chosen, p is **determined**: either this fraction is a prime not dividing A, or that A is useless. We built A as a product of small prime powers by a depth-first search and, for each A, simply computed p. A sum σ(A)/A has to be large for 5A − σ(A) − φ(A) to be small and positive, so A needs many small prime factors, which lets the search skip any branch that can no longer get σ(A)/A high enough.

## The math

With A = 2⁹·3⁵·5·7³·13²·31²·41:

```
σ(A) − φ(A)        = 42577 · (5A − σ(A) − φ(A))
p                  = 42577,   prime, not dividing A
m = A · p          = 60493590969525342720
φ(m) + σ(m)        = 302467954847626713600 = 5 · m
```

## Validation

This script checks the factorisation, checks φ(m) + σ(m) = 5m exactly, and shows that the last prime 42577 follows from A by the formula above.

```python
from sympy import totient, divisor_sigma, factorint, isprime

m = 60493590969525342720
assert factorint(m) == {2: 9, 3: 5, 5: 1, 7: 3, 13: 2, 31: 2, 41: 1, 42577: 1}
assert totient(m) + divisor_sigma(m) == 5 * m            # the equation holds exactly

A = m // 42577                                            # everything except the last prime
num = divisor_sigma(A) - totient(A)
den = 5 * A - divisor_sigma(A) - totient(A)
assert num % den == 0
p = num // den                                            # the last prime is forced by A
assert p == 42577 and isprime(p) and A % p != 0

print("phi(m) + sigma(m) =", totient(m) + divisor_sigma(m), "= 5 *", m)
```
