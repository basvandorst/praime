# Puzzle 11: Distinct, increasing and decreasing gaps

> **In short:** The page lists where the first run of N consecutive primes with N pairwise distinct gaps starts, for N up to 20 and then N = 36. Rivera notes that Gennady Gusev (2001) computed every N from 21 to 36 but only N = 36 was published. We publish the missing values N = 21 to 35, recomputed by one exhaustive pass of all primes below 1.7·10¹², which also proves each one is the first. The same pass confirms that the page's entries for N = 36, 14 increasing gaps and 13 decreasing gaps are the first ones. Our own new result is a bound: no run of 37 distinct, 15 increasing or 14 decreasing gaps starts below 1.01·10¹³.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_011.htm)

**Status:** answered · N = 21–35 published (computed by Gusev in 2001, unpublished), recomputed and proved minimal; no 37 / 15 / 14 below 1.01·10¹³ (new); proven primes

## The question

Let g = p_(i+1) − p_i be the gaps between consecutive primes. Find the earliest run of N consecutive gaps that are pairwise distinct, the earliest run of N strictly increasing gaps, and the earliest run of N strictly decreasing gaps. The page asks readers to extend its tables.

## Current record vs ours

## How we found it

The program slides a two-pointer window over the gaps. For each new gap it drops gaps from the left until the window holds no repeat. The first time the window holds N gaps, its last N gaps form the earliest-ending run of N distinct gaps. The earliest-ending run is also the earliest-starting one: if a run started earlier, it would also have ended earlier.

The same pass tracks the current increasing and decreasing runs. We sieved all primes below 1.7·10¹² in four overlapping chunks, about 25 minutes per chunk.

Checks:

- The pass reproduces every entry on the page: distinct N = 3–20, increasing N = 3–14, decreasing N = 3–13.
- A second program with a different method confirms every distinct entry for N ≤ 32 (all of them below 6.95·10¹¹). It recounts the run length from every single start prime.
- A third check confirms everything below 3·10⁸. It uses a numpy sieve, sorted gap windows and pure Python.
- Every run in the table was rebuilt with `sympy.nextprime`. All primes are below 2⁶⁴, so `sympy.isprime` is a proof.

## The math

A run of N distinct gaps needs N different even numbers, so its span is at least 2 + 4 + … + 2N = N(N + 1). The 36-run spans 1660, against the minimum of 1332. Long runs of distinct gaps are rare because gaps repeat often: two consecutive gaps are equal with probability about 0.025 near 10⁹ (half the rate for shuffled gaps, because equal gaps g need 6 | g). Small gaps such as 6, 12 and 30 also recur often within any window.

## Validation

```python
from sympy import isprime, nextprime

def run(p, n):
    ps = [p]
    while len(ps) < n + 1:
        ps.append(nextprime(ps[-1]))
    assert all(isprime(q) for q in ps)
    return [b - a for a, b in zip(ps, ps[1:])]

distinct = {21: 69931991, 22: 203674907, 23: 1092101119, 24: 1363592621, 25: 1363592677,
            26: 2124140323, 27: 23024158649, 28: 30282104173, 29: 30282104173,
            30: 196948778371, 31: 263552821783, 32: 691340780027,
            33: 1625800359439, 34: 1625800359439, 35: 1625800359439, 36: 1625800359439}
for n, p in distinct.items():
    g = run(p, n)
    assert len(set(g)) == n, n                      # n pairwise distinct gaps

# The page's increasing / decreasing records, confirmed first below 1.7e12 by our pass.
g = run(1472840004017, 14); assert all(b > a for a, b in zip(g, g[1:]))
g = run(1273135176799, 13); assert all(b < a for a, b in zip(g, g[1:]))
print("all runs verified")
```
