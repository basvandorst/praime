# Puzzle 665: (p + q)·(q + r) = mⁿ

> **In short:** Asked: for consecutive primes p < q < r, is (p + q)(q + r) a perfect power other than (5 + 7)(7 + 11) = 6³? Checked on the page for p < 10¹⁰. The proof: (1) with A = p + q and g = r − p the product is A(A + g); (2) coprimality turns A(A + g) = mⁿ into finitely many equations β·yⁿ − α·xⁿ = g/d for each g; (3) beyond a small bound every solution y/x is a convergent of the n-th root of α/β. For g ≤ 3000 the largest A is 990100714252. So 5, 7, 11 is the only case below 4·10¹⁸.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_665.htm)

**Status:** answered · proved for p < 4·10¹⁸ (computed; uses the published list of all prime gaps below 4·10¹⁸); beyond that for r − p ≤ 3000 and p < 10¹⁰⁰

## The question

For three consecutive primes p < q < r, can (p + q)·(q + r) be mⁿ with n > 1, other than (5 + 7)·(7 + 11) = 216 = 6³? Find a solution or prove it impossible.

## Record vs ours

| | Range | Result |
|---|---|---|
| Page (Vantieghem) | p < 10¹⁰ | no other solution; a heuristic argument against squares |
| Ours | p < 4·10¹⁸, every exponent | no other solution (proved, given the gap list) |
| Ours | p < 10¹⁰⁰ with r − p ≤ 3000, every exponent | no other solution |

A further solution needs p > 4·10¹⁸ and r − p > 3000. For comparison: the largest known gap between consecutive primes below 10²⁰ is 1854.

## How we found it

1. A search over p cannot go far beyond 10¹⁰. But the product depends on only two numbers: A = p + q and g = r − p, and g is small.
2. For a fixed g, A(A + g) = mⁿ is a classical type of equation with finitely many solutions. Splitting off the common factor gives equations β·yⁿ − α·xⁿ = c with small c.
3. A solution of such an equation with large x makes y/x an extremely good approximation of (α/β)^(1/n), so it must be a convergent of the continued fraction. Convergents grow exponentially: reaching 10¹⁰⁰ takes about 200 steps.
4. All 8046580 equations for g ≤ 3000 were solved. They have 12774 solutions (A, g, n); the largest is A = 990100714252 (g = 1330, a cube). Only A = 12, g = 6 comes from consecutive primes.

## The math

**Setup (proved).** Let A = p + q and g = r − p, so q + r = A + g. For p ≥ 3 all three primes are odd and g is even. (p = 2: 5·8 = 40 is not a power.) If A(A + g) = mⁿ with n > 1, it is also a perfect ℓ-th power for a prime ℓ | n, so n may be taken prime.

**Splitting (proved).** Let d = gcd(A, A + g); d divides g. Write A = d·u, A + g = d·v with gcd(u, v) = 1, so d²uv = mⁿ and v − u = c = g/d. A prime ℓ not dividing d divides at most one of u, v, and then to a power divisible by n. So

u = α·xⁿ, v = β·yⁿ,

where α and β contain only primes of d, with exponents below n, and gcd(α, β) = 1. For each prime ℓ | d the exponents satisfy v_ℓ(α) + v_ℓ(β) + 2·v_ℓ(d) ≡ 0 (mod n) and one of the two is 0. That leaves at most two choices per prime of d. The equation is

β·yⁿ − α·xⁿ = c, A = d·α·xⁿ.

**Case α = β = 1 (proved).** yⁿ − xⁿ = c with y ≥ x + 1 gives c ≥ n·x^(n−1), so x ≤ (c/n)^(1/(n−1)): a short loop. For n = 2 this is the only case, and A = d·x² ≤ g²/4; this is the page's argument for squares, made exact.

**Case α ≠ β (proved).** θ = (α/β)^(1/n) is irrational. From β·yⁿ − α·xⁿ = c > 0: y > θx and

y − θx = c / (β·(y^(n−1) + y^(n−2)·θx + … + (θx)^(n−1))) < c / (n·β·θ^(n−1)·x^(n−1)) ≤ c / (n·x^(n−1)),

because β·θ^(n−1) = β^(1/n)·α^((n−1)/n) ≥ 1. If x^(n−2) > 2c/n, then |y/x − θ| < 1/(2x²), and by Legendre's theorem y/x equals a convergent h/k of θ; then x = t·k, y = t·h and β·hⁿ − α·kⁿ = c/tⁿ. The program tests every x up to (2c)^(1/(n−2)) + 2 directly and beyond that every convergent with k ≤ x_max. θ is computed to 240 digits (40 more than twice the 100 digits of the bound).

**Range of n.** A(A + g) < 10²⁰¹ and m ≥ 2, so n ≤ 666; all primes up to that are used.

**Result (computed).** [`code/p665_power.py`](code/p665_power.py) `3000 1e100`: 8046580 equations, 772045 continued fractions, 12774 solutions (A, g, n) with g ≤ 3000 and A ≤ 10¹⁰⁰. The largest have A = 990100714252 (g = 1330), 445971980288 (g = 2900), 349774825888 (g = 1854), all cubes. For each solution the program takes the largest prime p ≤ A/2, the next primes q and r, and tests p + q = A, q + r = A + g. Only A = 12, g = 6 passes.

**Gaps (literature).** Every gap between consecutive primes below 4·10¹⁸ has been computed (Oliveira e Silva, Herzog, Pardi, 2014); the largest is 1476. So r − p ≤ 2952 < 3000 for all p < 4·10¹⁸, and the result above covers every such p.

**Not proved.** Beyond 4·10¹⁸ a solution would need r − p > 3000. Then A·g ≈ mⁿ forces very large gaps: for squares g ≥ 2·√(2p), which contradicts every reasonable gap conjecture; for cubes no such simple bound comes out of the equation, since α ≠ β is possible.
