# Puzzle 359: The first N primes in a circle

> **In short:** We arranged the first 202 primes in a circle so that no two neighbours and no two opposite primes share a digit. The best full arrangement before had 108 primes, and 202 is the largest number possible.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_359.htm)

**Status:** beaten (Q1) · proven maximum

## The question

Arrange the first N primes (2, 3, 5, 7, 11, …) in a circle so that every two **neighbouring** primes and every two **diagonally opposite** primes have no digit in common. How large can N be?

Example: 13 and 47 may sit next to each other (no shared digit), but 13 and 31 may not (both contain 1 and 3).

## Current record vs ours

| | Circle | N |
|---|---|---|
| Current record (A. Sahay, 2006) | full arrangement on the page | 108 |
| On the page (E. Clark, 2006) | a circle of 202 primes for the neighbour rule only, ignoring opposite pairs | (202, partial) |
| **Ours** | both rules satisfied, in [data/359.txt](data/359.txt) | **202 (maximum)** |

## How we found it

The digit 1 is the bottleneck. Among the first 202 primes, exactly 101 contain a 1, and no two of them can be neighbours. In a circle of 202 places that forces them onto every second place, alternating with the 101 primes that have no 1. We kept that alternation fixed and let a local search (simulated annealing) swap primes within each half until every neighbour pair and every opposite pair was digit-disjoint.

The same counting shows nothing larger works, so 202 is the answer to "how large can N be".

## The math

**Why 202 is the maximum.** In a circle of N places, at most N/2 primes can avoid touching each other. So if more than half of the first N primes contain the digit 1, two of them must be neighbours and share the 1:

```
N = 202:          101 of 202 primes contain a 1   (exactly half: possible, they must alternate)
N = 203 … 297:    more than half contain a 1      (impossible)
N ≥ 298:          the 298th prime 1973 shares a digit with every earlier prime except 2 and 5,
                  but it needs three digit-disjoint partners (two neighbours and its opposite)
```

Clark noted the N ≥ 298 argument on the page; the digit-1 count closes the gap from 203 to 297.

**Our circle.** With the circle written as c₀, c₁, …, c₂₀₁, the conditions are

```
digits(cᵢ) ∩ digits(c_{i+1 mod 202}) = ∅     (neighbours)
digits(cᵢ) ∩ digits(c_{i+101})       = ∅     (opposite, i < 101)
```

## Verify it yourself

This script reads the circle, checks it uses exactly the first 202 primes, checks both digit rules, and confirms the counting argument that rules out every larger N.

```python
from sympy import prime

# read the circle from the data file (first line is a comment)
lines = open("writeup/data/359.txt").read().splitlines()
c = [int(x) for x in lines[1].split()]
N = len(c)
assert N == 202
assert sorted(c) == [prime(i) for i in range(1, N + 1)]       # exactly the first 202 primes

disjoint = lambda a, b: not set(str(a)) & set(str(b))         # no digit in common
assert all(disjoint(c[i], c[(i + 1) % N]) for i in range(N))  # neighbours, the circle closes
assert all(disjoint(c[i], c[i + N // 2]) for i in range(N // 2))   # opposite pairs

# maximum: for N = 203..297 more than half of the first N primes contain a 1
P = [prime(i) for i in range(1, 299)]
assert all(2 * sum('1' in str(p) for p in P[:n]) > n for n in range(203, 298))
# for N >= 298: the 298th prime 1973 has only two digit-disjoint partners, it needs three
assert [q for q in P if disjoint(q, 1973)] == [2, 5]

print("202 primes in a valid circle; no circle exists for N > 202")
```

Run it from the repository root, so the relative path `writeup/data/359.txt` resolves.
