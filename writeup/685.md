# Puzzle 685, Q3: 1..N in a row with odd composite neighbour sums, for every N ≥ 14

> **In short:** Yes, for every N ≥ 14, by an explicit construction. The numbers are grouped in blocks 30m + 1, …, 30m + 30, all ordered by one fixed residue order. Every neighbour sum, inside a block and across the joint to the next block, is odd and divisible by 3 or 5. Such a sum is at least 9, so it is composite. For each N mod 30 a short "tail" closes the path; for N mod 30 = 4..12 the tail also absorbs the last full block. The conditions depend only on residues mod 30, so checking them once proves them for every N ≥ 120. The cases 14 ≤ N < 120 are solved directly. The construction is also checked for every N from 14 to 3000.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_685.htm)

**Status:** answered · proved by construction

## The question

Arrange 1..N in a row so that the sum of every two neighbours is an odd composite number. N₀ = 14 is the smallest N with a solution (Q2). Q3 asks whether there is a solution for every N > N₀.

On the page:
- W. E. Clark found paths for N ≤ 200.
- Emmanuel Vantieghem extended solutions up to N < 20000, but wrote "I cannot prove this will work for all N".
- Hakan Summakoglu's "Yes" refers to Q1 (sums that are merely not prime), not to odd composite sums.

## The construction

**The block.** Fix the residue order

```
1, 14, 19, 6, 9, 18, 27, 28, 5, 10, 23, 2, 7, 20, 15, 24, 11, 16, 29, 26, 25, 30, 3, 12, 21, 4, 17, 22, 13, 8
```

Two neighbours always have opposite parity, so every neighbour sum is odd. Each sum is ≡ 0 (mod 3) or ≡ 0 (mod 5), and so is the wrap-around 8 + 1 (+ 30). Block m is the sequence 30m + r for r in this order. Every sum inside a block, and across the joint from block m to block m + 1, is odd and divisible by 3 or 5. The smallest such sum, in block 0, is 9. So every sum is composite.

**The tails.** Write N = 30M + ρ.

- ρ ∈ {0, 1, 2, 3, 13, …, 29}: after blocks 0, …, M − 1, append 30M + t for the offsets t of a short tail. The tail is an order of {1, …, ρ} that starts with a residue compatible with the block's last residue, 8.
- ρ ∈ {4, …, 12}: no such short tail exists. Instead, after blocks 0, …, M − 2, append 30(M − 1) + t, where t runs over a long tail: an order of {1, …, 30 + ρ}.

All tails are listed by the script. Every condition used is a congruence mod 30, and every sum involved is larger than 5. So one check per residue class proves the construction for every M.

**Small N.** For 14 ≤ N < 120, a depth-first search with the real sums finds a solution for each N.
