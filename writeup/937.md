# Puzzle 937: A non-composite sequence?

> **In short:** The page asked whether m(n) = X·p_(n+1) − B, with B = p₁⋯pₙ and X the least integer above B/p_(n+1) coprime to B, is always 1 or prime; it was checked, not proved. Proved here: (1) m(n) is the least term of a fixed progression with no prime factor ≤ pₙ; (2) so it is 1 or prime while below p_(n+2)². This explains the pattern; a counterexample needs a Jacobsthal-type covering.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_937.htm)

**Status:** explained · exact reformulation (proof) and the precise condition for a counterexample; verified for n ≤ 1500; a proof for all n would need Jacobsthal-type bounds in a fixed progression

## The question

For n > 0 let B = p(1)·p(2)⋯p(n), X the least number above B/p(n+1) coprime to B, and m(n) = X·p(n+1) − B. The first values are 1, 19, 19, 43, 17, 43, 1, 31, 41, 43, 137, … "These look to be always either 1 or prime. Q. Can you prove this or can you find a counterexample?"

On the page:

- Dmitry Kamenetsky checked 150000 terms (all 1 or prime; 1 occurs at n = 1, 7, 232, 430).
- Pedrag Terzic gave a mirror version (largest X below B/p(n+1)).
- Ken Wilke showed that no prime ≤ p(n+1) divides m(n).

## The math

| # | Claim | Why | Validated |
|---|---|---|---|
| 1 | write B = c·p_(n+1) + r (0 < r < p_(n+1)) and X = c + t; then m(n) = t·p_(n+1) − r | m = (c + t)p_(n+1) − (c·p_(n+1) + r) | n ≤ 1500, both definitions agree |
| 2 | X is coprime to B ⇔ m is coprime to B | for q ≤ pₙ: q \| B, so m ≡ X·p_(n+1) (mod q), and q ∤ p_(n+1) | algebra |
| 3 | so m(n) is the least positive term of t·p_(n+1) − r, t = 1, 2, …, with no prime factor ≤ pₙ | claims 1–2 | n ≤ 1500 |
| 4 | m(n) is not divisible by p_(n+1) | m ≡ −r ≢ 0 (mod p_(n+1)) | algebra |
| 5 | if m(n) < p_(n+2)², then m(n) is 1 or a prime > p_(n+1) | a composite with all prime factors ≥ p_(n+2) is ≥ p_(n+2)² | n ≤ 1500: always the case, with t at most 41 % of p_(n+2)²/p_(n+1) |
| 6 | a counterexample needs t ≥ p_(n+2)²/p_(n+1) ≈ pₙ: every term t = 1 … ≈ pₙ divisible by some prime q ≤ pₙ | claim 5 | — |
| 7 | each prime q ≤ pₙ kills exactly one residue class of t mod q | p_(n+1) is invertible mod q | algebra |

So the question is a Jacobsthal problem. The primes q ≤ pₙ each remove one class of t, and we ask whether they remove every t up to about pₙ. Jacobsthal's function j(pₙ#), the longest such run for the best possible choice of classes, does exceed pₙ for most n. That is why there is no easy proof. But here the classes are fixed by r = B mod p_(n+1), with no freedom.

**How unlikely a counterexample is.** If the classes behave like random ones, a term survives all primes ≤ pₙ with probability ρ = ∏(1 − 1/q) ≈ e^(−γ)/ln pₙ (Mertens). All of the first T ≈ pₙ terms then fail with probability about (1 − ρ)^T ≈ exp(−pₙ·e^(−γ)/ln pₙ). At n = 150000 (pₙ ≈ 2·10⁶) this is e^(−78000). The sum over all larger n is just as negligible. Small n carry all the risk, and they are checked. So m(n) is 1 or prime for all n with overwhelming probability. A proof would need to control the least rough number in one specific progression of modulus p_(n+1), a problem of the same depth as the least prime in a progression.
