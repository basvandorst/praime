# Puzzle 851: Why 2^n + 1 starts long runs of equal Collatz height

> **In short:** For x = 2^n + k with small k, the low part k runs its own Collatz path. After that path ends, x has become 3^o·2^(n−e) + 1, which turns into 3^A + 1 three steps at a time. So the height of 2^n + k depends on k only through one number A ≈ n/2, plus the correction A + H(3^A + 1). Whole intervals of k share one height exactly when A + H(3^A + 1) is constant on the window of A they reach. This happens on long plateaus, which occur where the neighbours 3^A and 3^A + 1 have equal height. For Kamenetsky's n = 1812, the plateau is A ∈ [894, 971], and every k < 2^18 lands in A ∈ [897, 931].

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_851.htm)

**Status:** answered · Q2 explained (exact reduction); Q3: L(3·2^n + 1) = L(2^(n+2) + 1), and the exceptions 17, 67, 68 explained

## The question

Dmitry Kamenetsky found that every number from 2^1812 + 1 to 2^1812 + 2^26 − 1 has the same Collatz height, 12969. Q2 asks why integers 2^n + 1 start such long runs. On the page, Emmanuel Vantieghem doubts that the form is special; nobody gives an explanation.

## The answer

Let H(x) be the number of standard Collatz steps (x ↦ x/2 or 3x + 1) from x to 1.

**Step 1: the low part runs on its own.** Let k reach 1 after e halvings and o tripling steps. As long as the high part stays even, the parity at every step is that of the low part. So after e + o steps, x = 2^n + k is exactly 3^o·2^(n−e) + 1.

**Step 2: a fixed three-step cycle.** A number 3^a·2^t + 1 with t ≥ 2 is odd. It goes to 3^(a+1)·2^t + 4, then to 3^(a+1)·2^(t−1) + 2, then to 3^(a+1)·2^(t−2) + 1. Hence

```
H(2^n + k) = e + o + 3·⌊(n − e)/2⌋ + F(A),   A = o + ⌊(n − e)/2⌋,
```

with F(A) = H(3^A + 1) if n − e is even, and H(2·3^A + 1) if it is odd. We checked this identity exactly for n = 1812 and 47 values of k.

**Step 3: when do all k agree?** Compare two values of k whose A values differ by Δ. Their heights differ by exactly Δ + F(A + Δ) − F(A). So every k has the same height when A ↦ A + F(A) is constant on the window of A that the k reach.

**Step 4: why plateaus exist.** One Collatz step takes the odd number 3^A to 3^(A+1) + 1, so H(3^(A+1) + 1) = H(3^A) − 1. If the neighbours 3^A and 3^A + 1 have equal height, then H(3^(A+1) + 1) = H(3^A + 1) − 1, and A + F(A) stays the same. The plateau breaks exactly where H(3^A) ≠ H(3^A + 1). We checked all 30 breaks for A = 820..999.

**For n = 1812:**

- The plateau around n/2 is A ∈ [894, 971], with A + H(3^A + 1) = 11157 (and one more for the 2·3^A + 1 version).
- Every k < 2^18 has A ∈ [897, 931], inside the plateau. So they all share the height 12969, as Kamenetsky observed for k < 2^26.

**Q3.** Vantieghem compared 3·2^n + 1 with 2^n + 1. The right comparison is with 2^(n+2) + 1.

- In 3·2^n + k the high part carries an extra factor 3, so step 2 ends at the same A as for 2^(n+2) + k, with the same parity. Hence H(3·2^n + k) = H(2^(n+2) + k) − 3, for every k whose own path needs fewer than n halvings, e(k) < n. So the runs have equal length: L(3·2^n + 1) = L(2^(n+2) + 1), for instance L(3·2^65 + 1) = 7 = L(2^67 + 1).
- The identity can only fail when the run reaches a k with e(k) ≥ n. The usual culprit is k = 27, whose path has 111 steps with e(27) = 70.
- For n = 3..140 the two run lengths differ exactly at n = 17, 67 and 68, which are Vantieghem's three exceptions. All three are among the n where the run reaches such a k. That condition is necessary, not sufficient: it also holds for n = 4, 23, 24, 62, 69 and 70, where the lengths still agree.

More generally, any c·2^n + k with an odd constant c gives the same reduction with c·3^A + 1. Long runs come from long plateaus of A ↦ A + H(c·3^A + 1).
