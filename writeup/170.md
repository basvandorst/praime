# Puzzle 170: A prime followed by a pseudoprime

> **In short:** A prime n with n + 1 a base-2 pseudoprime was asked for, or a proof that none exists. The proof: (1) N = n + 1 is even, so N = 2m with m odd; (2) 2^(N−1) ≡ 1 (mod m); (3) the order of 2 mod m divides n and lies strictly between 1 and n. This proves n is composite, so no such pair exists.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_170.htm)

**Status:** first answer (Q10) · proof

## The question

A composite number N is a **base-2 pseudoprime**, psp(2), when it passes the test that primes always pass: 2^N ≡ 2 (mod N). Rivera found many pairs where n is a psp(2) and n + 1 is prime, the first being 161038 and 161039. Question 10 asks for the first pair the other way round: n prime and n + 1 a psp(2), or a proof that such pairs cannot exist.

## How we found it

If n = 2, then n + 1 = 3 is prime, not a pseudoprime. Every other prime n is odd, so n + 1 is **even**. Even pseudoprimes are rare and have a very rigid shape, so we looked at what 2^N ≡ 2 (mod N) says about an even N, and then at what it says about N − 1. It turns out to give a factor of N − 1 for free.

## The math

Let N = n + 1 be an even psp(2).

```
1. 4 does not divide N:   if it did, 2^N ≡ 0 (mod 4) but 2 ≢ 0 (mod 4).
   So N = 2m with m odd, and m > 1 because N is composite.

2. From 2^N ≡ 2 (mod m) and m odd, divide by 2:   2^(N−1) ≡ 1 (mod m).

3. Let t be the order of 2 modulo m (the least t with 2^t ≡ 1 mod m).
   Then t divides N − 1,
   t > 1            because 2 ≢ 1 (mod m),
   t < m < N − 1    because t ≤ φ(m) < m.
```

So N − 1 = n has a divisor t strictly between 1 and n, and n is composite. No prime n can be followed by a base-2 pseudoprime.

## The numbers

```
smallest even psp(2):  N = 161038 = 2 · 73 · 1103,   m = 80519
order of 2 mod 80519:  t = 261
N − 1 = 161037 = 261 · 617   (composite, as the proof says)
```

## Validation

This script finds every even pseudoprime below 10⁷ and checks each step of the proof: N is 2 times an odd m, the order t of 2 mod m divides N − 1, and 1 < t < N − 1. So N − 1 is never prime.

```python
from sympy import isprime, n_order

LIMIT = 10**7
even_psp = [N for N in range(4, LIMIT, 2) if pow(2, N, N) == 2 and not isprime(N)]
assert even_psp[0] == 161038                      # the first even base-2 pseudoprime

for N in even_psp:
    m = N // 2
    assert N % 4 != 0 and m % 2 == 1 and m > 1    # N = 2m with m odd
    t = n_order(2, m)                             # order of 2 modulo m
    assert (N - 1) % t == 0 and 1 < t < N - 1     # a proper divisor of N - 1
    assert not isprime(N - 1)                     # so N - 1 is not prime

print(len(even_psp), "even pseudoprimes below 10^7; none follows a prime")
```
