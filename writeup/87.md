# Puzzle 87: Adding prime magic squares

> **In short:** The records for 3×3 prime magic squares whose sum A + B + 1 (or A + B + C) is again prime magic had constants 1263 and 3327; no 4×4 case was published. The method: (1) sums of magic squares are magic; (2) list all prime magic squares with entries below 2000; (3) try pairs and triples from the smallest up. This gives 1041 and 789, plus first 4×4 answers.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_087.htm)

**Status:** beaten (Q1, Q2) · first answer (Q3) · proven primes

## The question

A prime magic square is a grid of different primes where every row, column and both diagonals have the same sum (the magic constant).

1. Find two different 3×3 prime magic squares A and B such that A + B + 1 (add cell by cell, then add 1 to each cell) is again a prime magic square. Make it as small as possible.
2. The same with three squares: A + B + C must be a prime magic square.
3. Redo both for 4×4 squares.

## Current record vs ours

| | Question | Magic constant of the result |
|---|---|---|
| Current record (J. E. Everett, example on the page) | Q1: A + B + 1 | 1263 |
| **Ours** | Q1: A + B + 1 | **1041** (smallest possible with entries below 2000) |
| Current record (J. E. Everett) | Q2: A + B + C | 3327 |
| **Ours** | Q2: A + B + C | **789** (smallest possible with entries below 2000) |

## How we found it

A 3×3 magic square has its centre equal to one third of its magic constant, and the constant of A + B + 1 is just the sum of the constants of A and B plus 3. So small results need small parts. We listed every 3×3 prime magic square with entries below 2000, sorted them by centre, and tried pairs (and triples) from the smallest up. The first pair whose sum is again all prime gives 1041, and the first triple gives 789. Because the list is complete below 2000, nothing smaller exists in that range.

## The math

For Q1 the result C = A + B + 1 is automatically magic (sums of magic squares are magic), with

```
constant(C) = constant(A) + constant(B) + 3
```

so the only real test is that all 9 cells of C are distinct primes. Q2 is the same with constant(A) + constant(B) + constant(C).

## Also: first answer to Q3 (4×4)

Nobody has published a 4×4 answer (Everett said he had some but kept them back). For 4×4 we used squares built from two orthogonal Latin squares: cell (i, j) holds a[L1(i,j)] + b[L2(i,j)]. Every such square is magic, and the cell-by-cell sum of two of them is again of this form, so the sum stays magic. We then searched small choices of a and b for all-prime squares.

## Validation

This script checks that every part is a prime magic square, that the parts differ, and that each sum is a prime magic square with the stated constant.

```python
from sympy import isprime

def magic(M):
    # return the magic constant if M is a magic square of distinct primes, else None
    n = len(M)
    cells = [x for row in M for x in row]
    lines = [sum(row) for row in M]                                   # rows
    lines += [sum(M[i][j] for i in range(n)) for j in range(n)]       # columns
    lines += [sum(M[i][i] for i in range(n)), sum(M[i][n-1-i] for i in range(n))]  # diagonals
    ok = len(set(lines)) == 1 and len(set(cells)) == n*n and all(isprime(x) for x in cells)
    return lines[0] if ok else None

def add(*Ms, extra=0):
    # cell-by-cell sum of the squares, plus `extra` in every cell
    n = len(Ms[0])
    return [[sum(M[i][j] for M in Ms) + extra for j in range(n)] for i in range(n)]

def check(parts, extra, want):
    # every part is a prime magic square, all parts differ, and the sum is prime magic with constant `want`
    assert all(magic(M) for M in parts)
    assert len({str(M) for M in parts}) == len(parts)
    assert magic(add(*parts, extra=extra)) == want

# Q1, 3x3: A + B + 1
check([[[53,251,197],[311,167,23],[137,83,281]],
       [[257,11,269],[191,179,167],[89,347,101]]], 1, 1041)
# Q2, 3x3: A + B + C
check([[[41,113,59],[89,71,53],[83,29,101]],
       [[29,167,71],[131,89,47],[107,11,149]],
       [[67,79,163],[199,103,7],[43,127,139]]], 0, 789)
# Q3, 4x4: A + B + 1
A4 = [[7,41,59,97],[83,73,31,17],[67,29,71,37],[47,61,43,53]]
check([A4, [[5,19,137,179],[167,149,11,13],[59,41,139,101],[109,131,53,47]]], 1, 548)
# Q3, 4x4: A + B + C (C is the A of the previous line)
check([[[3,13,37,127],[103,61,5,11],[43,17,97,23],[31,89,41,19]],
       [[3,17,53,113],[107,59,7,13],[47,37,83,19],[29,73,43,41]], A4], 0, 570)

# not checked here: that 1041 and 789 are minimal (that needs the full search over all squares below 2000)
print("all four constructions are valid: 1041, 789, 548, 570")
```
