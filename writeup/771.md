# Puzzle 771: First primes in a square of digits

> **In short:** Fill an N × N grid with digits so that every prime from 2 to P can be read along contiguous cells in a straight line, with P as large as possible; the page has P = 61 for N = 3, 131 and 157 for N = 4, and 223 and 241 for N = 5, none proved best. The proof: (1) "every prime up to P is readable" is a finite set of conditions on the digits; (2) each prime is an OR over its straight placements, which a SAT solver handles exactly; (3) the solver finds grids for P = 61 and 131 and proves that 67 and 137 are impossible. This proves 61 (N = 3) and 131 (N = 4) maximal; the grids claimed for 157 and 241 do not satisfy the rules, so 223 is the best valid value for N = 5.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_771.htm)

**Status:** open (Q1 answered: 61 and 131 are the maxima for N = 3 and 4; Q2, N = 5 and 6, open) · proof (SAT, both directions)

## The question

Fill each cell of an N × N matrix with one digit so that all primes from 2 to P can be read. A prime with k digits must lie on k contiguous cells in a straight line (horizontal, vertical or diagonal, in either direction), each cell used once.

- **Q1.** Larger P for N = 3 and N = 4?
- **Q2.** Largest P for N = 5 and N = 6.

## What the page had vs ours

| N | on the page | ours |
|---|---|---|
| 3 | 61 (Kamenetsky, Vantieghem) | **61 is the maximum** (no grid holds every prime up to 67) |
| 4 | 131 (Kamenetsky), 157 (Vantieghem) | **131 is the maximum** (none up to 137); the grid for 157 cannot read 101, 103, 109, 127, … |
| 5 | 223 (Kamenetsky), 241 (Vantieghem) | the grid for 241 cannot read 101, 103, 109, 137, …; 223 is the best valid value; we also find a grid for 223 |
| 6 | 283 (Kamenetsky) | the printed grid has a row of five digits, so it cannot be checked |

Our grids: N = 3: 247 / 931 / 516; N = 4: 8346 / 1971 / 5200 / 1311; N = 5: 93181 / 47359 / 11127 / 10962 / 73193.

## How we found it

"All primes up to P can be read" fixes no cell in advance, but each prime gives one condition: at least one of its finitely many straight placements carries its digits. That is a Boolean formula in the digits of the cells, so a SAT solver either finds a grid or proves that none exists. For N = 3 and 4 both directions take seconds to a minute; for N = 5 the solver finds a grid for 223 but does not decide 227 within 25 minutes.

## The math

**Step 1 (proved). The formula.** For each cell c and digit d, a variable x(c, d), with exactly one digit per cell. For each prime q ≤ P with k digits and each straight run of k cells (any of the 8 directions; single cells for k = 1), an auxiliary variable y implies that the run carries the digits of q in order. The clause "one of the y's of q is true" says q is readable. The formula is satisfiable iff a grid with all primes up to P exists.

**Step 2 (computed). N = 3 and N = 4.** CaDiCaL finds the grids above for P = 61 and P = 131 and reports the formulas for P = 67 (N = 3) and P = 137 (N = 4) unsatisfiable. Since 67 and 137 are the primes after 61 and 131, these are the maxima.

**Step 3 (checked). The page's grids.** Reading every straight segment of each grid:

- Kamenetsky's grids for 131 (N = 4) and 223 (N = 5) are valid.
- Vantieghem's grid for N = 4 (1921 / 0347 / 7159 / 6138) cannot read 101, 103, 109, 127, 131, 137, 149 or 151.
- His grid for N = 5 cannot read 101, 103, 109, 137, … So the claims 157 and 241 do not meet the straight-line rule.

**What this does not settle.** The maxima for N = 5 (at least 223) and N = 6 (283 claimed, not checkable as printed).

## Validation

[code/p771_verify.py](code/p771_verify.py) reads every straight segment of our grids in [data/p771_grids.txt](data/p771_grids.txt) and of the page's grids, and reports which primes are missing. With --sat it rebuilds the formula of step 1 and confirms that 67 (N = 3) and 137 (N = 4) are impossible. Run after `pip install sympy python-sat`:

```
python3 p771_verify.py --sat     # about a minute
```
