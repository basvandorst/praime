# Puzzle 324: The largest self-descriptive prime

> **In short:** A self-descriptive number reads like an inventory of its own digits ("one 5, three 3, …"). We reordered the pairs of the largest possible self-descriptive number (74 digits, found in 2025) and found the largest ordering that is prime, beating the 70-digit prime on the page.

## The question

Read a number in pairs of digits: each pair "c d" says "the digit d appears c times". The number is **self-descriptive** if this inventory is exactly right. Example: 15333110 reads "one 5, three 3, three 1, one 0", and indeed 15333110 has one 5, three 3s, three 1s and one 0.

Question 3 asks for the largest self-descriptive **prime** (repeated pairs allowed).

## How we found it

The order of the pairs does not change what the number describes: "nine 9, eight 9, …" says the same thing in any order. So once you have a self-descriptive number, every reordering of its pairs is self-descriptive too, and some reorderings end in an odd digit and can be prime.

In October 2025 Ash Manning posted the largest possible self-descriptive numbers, with 74 digits, in two essentially different forms (as an answer to Q2, the largest such number, not a prime). Rivera had found his 70-digit prime the same way, by scrambling the pairs of Capelle's largest number. We applied that idea to Manning's 74-digit forms: list the pair orderings from the largest downwards, and take the first one that passes a primality test.

## The math

For a number written as pairs (c₁ d₁)(c₂ d₂)…(c_k d_k), the condition is

```
every pair is true:      the digit d_i appears exactly c_i times in the whole number
every digit is covered:  each digit that occurs in the number is described by some pair
```

On this page repeated pairs are allowed: a repeated pair repeats the same statement (six copies of "73" all say "seven 3s"), they are not added up. Both conditions only depend on which pairs occur, so any permutation of the pairs keeps the property. A permutation gives a prime candidate only if its last pair ends in 1, 3, 7 or 9. Ours ends in the pair "51", meaning "five 1s".

## The number

```
99 98 98 97 97 96 96 96 85 85 85 84 84 84 84 73 73 73 73 73 73 62 62 62 62 62 62 51 51 40 40 51 51 40 40 51
```

Read as a 74-digit number, it is prime by the BPSW test and 50 Miller-Rabin rounds: a probable prime, not a proven one.

## Validation

This script reads the number pair by pair, checks that every pair states a true digit count and that every digit is described, and tests it for primality.

```python
from collections import Counter
import gmpy2

n = "99989897979696968585858484848473737373737373626262626262515140405151404051"
assert len(n) == 74

# the real digit counts of the whole number
actual = Counter(n)

# read the pairs: pair "c d" says "digit d appears c times"
pairs = [(int(n[i]), n[i + 1]) for i in range(0, len(n), 2)]

assert all(actual[d] == c for c, d in pairs)          # every pair is a true statement
assert set(actual) == {d for c, d in pairs}           # every digit in the number is described

assert gmpy2.is_prime(int(n), 50)              # probable prime (BPSW + Miller-Rabin)
assert int(n) > 9998979595959595848484848484848476737373737373736262626251516210516251  # beats the 70-digit record

print("74-digit self-descriptive probable prime")
```
