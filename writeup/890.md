# Puzzle 890: No magic square from three primitive Pythagorean triples

> **In short:** Q1 asked for the smallest 3×3 magic square made of three primitive Pythagorean triples, or a proof that none exists. The proof: (1) parity fixes where the even legs sit; (2) mod 4 fixes the hypotenuses; (3) the remaining three equations have only solutions with a repeated or a negative entry. This proves that no such square exists.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_890.htm)

**Status:** first answer (Q1) · proof

## The question

William Walkington asked for a 3×3 magic square made of three Pythagorean triples. His best was only semi-magic and used non-primitive triples (6-8-10, 9-12-15). Q1 asks for the smallest magic square using only **primitive** triples (no common factor), or a proof that none exists.

## What the page had vs ours

| | Answer |
|---|---|
| On the page | a semi-magic square with non-primitive triples, no contributions on Q1 |
| **Ours** | **impossible** (proof) |

## How we found it

Every 3×3 magic square has the shape (Édouard Lucas): a centre c, and eight more cells c ± a, c ± b, c ± (a + b), c ± (a − b), placed in a fixed pattern. Opposite cells add up to 2c. So we asked which of these nine numbers can be the legs and hypotenuses of primitive triples.

**Parity.** A primitive triple has one even leg (a multiple of 4) and two odd numbers, the other leg and the hypotenuse (which is 1 mod 4). So the square holds 3 even and 6 odd numbers. Checking the possible parities of c, a and b, the only way to get exactly 6 odd numbers is c even and exactly one of a, b even, say b. The three even numbers are then c − b, c, c + b, and since each is a multiple of 4, so are c and b.

**Remainders mod 4.** The six odd numbers are c ± a, c ± (a + b), c ± (a − b), and with c and b multiples of 4 they are all ±a mod 4. Hypotenuses are 1 mod 4, so they are exactly the three numbers c + s·a, c + s·(a + b), c + s·(a − b) for one sign s, and the odd legs are the other three. Replacing a by −a we may take s = 1.

**What is left.** Each triple is (odd leg, even leg, hypotenuse) = (c − a + l·b, c + k·b, c + a + j·b) with k, j, l running over −1, 0, 1 in some order. Ordering the triples by k leaves 6·6 = 36 ways to match the rest, each giving three equations "leg² + leg² = hypotenuse²".

## The math

For one triple, (c − a + l·b)² + (c + k·b)² = (c + a + j·b)² expands to

```
c² − 4ac + 2b·((c − a)·l + c·k − (c + a)·j) + (l² + k² − j²)·b² = 0
```

The equations only depend on the ratios a/c and b/c (c is a positive even leg, so c ≠ 0). Solving the three equations for each of the 36 matchings gives:

```
b/c = 0, a/c = 1/4       (all 36 matchings)    b = 0 makes c − b = c + b: numbers repeat
b/c = ±6, a/c = 25/4     (2 of them, also)     c − a = −21c/4 < 0: a negative entry
```

For example a = 25, b = 24, c = 4 gives the "triples" (−21, −20, 29), (3, 4, 5) and (−45, 28, 53), which satisfy the equations but contain negative numbers. So no magic square of three primitive Pythagorean triples exists.

## Validation

This script solves the three equations for all 36 matchings and checks that every solution repeats a number or contains a negative one. As an independent check, it then tries every set of three primitive triples with hypotenuse below 300 and confirms none of them fits the magic-square shape.

```python
from itertools import combinations, permutations
from math import gcd
from sympy import Rational, solve, symbols

a, b = symbols("a b")
c = 1                                                # only the ratios a/c and b/c matter
K = (-1, 0, 1)                                       # even legs c - b, c, c + b, in this order
cases = 0
for J in permutations(K):
    for L in permutations(K):
        eqs = [c**2 - 4*a*c + 2*b*((c - a)*l + c*k - (c + a)*j) + (l*l + k*k - j*j)*b**2
               for k, j, l in zip(K, J, L)]
        for s in solve(eqs, [a, b], dict=True):
            A, B = s[a], s[b]
            cells = [c, c + A, c - A, c + B, c - B, c + A + B, c - A - B, c + A - B, c - A + B]
            assert B == 0 or min(cells) < 0          # repeated numbers, or a negative entry
            cases += 1
print(cases, "solutions over all 36 matchings: none gives a valid square")

# independent brute force: three primitive triples with hypotenuse < 300
triples = [(m*m - n*n, 2*m*n, m*m + n*n) for m in range(2, 18) for n in range(1, m)
           if (m - n) % 2 and gcd(m, n) == 1 and m*m + n*n < 300]

def magic_shape(values):
    v = sorted(values)
    if len(set(v)) < 9:
        return False
    centre = v[4]
    if any(v[i] + v[8 - i] != 2 * centre for i in range(4)):
        return False                                 # opposite cells must sum to 2c
    offsets = {x - centre for x in v[5:]}            # the four positive offsets
    return any({x, y, x + y, x - y} == offsets for x in offsets for y in offsets if y < x)

hits = [t for t in combinations(triples, 3) if magic_shape([x for tr in t for x in tr])]
assert hits == []
print(len(triples), "primitive triples, no three of them form a magic square")
```
