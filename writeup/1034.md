# Puzzle 1034: Chains p, p + 6k, p + 6k + 6(k+1), … of primes

> **In short:** A chain p, p + 6k, p + 6(k + k+1), … of primes with increasing multiples of 6 is a run of consecutive n with f(n) = 3n² + 3n + c prime; the record is 23 primes (c = 3789041, from n = 564). (1) f has no root modulo a prime q ≥ 5 exactly when 9 − 12c is a non-residue mod q, and the Hardy–Littlewood constant built from these residue symbols measures how prime-rich f is: 7.3 for the record, matching its observed density. (2) A search over all c with |c| ≤ 4·10⁸ whose constant is at least 6.5 (250367 polynomials, n ≤ 6000) finds the record run again and nothing longer. (3) A run of 24 needs a polynomial with constant 9 or more at small values; such c are rare, and the expected yield of the searched region was below 0.1.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1034.htm)

**Status:** open · explained (record 23 reproduced and shown unique for |c| ≤ 4·10⁸ among prime-rich polynomials; no run of 24 found)

## The question

J. M. Bergot: 11 + 6 = 17, 17 + 12 = 29, …, 227 + 54 = 281, then 281 + 60 = 341 fails: a chain of nine successes. Carlos Rivera found 21 terms from 23 (step 6), and Oscar Volpatti a chain of 23 primes from p = 4745021 with first step 3390 (22 successes), which cannot be extended at either end. Q: a longer chain. The same chains are the "stairs of primes" of puzzle 1091, where Alain Rochelli relates them to the polynomials 3X² − 3X + q (Ribenboim).

## How we found it

Steps 6k, 6(k+1), 6(k+2), … add up to 3m(m + 2k + 1) after m steps, so the chain is p + 3m² + 3m(2k+1) = f(n₀ + m) with f(n) = 3n² + 3n + c, n₀ = k and c = p − 3k(k+1). A long chain is a long run of prime values of a quadratic, and the quadratics with many primes are those whose discriminant D = 9 − 12c is a quadratic non-residue modulo many small primes: then f(n) is never divisible by those primes and each value is prime with probability C(c)/ln f(n), C(c) = 3·Π_{q≥5} (1 − w_q/q)/(1 − 1/q), w_q = 1 + (D|q). The program ([`code/p1034_search.c`](code/p1034_search.c), Python twin [`code/p1034_search.py`](code/p1034_search.py)) keeps the c (odd, prime to 3) with D a non-residue modulo 5 … 23 and C(c) ≥ 6.5 and scans n ≤ 6000 for runs with a 64-bit Miller–Rabin test.

## The math

**Step 1 (proved). Chains are runs of a quadratic.** With steps 6k, 6(k+1), …, the m-th term is p + Σ_{j<m} 6(k+j) = p + 6mk + 3m(m−1) = 3(k+m)² + 3(k+m) + (p − 3k² − 3k). So the chain is f(k), f(k+1), …, f(k+m) with c = p − 3k(k+1), and conversely every run of consecutive prime values of f is such a chain. The record: c = 4745021 − 3·564·565 = 3789041, run from n = 564 to 586 (23 values), f(563) and f(587) composite. f(n) = 3n(n+1) + c is odd iff c is odd and prime to 3 iff 3 ∤ c, which every chain of more than one odd prime requires.

**Step 2 (proved). Local densities.** For a prime q ≥ 5, f(n) ≡ 0 (mod q) has 1 + (D|q) solutions n mod q with D = 9 − 12c (the discriminant of 3n² + 3n + c; 9 − 12c ≡ 9(1 − 4c/3)… the usual b² − 4ac). Hence the fraction of n with q ∤ f(n) is 1 − (1 + (D|q))/q, and the Hardy–Littlewood (Bateman–Horn) heuristic gives for the number of prime values with n ≤ N the sum of C(c)/ln f(n), with C(c) the product above (the factors for q = 2 and 3 are 2 and 3/2). For the record polynomial C = 7.33, and the actual count of primes among f(1 … 20000) is 7.30 times the random expectation.

**Step 3 (computed). The search.** Among the c with |c| ≤ 4·10⁸, 1022428 have D a non-residue modulo 5, 7, 11, 13, 17, 19 and 23, and 250367 of them have C(c) ≥ 6.5 (largest 8.87). Scanning n = 0 … 6000 for each: the only run of 23 or more is the record ([`data/p1034_runs.txt`](data/p1034_runs.txt)). Below |c| = 5·10⁶ with n ≤ 3000 the runs of at least 21 are: 23 for c = 3789041 (from n = 564), 22 for c = −205609 (n = 262, p = 1109, step 1578), 21 for c = −765949, −414899, −1832729 ([`data/p1034_small.txt`](data/p1034_small.txt)). Negative c means a real quadratic field; the chains are as good there.

**Step 4 (heuristic). What a longer chain needs.** A value f(n) ≈ 10⁷ of a polynomial with C = 7.3 is prime with probability 7.3/ln 10⁷ ≈ 0.45, so a given start yields 23 primes with probability 0.45²³ ≈ 1·10⁻⁸, and 24 with 5·10⁻⁹; over the ≈ 3000 polynomials with C ≥ 6.5 below |c| = 5·10⁶ and about 1000 starts with values near 10⁷ each, the expected number of 23-runs is about 0.03 to 0.1 (one exists) and of 24-runs below 0.05; at larger |c| the values are larger and the probability per value smaller (0.35 at 10⁹), so the whole search to 4·10⁸ expected fewer than 0.1 runs of 24. The way to a longer chain is not a wider c range but a polynomial with C(c) ≥ 9, which needs D a non-residue modulo every prime up to about 60; such discriminants are those of small class number, and the known champions (3n² + 3n + 23, discriminant −267, 22 primes from n = 0) are of this kind. Expect the record to fall only with such a c and values below 10⁸.
