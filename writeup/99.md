# Puzzle 99: Primes whose square survives reversal

> **In short:** We found a 3001-digit prime p for which reversing p, squaring, and reversing again gives back exactly p². The largest example before had 50 digits.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_099.htm)

**Status:** beaten · PRP (probable primes)

## The question

Write R(n) for n with its digits reversed. Find primes p where R(p) is also prime and p² = R(R(p)²).

The smallest is 13: R(13) = 31 is prime, and 31² = 961, whose reversal 169 is 13². The puzzle asks for examples with 20, 30, 40, 50 or more digits.

## Current record vs ours

| | Prime p | Digits |
|---|---|---|
| Current record (F. Russo, 2000) | 10000000000000000000000000000000000000000000010111 | 50 |
| **Ours** | 10³⁰⁰⁰ + 10¹⁸⁸⁹ + 10¹⁵⁰⁰ + 10¹¹¹¹ + 1 | **3001** |

## How we found it

The condition holds by itself when two things are true: p is a palindrome (so R(p) = p, and R(p) is prime because p is), and squaring p causes no carries. With no carries, the digits of p² are just the coefficients of a polynomial square, and the square of a symmetric polynomial is symmetric, so p² is a palindrome too. Then R(R(p)²) = R(p²) = p². So we only needed a sparse palindrome with few nonzero digits and a pattern of exponents that keeps every digit of p² below 10, and then a primality test.

## The math

Take p = 1 + 10ᵃ + 10ᵏ + 10²ᵏ⁻ᵃ + 10²ᵏ with k = 1500, a = 1111. Squaring gives a sum of powers 10^(eᵢ+eⱼ) over the exponents e = {0, 1111, 1500, 1889, 3000}:

```
squares:     10^0, 10^2222, 10^3000, 10^3778, 10^6000       (coefficient 1 each)
cross terms: 10^1111, 10^1500, 10^1889, 10^2611, 10^3389,
             10^4111, 10^4500, 10^4889                      (coefficient 2 each)
collision:   0 + 3000 = 1111 + 1889 = 1500 + 1500  ->  2 + 2 + 1 = 5 at 10^3000
```

Every coefficient is at most 5, so there are no carries, p² is a palindrome, and

```
R(R(p)²) = R(p²) = p²
```

## The prime

```
p = 10^3000 + 10^1889 + 10^1500 + 10^1111 + 1
  = 1 000…000 1 000…000 1 000…000 1 000…000 1   (3001 digits, five 1s)
```

p passes the BPSW test and 25 Miller-Rabin rounds: it is a probable prime, not a proven one.

## Validation

This script checks that p is a 3001-digit palindromic probable prime and that p² = R(R(p)²) holds.

```python
import sys
import gmpy2

sys.set_int_max_str_digits(0)                       # allow printing numbers with thousands of digits
R = lambda n: int(str(n)[::-1])                     # R(n) = n with its digits reversed

p = 10**3000 + 10**1889 + 10**1500 + 10**1111 + 1

assert len(str(p)) == 3001                          # 3001 digits
assert R(p) == p                                    # p is a palindrome, so R(p) = p
assert gmpy2.is_bpsw_prp(p) and gmpy2.is_prime(p, 25)   # p (and so R(p)) is a probable prime
assert max(str(p * p)) <= '5'                       # p^2 only has small digits: no carries happened
assert p * p == R(R(p)**2)                          # the puzzle's condition
print("3001-digit probable prime with p^2 = R(R(p)^2)")
```
