# Puzzle 1235: Is 6ⁿ + n⁶ composite for every n > 1?

> **In short:** F(n) = 6ⁿ + n⁶ is prime for n = 1 and composite for 2 ≤ n ≤ 150000; the page asks for a proof of compositeness or a prime. The analysis: (1) the primes 2, 3, 5, 7 leave exactly the classes n ≡ 35, 49, 91, 119, 161, 175 (mod 210); (2) for every other prime q the fraction of these n with q | F(n) has a closed form from the subgroup generated by 6 and the sixth powers mod q; (3) no finite set of primes divides all F(n), since n ≡ 0 (mod q) escapes q, so no covering-set proof exists; (4) the resulting model, calibrated on the sieve to 0.2 %, expects 0.85 primes with 1 < n ≤ 150000 and only 0.1·ln(X/150000) more beyond. The claim is probably false, but the next prime F(n) is expected near n ≈ 10^9.7, far beyond any test.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1235.htm)

**Status:** open · proved: no covering set; heuristic (calibrated): primes F(n) exist but the first with n > 1 is expected near n ≈ 10^9.7

## The question

F(n) = 6ⁿ + n⁶ (OEIS A001594). F(1) = 7 is prime, and no other prime was found for n ≤ 150000.

**Q.** Prove that F(n) is composite for all n > 1, or find a prime.

## How we found it

The question has the shape of 1022: a self-referential form with no covering set, where the honest answer is a calibrated count. The new part is the local density. For a prime q, "q divides 6ⁿ + n⁶" means 6ⁿ ≡ −n⁶ (mod q): the left side runs through the powers of 6, the right side through the negatives of sixth powers. Both are subgroups of the cyclic group (ℤ/q)*, so the fraction of n that works follows from the orders of these subgroups. Because the allowed n are restricted mod 210, the density must be taken conditional on the class; without that the model is off by 45 %.

## The math

**Step 1 (proved). The primes 2, 3, 5, 7.** 2 | F(n) iff n is even. 3 | F(n) iff 3 | n (6ⁿ ≡ 0). Mod 5, 6ⁿ ≡ 1 and n⁶ ≡ (n²)³ ≡ 1 for n ≡ ±1, ≡ 4 for n ≡ ±2, ≡ 0 for 5 | n; so 5 | F(n) iff n ≡ ±2 (mod 5). Mod 7, 6ⁿ ≡ (−1)ⁿ and n⁶ ≡ 1 for 7 ∤ n (Fermat); so 7 | F(n) iff n is odd and 7 ∤ n. Together: n odd, 7 | n, 3 ∤ n, n ≢ ±2 (mod 5), the six classes mod 210 above.

**Step 2 (proved). The density for a prime q ≥ 11.** Let o = ord_q(6), g = gcd(6, q − 1), H = ⟨6⟩ (order o), S = the sixth powers (a subgroup of index g), and m = o / |H ∩ S| = o / gcd(o, (q−1)/g). Write w = 6^((q−1)/g), an element of order m, and ε = (−1)^((q−1)/g). Then 6ˢ ∈ −S iff (−6ˢ)^((q−1)/g) = 1 iff wˢ = ε: for ε = 1 iff s ≡ 0 (mod m), for ε = −1 iff m is even and s ≡ m/2 (mod m). For such s exactly g residues r mod q satisfy r⁶ ≡ −6ˢ. An allowed class c mod 210 fixes n mod d = gcd(o, 210), leaving o/d residues s = n mod o; the condition picks o/lcm(m, d) of them when c is compatible and none otherwise. Hence

  f_q(c) = g · gcd(m, d) / (q · m) if (ε = 1 and c ≡ 0 mod gcd(m, d)) or (ε = −1, m even, c ≡ m/2 mod gcd(m, d)); else 0.

Examples: q = 11 gives 1/11; q = 19, 23, 43, 47 give 0 (there −1 is not in H·S, so 19, 23, 43, 47 never divide F(n)); q = 37 gives 3/37. The formula is checked against a brute-force count over a full period for all q < 50 and all six classes.

**Step 3 (proved). No covering set.** For any finite set of primes q₁, …, q_k ≥ 11, choose n ≡ 35 (mod 210) and n ≡ 0 (mod q₁ ⋯ q_k). Then F(n) ≡ 6ⁿ ≢ 0 (mod q_i) for every i, and F(n) is odd and prime to 3, 5, 7. So no finite set of primes divides all F(n), n > 1, and a proof of compositeness cannot come from a covering set. An algebraic factorisation is not available either: 6ⁿ + n⁶ is a sum of two cubes only when 3 | n (excluded) and of the form a⁴ + 4b⁴ only when n is even.

**Step 4 (computed). Calibration.** Among the 4286 allowed n ≤ 150000, 2078 have no prime factor q ≤ 1000, and the model (independent events with the densities of step 2) predicts 2073.2: a ratio of 1.002. Without the conditioning on the class the prediction would be 1431.

**Step 5 (heuristic). The expected number of primes.** With C = ∏_{q ≥ 11} (1 − f_q(c))/(1 − 1/q) = 1.389 (the same for all six classes; the product converges: 1.313 at Q = 97, 1.386 at 10⁵, 1.389 at 2·10⁵), the probability that F(n) is prime for allowed n is (2·3/2·5/4·7/6)·C / ln F(n). The expected number of primes with 1 < n ≤ X is 0.36 (X = 1000), 0.59 (10⁴), 0.85 (1.5·10⁵), 1.03 (10⁶), 1.25 (10⁷); beyond 150000 it grows like 0.097·ln(X/150000), so one more prime is expected near X ≈ 10^9.7. The chance that no prime appears up to 150000 is e^(−0.85) ≈ 43 %.

**What this does not settle.** Whether a prime F(n) with n > 1 exists. The model says yes, infinitely many, but the first one is out of reach of any primality test (F(10^9.7) has about 4·10⁹ digits).
