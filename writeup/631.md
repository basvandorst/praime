# Puzzle 631: Three prime gaps in a row, all as large as you like

> **In short:** Puzzle 630 showed that two neighbouring prime gaps can both be arbitrarily large. Luke Pebody added that three in a row "would probably be much harder". It is, but it follows from a deep theorem by D. K. L. Shiu: for every q there are four consecutive primes that all leave remainder 1 when divided by q, so all three gaps between them are multiples of q, and so at least q.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_631.htm)

**Status:** first answer · proof (using a published theorem)

## The question

Let p(n) be the n-th prime. In puzzle 630, Emmanuel Vantieghem asked whether the two gaps p(n) − p(n−1) and p(n+1) − p(n) can **both** be arbitrarily large, and contributors showed they can. Luke Pebody then posed puzzle 631: can **three** consecutive gaps all be arbitrarily large?

## What the page had vs ours

| | Answer |
|---|---|
| On the page | the question, no answers |
| **Ours** | **yes**, by Shiu's theorem on strings of congruent primes |

## How we found it

The classic trick for one big gap is to find a long run of composite numbers, like n! + 2, …, n! + n. For three gaps at once that is not enough: you need three long runs of composites, with exactly one prime between each pair, and nothing elementary controls where those single primes fall.

So we turned it around. Instead of making the gaps big directly, make them **multiples of q**. If consecutive primes all leave the same remainder when divided by q, every gap between them is a positive multiple of q, so at least q. That is exactly what Shiu proved can happen.

## The math

**Shiu's theorem** (D. K. L. Shiu, *Strings of congruent primes*, J. London Math. Soc. 61 (2000)): for any q, any a coprime to q and any k, there are k **consecutive** primes that are all ≡ a (mod q).

Take k = 4 and a = 1. Then there are consecutive primes

```
p(n−1) ≡ p(n) ≡ p(n+1) ≡ p(n+2) ≡ 1   (mod q)
⇒  each of the three gaps is a positive multiple of q
⇒  each of the three gaps is ≥ q
```

Since q is arbitrary, the three gaps can all be made as large as you like. The same argument gives any number of consecutive large gaps.

## The numbers

For q = 30 the first such string is

```
4560121, 4560151, 4560181, 4560211       (consecutive primes, three gaps of 30)
```

The theorem guarantees such strings for every q, but they become rare quickly: for q = 210 there is none below 10⁸.

## Verify it yourself

The proof rests on Shiu's theorem, so there is nothing to compute for the general case. This script illustrates it: it sieves the primes below 10⁸ and finds the first four consecutive primes that are all 1 mod 30.

```python
import numpy as np
from sympy import isprime, nextprime

N = 10**8
sieve = np.ones(N // 2, dtype=bool)          # sieve[k] stands for 2k + 1
sieve[0] = False
for i in range(3, int(N**0.5) + 1, 2):
    if sieve[i // 2]:
        sieve[i * i // 2::i] = False
primes = 2 * np.flatnonzero(sieve) + 1

q = 30
one = primes % q == 1
run = one[:-3] & one[1:-2] & one[2:-1] & one[3:]   # four consecutive primes, all 1 mod q
first = int(np.flatnonzero(run)[0])
string = [int(p) for p in primes[first:first + 4]]

assert string == [4560121, 4560151, 4560181, 4560211]
assert all(isprime(p) for p in string)
assert all(nextprime(a) == b for a, b in zip(string, string[1:]))   # really consecutive
print("four consecutive primes, all 1 mod 30:", string, "gaps:", [b - a for a, b in zip(string, string[1:])])
```
