# Puzzle 1218: 3, 41, 463, …

> **In short:** The page asks for primes p with LPF(prime(q) + prime(q+1)) = p where q = prime(p); 3, 41, 463 were known and a search to prime(10⁹) added 4724804933. (1) For p ≥ 11 the sum x + y is about 2p·ln²p, so its cofactor after dividing by p is below p: the condition is just p | x + y, an event of probability 1/p. (2) The expected count below X is Σ 1/p = ln ln X − 0.24: 2.9 below 2.28·10¹⁰ (4 found). So infinitely many such primes are expected, but the next one only near 10³⁰; a search is hopeless.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1218.htm)

**Status:** open · explained (the four known solutions verified; none below 1.5·10⁶ besides the first three, direct; heuristic: infinitely many, growing like ln ln X)

## The question

For a prime p let q = prime(p) (the p-th prime), x = prime(q), y = prime(q+1). The page asks for primes p with LPF(x + y) = p, where LPF is the largest prime factor. Examples: p = 3 (24 = 2³·3), p = 41 (2132 = 2²·13·41), p = 463 (61116 = 2²·3·11·463). Oscar Volpatti writes that below p = prime(10⁹) = 22801763489 there is one more: p = 4724804933, with x + y = 6406835489148 = 2²·3·113·4724804933.

## How we found it

Both x and y are about q·ln q with q about p·ln p, so x + y ≈ 2p·ln p·ln(p ln p) is only a polylogarithmic multiple of p. The question is therefore whether p divides a number of size p·polylog(p), a 1-in-p event. The sum of 1/p over primes diverges, but like ln ln X.

## The math

**Step 1 (proved). LPF(x + y) = p iff p | x + y, for p ≥ 11.** If LPF(x + y) = p then p | x + y. Conversely, let x + y = p·m. By the prime number theorem bounds, x + y < 2y < 2·(q+1)(ln(q+1) + ln ln(q+1)) and q < p(ln p + ln ln p) (Rosser–Schoenfeld, p ≥ 6), so m < 2(ln p + ln ln p + 1)(ln p + 2 ln ln p + 2) < p for p ≥ 11 (checked numerically: m ≈ 2 ln²p; m = 8, 52, 132, 1356 for the four solutions). Every prime factor of m is then below p, so LPF(x + y) = p. (For p = 5, 7 the direct check applies.)

**Step 2 (computed). Verification.** With Lucy's prime-counting recursion ([`code/p9_lucy.c`](code/p9_lucy.c)): π(4724804933) = 222617381, π(115412584783) = 4724804933, π(3203417744519) = 115412584783, and 3203417744629 is the next prime after 3203417744519. So q = prime(p), x = prime(q), y = prime(q+1) as stated, and x + y = 2²·3·113·4724804933. A direct search with a sieve to 4.6·10⁸ finds exactly 3, 41, 463 among the 114155 primes p < 1.5·10⁶.

**Step 3 (heuristic). Expected count.** x + y is even; for an odd prime p the chance that p divides a given even number is 1/p. The expected number of solutions with 3 ≤ p ≤ X is Σ_{3≤p≤X} 1/p = ln ln X + M − 1/2 with Mertens' constant M = 0.2615: 2.93 below 2.28·10¹⁰, where 4 were found (Poisson probability of 4 or more: 0.34). The next solution needs ln ln X to grow by 1, which happens near X = 10³⁰; the expected number of solutions between 2.28·10¹⁰ and 10¹⁵ is 0.37.

**Step 4 (heuristic). Infinitely many.** Since Σ 1/p diverges, infinitely many solutions are expected, but no proof is in sight: the condition links the prime counting function at three nested levels.
