# Puzzle 356: Prime sets with all pairwise sums different

> **In short:** We found sets of 20, 25 and 30 primes where every pair (including a prime with itself) has a different sum, with a smaller largest prime than the published sets. The best before were 751, 1409 and 2273; ours are 661, 1297 and 2213.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_356.htm)

**Status:** beaten (Q1, K = 20, 25, 30) · not claimed minimal

## The question

Take K primes p₁ < p₂ < … < p_K such that all pairwise sums pᵢ + pⱼ (with i ≤ j, so a prime added to itself counts too) are different. Such a set is called a Sidon set. How small can the largest prime p_K be?

Example for K = 10 (from the puzzle): {2, 3, 5, 13, 17, 41, 61, 67, 83, 101}. Every one of its 55 pairwise sums is different, and the largest prime is 101.

## Current record vs ours

| K | Current record (F. Schneider, April 2006) | **Ours** |
|---|---|---|
| 20 | 751 | **661** |
| 25 | 1409 | **1297** |
| 30 | 2273 | **2213** |

Schneider found his sets with a "crude brute search" and wrote that they "most likely aren't minimal". A side note: his K = 10 set with maximum 89, {2, 3, 5, 13, 23, 37, 41, 67, 83, 89}, breaks the page's rule that a prime added to itself counts, since 13 + 13 = 3 + 23 = 26 and 23 + 23 = 5 + 41 = 46.

## How we found it

Choosing K primes one by one in increasing order (greedy) quickly runs into a dead end, because an early choice blocks many sums later. So we used local search: start from a set of K primes below a target maximum, count how many pairs of sums collide, and repeatedly swap one prime for another when that lowers the number of collisions, sometimes accepting a worse swap to escape a dead end (simulated annealing). When the collision count reaches zero, we have a valid set, then lower the target and repeat.

This is a guided search, not a proof: our sets beat the published ones, but we do not claim they are the smallest possible.

## The math

A set S is valid when

```
pᵢ + pⱼ = pₖ + pₗ  with i ≤ j, k ≤ l   implies   {i, j} = {k, l}
```

Equivalently, all differences pⱼ − pᵢ (i < j) are different. A set of K numbers has K(K+1)/2 pairwise sums (with repeats allowed), so all of them must fit below 2·p_K:

```
K(K+1)/2 ≤ 2·p_K   (roughly)   →   p_K grows at least like K²/4
```

For K = 30 that gives about 233, far below the sizes reachable in practice, so the true minimum is unknown.

## Validation

This script checks that each set has the right size, contains only primes, and has all pairwise sums (including doubles) different.

```python
from sympy import isprime

sets = {
    20: [2, 3, 5, 29, 79, 97, 107, 193, 239, 311, 349, 401, 461, 541, 577, 599, 607, 641, 647, 661],
    25: [2, 3, 13, 31, 103, 151, 281, 307, 347, 389, 433, 449, 577, 599, 673, 761, 797,
         983, 1033, 1063, 1097, 1117, 1289, 1291, 1297],
    30: [2, 3, 7, 23, 89, 139, 193, 211, 467, 503, 547, 631, 659, 719, 877, 997, 1021, 1301,
         1439, 1451, 1549, 1613, 1811, 1873, 1907, 2053, 2083, 2161, 2207, 2213],
}
record = {20: 751, 25: 1409, 30: 2273}

for K, S in sets.items():
    assert len(set(S)) == K                          # K different numbers
    assert all(isprime(p) for p in S)                # all prime
    sums = [a + b for i, a in enumerate(S) for b in S[i:]]   # all pairs, a prime with itself included
    assert len(sums) == len(set(sums))               # no two pairs have the same sum
    assert max(S) < record[K]                        # smaller largest prime than the record
    print(f"K = {K}: valid, largest prime {max(S)} (record {record[K]})")
```
