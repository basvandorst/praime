# Puzzle 753: Prime lattices of every order (attempt)

> **In short:** The page asked for a proof that prime lattices of every order m×n exist: equal-length strings s_i, t_j with every concatenation s_i t_j prime. Proved here: (1) without the digit constraint, Green–Tao–Ziegler gives solutions; (2) the constraint uses a modulus 10^L that grows, which that theorem does not cover. The question stays open; it holds under the Bateman–Horn conjecture.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_753.htm)

**Status:** open · conditional proof (Hardy–Littlewood); unconditional proof not found

## Reductions

1. **Fixed t_j is at least as hard as twin primes.** With fixed t_j, every row is a prime n-tuple with fixed gaps. A proof has to let both the s_i and the t_j vary.
2. **Without the digit constraint it is a theorem.** The mn forms x_i + y_j are pairwise non-proportional, and there is no local obstruction (take x ≡ 1 and y ≡ 0 mod p). So Green–Tao–Ziegler ("Linear equations in primes") gives infinitely many (x, y) with every x_i + y_j prime.
3. **The digit constraint breaks it.** It requires x_i ≡ 0 (mod 10^L) and 0 ≤ y_j < 10^L, which is a congruence with a modulus that grows with N. Green–Tao–Ziegler is uniform only for bounded coefficients and fixed moduli.
4. **An arithmetic progression would suffice, but is not available.** An AP of m·n′ primes c + k·d with d = 10^L/n′ (n′ a power of 2 at least n) and c mod 10^L < d gives a lattice directly:
   - s_i = ⌊c/10^L⌋ + i
   - t_j = (c mod 10^L) + j·d

   Green–Tao does not allow a prescribed difference. Length 2 with difference 2 is the twin prime conjecture.

## Conditional proof

The Bateman–Horn conjecture predicts how often a set of linear forms is prime at the same time. Assume it holds uniformly in the coefficient 10^L, applied to the mn forms s_i·10^L + t_j. Then the number of order-m×n lattices with L-digit strings is about

𝔖 · 10^(L(m+n)) / (2L·ln 10)^(mn).

Here 𝔖 > 0 is the product of the local densities, and it is positive because there is no local obstruction. For fixed m and n this tends to infinity as L grows.

## What would close it

A version of Green–Tao–Ziegler for linear forms whose variables lie in residue classes modulo a growing power of 10. Maynard's work on primes with restricted digits handles related digit conditions, but not this joint system.
