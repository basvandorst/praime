# Puzzle 92: A pile of prime spheres

> **In short:** The record 5-level pyramid of different primes, each ball the sum of the three it rests on, had top ball 804313; no 6- or 7-level pile was known. The construction: (1) every upper ball is a fixed weighted sum of the bottom balls; (2) choose bottom residues mod 3 so no upper ball is divisible by 3; (3) fill in small primes by search. This gives top 4999, plus first 6- and 7-level piles.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_092.htm)

**Status:** beaten (n = 5) · first answer (n = 6, 7) · proven primes

## The question

Stack balls into a tetrahedron (a triangular pyramid) with n levels. Every ball holds a different prime, and every ball that is not on the bottom level holds the sum of the three balls just below it that it touches. Find the least pile for n = 5, 6 and 7.

Small example (n = 2): the bottom is 3, 5, 11 and the top is 3 + 5 + 11 = 19.

## Current record vs ours

| | n | Top ball | Total of all balls |
|---|---|---|---|
| Current record (E. Haga, 11/3/2001) | 5 | 804313 | 2675763 |
| **Ours** | 5 | **4999** | **16561** |

For n = 6 and 7 the page has no pile at all.

## How we found it

Every ball above the bottom is a fixed weighted sum of the bottom balls, so the whole pile is decided by the bottom level. The danger is that some upper ball becomes divisible by 3. We first chose, for each bottom ball, its remainder after dividing by 3 (and by a few other small primes) so that no upper ball can ever be a multiple of those primes. Then we filled the bottom with small primes that have those remainders, using a guided depth-first search that checks each upper ball as soon as all balls under it are known, and rejects repeats.

## The math

Number the levels from the top. Level k is a triangle of k(k+1)/2 balls, and ball (i, j) on level k rests on balls (i, j), (i+1, j), (i+1, j+1) of level k+1:

```
x[k][i][j] = x[k+1][i][j] + x[k+1][i+1][j] + x[k+1][i+1][j+1]
```

Unrolling this, every ball is Σ w·b over the bottom balls b, with fixed whole-number weights w. If the bottom remainders r_b (mod 3) make Σ w·r_b ≢ 0 (mod 3) for every upper ball, then no upper ball is divisible by 3, whatever primes we pick with those remainders. The same works for other small primes. In our n = 5 pile the bottom has 7 primes ≡ 1 and 8 primes ≡ 2 (mod 3).

## Validation

This script builds each pile up from its bottom level and checks that all balls are different primes, with the stated top and total.

```python
from sympy import isprime

def pile(bottom):
    # build the pile upwards: each ball is the sum of the three balls it rests on
    levels = [bottom]
    while len(levels[-1]) > 1:
        B = levels[-1]
        levels.append([[B[i][j] + B[i+1][j] + B[i+1][j+1] for j in range(i+1)]
                       for i in range(len(B) - 1)])
    balls = [x for level in levels for row in level for x in row]
    # every ball holds a prime, and no prime is used twice
    assert all(isprime(x) for x in balls)
    assert len(set(balls)) == len(balls)
    return levels[-1][0][0], sum(balls)          # top ball, total of all balls

# bottom levels, written as triangles (row by row)
n5 = [[23],[61,127],[41,29,71],[139,43,7,103],[17,101,137,89,37]]
n6 = [[43],[137,19],[61,59,79],[173,37,197,211],[223,53,13,191,17],[5,229,71,67,73,283]]

      [7,59,11,431,181,593],[13,557,127,211,19,347,109]]

assert pile(n5) == (4999, 16561)        # n = 5: beats Haga's top 804313
```
