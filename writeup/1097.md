# Puzzle 1097: A prime generator built from "mod"

> **In short:** We wrote a formula using only n, constants and the remainder operation "mod" that gives 130 different primes for n = 0 to 129. The best on the page gave 65 different primes. It reuses the blocks of prime progressions from puzzle 1099, glued together with a trick Paolo Lava described on the page.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1097.htm)

**Status:** beaten · proven primes

## The question

Build a prime generator that is not a polynomial but may use the modular operator (remainder after division) anywhere. Davide Rotondo's formula on the page gives 75 primes in a row for n = 1 … 75, but only 65 of them are different. Can you do better?

## Current record vs ours

| | Formula | Primes | Different primes |
|---|---|---|---|
| Current record (D. Rotondo) | a quadratic in a mod-5 expression | 75 | 65 |
| Also on the page (S. Cavegn, 2022) | | 103 | 42 |
| **Ours** | 9699690·(n mod 10) + Σ e_j·((⌊n/10⌋ + j) mod 13) | 130 | **130** |

## How we found it

Two ideas from the page fit together:

- **The values.** In [puzzle 1099](1099.md) the primes come in blocks of ten: I_m, I_m + d, …, I_m + 9d with d = 9699690. So on block m we want f(n) = I_m + d·(n mod 10).
- **The glue.** Paolo Lava explains that a sum Σ e_j·((m + j) mod k) can produce **any** list of k values for m = 0, …, k − 1: you just solve a linear system for the numbers e_j. He did not carry it out.

We did: with k = 13 blocks, solve for the 13 numbers e_j so that the mod-sum equals I₀, I₁, …, I₁₂, then add d·(n mod 10). The result is 13 blocks of 10 primes, 130 in total, all different.

As Stinchcombe remarks on the page, rules like these let a formula reproduce any list you choose, so the real content is in the list itself: 13 blocks of ten primes in arithmetic progression.

## The math

Write n = 10m + r with r = n mod 10 and m = (n − r)/10. We want

```
f(n) = I_m + d·r,      d = 9699690,  m = 0, …, 12,  r = 0, …, 9
```

The "circulant" matrix C with entries C[m][j] = (m + j) mod 13 is invertible, so the system

```
Σ_{j=0..12} e_j · ((m + j) mod 13) = I_m      for m = 0, …, 12
```

has exactly one solution. It is

```
e = [933516151, −104434997, 23700127, −128911085, 56766199, 48442819, −1599797,
     −152799521, 32343931, −71698241, 45728731, 44720503, 43956415] / 1014
```

and then f(n) = d·(n mod 10) + Σ e_j·((⌊n/10⌋ + j) mod 13) is a whole number for every n = 0, …, 129.

## The numbers

The block starts I_m are the first 13 primes a for which a, a + d, …, a + 9d are all prime:

```
35969, 231529, 417293, 590131, 2268443, 2612881, 5330953, 6110567, 6248609, 6279941, 8691751, 9147007, 11245021
```

All 130 values are below 2⁶⁴, where sympy's test is exact: proven primes.

## Validation

This script evaluates the formula with exact fractions for n = 0 … 129 and checks that every value is a whole number, prime, and different from the others.

```python
from fractions import Fraction
from sympy import isprime

d = 9699690
e = [Fraction(x, 1014) for x in (933516151, -104434997, 23700127, -128911085, 56766199,
                                  48442819, -1599797, -152799521, 32343931, -71698241,
                                  45728731, 44720503, 43956415)]

def f(n):
    r = n % 10                       # position inside the block
    m = (n - r) // 10                # which block
    return d * r + sum(e[j] * ((m + j) % 13) for j in range(13))

values = [f(n) for n in range(130)]
assert all(v.denominator == 1 for v in values)          # whole numbers
values = [int(v) for v in values]
assert all(isprime(v) for v in values)                  # all prime (exact below 2^64)
assert len(set(values)) == 130                          # all different

print("130 different primes for n = 0..129, first ones:", values[:4])
```
