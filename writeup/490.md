# Puzzle 490: When is 2^n − 2^k + 1 a square for odd n?

> **In short:** For odd n only 2⁵ − 2³ + 1 = 5², 2⁷ − 2³ + 1 = 11² and 2¹⁵ − 2³ + 1 = 181² were known; more, and whether k is always 3, was asked. The proof: (1) rewrite as y² + (2^k − 1) = 2^n; (2) k = 3 is the Ramanujan–Nagell equation; (3) for k ≥ 4 Apéry's theorem (1960) allows at most two solutions, and two with n = k or n even exist. This proves there are no others, and k = 3 always.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_490.htm)

**Status:** first answer (Q1, Q2) · proof (using two published theorems)

**Correction (2026-11-03):** an earlier version credited the at-most-two theorem to Beukers (1981) and gave it the wrong list of exceptions. The theorem is Apéry's (1960); Beukers' 1981 paper sharpens it. Pointed out by Carlos Rivera in his review for Puzzle 1288. The proof itself is unchanged.

## The question

For even n there is always a solution: 2^n − 2^(n/2+1) + 1 = (2^(n/2) − 1)². For odd n the page knows only n = 5, 7 and 15, all with k = 3. Q1 asks for other odd n; Q2 asks whether k is always 3. (The case k = n, giving 1 = 1², is trivial and left out.)

## What the page had vs ours

| | Answer |
|---|---|
| On the page | n = 5, 7, 15 (k = 3), nothing else known |
| **Ours** | **no other odd n exists, and k = 3 always** (proof) |

## How we found it

Move the terms around:

```
2^n − 2^k + 1 = y²    ⇔    y² + (2^k − 1) = 2^n
```

This is the equation x² + D = 2^n with D = 2^k − 1, which number theorists studied for a century.

- **k = 3** gives D = 7: the **Ramanujan–Nagell equation** x² + 7 = 2^n. Nagell proved its only solutions are n = 3, 4, 5, 7, 15. The odd ones are 3 (the trivial k = n case), 5, 7 and 15: exactly the three on the page.
- **k ≥ 4.** R. Apéry (1960) proved that for every D > 0 except D = 7, x² + D = 2^n has **at most two** solutions in positive integers (x, n). Our D = 2^k − 1 is not 7. So at most two solutions, and we can name two that always exist:

```
x = 1:            1 + (2^k − 1)               = 2^k            (n = k, the trivial case)
x = 2^(k−1) − 1:  (2^(k−1) − 1)² + (2^k − 1)  = 2^(2k−2)       (n = 2k − 2, even)
```

Those use up both places, so there is no solution with odd n other than the trivial one.

F. Beukers (1981) later showed which D > 0 have two solutions at all: only D = 23 and D = 2^k − 1 with k ≥ 4. Our D is that second family, with exactly the two solutions above. (The family D = 2^(2m) − 3·2^(m+1) + 1 that the earlier version listed belongs to the other sign, x² − D = 2^n, where Beukers allows up to four solutions.)

- **k = 1 or 2** gives D = 1 or 3, and a remainder check mod 8 leaves only the trivial n = k. **k = 0** gives 2^n itself, which is never a square for odd n.

## The math

```
Apéry's only exception is D = 7:
  D = 2^k − 1 = 7 only for k = 3, so every k ≥ 4 is covered
  the two solutions for k ≥ 4 are distinct: x = 1 and x = 2^(k−1) − 1 ≥ 7

k = 1:  x² + 1 = 2^n     x² + 1 ≡ 1 or 2 (mod 4)    ⇒ n = 1 = k
k = 2:  x² + 3 = 2^n     x² + 3 ≡ 3, 4 or 7 (mod 8) ⇒ n ≤ 2 = k
```

## The numbers

```
2^5  − 2^3 + 1 = 25    = 5²
2^7  − 2^3 + 1 = 121   = 11²
2^15 − 2^3 + 1 = 32761 = 181²
```

## Validation

The proof covers all n. This script is a numerical check: it tries every odd n below 1200 and every k from 0 to n − 1, and confirms that only the three known cases give a square.

```python
from math import isqrt

found = []
for n in range(1, 1200, 2):                  # odd n
    for k in range(0, n):                    # k = n would give the trivial 1 = 1^2
        v = 2**n - 2**k + 1
        if isqrt(v) ** 2 == v:
            found.append((n, k, isqrt(v)))

assert found == [(5, 3, 5), (7, 3, 11), (15, 3, 181)]
print("odd n < 1200:", found)

# the two solutions Apery's bound leaves room for, when k >= 4
for k in range(4, 60):
    assert 1 + (2**k - 1) == 2**k                              # n = k
    assert (2**(k - 1) - 1)**2 + (2**k - 1) == 2**(2*k - 2)    # n = 2k - 2, even
```
