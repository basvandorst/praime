# Puzzle 1257: Is 2^p − 7 composite for every prime p?

> **In short:** All 12 known n with 2ⁿ − 7 prime are composite, and Sebastián Martín Ruiz asked whether 2ᵖ − 7 is always composite for prime p. We proved that small primes force n into just 8 of the 60 classes mod 60. 5 of those 8 classes hold only multiples of 3 or 5, which is why 10 of the 12 known n are. A prime p can only use the other 3 classes (19, 31, 43 mod 60). There is no covering set that rules out prime p, and a calibrated heuristic expects 2 to 3 primes 2ᵖ − 7 below the searched limit, with more appearing forever. So the claim is almost certainly false. Finding none so far has a chance of about 6 to 13%.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1257.htm)

**Status:** first answer (Q2) · partial proof + heuristic (no counterexample found; Q1 not attempted)

## The question

2ⁿ − 7 is prime for n = 39, 715, 1983, 2319, 2499, 3775, 12819, 63583, 121555, 121839, 468523 and 908739 (OEIS A059609). Every one of these n is composite. Q1 asks for the next n. Q2 asks for a proof that 2ᵖ − 7 is composite for every prime p > 2, or a counterexample.

## What the page had vs ours

| | On the page | Ours |
|---|---|---|
| Q2 | the observation only | **the classes allowed for n are proved; a covering-set proof is impossible; heuristic says the claim is false** |
| Why the known n are composite | not explained | 5 of the 8 allowed classes mod 60 are multiples of 3 or 5 |
| Expected number of prime p ≤ 908731 | — | 2.1 to 2.7 (zero has a 6–13% chance) |

## How we found it

We used two earlier results. In [puzzle 1145](../results/1145.md) a **covering set** (a few primes, one of which always divides the number) made k·2ⁿ + 1 composite for every odd n. In [puzzle 170](../results/170.md) the **order of 2** mod a prime turned a divisibility condition into a condition on n. So we first asked: does a covering set exist for 2ᵖ − 7 when p is prime?

For each prime q, q divides 2ⁿ − 7 exactly when n is in one class mod the order of 2 mod q. With q = 3, 5, 11, 13 and 61 this already rules out 52 of the 60 classes mod 60. But prime p (except for a few small ones) only falls in the 16 classes coprime to 60, and 3 of those survive. Adding every q below 30000 and going up to modulus 55440 does not close the gap: 1972 of the 11520 classes coprime to 55440 are still free. So no covering set exists for these moduli, and the surviving share stays near 17%, nowhere near zero.

Without a covering set the question becomes "how many should we expect?". That is the [puzzle 1204](../results/1204.md) method: a Hardy–Littlewood style count with the small-prime factors done exactly.

## The math

**Forced classes (proof).** The table gives the n for which q divides 2ⁿ − 7:

```
q = 3 :  n ≡ 0  (mod 2)        q = 13:  n ≡ 11 (mod 12)
q = 5 :  n ≡ 1  (mod 4)        q = 61:  n ≡ 49 (mod 60)
q = 11:  n ≡ 7  (mod 10)
```

So 2ⁿ − 7 (n > 6) can only be prime if n mod 60 is one of **3, 15, 19, 31, 39, 43, 51, 55**. Five of these (3, 15, 39, 51, 55) are multiples of 3 or 5, and 10 of the 12 known n lie in them. A prime p > 61 has to be **19, 31 or 43 mod 60**. So the pattern on the page is real, but it is a bias, not a rule: the small primes push the survivors towards multiples of 3 and 5.

**No covering set.** A proof by covering set would need finitely many q whose classes cover every class coprime to some modulus M. For M = 55440 and all q < 30000, 1972 of the 11520 classes stay uncovered. The share of uncovered classes drops only slowly as M and q grow, so a covering set that does the job is very unlikely to exist.

**Expected count.** Sieve n ≤ 908739 with every prime q < 200000. A number N = 2ⁿ − 7 with no factor below Q is prime with probability about e^γ·ln Q / ln N. Summing gives:

```
all n ≤ 908739         expected 16.0    observed 12      (the model is calibrated)
prime n ≤ 908731       expected 2.74    observed 0       P(none) = e^−2.74 = 6%
scaled by 12/16        expected 2.06                     P(none) = 13%
```

Prime exponents are actually a bit better off than average: 6.3% of them survive the sieve against 4.8% of all n. They lose only because primes are rare. The expected number grows like 1.93·ln ln X, roughly 3.2 primes for p ≤ 10⁷ and 4.3 for p ≤ 10¹², and without bound after that. So we expect infinitely many primes p with 2ᵖ − 7 prime. The first one is probably not far beyond the current search limit, but each test is on a number with over 270,000 digits.

**What this does not settle.** This is a heuristic. It cannot rule out a hidden reason that we did not find. The answer to Q2 is: the claim cannot be proved by the usual method (no covering set), and the evidence for it (zero hits) is about as likely as a 1-in-8 chance. Q1, the next n beyond 908739, needs a large PRP search that we did not run.

## Verify it yourself

This script checks the forced classes, the small cases, the uncovered classes mod 55440 and the heuristic counts. Run it after `pip install sympy numpy` (about 3 seconds).

```python
from math import gcd, exp, log
from sympy import isprime, primerange, n_order, discrete_log
import numpy as np

# 1. Five small primes and the classes of n they rule out (q | 2^n - 7 exactly for these n).
rules = {3: (0, 2), 5: (1, 4), 11: (7, 10), 13: (11, 12), 61: (49, 60)}
for q, (r, d) in rules.items():
    assert all(((pow(2, n, q) - 7) % q == 0) == (n % d == r) for n in range(1, 241))

# 2. All n: 8 of the 60 classes survive, and 5 of those 8 are multiples of 3 or 5.
alive = [c for c in range(60) if all(c % d != r for r, d in rules.values())]
assert alive == [3, 15, 19, 31, 39, 43, 51, 55]
assert [c for c in alive if gcd(c, 15) > 1] == [3, 15, 39, 51, 55]

# 3. So a prime p > 61 can give a prime 2^p - 7 only if p = 19, 31 or 43 (mod 60).
assert [c for c in alive if gcd(c, 60) == 1] == [19, 31, 43]
known = [39, 715, 1983, 2319, 2499, 3775, 12819, 63583, 121555, 121839, 468523, 908739]
assert all(n % 60 in alive for n in known)
assert sum(n % 60 in (3, 15, 39, 51, 55) for n in known) == 10

# 4. Small cases: 2^n - 7 is prime for n < 2500 only at the first five known n, none of them prime.
assert [n for n in range(3, 2500) if isprime(2**n - 7)] == known[:5]

# 5. No covering set on prime exponents: modulo 55440, every q < 30000 together still leaves
#    1972 of the 11520 classes coprime to 55440, so prime exponents in those classes are never ruled out.
M, Q0 = 55440, 30000
kill = []
for q in primerange(3, Q0):
    if q == 7:
        continue
    d = n_order(2, q)
    try:
        kill.append((d, discrete_log(q, 7, 2) % d))
    except ValueError:
        pass
units = [c for c in range(M) if gcd(c, M) == 1]
left = [c for c in units if all(c % d != r for d, r in kill if M % d == 0)]
assert len(units) == 11520 and len(left) == 1972

# 6. Heuristic count. Sieve n <= 908739 by every q < Q; a survivor N = 2^n - 7 is prime with
#    probability about e^gamma * ln Q / ln N (Mertens). The model must reproduce the 12 known hits.
X, Q = 908739, 200000
survive = np.ones(X + 1, bool)
for q in primerange(3, Q):
    if q == 7:
        continue
    d = n_order(2, q)
    try:
        survive[discrete_log(q, 7, 2) % d::d] = False
    except ValueError:
        pass
n = np.arange(X + 1)
weight = exp(0.5772156649) * log(Q) / (np.maximum(n, 1) * log(2))
is_p = np.zeros(X + 1, bool)
is_p[list(primerange(2, X + 1))] = True
all_n = weight[20:][survive[20:]].sum()
prime_n = weight[20:][survive[20:] & is_p[20:]].sum()
assert all(survive[k] for k in known)
print("expected hits, all n <= 908739:   %.1f   (observed 12)" % all_n)
print("expected hits, prime n <= 908731: %.2f  (observed 0), chance of zero %.0f%%"
      % (prime_n, 100 * exp(-prime_n)))
print("scaled by 12/%.1f: %.2f, chance of zero %.0f%%"
      % (all_n, prime_n * 12 / all_n, 100 * exp(-prime_n * 12 / all_n)))
```
