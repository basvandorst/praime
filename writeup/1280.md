# Puzzle 1280: Stairways and Keller cycles of Sierpiński and Riesel numbers

> **In short:** A Sierpiński (or Riesel) number N with covering set CS gives two families with the same covering set: the "stairway" N + jP (j = 2, 4, 6, …) and the cycle N → (2N + P) mod 2P, where P is the product of the primes in CS and M = lcm ord_p(2) is the length of the cycle. The page asks (Q1) whether the two families can share an element other than the starting number and (Q2) how large Nmax − Nmin can be in a cycle. (1) On odd numbers mod 2P the map is multiplication by 2 mod P, so the cycle is the set of the M odd numbers below 2P that are ≡ 2ⁱN (mod P). (2) Every stairway term is above 2P, so Q1 is no: the only cycle member in the class of N mod 2P is N mod 2P itself, the starting number when N < 2P. (3) The conversion R = 2P − S maps the cycle onto the cycle of a Riesel number, so Nmax = 2P − Rmin and Nmax − Nmin = 2P − Smin − Rmin < 2P. Smin is the least Sierpiński number in the cycle and Rmin the least Riesel number in the mirrored cycle. (4) For the covering set {3, 5, 7, 13, 17, 241} there are exactly 2 Sierpiński cycles; the largest range is 2P − (271577 + 509203) = 10404030. For {3, 5, 7, 13, 19, 37, 73} there are 4; the largest range is 2P − (78557 + 790841) = 139231472. In the standard catalogue of Brier numbers every cycle spans between 99.17 % and 99.99965 % of 2P.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1280.htm)

**Status:** answered (Q1 no, proof; Q2 exact formula, proof; complete cycle lists for the two smallest covering sets, computed)

## The question

N is odd and N·2ⁿ + 1 (Sierpiński) or N·2ⁿ − 1 (Riesel) is divisible by a prime from the covering set CS for every n ≥ 1. Let P be the product of the primes in CS and M the least common multiple of their orders of 2. The page's calculator produces

- the **stairway** N_j = N + j·P, j = 2, 4, 6, …;
- the **Keller cycle** N → (2N + P) mod 2P, which returns after M steps;
- the **conversion** R = 2P − S between Sierpiński and Riesel numbers.

Q1: can the stairway share an element with the Keller cycle, other than the starting number when it is the cycle's Nmin? Q2: in a Keller cycle, how large can Nmax − Nmin be?

No contribution is on the page. The sibling puzzle [1279](https://www.primepuzzles.net/puzzles/puzz_1279.htm) uses the same cycle for the example 19964725987718971 → 150870306352861.

## How we found it

We wrote the Keller map in residues. Mod P it doubles the number. Mod 2 it gives an odd number. So the whole cycle is just the doubling orbit of N mod P, written as odd numbers below 2P. Once that is clear, Q1 is a size comparison. For Q2, the conversion R = 2P − S commutes with the Keller map, so it maps the top of a Sierpiński cycle to the bottom of a Riesel cycle. All claims were then checked on the classical numbers, on the page's own example and on every Brier number in Keller's catalogue ([`references/Catalogue.txt`](../references/Catalogue.txt)).

## The math

Notation: CS is a set of odd primes, m_p = ord_p(2), M = lcm m_p, P = ∏ p. The sign s is +1 for Sierpiński and −1 for Riesel. An odd N is *covered* if for every n some p ∈ CS divides N·2ⁿ + s. Since 2ⁿ mod p has period m_p, this depends only on n mod M. The calculator's sets are minimal, so every p ∈ CS divides some N·2ⁿ + s, hence p ∤ N.

**Step 1 (proved): the cycle is the doubling orbit.** Let K(x) = (2x + P) mod 2P. For odd x, K(x) is odd and K(x) ≡ 2x (mod P). By the Chinese remainder theorem, the odd residues mod 2P correspond one to one to the residues mod P, and K corresponds to x ↦ 2x mod P. So the k-th member is c_k = the odd number in (0, 2P) that is ≡ 2^k·N (mod P). The cycle closes after t steps exactly when 2^t·N ≡ N (mod p) for every p ∈ CS, that is (because p ∤ N) when m_p | t for all p, that is when M | t. So the cycle has exactly M distinct members, all odd and below 2P, and c_M = N mod 2P. If the input N is above 2P (like the 22-digit Brier number on the page), N itself is not on the cycle; N mod 2P is.

**Step 2 (proved): the covering is kept.** Mod p, c_k·2ⁿ + s ≡ N·2^(n+k) + s. So every member is covered by the same set, with each class shifted by k. The same holds for N + jP with j even: it is odd and ≡ N (mod P). A covered number is a Sierpiński (Riesel) number unless some c·2ⁿ + s equals a prime of CS, which can only happen for c below max(CS).

**Step 3 (proved): Q1.** Every stairway term N + jP with j ≥ 2 is at least N + 2P > 2P, and every cycle member is below 2P. So the stairway and the cycle never meet. More generally, the stairway extended both ways, {N + jP : j even}, is the class of N mod 2P, and by Step 1 the cycle has exactly one member in that class, N mod 2P. When N < 2P that member is N itself, the exception the question names. Put together, the M stairways rooted at c_1, …, c_M are pairwise disjoint. Their union is the set of all odd k with k ≡ 2ⁱN (mod P) for some i, which is every number whose covering is a shift of N's covering. The cycle members are the least elements of these M classes mod 2P.

**Step 4 (proved): the mirror.** For odd x in (0, 2P), K(2P − x) = (P − 2x) mod 2P, and 2P − K(x) ≡ −2x − P ≡ P − 2x (mod 2P), with both sides in (0, 2P). So K(2P − x) = 2P − K(x): the conversion x ↦ 2P − x maps the Keller cycle of N onto the Keller cycle of 2P − N. Mod p, (2P − x)·2ⁿ − s ≡ −(x·2ⁿ + s), so the mirrored cycle is covered by the same set with the opposite sign. A Sierpiński cycle mirrors to a Riesel cycle and vice versa, and the two ranges are equal.

**Step 5 (proved): Q2.** Let Smin = min of the cycle and Rmin = min of the mirrored cycle. Then Nmax = 2P − Rmin, so

```
Nmax − Nmin = 2P − Smin − Rmin.
```

Smin is the least covered number of the cycle's type and Rmin the least covered number of the opposite type in the mirror, so the range is always below 2P. In terms of the orbit O = {2ⁱN mod P}, let a be its largest element below P/2 and b its smallest element above P/2. Then Smin = 2b − P, Nmax = 2a + P, and Smin + Rmin = 2(b − a): the deficit is twice the gap of O that contains P/2.

**Step 6 (computed): the largest range for a given covering set.** For a fixed CS the covered residues mod 2P are finite. Each one corresponds to a choice of one class a_p (mod m_p) per prime whose union covers Z/M, with N ≡ −s·2^(−a_p) (mod p). They split into Keller cycles, and the largest possible range is 2P − min over the cycles of (Smin + Rmin). We enumerated all class choices for the two smallest covering sets:

| CS | P | M | covered residues | cycles | Smin of each cycle (Rmin of its mirror) | largest range |
|---|---|---|---|---|---|---|
| {3, 5, 7, 13, 17, 241} | 5592405 | 24 | 48 | 2 | 271577 (509203), 271129 (992077) | 10404030 = 2P − 780780 (93.0 % of 2P) |
| {3, 5, 7, 13, 19, 37, 73} | 70050435 | 36 | 144 | 4 | 78557 (790841), 8184977 (777149), 12756019 (1715053), 2510177 (12000697) | 139231472 = 2P − 869398 (99.4 % of 2P) |

So 271129 and 509203 are the least Sierpiński and the least Riesel number covered by {3, 5, 7, 13, 17, 241}. The longest cycle of that set is the Sierpiński cycle that mirrors the Riesel cycle of 509203. For {3, 5, 7, 13, 19, 37, 73} the least Sierpiński number is 78557, and its cycle has the largest range.

**Step 7 (heuristic, checked): typical size.** If the M members of a cycle were random odd numbers below 2P, then Rmin·(M + 1)/2P would be close to an exponential variable with mean 1 and median ln 2 = 0.693. Brier numbers in the catalogue were selected for a small Smin, while the mirror's Rmin was not selected. Over the catalogue cycles (combined covering set, M = 288 to 720), Rmin·(M + 1)/2P has mean 1.016 and median 0.669. So the range is typically 2P·(1 − 1/(M + 1)) − Smin, and in the catalogue it lies between 99.1731 % (Clavier 7) and 99.99965 % (Gurisatti 84) of 2P.

**Side results on Keller's catalogue (computed).** The catalogue has 283 basic entries. An entry is a number k together with a pair of covering sets, and 31 numbers appear twice with different pairs (for example Gurisatti 2 and 3), so there are 252 distinct k. Every entry is the least member of its Keller cycle for the combined covering set. No two different basic k with the same P lie in the same cycle or in mirrored cycles. Each of the catalogue's 7 "duplicates" is either the same number again (Clavier 12, Vantieghem 1, Gallot 4, Gallot 5) or a member of a basic number's class: Gurisatti 90 and Wesołowski 2 lie in the mirrored cycles of Gurisatti 84 and Wesołowski 1, and Wesołowski 3 lies in the cycle of Wesołowski 1. So the catalogue lists one number per pair of mirrored Keller cycles, always the least one. Two slips in the catalogue:

- Gallot 6 (k = 6752111260707276586600527347): the listed Riesel set {3, 13, 19, 37, 97, 109, 241, 257} leaves 140 of the 720 classes of n uncovered. The set {3, 7, 13, 19, 37, 73, 97, 109, 241, 257} covers them. Its two extra primes are in the Sierpiński set, so the listed P is right.
- Gurisatti 57, 85, 88, 122, 178: the listed P = 33241542480794255062005345795 belongs to sets with 97. The listed sets have 673 instead, so P should be 230634619480149831512676265155.

## Validation

[`code/p1280_keller.py`](code/p1280_keller.py) uses plain integers only (orders by trial division). It checks, for 78557, 271129, 509203, the puzzle-1279 example, A206001 (11679013547), A206430 (10909924841) and the page's Brier number (each side and combined; the page's M and P values are asserted):

- the covering over a full period;
- the cycle length M and that the cycle closes at N mod 2P;
- the covering of every member;
- Q1 against the first 20 stairway terms, and that exactly one member lies in N's class;
- the mirror covering with the opposite sign;
- the identity of Step 5 and the gap formula.

It then enumerates all class choices for the two covering sets of Step 6 and checks every resulting cycle the same way. Finally it parses the whole catalogue and checks the covering of both sides of every Brier number, the minimum property, the duplicates, the slips and the statistics of Step 7. It runs in about 3 minutes.
