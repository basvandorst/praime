# Puzzle 808: A palindromic prime that stays a palindrome in many bases

> **In short:** The record palindromic prime was a palindrome in 82 bases. The construction: (1) where p has three digits in base b, it is the palindrome [1, c, 1] exactly when b divides p − 1; (2) so search 15-digit palindromic primes with p ≡ 1 (mod 720720), which gives p − 1 many divisors near √p. This gives 108864424468801, a proven prime that is a palindrome in 227 bases.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_808.htm)

**Status:** beaten · proven prime

## The question

A palprime is a prime that is a palindrome in base 10. Some palprimes are palindromes in other bases too. Example: 191 is 515 in base 6 and 232 in base 9, so it is a palindrome in 3 bases (6, 9 and 10). The puzzle asks for palprimes that stay palindromic in as many bases as possible (counting base 10, and leaving out the trivial base p − 1 where every number is "11").

## Current record vs ours

| | Palprime | Bases where it is a palindrome |
|---|---|---|
| Current record (E. Vantieghem) | 1002113112001 | 82 |
| **Ours** | 108864424468801 | **227** |

## How we found it

Look at Vantieghem's long base lists: almost all the bases are large, around √p, where p has exactly three digits. A three-digit palindrome in base b looks like [a, c, a], and the simplest kind, [1, c, 1], means p = b² + c·b + 1, so p − 1 = b·(b + c). In other words: **every divisor b of p − 1 in the right range gives a palindromic base.**

So instead of searching palindromes at random, we looked only at 15-digit palindromic primes with p ≡ 1 (mod 720720), so that p − 1 is divisible by many small numbers and has a huge number of divisors near √p. Among those, 108864424468801 has the most.

## The math

For base b with √(p/2) < b ≤ √(p − 1), p has three digits in base b. It is the palindrome [1, c, 1] exactly when

```
p = b² + c·b + 1   with 0 ≤ c < b     ⇔     b divides p − 1   (and c = (p − 1)/b − b)
```

So the number of such bases is the number of divisors of p − 1 in a narrow window around √p. More generally a three-digit palindrome [a, c, a] needs b | p − a with leading digit a = ⌊p/b²⌋. Bases between p^(1/4) and p^(1/3) give 4 digits, and any palindrome with an even number of digits in base b is divisible by b + 1, so a prime is never one. Bases below p^(1/4) give 5 or more digits and are checked one by one (only base 10 works for ours).

Our prime:

```
p     = 108864424468801            (palindrome, prime)
p − 1 = 2^6 · 3^2 · 5^2 · 7 · 11 · 13 · 37 · 43 · 47 · 101
bases: 221 of the form [1, c, 1],  5 of the form [a, c, a] with a = 10, 105, 1669, 20311, 27937,  plus base 10
```

## Validation

This script counts every base b from 2 to p − 2 in which p is a palindrome, using the three-digit shortcut for large bases and a direct check for small ones. It also re-counts Vantieghem's prime to show the convention matches.

```python
import math
import numpy as np
from sympy import isprime

def palindromic_bases(p):
    count = 0
    r4 = int(round(p ** 0.25)) + 2
    for b in range(2, r4 + 1):                         # small bases: write p out in base b
        d, x = [], p
        while x:
            d.append(x % b)
            x //= b
        count += d == d[::-1]
    # bases between p^(1/4) and p^(1/3) give 4 digits: an even-length palindrome is divisible by b+1, never prime
    lo, hi = max(r4 + 1, int(p ** (1 / 3)) + 1), math.isqrt(p)
    b = np.arange(lo, hi + 1, dtype=np.int64)          # bases where p has exactly 3 digits
    lead, last = p // (b * b), p % b                    # first and last base-b digit
    count += int(np.count_nonzero((lead == last) & (lead >= 1) & (lead < b)))
    # bases above sqrt(p) give 2 digits; a 2-digit palindrome [a, a] = a(b+1) is never prime
    # (except base p-1, which the puzzle leaves out)
    return count

for p, expected in [(1002113112001, 82), (108864424468801, 227)]:
    assert str(p) == str(p)[::-1] and isprime(p)       # palindromic prime (sympy is exact below 2^64)
    assert palindromic_bases(p) == expected
    print(p, "is a palindrome in", expected, "bases")
```
