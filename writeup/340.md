# Puzzle 340: A prime hidden inside its own square

> **In short:** The record prime p that appears as a digit block inside p² had 1339 digits. The construction: (1) aim for p² = "55", then p, then b digits; (2) this gives p ≈ 10^b·(1 + √22001)/2; (3) test b until p is prime. This gives a 3925-digit p (b = 3923), beating 1339 digits; PRP.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_340.htm)

**Status:** beaten (Q1) · PRP (probable prime)

## The question

Find primes p whose decimal digits appear, as one unbroken block, inside the digits of p². Example: 50385563791193² = 2538705038556379119304363249, and 50385563791193 sits right there after "25387". Question 1 asks for larger such primes.

## Current record vs ours

| | Prime | Digits |
|---|---|---|
| Current record (G. Resta) | 826208…71751 | 1339 |
| **Ours** | p = ⌈10³⁹²³·(1 + √22001) / 2⌉ | **3925** |

## How we found it

Resta's idea, explained on the page, is to aim for a square with a fixed shape: a short prefix k, then p itself, then a tail.

```
p² = k · 10^(…) + p · 10^b + (tail below 10^b)
```

If p is about 10^b times a constant, this is close to a quadratic equation, and its root can be written down directly. We took the prefix k = 55, which gives the clean root (1 + √22001)/2, and simply took p as the first whole number at or above 10^b times that root. Every b gives a candidate with the right shape; we tested candidates for primality until b = 3923 gave a prime.

## The math

Ask for p² = 55·10^(2b+2) + p·10^b + B with 0 ≤ B < 10^b. Dropping B gives a quadratic for p:

```
p² − 10^b·p − 55·10^(2b+2) = 0
p = 10^b · (1 + √(1 + 4·55·100)) / 2 = 10^b · (1 + √22001) / 2
```

Take p = ⌈10^b·(1 + √22001)/2⌉. Then the left-over B = p² − 55·10^(2b+2) − p·10^b is small: 0 ≤ B < 10^b holds for our b (the script checks it). So p² is written as

```
"55"  followed by the digits of p,  followed by the b digits of B (padded with zeros)
```

and p appears inside p² automatically. Only primality is left to luck.

## The number

```
b = 3923,   p = ⌈10^3923 · (1 + √22001) / 2⌉   (3925 digits, starts 746636…)
```

p passes the BPSW test and 25 Miller-Rabin rounds: a probable prime, not a proven one.

## Validation

This script rebuilds p with exact integer square roots, checks the shape of p², checks that p appears inside p², and tests p for primality.

```python
import gmpy2
from gmpy2 import mpz, isqrt

b = 3923
ten_b = mpz(10) ** b

# p = ceil(10^b * (1 + sqrt(22001)) / 2), computed exactly with an integer square root
p = (ten_b + isqrt(22001 * ten_b * ten_b)) // 2
while p * p - 55 * mpz(10) ** (2 * b + 2) - p * ten_b < 0:
    p += 1                                            # round up until the left-over is non-negative

B = p * p - 55 * mpz(10) ** (2 * b + 2) - p * ten_b   # the tail of p^2
assert 0 <= B < ten_b                                 # tail fits in b digits, so p^2 = "55" + p + tail

s, s2 = gmpy2.digits(p), gmpy2.digits(p * p)
assert len(s) == 3925
assert s2.startswith("55" + s)                        # p sits right after "55" in p^2
assert gmpy2.is_prime(p, 25)                          # probable prime (BPSW + Miller-Rabin)

print("3925-digit probable prime p that appears inside p^2")
```
