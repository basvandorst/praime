# Puzzle 120, Q4: no full-torus primal square for n = 4, 6, 8, 10

> **In short:** Q4 asked for n×n arrangements of 1…n² in which all neighbours, including the mirror cells of the "full torus" condition, sum to primes, for n = 4, 6, 8, 10; a search had found no 6×6 square. The proof: (1) neighbour sums are odd, so parities follow a checkerboard; (2) prime sums above 3 avoid multiples of 3, so the multiples of 3 can never be neighbours and residues 1 and 2 can never touch; (3) a complete search shows that no residue colouring obeys these rules. This proves that no such square exists for n = 4, 6, 8 or 10.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_120.htm)

**Status:** answered (Q4: impossible for every n asked, 4, 6, 8, 10) · proof (residue argument, complete computer check; n = 4 also by hand)

## The question

A primal square is an n×n arrangement of 1, 2, …, n² in which every two horizontally or vertically adjacent numbers sum to a prime. It satisfies the *full torus condition* if, in addition, every number plus the number in the mirror cell, across the vertical or across the horizontal axis, is prime. The definition on the page, written at Rivera's request: in every row the cells at distance y from the left and from the right edge pair up, and in every column the cells at distance y from the top and from the bottom. For n = 4 this adds the wrap-around pairs and turns the grid into the 4×4 torus.

**Q4.** Can you find a primal square that satisfies the full torus condition for n = 4, 6, 8 and 10?

## What the page had vs ours

| n | On the page | Ours |
|---|---|---|
| 4 | — | **impossible** (proof by hand and by the residue argument) |
| 6 | no solution (complete search, Jan 2001) | **impossible** (residue argument, a different proof) |
| 8 | — | **impossible** (residue argument) |
| 10 | — | **impossible** (residue argument) |

The question's own first wording drops the mirror pairs of cells on the main diagonals. Under that reading the residue argument still rules out n = 4 and 6, but not n = 8.

## How we found it

A randomised backtracking search for an 8×8 square found nothing in 6·10⁸ nodes, although a naive count predicts about 10¹⁹ squares. Something structural had to be in the way. The n = 4 proof pointed to it: 14 has too few partners. That obstruction is local, and its global version is mod 3. If every neighbour sum is prime, the 21 multiples of 3 in 1…64 can never be neighbours, and they must cut every path from a number ≡ 1 to a number ≡ 2. In a grid that is this well connected, that cut is too large to exist.

## The math

Let G_n be the graph on the n² cells whose edges are the grid neighbours and the mirror pairs (r, c)–(r, n−1−c) and (r, c)–(n−1−r, c). A full-torus primal square labels the cells bijectively with 1…n² so that every edge has a prime sum.

**Step 1 (proved). Parity.** An edge sum is at least 1 + 2 = 3, so it is an odd prime and the two labels have opposite parity. G_n is bipartite with the checkerboard classes (a mirror pair joins (r, c) and (r, n−1−c), whose coordinate sums differ by n − 1 − 2c, which is odd for even n). So one checkerboard class holds the n²/2 even numbers and the other the odd ones: two possible orientations.

**Step 2 (proved). Residues mod 3.** If the labels a, b of an edge have a + b > 3, then 3 ∤ a + b, so (a mod 3, b mod 3) is not (0, 0), (1, 2) or (2, 1). The sum 3 occurs only for {1, 2}, so at most one edge has residues {1, 2}: the one joining the cell of 1 (odd, residue 1) to the cell of 2 (even, residue 2).

**Step 3 (proved). Counting.** For n = 8 the numbers 1…64 contain, by (parity, residue):

```
           residue 0   residue 1   residue 2
even          10          11          11
odd           11          11          10
```

So a square induces a colouring of the cells with residues 0, 1, 2 such that: the multiples of 3 form an independent set; no 1 touches a 2, except possibly one exceptional edge as in step 2; and each checkerboard class carries exactly the counts above (similarly for n = 4, 6).

**Step 4 (complete search). No such colouring exists.** A backtracking search over all residue colourings that obey steps 1–3 finds none:

| n | orientation 0 | orientation 1 | nodes searched |
|---|---|---|---|
| 4 | none | none | 469 each |
| 6 | none | none | 30451 each |
| 8 | none | none | 9.1·10⁶ each |
| 10 | none | none | 5.3·10¹⁰ each |

For n = 4, 6, 8 two independent programs give the same answer: the C search above and a Python search with row-major cell order (46,105,209 nodes for each orientation of n = 8). For n = 10 only the C search was run (about 30 minutes per orientation). So no full-torus primal square exists for n = 4, 6, 8, 10.

**Step 5 (proved by hand, n = 4). The 14 argument.** For n = 4, G₄ is the 4-dimensional hypercube. The number 14 can only sit next to 3, 5, 9 and 15 (14 + x prime), and every pair of its neighbours has exactly one other common neighbour; the six such cells are distinct. For the three pairs that contain 5, that common neighbour must be an even number e with e + 5 and e + x prime, and only e = 2 and e = 8 work. Three cells cannot all be filled from {2, 8}.

**What this does not settle.** Under the first wording on the page (mirror pairs of diagonal cells dropped), a residue colouring for n = 8 exists, so that weaker version is open for n = 8 and 10.
