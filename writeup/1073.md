# Puzzle 1073: p·q = 1 + k² for consecutive primes

> **In short:** The page asks for a proof that no two consecutive primes p < q satisfy p·q = 1 + k². It reduces this to a gap condition and notes that a full proof would need a gap bound such as Andrica's conjecture. (1) Write q = p + g. Then p·q = (p + g/2)² − g²/4, and k ≤ p + g/2 − 1 forces (g − 2)² ≥ 4(2p − 1), that is, g ≥ 2 + 2√(2p − 1). (2) The bound is sharp: the Sophie Germain identity 4e⁴ + 1 = (2e² − 2e + 1)(2e² + 2e + 1) gives solutions with g = 4e, exactly the bound (5·13, 41·61, 1201·1301, …), but those primes are never consecutive. (3) No consecutive pair below 10⁷ works (direct check). Above 10⁷ the bound exceeds 8946, while no gap below 4·10¹⁸ exceeds 1476 (complete computation in the literature). So there is no solution with p ≤ 4·10¹⁸. Beyond that, at most O(X^(0.07+ε)) pairs below X can have such a gap; the general case stays open.

## The question

Q1: prove that for two consecutive primes p < q there is no integer k with p·q = 1 + k², or find a counterexample. Q2: the same for the smallest pair of primes, not necessarily consecutive. The page answers Q2 with 2·5 = 3² + 1 (and 2·13 = 5² + 1, 5·13 = 8² + 1). For Q1 it has:

- the solutions with q − p = d, k = d²/2, all with d a multiple of 10 except d = 4;
- the bound q − p > 2√(2p − 1), which would contradict Andrica's conjecture (not proved);
- an empirical comparison with maximal gaps up to 10¹⁰, with no proof.

## The math

**Step 1 (proved): the reduction.** p = 2 fails, since 2·3 − 1 = 5 is not a square. So p, q are odd, k is even, and every odd prime factor of k² + 1 is ≡ 1 (mod 4); so g = q − p ≡ 0 (mod 4). Now p·q = p² + pg = (p + g/2)² − g²/4, so k² = (p + g/2)² − g²/4 − 1 < (p + g/2)², hence k ≤ p + g/2 − 1 and

```
(p + g/2)² − g²/4 − 1 ≤ (p + g/2 − 1)²   ⇔   g²/4 − g + 2 ≥ 2p   ⇔   (g − 2)² ≥ 4(2p − 1).
```

So a solution needs g ≥ 2 + 2√(2p − 1). The script also checks this on all pairs of odd numbers below 2000.

**Step 2 (proved): the bound is sharp.** Equality means k = p + g/2 − 1. With g = 4e this gives p = 2e² − 2e + 1, q = 2e² + 2e + 1 and k = 2e², the Sophie Germain identity 4e⁴ + 1 = (2e² − 2e + 1)(2e² + 2e + 1). Both factors are prime for e = 2, 5, 25, 30, 35, 70, 85, 100, … (pairs 5·13, 41·61, 1201·1301, …; the page's list). For these pairs to be consecutive, the interval (2e² − 2e + 1, 2e² + 2e + 1) of length 4e ≈ 2√(2p) would have to contain no prime.

**Step 3 (computed): p < 10⁷.** For every pair of consecutive primes below 10⁷, p·q − 1 is not a square (exact test), and every gap is below 2 + 2√(2p − 1).

**Step 4 (proved from the literature): 10⁷ ≤ p ≤ 4·10¹⁸.** Here 2 + 2√(2p − 1) > 8946, but every gap below 4·10¹⁸ is at most 1476 (complete computation of Oliveira e Silva, Herzog and Pardi; FACTS 3023). So no solution with p ≤ 4·10¹⁸.

**Step 5 (proved from the literature): beyond.** A solution needs a gap ≥ 2√(2p) > √p after p. The gaps ≥ √x in [x, 2x] have total length O(x^(0.57+ε)) (Järviniemi 2022, arXiv:2212.10965). So there are O(x^(0.07+ε)) of them in each dyadic block and O(X^(0.07+ε)) up to X. Heuristically (Cramér) a gap of length 2√(2p) at p has probability about exp(−2√(2p)/ln p), which is 10⁻²⁴¹ at p = 10⁷ and falls from there, so the sum over p > 10⁷ is below 10⁻²³⁰ and no solution is expected at all.
