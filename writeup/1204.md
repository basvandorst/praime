# Puzzle 1204: Why 51.6% of primes below 15015 mirror to primes

> **In short:** For n = 15015, 51.6% of the primes p < n have 30030 − p prime too; the page asked why, and whether larger n do the same. The explanation: (1) 30030 = 2·3·5·7·11·13; (2) so 30030 − p avoids those factors; (3) Hardy–Littlewood predicts 51.7%. No n with 15015 < n ≤ 2·10⁶ exceeds 50%; the explanation is heuristic.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1204.htm)

**Status:** first answer (Q1, Q2) · heuristic explanation, checked numerically

## The question

For a number n, take the primes p < n and count how many have 2n − p prime as well. For n = 15015, that is 51.6% of them: primes look "symmetric" around 15015. Q1 asks for an explanation. Q2 asks whether larger n behave the same way; Kamenetsky found none above 50% up to 100,000.

## What the page had vs ours

| | On the page | Ours |
|---|---|---|
| Q1 | the observation only | **explained** by the Hardy–Littlewood formula, which predicts 51.7% |
| Q2 | none above 50% up to 10⁵ | **none above 50% for 15015 < n ≤ 2·10⁶**, and a reason why none should exist |

## How we found it

The count is a Goldbach count in disguise: the pairs (p, 2n − p) of primes are exactly the ways to write 2n = 30030 as a sum of two primes. Goldbach counts are known to swing wildly with the small prime factors of 2n, and 30030 is 13#, the product of the first six primes, which is as factor-rich as a number of that size can be.

The effect is simple to see. Take a prime p > 13. Since p is not a multiple of 3 and 30030 is, 30030 − p is not a multiple of 3 either. The same holds for 2, 5, 7, 11 and 13. A random odd number is divisible by 3 a third of the time, by 5 a fifth of the time, and so on, but 30030 − p never is. That alone makes it several times more likely to be prime.

## The math

Hardy and Littlewood's conjectured formula for the number of ways to write an even number 2n as p + q:

```
r(2n) ≈ 2·C₂ · ∏_{q | n, q > 2} (q − 1)/(q − 2) · ∫₂ⁿ dt / (ln t · ln(2n − t)),     C₂ = 0.6601618…
```

For n = 15015 the product over q = 3, 5, 7, 11, 13 is 2 · 4/3 · 6/5 · 10/9 · 12/11 = 3.879, and the whole constant is 5.121. Dividing the predicted count by the number of primes below n gives

```
n          predicted   actual
15015      51.7 %      51.6 %     (905 of 1755 primes)
30030      48.3 %      48.2 %
255255     42.6 %      42.3 %     (17#/2)
```

**Why nothing larger reaches 50%.** The fraction is roughly the constant above divided by ln n. The constant can grow only very slowly, like ln ln n, even for the most factor-rich n (half-primorials such as 15015 and 255255), while ln n keeps growing. So the fraction drifts down, and 15015 is the last half-primorial above 50%. This part is a heuristic: it rests on the unproven Hardy–Littlewood formula, backed by the check up to 2·10⁶.

## Validation

This script counts, for every n up to 2·10⁶ at once, the primes p < n with 2n − p prime (with one FFT convolution), checks the 51.6% for 15015, confirms nothing above 15015 reaches 50%, and computes the Hardy–Littlewood prediction. It takes a few seconds and about 400 MB.

```python
import numpy as np
from math import log
from sympy import primefactors

M = 2_000_000
N = 2 * M + 1
is_prime = np.ones(N, dtype=bool)
is_prime[:2] = False
for i in range(2, int(N**0.5) + 1):
    if is_prime[i]:
        is_prime[i * i::i] = False

# conv[m] = number of ordered pairs (p, q) of primes with p + q = m
f = is_prime.astype(np.float64)
size = 1 << int(np.ceil(np.log2(2 * N)))
conv = np.rint(np.fft.irfft(np.fft.rfft(f, size) ** 2, size)[:N]).astype(np.int64)

n = np.arange(M + 1)
pairs = (conv[2 * n] - is_prime[n]) // 2           # primes p < n with 2n - p prime
below = np.cumsum(is_prime[:M + 1])[n] - is_prime[n]
share = np.where(below > 0, pairs / np.maximum(below, 1), 0)

assert (pairs[15015], below[15015]) == (905, 1755)  # 905 / 1755 = 51.6%
assert not np.any(share[15016:] > 0.5)              # nothing above 50% for 15015 < n <= 2e6

def predicted(n, steps=20000):
    constant = 2 * 0.6601618158
    for q in primefactors(n):
        if q > 2:
            constant *= (q - 1) / (q - 2)
    h = (n - 2) / steps
    integral = sum(h / (log(2 + (i + 0.5) * h) * log(2 * n - 2 - (i + 0.5) * h)) for i in range(steps))
    return constant * integral / below[n]

for m in (15015, 30030, 255255):
    print(m, "actual %.1f%%" % (100 * share[m]), "predicted %.1f%%" % (100 * predicted(m)))
```
