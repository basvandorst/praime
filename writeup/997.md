# Puzzle 997: m − n + s − ⌊ms/n⌋ = 1 for three consecutive primes

> **In short:** Q3 and Q4 come down to one inequality for consecutive gaps: **g_n · g_(n+1) < p_(n+1)**. We prove it unconditionally for every n with p_(n+1) ≤ 4·10¹⁸ except the page's two exceptions n = 3 and n = 8. Below 2·10⁸ we check it directly. Above that, every gap up to 4·10¹⁸ is at most 1476 (the complete gap computation of Oliveira e Silva, Herzog and Pardi), and 1476² is far below p. Beyond that range it holds for all but very few n: from Järviniemi's 2022 bound on large prime gaps, at most O(X^(0.07+ε)) values of n with p_(n+1) ≤ X can fail. A proof for every n would need gaps below √p (Oppermann strength), which is not known even under the Riemann hypothesis.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_997.htm)

**Status:** answered · Q3/Q4 proved for p_(n+1) ≤ 4·10¹⁸ (n ≠ 3, 8) and for all but O(X^(0.07+ε)) n ≤ X; the full statement is open (needs gaps < √p)

## The question

Sebastián Martín Ruiz (April 2020):

1. Prove m − n + s − ⌊ms/n⌋ = 1 for all integers s < n < m iff m − s < √m.
2. Is √m the best bound?
3. Prove that p_(n+2) − p_(n+1) + p_n − ⌊p_(n+2)·p_n/p_(n+1)⌋ = 1 for all n > 1 except n = 3 and n = 8.
4. Then prove p_(n+2) < (1/(p_(n+1) − p_n) + 1)·p_(n+1).

On the page, Oscar Volpatti settled Q1–Q2: the identity holds for all s < n < m exactly when m − s ≤ √(4m + 1) − 1, so √m is not the best bound. Emmanuel Vantieghem and Jan van Delden gave the equivalent form √m − √s ≤ 1. For Q3, Volpatti reduced it to (p_(n+2) − p_(n+1))(p_(n+1) − p_n) < p_(n+1). He derived it from the conjectured bound p_(n+1) − p_n < √p_n and checked n ≤ 30. Vantieghem and van Delden note that Q3 and Q4 then rest on a conjecture. Nobody gave a proof or a range beyond n ≤ 30.

| | Q3 / Q4 |

| **Ours** | **proved for every p_(n+1) ≤ 4·10¹⁸ (n ≠ 3, 8)**; failures up to X number O(X^(0.07+ε)); full proof needs gaps < √p |

## The math

The chain of claims, each validated before the next is used:

| # | Claim | Why | Validated |
|---|---|---|---|
| 1 | for all s < n < m: identity ⇔ (m − s + 1)² ≤ 4m + 1 | Volpatti (page) | all m < 600 (exhaustive; we also ran m < 1500) |
| 2 | Q3 at n ⇔ (★) g_n·g_(n+1) < p_(n+1); Q4 is (★) solved for p_(n+2) | p_(n+1) ∤ p_n·p_(n+2), so the floor bounds are strict (Volpatti) | the first 200 triples and every 4999th below 2·10⁸ (about 2,400) |
| 3 | (★) fails only at n = 3 (5, 7, 11) and n = 8 (19, 23, 29) for p < 2·10⁸ | direct check | all primes below 2·10⁸ |
| 4 | (★) holds for 2·10⁸ < p_(n+1) ≤ 4·10¹⁸ | every gap below 4·10¹⁸ is ≤ 1476, so g_n·g_(n+1) ≤ 1476² = 2178576 < p_(n+1) | theorem from a complete computation (literature) |
| 5 | #{n : p_(n+1) ≤ X, (★) fails} ≪ X^(0.07+ε) | a failure needs a gap ≥ √x near x; Järviniemi bounds the total length of such gaps | theorem (literature + one line) |
| 6 | (★) for all n would follow from g_n < √p_n | √p_n·√p_(n+1) < p_(n+1) (Volpatti) | conditional; RH gives only g ≪ √p·ln p |

**Claim 2.** Write a = p_n, b = p_(n+1), c = p_(n+2). The identity says ⌊ac/b⌋ = c − b + a − 1, that is c − b + a − 1 ≤ ac/b < c − b + a. The right inequality is (b − a)(c − b) > 0, always true. The left one is (b − a)(c − b) ≤ b, and equality is impossible because b is a prime that does not divide ac. So the identity holds iff g_n·g_(n+1) < p_(n+1). Q4, p_(n+2) < p_(n+1)·(1 + 1/g_n), is the same inequality after dividing by g_n.

**Claim 3.** Below 2·10⁸ only the two known exceptions fail: 2·4 = 8 > 7 and 4·6 = 24 > 23. The margin then grows fast. The largest ratio g_n·g_(n+1)/p_(n+1) after the first few primes is 0.68 (at 199, 211, 223), and above p = 1000 it is 18·24/2179 = 0.198 (at 2161, 2179, 2203). Typical values are about (ln p)²/p.

**Claim 4.** Oliveira e Silva, Herzog and Pardi (2014) computed every prime gap below 4·10¹⁸. The largest is 1476, after 1425172824437699411 (FACTS 3023 and 10206, OEIS A005250). So for 2·10⁸ < p_(n+1) ≤ 4·10¹⁸ both gaps are at most 1476, and g_n·g_(n+1) ≤ 2178576 < 2·10⁸ < p_(n+1). With claim 3 this proves Q3 and Q4 for every n with p_(n+1) ≤ 4·10¹⁸, n ≠ 3, 8.

**Claim 5.** Suppose (★) fails at n with p_(n+1) ∈ (x, 2x]. Then max(g_n, g_(n+1)) ≥ √p_(n+1) > √x. So there is a gap of length ≥ √x that starts in [x/2, 2x]. Järviniemi (arXiv:2212.10965, 2022) proves

  Σ_(p_n ∈ [x, 2x], p_(n+1) − p_n ≥ √x) (p_(n+1) − p_n) ≪ x^(0.57+ε).

So a dyadic block holds at most O(x^(0.57+ε)/√x) = O(x^(0.07+ε)) such gaps, and each gap accounts for at most two failures. Summing over the blocks, at most O(X^(0.07+ε)) values of n with p_(n+1) ≤ X fail (★). Heath-Brown's earlier exponent 3/5 (arXiv:1906.09555) would give X^(1/10+ε). So the identity holds for almost all n, with very few possible exceptions.

**Claim 6.** A full proof needs control of every single gap. g_n < √p_n for large n (implied by Oppermann's conjecture) would be enough, as Volpatti noted. Andrica's conjecture is not: it only gives g_n < √p_n + √p_(n+1), and a product below about 4p. Even the Riemann hypothesis gives only g_n = O(√p_n·ln p_n). Unconditionally the best gap bound is p^0.525 (Baker–Harman–Pintz), which gives a product of about p^1.05. So Q3 for all n is open, and it is true wherever it can be checked.

**Beyond 4·10¹⁸ (conditional).** The published list of 85 maximal gaps (OEIS A005250; the 85th is 1854 after 101412319996363309069, found in 2026) comes from distributed searches with no refereed statement of completeness (FACTS 3023). If that list is complete, every gap below 1.01·10²⁰ is at most 1854, and the same argument extends the result to p < 1.01·10²⁰, since 1854² ≈ 3.4·10⁶ and (2·1854)² ≈ 1.4·10⁷ are both far below 2·10⁸.
