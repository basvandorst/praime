# Puzzle 516: Why 59 = 5·9 + π(5·9) is unique

> **In short:** It was claimed, without proof, that 59 = 5·9 + π(45) is the only n > 1 with n = P(n) + π(P(n)), P the digit product. The proof: (1) a zero digit gives n = 0; (2) otherwise n ≥ a·10^(d−1), while n < 2P ≤ 2a·9^(d−1); (3) so (10/9)^(d−1) < 2, and n has at most 7 digits. A check of all n below 10⁷ finds only 59, which proves the claim.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_516.htm)

**Status:** first answer (Q1) · proof

## The question

Let P(n) be the product of the digits of n and π(x) the number of primes up to x. Then 59 = P(59) + π(P(59)) = 45 + 14. Question 1 asks to prove that 59 is the only n > 1 with

```
n = P(n) + π(P(n))
```

## What the page had vs ours

| | Answer |
|---|---|
| On the page | the claim, no proof |
| **Ours** | **proof**: no solution can have more than 7 digits, and below 10⁷ only 59 works |

## How we found it

The right side depends only on the digit product, and a digit product is small: each digit is at most 9, while each place in n is worth a factor 10. So the right side falls behind n as n gets longer. We made that precise, which gave a bound of 7 digits, and then checked every number below 10⁷ by computer.

## The math

If some digit is 0, then P(n) = 0 and the right side is 0, so n = 0. Otherwise, let n have d digits with leading digit a. Then

```
n ≥ a · 10^(d−1)                     (n starts with the digit a)
P(n) ≤ a · 9^(d−1)                   (every other digit is at most 9)
π(P) < P                             (fewer primes than numbers up to P)
⇒ n = P + π(P) < 2P ≤ 2a · 9^(d−1)
```

Combining the first and last lines gives a·10^(d−1) < 2a·9^(d−1), that is (10/9)^(d−1) < 2. Since (10/9)⁷ ≈ 2.09 > 2, this forces d − 1 ≤ 6, so n has at most 7 digits.

## The numbers

```
59:   P = 5 · 9 = 45,   π(45) = 14  (2, 3, 5, …, 43),   45 + 14 = 59
```

## Validation

This script computes P(n) + π(P(n)) for every n below 10⁷ at once with numpy, and confirms that 59 is the only n > 1 where it equals n. It also checks the inequality that rules out 8 or more digits.

```python
import numpy as np

N = 10**7
n = np.arange(N, dtype=np.int64)

P = np.ones(N, dtype=np.int64)                 # product of the digits of n
rest = n.copy()
while rest.any():
    digit = rest % 10
    P = np.where(rest > 0, P * digit, P)       # multiply in each digit (leading zeros are not digits)
    rest //= 10
P[0] = 0

limit = 9**7                                   # the largest possible digit product below 10^7
sieve = np.ones(limit + 1, dtype=bool)
sieve[:2] = False
for i in range(2, int(limit**0.5) + 1):
    if sieve[i]:
        sieve[i * i::i] = False
pi = np.cumsum(sieve)                          # pi[x] = number of primes up to x

solutions = np.flatnonzero((P + pi[P] == n) & (n > 1))
assert solutions.tolist() == [59]
assert (10 / 9) ** 7 > 2                       # so 8 or more digits are impossible
print("only solution below 10^7:", solutions.tolist())
```
