# Puzzle 247: Eight consecutive Smith numbers

> **In short:** The page's Q1 ("find more terms to A059754") stops at a(7) = 164736913905, the first run of 7 consecutive Smith numbers (J. K. Andersen, 2008). OEIS now lists **a(8) = 8090674745553**, found by Max Alekseyev in 2010. We checked that 8090674745553 … 8090674745560 are 8 consecutive Smith numbers and that the numbers just before and after are not. That it is the *smallest* such run is Alekseyev's result, not rechecked here. For Q2 the page already has the last OEIS term (Resta's 1979414080360).

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_247.htm)

**Status:** answered · Q1 extended from the literature (OEIS A059754, Alekseyev 2010), verified; minimality not rechecked

## The question

A Smith number is a composite whose digit sum equals the digit sum of its prime factors, counted with multiplicity. A059754(n) is the start of the first run of n consecutive Smith numbers. The page gives 4, 728, 73615, 4463535, 15966114 and 2050918644 (Rivera), then 164736913905 (Andersen, 2008), and asks for more terms (Q1).

Q2 asks the same with primes allowed. The page ends with Resta's 9th term, 1979414080360, now OEIS A235812.

## How we found it

The term came from a scan of all lists on the puzzle pages against the local OEIS copy (`references/oeis/`, see CLAUDE.md). The scan looks for pages whose list is a prefix of an OEIS sequence whose next term appears nowhere on the page.

For Q2, OEIS A235812 ends at 1979414080360, which the page already has.

## The math

The run is 8090674745553 + k for k = 0 … 7. Each number is composite with matching digit sums, and 8090674745552 and 8090674745561 are not Smith numbers. The verify script recomputes all eight terms a(1) … a(8) from their factorisations.

## Verify it yourself

`writeup/code/p247_verify.py` factors each number with sympy. It checks that every a(n) starts a run of at least n Smith numbers and that a(n) − 1 is not a Smith number.
