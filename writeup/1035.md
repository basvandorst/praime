# Puzzle 1035: x = τ(σ(x))·σ(τ(x))

> **In short:** There are no more roots. Two classical inequalities show τ(σ(x))·σ(τ(x)) < x for every x ≥ 10⁶: the number of divisors is at most 8.447·x^(1/4), and the sum of divisors is at most x(1 + ln x). Below 10⁶ we checked every x two ways. **1, 468 and 3240 are the only roots.**

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1035.htm)

**Status:** answered · proof (complete)

## The question

Ianakiev: the only roots of x = τ(σ(x))·σ(τ(x)) up to 10⁸ are x = 1, 468 and 3240. Can you find more?

On the page, Fred Schneider (24 April 2021) compares τ and σ with superabundant numbers and writes "I can say with certainty that there are no other solutions". His argument checks a few sample numbers and does not bound the expression for every x. Here is a complete proof.

## The math

**Lemma 1 (divisor count).** For every m ≥ 1, τ(m) ≤ c·m^(1/4) with

```
c⁴ = ∏_(p < 16) max_a (a+1)⁴ / p^a = (6⁴/2⁵)·(4⁴/3³)·(3⁴/5²)·(2⁴/7)·(2⁴/11)·(2⁴/13) = 127401984 / 25025,
c  = 8.44696…
```

*Proof.* τ(m)⁴/m = ∏_(p^a ‖ m) (a+1)⁴/p^a, and each factor is at most max_a (a+1)⁴/p^a. For p ≥ 17 that maximum is 1 (at a = 0), because (a+1)⁴ ≤ 16^a. For p = 2, 3, 5, 7, 11, 13 the maximum is at a = 5, 3, 2, 1, 1, 1. Equality holds for m = 2⁵·3³·5²·7·11·13. ∎

**Lemma 2 (divisor sum).** σ(m) ≤ m(1 + ln m), because σ(m)/m = Σ_(d|m) 1/d ≤ H_m ≤ 1 + ln m.

**Theorem.** τ(σ(x))·σ(τ(x)) < x for all x ≥ 10⁶.

*Proof.* By Lemma 1 and then Lemma 2, τ(σ(x)) ≤ c·σ(x)^(1/4) ≤ c·(x(1 + ln x))^(1/4). By Lemma 2, since t(1 + ln t) increases, and then Lemma 1, σ(τ(x)) ≤ τ(x)(1 + ln τ(x)) ≤ c·x^(1/4)·(1 + ln c + ¼ ln x). Together:

```
τ(σ(x))·σ(τ(x)) ≤ f(x) = c²·√x·(1 + ln x)^(1/4)·(1 + ln c + ¼ ln x).
```

In t = ln x, the log of f(x)/x has derivative 1/(4(1 + t)) + 1/(4(1 + ln c + t/4)) − 1/2. Both fractions are at most 1/4, and the second is strictly smaller (ln c > 0), so the derivative is negative and f(x)/x decreases. At x = 10⁶, f(x)/x = 0.9222 < 1. ∎

**Below 10⁶** we computed both sides for every x, once with a numpy divisor sieve and once with sympy. The roots are exactly 1, 468, 3240, matching Ianakiev's search to 10⁸:

```
468  = 2²·3²·13:      σ = 1274 = 2·7²·13,  τ(1274) = 12;  τ = 18, σ(18) = 39;   12·39 = 468
3240 = 2³·3⁴·5:       σ = 10890 = 2·3²·5·11², τ(10890) = 36;  τ = 40, σ(40) = 90;  36·90 = 3240
```

## How we found it

Schneider's idea is right: τ grows like a small power of x and σ(x)/x only like ln x, so the product falls behind x. It only needs explicit constants. The exponent 1/4 is a good balance. A smaller exponent makes c much larger, and a larger one makes the bound kick in later. With 1/4 the crossover is just below 10⁶, small enough to check exhaustively in a minute. Other exponents give a crossover too, just later.

## Validation

[`writeup/code/p1035_verify.py`](code/p1035_verify.py) (about 1 minute) checks the constant exactly as a fraction, the bound at 10⁶ and its decrease, and both lemmas on m ≤ 10⁵. It also runs the two independent exhaustive searches below 10⁶.

```python
import math
from fractions import Fraction
import numpy as np
from sympy import divisor_count, divisor_sigma, primerange

# 1. The constant: tau(m) <= c * m^(1/4) with c^4 = prod_{p < 16} max_a (a+1)^4 / p^a.
c4 = Fraction(1)
for p in primerange(2, 16):
    c4 *= max(Fraction((a + 1)**4, p**a) for a in range(60))
assert c4 == Fraction(127401984, 25025)
assert all((a + 1)**4 <= 16**a for a in range(200))      # primes p >= 17 contribute 1
c = float(c4) ** 0.25 * (1 + 1e-12)

# 2. The bound f(x) is below x at 10^6; f(x)/x decreases (see the proof).
f = lambda x: c * c * math.sqrt(x) * (1 + math.log(x))**0.25 * (1 + math.log(c) + math.log(x) / 4)
assert f(1e6) / 1e6 < 0.93 and math.log(c) > 0

# 3. Sanity checks of the two lemmas on m <= 10^5.
for m in range(1, 100001):
    t, s = int(divisor_count(m)), int(divisor_sigma(m))
    assert t**4 <= c4 * m and s <= m * (1 + math.log(m)) + 1e-9

# 4. Exhaustive below 10^6, two ways.
X = 10**6
S = 8 * X
tau = np.zeros(S + 1, dtype=np.int32); sig = np.zeros(X + 1, dtype=np.int64)
for d in range(1, S + 1):
    tau[d::d] += 1
for d in range(1, X + 1):
    sig[d::d] += d
assert sig[1:].max() <= S
sol_np = [x for x in range(1, X) if tau[sig[x]] * int(sig[tau[x]]) == x]
sol_sympy = [x for x in range(1, X) if divisor_count(divisor_sigma(x)) * divisor_sigma(divisor_count(x)) == x]
assert sol_np == sol_sympy == [1, 468, 3240]
print("all checks pass")
```
