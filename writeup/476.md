# Puzzle 476: A Collatz trajectory full of primes

> **In short:** We found a 458-digit starting number whose Collatz sequence passes through 30 odd numbers in a row that are all prime, before it reaches 1. The best before was 19.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_476.htm)

**Status:** beaten (Q1) · PRP (probable primes)

## The question

The Collatz rule: if X is odd, replace it by 3X + 1; if X is even, halve it. Start from a seed and write down only the **odd** numbers along the way. Question 1 asks for a seed whose odd numbers form the longest possible chain of primes.

Example: the seed 157 gives the odd numbers 157, 59, 89, 67, 101, 19, 29, 11, 17, 13, 5, a chain of 11 primes.

## Current record vs ours

| | Seed | Primes in the chain |
|---|---|---|
| Current record (J. K. Andersen's chain, extended by D. Dima) | top prime a 1462-digit PRP | 19 |
| **Ours** | a 458-digit seed (in [data/476.txt](data/476.txt)) | **30** |

## How we found it

Andersen already explains the key move on the page: build the chain **backwards**. If p is the first prime of a chain, any prime q = (p·2ⁿ − 1)/3 leads straight into p (3q + 1 = p·2ⁿ, and halving n times gives p). So you can keep adding primes in front.

He always took the **smallest** such q, which makes the numbers grow very fast, and noted that other choices might do better. That is what we did: at each step we kept the 40 smallest prime predecessors (a beam search) instead of just one, and let the most promising branches continue. Starting from the top of a known 16-prime chain (711868714549), this reached 30 primes with a seed of "only" 458 digits.

## The math

Going forward, an odd x is followed by the odd part of 3x + 1. Going backward:

```
q → p   exactly when   3q + 1 = p · 2^n   for some n ≥ 1
q = (p · 2^n − 1) / 3      (a whole number only for n of the right parity, depending on p mod 3)
```

Each step multiplies the size by about 2ⁿ/3, so choosing predecessors with small n keeps the numbers small, and small numbers are more likely to be prime. The beam keeps several small candidates alive at every level so the chain does not get stuck.

## The numbers

The 30 odd terms have these digit lengths, from the seed down to 5:

```
458 363 334 213 153 147 130 124 101 73 30 27 17 13 12 11 8 9 8 5 2 2 2 3 2 2 2 2 2 1
```

The chain ends ... 711868714549, 66737691989, 97760291, 146640437, 13747541, 10069, 59, 89, 67, 101, 19, 29, 11, 17, 13, 5. The seed is in [data/476.txt](data/476.txt). The large terms pass the BPSW test: they are probable primes, not proven ones.

## Verify it yourself

This script reads the seed, runs the Collatz sequence forward, collects the odd numbers, and checks that all 30 are prime.

```python
import sys
from sympy import isprime

sys.set_int_max_str_digits(0)                  # allow converting a 458-digit number

# read the seed (skip the comment line)
seed = int([l for l in open("writeup/data/476.txt") if not l.startswith("#")][0])
assert len(str(seed)) == 458

odd_terms = []
x = seed
while x != 1:
    if x % 2:                                  # odd: record it, then 3x + 1
        odd_terms.append(x)
        x = 3 * x + 1
    else:                                      # even: halve it
        x //= 2

assert len(odd_terms) == 30                    # 30 odd numbers before reaching 1
assert odd_terms[-1] == 5                      # the chain ends at 5
assert all(isprime(t) for t in odd_terms)      # all 30 are (probable) primes; sympy uses BPSW

print("30 consecutive odd Collatz terms, all prime")
```

Run it from the repository root, so the relative path `writeup/data/476.txt` resolves.
