# Puzzle 1181 Q2: when can Floor(q²/p) be prime?

> **In short:** Write F(p, q) = ⌊q²/p⌋ = (q² − r)/p, where r = q² mod p.
> - **r odd:** F is even, so composite.
> - **r = s², an even perfect square:** F = (q − s)(q + s)/p factors. It can only be prime when q = p + s, the arithmetic progression p, p + s, p + 2s of Q1 (and then 6 | s). The exception on the page, F(7, 11) = 17, is the other kind: r = 2.
> - **So every prime F comes from an even quadratic residue r < p that is not a square,** apart from that progression case.
>
> We prove that such an r exists for every prime p except 2, 3, 5 and 11. That explains Vantieghem's observation that T(p) is empty for p = 2, 3, 5, 11: we prove it is empty for exactly those four. For every other p below 3000 a prime F exists. Bateman–Horn predicts infinitely many for each such p, which is not proved.

## The question

S. M. Ruiz: F(n) = ⌊p(n+1)²/p(n)⌋. Q1 shows that a prime F(n) forces p(n+1) = p(n) + 6k and F(n) = p(n) + 12k, with the one exception n = 4. Q2 asks to generalise this to F(p, q) = ⌊q²/p⌋ for primes q > p.

Emmanuel Vantieghem extended the Q1 argument to q < p + √p. He also found by computation that the set T(p) of primes q > p with F(p, q) prime is empty for p = 2, 3, 5, 11, and "seems to contain many primes" for every other p. There is no explanation on the page.

## The answer

**1. Parity.** Take an odd prime p and a prime q > p, so q is odd. Then q² − r ≡ 1 − r (mod 2), so F = (q² − r)/p is even whenever r is odd. Since F > q > 2, F is composite. **A prime F needs r even.** For p = 2, F = (q² − 1)/2 = (q − 1)(q + 1)/2 is composite for q ≥ 5, and F(2, 3) = 4.

**2. Square remainders.** Suppose r = s² with s ≥ 0. Then F = (q − s)(q + s)/p, and p divides q − s or q + s.
- In either case, F is composite unless the quotient of that factor by p is 1.
- That happens only for q − s = p, because q + s = p is impossible for q > p.
- Then F = p + 2s, and s is even by step 1.
- So p, q, F form an arithmetic progression with difference s, and s² < p. This is exactly Vantieghem's range q < p + √p, and the mod-3 argument of Q1 gives 6 | s once p > 3.

**3. The general rule.** Apart from that progression case, **F(p, q) can be prime only if r = q² mod p is an even quadratic residue below p that is not a perfect square.** The rule only excludes cases: it says nothing about whether such a residue actually gives a prime.

**4. When does such an r exist?** It exists for every prime p ≥ 7 except p = 11:

- **p ≡ ±1 (mod 8):** 2 is a residue, so take r = 2.
- **p ≡ 5 (mod 8):** −1 is a residue, so x ↦ p − x preserves residues and flips parity. Exactly (p − 1)/4 of the residues are even. Only ⌊√p/2⌋ even squares lie below p, and (p − 1)/4 > √p/2 for p ≥ 7.
- **p ≡ 3 (mod 8):** pick k with p/2 < 4k² < p. Then x = p − 4k² is odd, x < p/2, and (x/p) = (−1/p) = −1. Since (2/p) = −1, r = 2x is a residue, it is even, and it is ≡ 2 (mod 4), so not a square.
  - Such a k exists once 0.146·√p ≥ 1, so for p ≥ 47.
  - Below 47, the primes p ≡ 3 (mod 8) are 3, 11, 19 and 43. For 19 and 43, r = 6 works, since 3 is a non-residue for both. For 11 the residues are 1, 3, 4, 5, 9, and the only even one is 4 = 2².

**5. The four exceptions.** For p = 3, 5 and 11 every even residue is a square:
- p = 3: residues {1}.
- p = 5: residues {1, 4}.
- p = 11: the only even residue is 4.

By step 2, only the progression case is left. For p = 5 it is q = 7, F = 9; for p = 11 it is q = 13, F = 15; for p = 3 there is none. Both values are composite. With p = 2 from step 1, **T(p) = ∅ exactly for p = 2, 3, 5, 11.**

**6. The other p.** Fix an even non-square residue r and a root a² ≡ r (mod p). Then q = pt + a and F = ((pt + a)² − r)/p are two irreducible polynomials in t with no fixed prime divisor. By the Bateman–Horn conjecture both are prime for infinitely many t, so T(p) should be infinite. That part is conjecture. We checked that T(p) contains a prime q < 10⁶ for every prime 7 ≤ p < 3000 other than 11.
