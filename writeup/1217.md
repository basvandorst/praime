# Puzzle 1217: A formula in two consecutive primes that stays prime

> **In short:** We fed half the gap between consecutive primes into a record prime-generating polynomial. Because prime gaps stay small for a very long time, the result is prime for 103,518 consecutive n (53 different primes), or even 1,319,943 consecutive n with Euler's famous polynomial. The best on the page was 30,800.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1217.htm)

**Status:** beaten · proven primes

## The question

Sebastián Martín Ruiz noticed that F(n) = 6·(p(n+1) − p(n)) − 7, where p(n) is the n-th prime, is prime for n = 2 to 29, but only 4 different primes appear. The puzzle asks for other non-trivial functions of p(n+1) and p(n) that are prime for longer runs of successive n, and preferably with more different primes.

## Current record vs ours

| | Function | Successive n | Different primes |
|---|---|---|---|
| Current record (A. Stinchcombe, 2025) | the gap fed into the PrimeGrid AP-27 | 30,800 (n = 2 … 30801) | 22 |
| **Ours** | \|S(h − 43)\|, S = Dress–Landreau sextic | **103,518** (n = 2 … 103519) | **53** |
| **Ours** | h² − 79h + 1601 (Euler's shifted form) | **1,319,943** (n = 2 … 1319944) | 41 |

Here h = (p(n+1) − p(n))/2, half the gap.

## How we found it

Stinchcombe's idea on the page is the right one: the gap between consecutive primes takes only a few small values for a very long time, so a function of the gap only needs to be prime for those few values. He fed the gap into the AP-27, which offers 27 primes.

We used objects that offer more room. A record prime-generating polynomial is prime for every input in a whole window: the Dress–Landreau sextic for 58 inputs, Euler's n² − 79n + 1601 for 80 inputs. Feeding it half the gap means the result stays prime until the first gap too large for the window, which comes much later.

## The math

The Dress–Landreau sextic

```
S(x) = x⁶/72 − 5x⁵/24 − 1493x⁴/72 + 1027x³/8 + 100471x²/18 − 11971x/6 − 57347
```

is prime in absolute value for every integer x from −42 to 15. With h = (p(n+1) − p(n))/2:

```
f(n) = |S(h − 43)|  is prime whenever  −42 ≤ h − 43 ≤ 15  ⇔  1 ≤ h ≤ 58  ⇔  gap ≤ 116
```

The first gap larger than 116 is the gap of 118 after p = 1349533, so f(n) is prime for n = 2 … 103519.

Euler's shifted polynomial E(h) = h² − 79h + 1601 is prime for h = 0 … 79, so g(n) = E(h) is prime for every gap up to 158; the run also survives a gap of 180 (E(90) = 2591 happens to be prime) and first fails at the gap of 210 after p = 20831323, at n = 1319945.

## The numbers

```
f(n) = |S(h − 43)|:     prime for n = 2 … 103519     (103,518 successive n, 53 different primes)
g(n) = h² − 79h + 1601: prime for n = 2 … 1319944    (1,319,943 successive n, 41 different primes)
```

All values are small (below 2⁶⁴), so sympy's primality test is exact: proven primes.

## Verify it yourself

This script sieves the primes up to 2.1·10⁷, computes half of each gap, and finds how long each function stays prime and how many different primes it produces. It takes about half a minute.

```python
import numpy as np
from fractions import Fraction as F
from sympy import isprime

# all primes up to 2.1e7, then half the gaps between consecutive primes (from p(2) = 3 on)
N = 21_000_000
sieve = np.ones(N + 1, dtype=bool)
sieve[:2] = False
for i in range(2, int(N ** 0.5) + 1):
    if sieve[i]:
        sieve[i * i::i] = False
primes = np.flatnonzero(sieve)
gaps = np.diff(primes)[1:]                      # gaps p(n+1) - p(n) for n = 2, 3, ...
h = gaps // 2

def S(x):                                       # the Dress-Landreau sextic
    return int(F(x**6, 72) - F(5 * x**5, 24) - F(1493 * x**4, 72) + F(1027 * x**3, 8)
               + F(100471 * x**2, 18) - F(11971 * x, 6) - 57347)

def run_length(func):
    # how many successive n (from n = 2) give a prime, and how many different primes
    value = {k: func(k) for k in range(1, int(h.max()) + 1)}
    good = {k: isprime(abs(v)) for k, v in value.items()}
    run, seen = 0, set()
    for k in h:
        if not good[int(k)]:
            break
        run += 1
        seen.add(abs(value[int(k)]))
    return run, len(seen)

assert run_length(lambda k: S(k - 43)) == (103518, 53)
assert run_length(lambda k: k * k - 79 * k + 1601) == (1319943, 41)
print("sextic: 103,518 successive n (53 primes); Euler: 1,319,943 successive n (41 primes)")
```
