# Puzzle 373: The largest known self prime

> **Withdrawn (31 Oct 2026):** Puzzle 951 (April 2019) already shows that 2⁸²⁵⁸⁹⁹³³ − 1 is a self number (Emmanuel Vantieghem and Oscar Volpatti), and that it is the only one of the ten Mersenne primes after 2²⁴⁰³⁶⁵⁸³ − 1 with this property. Our check rediscovered it; it is not a new record.
>
> **In short:** A "self number" is a number that cannot be written as m plus the digit sum of m. With a quick test that only looks at the last few digits, we found that the Mersenne prime 2⁸²⁵⁸⁹⁹³³ − 1 (24.8 million digits) is a self number, which makes it the largest known self prime.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_373.htm)

**Status:** open · not new: Vantieghem and Volpatti showed it on puzzle 951 (2019)

## The question

For any m, write m + (digit sum of m); for example 21 + 2 + 1 = 24. A **self number** is a number that never comes out of this, whatever m you start from. The first ones are 1, 3, 5, 7, 9, 20, 31, 42, 53, 64, … Question 3 asks for large primes that are self numbers.

## Current record vs ours

| | Prime | Digits |
|---|---|---|
| Current record (L. Pebody) | 2²⁴⁰³⁶⁵⁸³ − 1 | 7,235,733 |
| **Ours** | 2⁸²⁵⁸⁹⁹³³ − 1 | **24,862,048** |

## How we found it

A generator m of n is always close to n: the digit sum of m is at most 9 times its number of digits, so m lies at most about 9·k below n (k = number of digits of n). For a number with 24.8 million digits that is about 223 million candidates, too many to test directly.

But all those candidates share the long front part of n and only differ in the last few digits. So the whole question collapses to two tiny equations about the last 9 digits (one for "same front part", one for "front part minus 1" after a borrow). That is the idea behind Pebody's test on the page. We wrote it out, checked it against brute force on 20,000 random numbers, and ran it on the known giant primes:

```
2^24036583 − 1    self       (Pebody's record, reproduced)
2^82589933 − 1    self       (ours)
2^136279841 − 1   not self   (the largest known prime)
```

2⁸²⁵⁸⁹⁹³³ − 1 is the second-largest known prime, and the largest is not self, so ours is the largest known self prime.

## The math

Let n have k digits and digit sum S(n). Any generator m (m + S(m) = n) satisfies n − m = S(m) ≤ 9k + 9. Pick a with 10ᵃ > 9k + 9 and split n = P·10ᵃ + t, where t is the last a digits and P the front part. Then m's front part is P or P − 1:

```
case 1 (same front):   m = P·10^a + u,        u + S(u) = t − S(P)                    0 ≤ u < 10^a
case 2 (borrow):       m = (P − 1)·10^a + u,  u + S(u) = t + 10^a − S(P − 1)         0 ≤ u < 10^a
                       with S(P − 1) = S(P) − 1 + 9·j,  j = number of trailing zeros of P
```

n is a self number exactly when neither equation has a solution. Each one is a question about numbers below 10ᵃ (here a = 9), answered by checking at most about 90 values of u. Only S(P) and the trailing zeros of P are needed, which one pass over the digits of n gives.

## Validation

This script implements the two-case test, checks it against brute force on random numbers, and then applies it to the Mersenne primes. It needs about 1 GB of memory and under a minute.

```python
import random
import gmpy2

ds = lambda x: sum(int(c) for c in str(x))          # digit sum

def generators_small(X):
    # all u >= 0 with u + ds(u) == X; such u lie at most 9*len(X)+9 below X
    return [u for u in range(max(0, X - 9 * len(str(X)) - 9), X + 1) if u + ds(u) == X]

def is_self(s):
    # s is the decimal string of n; True if no m has m + ds(m) == n
    k = len(s)
    a = 1
    while 10 ** a <= 9 * k + 9:                      # generators differ from n only in the last a digits
        a += 1
    if a >= k:
        return not generators_small(int(s))          # small n: plain search
    front, t = s[:-a], int(s[-a:])
    S_front = sum(int(c) for c in front)             # digit sum of the front part P
    j = len(front) - len(front.rstrip("0"))          # trailing zeros of P
    case1 = [u for u in generators_small(t - S_front) if u < 10 ** a] if t >= S_front else []
    X2 = t + 10 ** a - (S_front - 1 + 9 * j)         # borrow case: front part P - 1
    case2 = [u for u in generators_small(X2) if u < 10 ** a] if front.strip("0") else []
    return not case1 and not case2

def brute_self(n):
    return not any(m + ds(m) == n for m in range(max(0, n - 9 * len(str(n)) - 9), n))

# the fast test agrees with brute force on random numbers
random.seed(1)
for _ in range(20000):
    n = random.randint(1, 10 ** random.randint(2, 9))
    assert is_self(str(n)) == brute_self(n)

# apply it to the Mersenne primes (their primality is proven by GIMPS, not re-checked here)
for e, expected in [(24036583, True), (82589933, True), (136279841, False)]:
    s = gmpy2.digits(gmpy2.mpz(2) ** e - 1)
    assert is_self(s) == expected
    print(f"2^{e} - 1 ({len(s)} digits): {'self' if expected else 'not self'}")
```
