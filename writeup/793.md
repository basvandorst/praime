# Puzzle 793: Primes where every pair of digits stands side by side

> **Withdrawn (31 Oct 2026):** Puzzle 960 (July 2019) already has these exact values: Oscar Volpatti's table of smallest prime solutions for K = 5 … 10 contains our K = 6, 8 and 10 numbers digit for digit, with a proof of minimal length. Our search rediscovered them; they are not new.
>
> **In short:** For K = 6, 8 and 10 different digits we found smaller primes in which every pair of those digits appears next to each other somewhere. The trick is to read the digits as a walk through a network where every pair of digits is a road that must be travelled.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_793.htm)

**Status:** open · not new: Volpatti's table on puzzle 960 (2019) has the same three numbers

## The question

A prime P uses K different digits. We want every pair of those digits to be **contiguous** (next to each other) somewhere in P. Example for K = 3: 1021 uses 0, 1, 2, and the pairs 0-1, 0-2 and 1-2 all appear side by side ("10", "02", "21"). The puzzle asks for the **smallest** such prime for K = 5 to 10.

Ours have the same length as his but are smaller. Vantieghem wrote that he believed smaller solutions might exist. For K = 5, 7 and 9 our search reproduced his values exactly.

## How we found it

Think of the K digits as towns and every pair of digits as a road between two towns. Reading the number from left to right is a walk from town to town, and the condition says: **every road must be used at least once**. That is a classical question about walks through a graph (Euler's problem of the Königsberg bridges).

This tells us the shortest possible length right away, and a search that tries walks in increasing numerical order (smallest digits first) finds small primes quickly. At each step we only kept walks that can still cover all remaining roads within the length limit, then tested each finished walk for primality.

## The math

With K digits there are K(K−1)/2 roads. A walk that uses every road exactly once exists only if every town has an even number of roads (K odd). Otherwise some roads must be used twice:

```
K odd:   shortest walk has K(K−1)/2 steps          → K(K−1)/2 + 1 digits
K even:  every town has K−1 (odd) roads; (K−2)/2 roads must be repeated
         shortest walk has K(K−1)/2 + (K−2)/2 steps → K(K−1)/2 + (K−2)/2 + 1 digits
```

That gives at least 18 digits for K = 6, 32 for K = 8 and 51 for K = 10. Our K = 8 and K = 10 primes reach that minimum length. For K = 6 both our prime and Vantieghem's have 19 digits; an 18-digit solution was not excluded.

## The numbers

```
K = 6:   1012031234062461463
```

The K = 6 number is below 2⁶⁴, where sympy's primality test is exact, so it is proven prime. The K = 8 and K = 10 numbers pass the BPSW test: they are probable primes, not proven ones.

## Validation

This script checks, for each K, that the number has K different digits, that every pair of them stands side by side somewhere, that it is prime, and that it is smaller than the listed value.

```python
from itertools import combinations
from sympy import isprime

def all_pairs_adjacent(n):
    s = str(n)
    digits = set(s)
    neighbours = {frozenset(pair) for pair in zip(s, s[1:]) if pair[0] != pair[1]}   # side-by-side pairs
    return all(frozenset(p) in neighbours for p in combinations(sorted(digits), 2)), len(digits)

ours = {6: 1012031234062461463,
        8: 10203123405142534560716273657467,
        10: 101203123405142534560716273647567809182938495869789}
listed = {6: 1021302341504253451,
          8: 10213041506170234253456275637467,
          10: 102031405123416071809152453627382938465749676859789}

for K in (6, 8, 10):
    ok, k = all_pairs_adjacent(ours[K])
    assert ok and k == K                         # K different digits, every pair adjacent
    assert isprime(ours[K])                      # prime
    assert ours[K] < listed[K]                   # smaller than the listed record
    assert len(str(ours[K])) == len(str(listed[K]))   # same length
    print(f"K = {K}: {ours[K]}")
```
