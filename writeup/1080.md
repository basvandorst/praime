# Puzzle 1080: A number that is σ₃ of three different numbers

> **In short:** σ₃(x) adds up the cubes of all divisors of x. Only one number with two solutions of σ₃(x) = y was known, and no third term after a search to 2·10⁸. We combined two known pairs by multiplication and got y = 190592992522906181161863557566464, which is σ₃ of exactly three numbers. So the third term exists and a(3) ≤ 1.9·10³². We do not claim it is the smallest.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1080.htm)

**Status:** first answer (upper bound for a(3)) · exact

## The question

σ₃(x) is the sum of the cubes of the divisors of x. Fred Schneider defines a(n) as the least y such that σ₃(x) = y has n solutions x. a(1) = 1 and a(2) = 7401260364550416 = σ₃(184926) = σ₃(194315). He searched to 2·10⁸ without finding a third term, and asks for a(3), a(4), …

## What the page had vs ours

| | a(3) |
|---|---|
| On the page | none known (search to 2·10⁸) |
| **Ours** | **a(3) ≤ 190592992522906181161863557566464**, a value with exactly three solutions |

## How we found it

σ₃ is **multiplicative**: if u and v share no factor, σ₃(u·v) = σ₃(u)·σ₃(v). So two pairs with equal σ₃ can be multiplied together:

```
σ₃(184926) = σ₃(194315) = Y₁        (the known pair)
σ₃(291741) = σ₃(295301) = Y₂        (the next pair, found by a sieve to 6·10⁶)
```

Any product u·v of one number from each pair, with u and v coprime, has σ₃(u·v) = Y₁·Y₂. Three of the four cross products are coprime, so Y₁·Y₂ has at least three solutions.

Then we proved it has **exactly** three. Any x with σ₃(x) = y is a product of prime powers p^e with each σ₃(p^e) dividing y. For e = 1, σ₃(p) = p³ + 1 = (p + 1)(p² − p + 1), so p + 1 must be a divisor of y, and y has only about 1.2 million divisors to try. For e ≥ 2, p is at most the (3e)-th root of y, a short list. That gives all 16 possible building blocks, and checking every way to combine them into exactly y finds three solutions.

## The math

```
x₁ = 184926 · 295301 = 54608832726
x₂ = 194315 · 291741 = 56689652415
x₃ = 194315 · 295301 = 57381413815
(184926 and 291741 share the factor 3, so that product does not count)

σ₃(x₁) = σ₃(x₂) = σ₃(x₃) = y = 190592992522906181161863557566464
```

## The numbers

```
y = 190592992522906181161863557566464  ≈ 1.9 · 10³²
solutions: 54608832726, 56689652415, 57381413815   (exactly these three)
```

## Validation

This script checks the two pairs, builds y, lists every prime power whose σ₃ divides y, and counts all ways to combine them into exactly y. It takes a few seconds.

```python
from math import gcd
from gmpy2 import is_prime, iroot, mpz
from sympy import divisor_sigma, factorint, primerange

sigma3 = lambda n: divisor_sigma(n, 3)

assert sigma3(184926) == sigma3(194315) == 7401260364550416       # the pair on the page
assert sigma3(291741) == sigma3(295301)                           # the next pair
y = sigma3(184926) * sigma3(291741)

# all prime powers p^e whose sigma3 divides y
fy = factorint(y)
divisors = [1]
for p, e in fy.items():
    divisors = [d * p**k for d in divisors for k in range(e + 1)]
blocks = set()
for d in divisors:                                  # e = 1: p + 1 divides p^3 + 1, which divides y
    p = d - 1
    if p >= 2 and is_prime(p) and y % (p**3 + 1) == 0:
        blocks.add((p, 1, p**3 + 1))
e = 2
while iroot(mpz(y), 3 * e)[0] >= 2:                 # e >= 2: p^(3e) < y keeps p small
    for p in primerange(2, int(iroot(mpz(y), 3 * e)[0]) + 2):
        s = sum(p**(3 * i) for i in range(e + 1))
        if y % s == 0:
            blocks.add((p, e, s))
    e += 1
blocks = sorted(blocks)

solutions = []
def combine(i, rest, x, used):                      # pick blocks with distinct primes, product of sigma3 = y
    if rest == 1:
        solutions.append(x)
        return
    for j in range(i, len(blocks)):
        p, e, s = blocks[j]
        if p not in used and rest % s == 0:
            combine(j + 1, rest // s, x * p**e, used | {p})
combine(0, y, 1, frozenset())

assert sorted(solutions) == [54608832726, 56689652415, 57381413815]
assert all(sigma3(x) == y for x in solutions)
assert gcd(184926, 291741) > 1                      # the fourth cross product is not coprime
print("y =", y, "has exactly", len(solutions), "solutions:", sorted(solutions))
```
