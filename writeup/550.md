# Puzzle 550: Consecutive primes producing semiprimes

> **In short:** For consecutive primes, Sᵢ = pᵢ·pᵢ₊₁ + pᵢ₊₂·pᵢ₊₃ is taken for i, i + 1, i + 2, …; the record was 4 semiprimes in a row (from 17017471 and from 757658339). The search: (1) Sᵢ is even, so it must be twice a prime; (2) that needs pᵢpᵢ₊₁ ≡ pᵢ₊₂pᵢ₊₃ (mod 12), a test on residues only; (3) a segmented sieve runs through all primes below 10¹² and tests only the runs that pass. This gives 16 runs of 5, the first from 4748135713; no run of 6 below 10¹².

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_550.htm)

**Status:** beaten · proven primes · the first run of 5 is the smallest (computed)

## The question

5·7 + 11·13 = 178 = 2·89, 7·11 + 13·17 = 298 = 2·149, 11·13 + 17·19 = 466 = 2·233 are semiprimes; the next, 13·17 + 19·23 = 658 = 2·7·47, is not. Find a longer run.

## How we found it

1. The sum of two odd products is even, so a semiprime Sᵢ is 2 times a prime. Factoring is not needed: one primality test of Sᵢ/2.
2. Sᵢ/2 must be odd and not divisible by 3. Both depend only on the primes modulo 12, so most positions are rejected before any large number is formed.
3. The survivors are tested modulo 5, 7, …, 31 with residues, then with a primality test.
4. With this, all primes below 10⁹ take 3 seconds and all below 10¹² about 50 minutes on two cores.

## The math

**Twice a prime (proved).** For pᵢ ≥ 3 both products are odd, so Sᵢ is even and Sᵢ > 4. A semiprime that is even and larger than 4 is 2·P with P an odd prime.

**Modulo 12 (proved).** Let a = pᵢpᵢ₊₁ and b = pᵢ₊₂pᵢ₊₃, both coprime to 12 for pᵢ ≥ 5.
- Modulo 4: a, b ∈ {1, 3}. If a ≢ b then 4 | a + b, so Sᵢ/2 is even: not prime.
- Modulo 3: a, b ∈ {1, 2}. If a ≢ b then 3 | a + b: not twice a prime.

So a ≡ b (mod 12) is necessary. A run of L semiprimes from position i needs mⱼ = mⱼ₊₂ for j = i … i + L − 1, where mⱼ = pⱼpⱼ₊₁ mod 12.
