# Puzzle 1249: Cycles of p ↦ GPD(2p + 3)

> **In short:** The page asks whether p ↦ GPD(2p + 3) has cycles other than 5 → 13 → 29 → 61 and 43 → 89 → 181 → 73 → 149. (1) On a cycle the cofactors multiply to an odd integer S = ∏(2 + 3/p_i) ≥ 2^L + 1, which forces long cycles when all primes are large. (2) Every prime below 2·10⁸ ends in a known cycle, so a new cycle has length ≥ 23, or ≥ 28 with the page's search to 10¹⁰. The analysis, shared with puzzle 1250, is in [1250.md](1250.md).

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1249.htm)

**Status:** open · explained: no new cycle with a prime below 2·10⁸; any new cycle has length ≥ 23 (≥ 28 given the page's search); see [1250.md](1250.md)
