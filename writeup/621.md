# Puzzle 621: A prime magic square M with p(M) magic

> **In short:** The page asks for the smallest 3×3 magic square M of primes such that p(M), the square of the M(i, j)-th primes, is also magic, or a proof that none exists. Without the prime condition the smallest such M is known (centre 25818). (1) A 3×3 magic square is c, c ± a, c ± b, c ± (a + b), c ± (a − b). p(M) is magic iff p(c) is the midpoint of p(c − x) and p(c + x) for these four offsets x, and the shifts d(x) = p(c + x) − p(c) satisfy d(a + b) = d(a) + d(b) and d(a − b) = d(a) − d(b). (2) If all nine entries of M are primes above 3, then c is prime and a, b ≡ 0 (mod 6). (3) A search over all prime centres c ≤ 2·10⁷ and offsets a, b ≤ 9000 finds no such square; the same program finds the known non-prime square at c = 25818, the smallest. (4) Each of the six conditions makes two independent sums of about x prime gaps equal, which has probability of order 1/(√x·ln p). The known square has b = 1, which makes the conditions dependent; the prime version cannot use that. So the object is probably very rare or absent; no proof.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_621.htm)

**Status:** open · no such square with centre ≤ 2·10⁷ and offsets ≤ 9000 (exhaustive within these bounds); heuristically very rare or absent

## The question

Resta's object of puzzle 411: a 3×3 magic square M such that replacing every entry k by the k-th prime p(k) gives a magic square p(M). The smallest is

```
M = 26199 25436 25819      p(M) = 302573 292667 297629
    25438 25818 26198             292679 297623 302567
    25817 26200 25437             297617 302579 292673
```

Q (puzzle 411, Q4): find the smallest such M with every entry prime, or show that it cannot exist. There are no contributions.

## The math

**Step 1 (proved): the conditions.** Every 3×3 magic square has the form

```
c − b       c + a + b   c − a
c − a + b   c           c + a − b
c + a       c − a − b   c + b
```

and a square of this shape is magic iff it can be written this way. p(M) has the same shape with centre p(c) iff, for x ∈ {a, b, a + b, a − b}, p(c + x) − p(c) = p(c) − p(c − x) =: d(x), and d(a + b) = d(a) + d(b), d(a − b) = d(a) − d(b).

**Step 2 (proved): prime entries.** The centre is an entry, so c is prime. For entries c ± a, c ± b, … prime and greater than 3, a and b must be ≡ 0 (mod 6): with c ≢ 0 (mod 3), c ± a ≢ 0 forces a ≡ 0 (mod 3), and evenness follows from odd entries. So only prime centres and offsets that are multiples of 6 need to be searched.

**Step 3 (computed): the search.** [code/p621_search.c](code/p621_search.c) lists, for each centre, the offsets x with p(c − x) + p(c + x) = 2p(c), and then tests all pairs (a, b) from that list. In the unrestricted mode (any centre, any offset) it finds Resta's square c = 25818, a = 381, b = 1 as the first one. In the prime mode (prime centre, offsets ≡ 0 mod 6, all nine entries prime) it finds nothing for c ≤ 2·10⁷ and a, b ≤ 9000 (4 seconds).

**Step 4 (heuristic): why it is rare.** Each condition of Step 1 says that two sums of x consecutive prime gaps are equal. Under a random model such a sum has spread about √(2x)·ln p, so equality has probability of order 1/(√x·ln p), around 10⁻³ for x near 1000 and p near 10⁸. The prime version needs six such equalities with offsets that are multiples of 6, and nine prime entries. Resta's square uses b = 1: then d(1) is a single gap, and two of the conditions become equalities of single gaps, which happen often. That shortcut is not available when all entries must be prime. The expected number of solutions in the searched range is therefore tiny, and it shrinks further for larger centres. A proof of impossibility would need much more than this.
