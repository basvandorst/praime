# Puzzle 1022: Is (n − 1)ⁿ + n always composite for n ≥ 4?

> **In short:** x(n) = (n − 1)ⁿ + n was conjectured to be composite for every n ≥ 4 (checked up to n = 13389); this stays open. Proved here: (1) n² − n + 1 divides x(n) when n ≡ 2 (mod 3), and by Selmer's theorem this is the only polynomial factor; (2) n + 1 divides x(n) exactly when (−2)ⁿ ≡ 1 (mod n + 1), always the case when n + 1 is prime; (3) 2n − 1 divides x(n) exactly when (−2)ⁿ⁻¹ ≡ 1 (mod 2n − 1), which for prime 2n − 1 means 2n − 1 ≡ 1 or 3 (mod 8); (4) no other divisor is linear in n, and no finite covering set exists, since n ≡ 1 (mod r) gives x(n) ≡ 1 (mod r). So the usual ways to prove "always composite" fail. A sieve model, calibrated on two published families, expects 1.5 primes for 30 ≤ n ≤ 13389 (finding none has a 22 % chance) and infinitely many in total, the next one most likely near n ≈ 6·10⁵, a number of about 3.5 million digits.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1022.htm)

**Status:** open · divisor structure proved (three families, no other linear one, no covering set) · composite for 4 ≤ n ≤ 3000 rechecked · heuristic: the claim is false, first prime expected near n ≈ 6·10⁵

## The question

Sebastián Martín Ruiz checked that x(n) = (n − 1)ⁿ + n is composite for 4 ≤ n ≤ 3000; x(2) = 3 and x(3) = 11 are prime. Eric Snyder noted that 3 | x(n) for n ≡ 2 (mod 3), and that for even n ≢ 2 (mod 3) "x(n) is divisible by n + 1 (if n + 1 is prime), or a factor of n + 1 (if n + 1 is composite), for almost all". Oscar Volpatti (Nov 2020) found no prime for n ≤ 13389.

**Q.** Prove that x(n) is always composite for n ≥ 4, or find a counterexample.

## How we found it

Snyder's two observations are x(n) evaluated modulo 3 and modulo n + 1. We asked why modulo n + 1 works. The base n − 1 is fixed modulo r = n + 1, and so is the exponent n modulo r − 1 = n, so Fermat's theorem closes the computation. The same happens for every prime r that is linear in n, so we went through all relations k·r = j·n − i. Only r = n + 1 and r = 2n − 1 give infinite families, and the second turned out to be the Cullen/Woodall rule in disguise (FACTS 6224, Euler's criterion 1301 and its supplement 1302).

To prove the claim one would need a covering set, as in Sierpinski's 78557·2ⁿ + 1 (FACTS 10113) or [puzzle 1145](1145.md). The class n ≡ 1 (mod r) kills that idea at once. What is left is the [puzzle 1257](1257.md) situation: no covering set, so count the expected primes with an exact small-prime sieve and Mertens' formula (FACTS 2002, 9505), and calibrate that count on families with published data.

## The math

Notation: x(n) = (n − 1)ⁿ + n. With Y = n − 1 it is the trinomial F(Y) = Yⁿ + Y + 1 at Y = n − 1. (a/r) is the Legendre symbol and ord_r(2) the order of 2 modulo r.

**1. Parity and two trivial residues (proved).** For even n, (n − 1)ⁿ is odd and n is even; for odd n, it is the other way around. So x(n) is always odd. Since n − 1 ≡ −1 (mod n), x(n) ≡ (−1)ⁿ (mod n), and x(n) ≡ 0 + n ≡ 1 (mod n − 1). So no prime factor of n(n − 1) divides x(n): a prime r never divides x(n) when n ≡ 0 or 1 (mod r).

**2. The polynomial factor (proved; Selmer's theorem is literature).** Let ω be a primitive cube root of unity. F(ω) = ωⁿ + ω + 1 is 0 exactly when ωⁿ = ω², that is n ≡ 2 (mod 3). So Y² + Y + 1 divides Yⁿ + Y + 1 for those n, and putting Y = n − 1:

```
n ≡ 2 (mod 3)  ⇒  (n² − n + 1) | x(n),   n² − n + 1 = 3·(3t² + 3t + 1) for n = 3t + 2
```

Since 1 < n² − n + 1 < x(n) for n ≥ 5, x(n) is composite. Snyder's 3 | x(n) is the factor 3 of n² − n + 1. Modulo n² − n + 1, n is a primitive 6th root of unity and n − 1 ≡ n², so x(n) ≡ n^(2n mod 6) + n. That is n + 1 for n ≡ 0 (mod 3) and n(n + 1) for n ≡ 1 (mod 3), and both are coprime to n² − n + 1. So outside the class n ≡ 2 (mod 3) the factor does not occur at all. Selmer (Math. Scand. 4 (1956) 287–302) proved that Yⁿ + Y + 1 is irreducible over ℚ for n ≢ 2 (mod 3), and equals (Y² + Y + 1) times an irreducible polynomial for n ≡ 2 (mod 3), n > 2. So there is no other polynomial factor (checked with sympy for n ≤ 60).

**3. Modulo n + 1: Fermat (proved).** n ≡ −1 and n − 1 ≡ −2 (mod n + 1), so

```
x(n) ≡ (−2)ⁿ − 1  (mod n + 1),   gcd(x(n), n + 1) = gcd((−2)ⁿ − 1, n + 1)
```

For odd n, n + 1 is even and x(n) is odd, so n + 1 never divides x(n). For even n, (n + 1) | x(n) ⇔ 2ⁿ ≡ 1 (mod n + 1), i.e. n + 1 is a Fermat probable prime to base 2. For prime n + 1 ≥ 5 this is Fermat's little theorem, which proves Snyder's observation. For composite n + 1 it holds exactly at the base-2 pseudoprimes 341, 561, 645, 1105, … (OEIS A001567): x(340) is divisible by 341 = 11·31.

For a single prime r | n + 1 with n + 1 = r·s: r | x(n) ⇔ ord_r(2) | n for even n, and ⇔ 2ⁿ ≡ −1 (mod r) for odd n. Since n = rs − 1 ≡ s − 1 (mod r − 1), the even case reads ord_r(2) | s − 1. It always holds when n + 1 is a prime power, and seldom otherwise. Snyder's "almost all" is therefore not right: among even n ≤ 13389 with n ≢ 2 (mod 3) and n + 1 composite, a prime factor of n + 1 divides x(n) for 1045 of 2877 (36.3 %).

**4. Modulo 2n − 1: Cullen and Woodall (proved; new).** Put N = 2n − 1. Then 2(n − 1) ≡ −1 and 2n ≡ 1 (mod N), so

```
2ⁿ·x(n) = (2n − 2)ⁿ + n·2ⁿ ≡ (−1)ⁿ + n·2ⁿ  (mod N)
```

The right-hand side is the Cullen number Cₙ = n·2ⁿ + 1 for even n and the Woodall number Wₙ = n·2ⁿ − 1 for odd n. With n·2ⁿ = 2n·2ⁿ⁻¹ ≡ 2ⁿ⁻¹, and since N is odd, this gives

```
(2n − 1) | x(n)  ⇔  2ⁿ⁻¹ ≡ (−1)ⁿ⁻¹  ⇔  (−2)ⁿ⁻¹ ≡ 1  (mod 2n − 1)
```

For prime N, n − 1 = (N − 1)/2, so Euler's criterion makes the condition (−2/N) = 1. That means N ≡ 1 or 3 (mod 8), or equivalently n ≡ 1 or 2 (mod 4). This is the classical rule "a prime 2n − 1 divides Cₙ iff (2/2n−1) = −1 and Wₙ iff (2/2n−1) = +1", carried over to x(n). Composite 2n − 1 can also divide x(n): 341, 561, 1105, 1729, 1905, 2465, 4033, … (20 values with n ≤ 13389).

Sections 3 and 4 make the same test: a base −2 probable-prime condition on n + 1 (full exponent) or on 2n − 1 (half exponent).

**5. No other linear family (proved).** Take integers j, k ≥ 1 and i with gcd(i, j) = 1, and a prime r with k·r = j·n − i that divides x(n) and not j·i·(i − j). (Any linear relation can be put in this form: if g = gcd(i, j) > 1 and r > g, then g | k.) Then n ≡ i/j (mod r), and n − 1 ≢ 0. Raising (n − 1)ⁿ ≡ −n to the power j and using j·n = k·r + i ≡ k + i =: e (mod r − 1) gives ((i − j)/j)^e ≡ (−i/j)^j (mod r). Clearing denominators, r divides

```
D(j, i, k) = (i − j)^e · j^j − (−i)^j · j^e      (e ≥ 0)
D(j, i, k) = j^(j−e) − (−i)^j · (i − j)^(−e)     (e < 0)
```

If D ≠ 0, only the finitely many primes dividing D can occur, and r fixes n, so the relation catches finitely many n. D = 0 forces the following, using that i, i − j and j are pairwise coprime:

- for j = 1: (i − 1)^e = −i, so e = 0 and i = −1, which is r = n + 1;
- for j ≥ 2: e = j and (i − j)^j = (−i)^j, so i − j = −i, j = 2 and i = 1, which is r = 2n − 1;
- e < 0 has no solution.

So n + 1 and 2n − 1 are the only linear divisor families. A scan of all j ≤ 6, |i| ≤ 40, k ≤ 12 and n ≤ 1500 found every hit inside these two families or dividing its D.

**6. Perfect-power n (proved).** If n = 4b⁴, then x(n) = a⁴ + 4b⁴ with a = (n − 1)^(b⁴), and Sophie Germain's identity a⁴ + 4b⁴ = (a² − 2ab + 2b²)(a² + 2ab + 2b²) splits it: x(4) = 85 = 5·17, and x(64) is divisible by a² − 2ab + 2b² with a = 63¹⁶, b = 2. (The same identity makes n + 1 = 4b⁴ + 1 composite for b ≥ 2, so the Fermat family of section 3 never covers these n.) If n = c^q with q an odd prime dividing c, then x(n) = A^q + c^q with A = (n − 1)^(n/q), which has the factor A + c: n = 27, 216, 729, 1728, … These n have density 0.

**7. No covering set (proved).** For any finite set S of primes, n ≡ 1 (mod ∏S) gives x(n) ≡ 0ⁿ + 1 = 1 (mod r) for every r ∈ S. Combine this with n ≡ 3 (mod 4) and, through 3 ∈ S, n ≡ 1 (mod 3). In the resulting progression no prime of S divides x(n), there is no polynomial factor, n + 1 is even, and 2n − 1 ≡ 5 (mod 8), so no prime 2n − 1 divides. A proof that x(n) is always composite would need a mechanism of a new kind: a fixed set of primes such as {3, 5, 7, 13, 19, 37, 73}, which makes 78557·2ⁿ + 1 composite, cannot exist here.

**8. Quadratic characters of the prime factors (proved).** For even n, x(n) = A² + n with A = (n − 1)^(n/2), so every prime factor r has (−n/r) = 1. For odd n, x(n) = (n − 1)A² + n with A = (n − 1)^((n−1)/2), so (−n(n − 1)/r) = 1. Half of all primes can never divide a given x(n): it is the non-residue mechanism of Euler's n² + n + 41. This was checked for all prime factors below 5000 of x(n), 4 ≤ n < 1200.

**9. The mod 4 law (proved, and seen in the data).** 5 never divides x(n) for n ≡ 2 or 3 (mod 4): the values (a − 1)³ + a and (a − 1)² + a (a = n mod 5) are never 0 mod 5. For n ≡ 3 (mod 4) neither family applies, because n + 1 is even and a prime 2n − 1 is ≡ 5 (mod 8). So n ≡ 3 (mod 4) is the only class that both families and 5 leave alone. Among the n that survive the sieve below (no factor below 10⁴), the classes n ≡ 0, 1, 2, 3 (mod 4) hold 246, 274, 278 and 701 values for 30 ≤ n ≤ 13389, and 24651, 25632, 28649 and 50780 for 13389 < n ≤ 10⁶.

**10. Which composites are explained.** Of the 13386 values 4 ≤ n ≤ 13389, the three proved divisors account for 7298 (54.5 %):

| divisor | n |
|---|---|
| n² − n + 1 (n ≡ 2 mod 3) | 4462 |
| n + 1 (20 of them composite n + 1) | 1605 |
| 2n − 1 | 1476 |
| both n + 1 and 2n − 1 | −245 |

The other 6088 are composite through "random" factors. 1499 of them, with n ≥ 30, have no prime factor below 10⁴.

**11. Expected number of primes (heuristic, calibrated).** For n ≥ 30, the model counts n as a survivor when n ≢ 2 (mod 3), no prime r ≤ R divides x(n), and gcd(x(n), (n + 1)(2n − 1)) = 1. The sieve is exact: x(n) mod r depends only on n mod r(r − 1). A survivor is prime with probability e^γ·ln R / ln x(n), with ln x(n) = n·ln(n − 1) (Mertens; FACTS 9505). Below n = 30, x(n) is too small for this formula; x(n) is composite for every 4 ≤ n < 30 (and up to 3000, see below).

```
                               R = 10⁴              R = 10⁵
30 ≤ n ≤ 13389   survivors     1499                 1211    (Mertens predicts 1499·ln10⁴/ln10⁵ = 1199)
                 expected      1.53                 1.52    P(no prime) = e^−1.53 = 22 %
30 ≤ n ≤ 3000    expected      1.21 (Martín Ruiz's range, P(none) = 30 %)
3001 ≤ n ≤ 13389 expected      0.31 (Volpatti's extension, P(none) = 73 %)
```

Calibration: the same program, with the same R = 10⁴, on two families of the same size whose prime indices are published.

| family | range | expected | observed |
|---|---|---|---|
| 3nⁿ + 2 (OEIS A160360; next term > 45000) | 30 ≤ n ≤ 45000 | 1.59 | 2 (93, 605) |
| (n − 1)nⁿ + 1 (OEIS A108879; no search limit given, so we stop at the last term) | 30 ≤ n ≤ 2835 | 2.54 | 4 (93, 100, 1536, 2835) |

Together that is 4.1 expected against 6 observed. P(≥ 6 | 4.1) = 24 %, so the model does not overestimate. Zero primes up to 13389 is therefore an ordinary outcome, not evidence for the claim.

**12. Where the next prime should be (heuristic).** The cumulative expected number of primes with 13389 < n ≤ N:

| N | 3·10⁴ | 5·10⁴ | 10⁵ | 2·10⁵ | 5·10⁵ | 10⁶ | 10⁷ |
|---|---|---|---|---|---|---|---|
| expected | 0.16 | 0.25 | 0.38 | 0.50 | 0.66 | 0.77 | 1.12 |
| P(at least one) | 14 % | 22 % | 32 % | 40 % | 48 % | 54 % | 67 % |

The median lies near n ≈ 6·10⁵, where x(n) has about 3.5 million digits; reaching it means about 75000 PRP tests on survivors with 55000 to 3.5 million digits. The weight per n, c = e^γ·ln R·[survivor], rises from 1.9 near n = 10⁴ to 2.3 near 10⁷. Without the two families it would be 2.99 (the sieve-only survivor density), and their share among survivors falls roughly like 3.5/ln n (fitted on the model output for 10⁴ < n ≤ 10⁷). So the expected count grows like 3·ln ln N without bound: the model predicts infinitely many primes x(n), arriving very slowly.

**What this does not settle.** We have neither a proof nor a counterexample. Proved: the divisor families of sections 2–6, the absence of any other linear family, the absence of a covering set, and compositeness for 4 ≤ n ≤ 3000. That every x(n) with 3000 < n ≤ 13389 is composite is Volpatti's result, which we did not recheck. The claim "always composite" contradicts the heuristic, but a counterexample is out of reach: the first prime is expected to have hundreds of thousands to millions of digits.

## Verify it yourself

[code/p1022_verify.py](code/p1022_verify.py) checks every claim above: parity and residues, the factor n² − n + 1 and Selmer's pattern, the n + 1 and 2n − 1 rules with their pseudoprime lists, the 36.3 % count for Snyder's "almost all", the linear-family scan, the perfect-power factors, the covering argument, the quadratic characters, the mod 4 law, the 54.5 % count and the heuristic counts with both calibrations. It recomputes the model in plain Python, independently of the C program, and proves x(n) composite for every 4 ≤ n ≤ 1000 by Miller–Rabin witnesses (`--full` goes to 3000). [code/p1022_model.c](code/p1022_model.c) is the fast sieve model used for the tables in sections 9, 11 and 12.

```
pip install sympy gmpy2
python3 p1022_verify.py            # about 15 seconds
python3 p1022_verify.py --full     # also n <= 3000, about 4 minutes
gcc -O2 -o p1022_model p1022_model.c -lm
./p1022_model 0 30 13389 10000     # expected 1.5278, survivors 1499 (246 274 278 701 by n mod 4)
./p1022_model 0 30 13389 100000    # expected 1.5179, survivors 1211
./p1022_model 1 30 45000 10000     # calibration 3n^n+2: 1.5907

```
