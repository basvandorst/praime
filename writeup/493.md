# Puzzle 493: Is p^p = x·a² + y·b² always solvable?

> **In short:** Michael Hiebl asked whether p^p = x·a² + y·b² always has a solution with x + y = p, a ≠ b, gcd(a, b) = 1. Yes, for every odd prime p and in fact for every split x + y = p. The solution comes from expanding (√x + i√y)^p: its size squared is (x + y)^p = p^p.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_493.htm)

**Status:** first answer · proof

## The question

For a prime p > 2, are there always positive integers x, y, a, b with

```
p^p = x·a² + y·b²,     x + y = p,     gcd(a, b) = 1,     a ≠ b ?
```

## What the page had vs ours

| | Answer |
|---|---|
| On the page | the question only |
| **Ours** | **yes, for every odd prime p and every x + y = p** (proof, plus an explicit formula) |

## How we found it

The left side p^p equals (x + y)^p, and x·a² + y·b² is the squared size of the complex number a√x + i·b√y. Sizes multiply, so the squared size of (√x + i√y)^p is (x + y)^p = p^p. That suggests simply expanding (√x + i√y)^p.

Because p is odd, the expansion splits neatly. Even powers of √x·i√y give whole numbers, and every term carries exactly one leftover √x or i√y:

```
(√x + i√y)^p = A·√x + i·B·√y,    with A, B whole numbers
```

Taking the squared size of both sides gives p^p = x·A² + y·B². The remaining work is to check that A and B have no common factor and are different.

## The math

**A and B are not divisible by p.** In the binomial expansion, every coefficient C(p, j) with 0 < j < p is a multiple of p. Only the two end terms survive mod p:

```
A ≡ x^((p−1)/2)              (mod p)
B ≡ ±y^((p−1)/2)             (mod p)
```

Since 0 < x, y < p, neither is 0 mod p.

**gcd(A, B) = 1.** A prime q dividing both A and B would divide x·A² + y·B² = p^p, so q = p. But p divides neither A nor B.

**|A| ≠ |B|.** If |A| = |B|, then gcd = 1 forces |A| = |B| = 1, and p^p = x + y = p, which is false for p > 1.

So a = |A|, b = |B| is a solution, for every split x + y = p. Example with p = 5, x = 1, y = 4:

```
(1 + 2i)^5 = 41 − 38i = 41·√1 + i·(−19)·√4     ⇒   5^5 = 3125 = 1·41² + 4·19²
```

## Verify it yourself

This script builds A and B with whole-number arithmetic only, for every odd prime p below 200 and every split x + y = p, and checks all the conditions.

```python
from math import gcd
from sympy import primerange

def coefficients(x, y, p):
    # (sqrt x + i sqrt y)^2 = (x - y) + 2 i sqrt(xy); keep powers of it as c + d * i sqrt(xy)
    c, d = 1, 0
    for _ in range((p - 1) // 2):
        c, d = c * (x - y) - d * 2 * x * y, c * 2 + d * (x - y)
    # one more factor (sqrt x + i sqrt y) gives A sqrt x + i B sqrt y
    return c - d * y, c + d * x

checked = 0
for p in primerange(3, 200):
    for x in range(1, p):
        y = p - x
        A, B = coefficients(x, y, p)
        a, b = abs(A), abs(B)
        assert x * a * a + y * b * b == p**p        # the equation
        assert gcd(a, b) == 1 and a != b and a > 0 and b > 0
        checked += 1

assert coefficients(1, 4, 5) == (41, -19)          # 5^5 = 41^2 + 4 * 19^2
print("checked", checked, "pairs (p, x); every one gives a solution")
```
