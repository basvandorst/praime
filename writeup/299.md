# Puzzle 299: The smallest run of 9 increasing primes

> **In short:** Start from a prime p and replace it by the largest prime factor of 3p + 1. Sometimes the primes go up several times in a row. The smallest start of a run of 9 increasing primes is 35014031359. The page only knew it was above 7·10⁸. The search was easy once we saw that every such run has the fixed shape m·3^k·2^(9−k) − 1.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_299.htm)

**Status:** first answer (Q2, run of 9) · proven primes · proven least

## The question

Rudolph Knjzek's Collatz-like rule: from a prime p, go to the largest prime factor of 3p + 1. For odd p, the next prime is larger than p only when (3p + 1)/2 is itself prime, so increasing runs look like 7, 11, 17 or 31, 47, 71, 107. Luke Pebody found the smallest starts of runs with 2 to 8 primes (3, 7, 31, 2111, 89599, 89599, 44102911) and showed the smallest run of 9 starts above 7·10⁸.

## What the page had vs ours

| | Smallest start of a run of 9 primes |
|---|---|
| On the page (L. Pebody) | "at least 7·10⁸" |
| **Ours** | **35014031359** |

## How we found it

In an increasing run, every step is p → (3p + 1)/2. Adding 1 to both sides gives p + 1 → (3/2)·(p + 1): the number p + 1 is multiplied by 3/2 at each step. After 8 steps it has been multiplied by 3⁸/2⁸, so p + 1 must be divisible by 2⁸ to start with, and actually by 2⁹, because the last prime is odd too.

So every run of 9 primes has the shape

```
p_k = m · 3^k · 2^(9−k) − 1,     k = 0, 1, …, 8
```

for some whole number m. Instead of following primes, we only have to find the least m for which all nine numbers are prime. A sieve over m does that in seconds: for each small prime q, each of the nine numbers is a multiple of q for exactly one value of m mod q, and those values can be crossed out at once.

## The math

```
p_(k+1) = (3·p_k + 1)/2   ⇔   p_(k+1) + 1 = (3/2)·(p_k + 1)
⇒  p_k + 1 = (3/2)^k · (p_0 + 1)
p_8 + 1 even and p_8 + 1 = 3^8 · (p_0 + 1)/2^8  ⇒  2^9 divides p_0 + 1
```

The smallest m that works is m = 68386780, which gives p₀ = 68386780 · 2⁹ − 1 = 35014031359.

## The numbers

```
35014031359  52521047039  78781570559  118172355839  177258533759

```

Each is (3·previous + 1)/2, and all nine are prime. All are below 2⁶⁴, so sympy's primality test is exact.

## Validation

This script sieves every m from 1 to 68386780, crossing out each m where one of the nine numbers m·3^k·2^(9−k) − 1 has a prime factor below 3000. It then tests the few survivors fully and checks that the first one is m = 68386780. It takes a few seconds.

```python
import numpy as np
from sympy import isprime, primerange, factorint

coef = [3**k * 2**(9 - k) for k in range(9)]          # p_k = m * coef[k] - 1
M = 68386780

alive = np.ones(M + 1, dtype=bool)
alive[0] = False
for q in primerange(3, 3000):
    for c in coef:
        if c % q:
            alive[pow(c, -1, q)::q] = False             # here q divides m*c - 1
small = [m for m in range(1, 10) if all(isprime(m * c - 1) for c in coef)]
assert small == []                                      # tiny m, where m*c - 1 could equal q itself

hits = [int(m) for m in np.flatnonzero(alive) if all(isprime(int(m) * c - 1) for c in coef)]
assert hits == [M]                                      # 68386780 is the least m

run = [M * c - 1 for c in coef]
assert all((3 * a + 1) // 2 == b for a, b in zip(run, run[1:]))
assert all(max(factorint(3 * a + 1)) == b for a, b in zip(run, run[1:]))   # the actual rule
print("smallest run of 9 starts at", run[0])
print(run)
```
