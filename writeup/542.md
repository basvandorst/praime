# Puzzle 542: σ(x) = q^n

> **In short:** We split n into its prime-power parts, which turns "every n up to 10¹⁸" into a list of about 5·10⁷ parts, so a 3-minute C run covers it. **81 and 400 are the only n ≤ 10¹⁸ with σ(n) = q^k (q an odd prime, k > 1).** For Q2, 3⁴ is the only prime power p^m ≤ 10¹⁸ with σ(p^m) = q^n. Two classical theorems (Ljunggren, Nagell) show that any other example needs an exponent n with no prime factor 2 or 3.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_542.htm)

**Status:** partial answer · exhaustive search to 10¹⁸ (Q1 and Q2) · Q2 reduced to exponents n with all prime factors ≥ 5 (literature)

## The question

Farideh Firoozbakht: σ(3⁴) = 11² and σ(20²) = 31².

- **Q1.** Find other n with σ(n) = q^k, q an odd prime, k > 1.
- **Q2.** Find another prime p with σ(p^m) = q^n, m, n > 1, q prime.

## How we found it

A direct search over n would stop near 10¹⁰. Instead we used three facts.

1. **σ(n) odd means n = m² or 2m².** For an odd prime p, σ(p^a) = 1 + p + … + p^a has a + 1 odd terms, so a must be even.
2. **σ is multiplicative.** Each part σ(p^a) of σ(n) = q^k is itself a power q^j, j ≥ 1.
3. **Each part is at most n.** For n ≤ X, every odd part p^a has a ≥ 2 even, so p ≤ √X.

So we list every prime power p^a ≤ 10¹⁸ (p = 2 with any a; p odd, p ≤ 10⁹, a even) whose σ is an odd prime power q^j. Then we group them by q. A solution n is a product of parts with the same q and distinct p, with total exponent k > 1. [`writeup/code/p542_components.c`](code/p542_components.c) does the listing: a segmented sieve, a deterministic 64-bit Miller–Rabin test, and integer roots. It ran in 3 minutes on 50,847,533 odd primes and found 1,974,296 parts. Of these, exactly **one q (31) has two parts** (2⁴ and 5²), and **exactly one part has j > 1** (3⁴, σ = 11²). [`writeup/code/p542_group.py`](code/p542_group.py) then gives:

```
(81,  11, k=2, parts 3^4)
(400, 31, k=2, parts 2^4 · 5^2)
```

## The math

**The part 2^a.** σ(2^a) = 2^(a+1) − 1 is never q^j with j ≥ 2 and q odd:

- If j is even, q^j ≡ 1 (mod 4), but 2^(a+1) − 1 ≡ 3 (mod 4).
- If j ≥ 3 is odd, then 2^(a+1) = q^j + 1 = (q + 1)(q^(j−1) − q^(j−2) + … + 1). The second factor is a sum of j odd terms, so it is odd and greater than 1. A power of 2 cannot have such a factor.

So 2 contributes only when 2^(a+1) − 1 is a Mersenne prime q, with j = 1.

**Q2 with q = 2 is impossible.** σ(p^m) = 2^n forces m = 1: for m ≥ 2, σ(p^m) has an odd factor greater than 1. This is the squarefree step of Lemma 1 in [489](489.md).

**Q2 with q odd** is the Nagell–Ljunggren equation (x^(m+1) − 1)/(x − 1) = y^n with x = p and y = q, both prime. Two classical theorems (literature; their statements are not in our archive):

- Ljunggren (1943): y² only for x = 3, m + 1 = 5 (11²) and x = 7, m + 1 = 4 (20²).
- Nagell (1920): y³ only for x = 18, m + 1 = 3 (7³).

If 2 | n, then q^n = (q^(n/2))² is a square, so Ljunggren applies. Only 3⁴ survives, because 20 is not a prime power. If 3 | n, then q^n is a cube and Nagell applies, but 18 is not prime. **So a new Q2 example needs an n whose prime factors are all ≥ 5.** The general equation is still open.

**Q1 beyond the search.** A new Q1 solution needs either a new Q2-type part (σ(p^a) = q^j, j ≥ 2), or two different prime powers with the same prime σ. The second is a case of Goormaghtigh's equation, whose only known solutions are 31 = σ(2⁴) = σ(5²) and 8191 = σ(2¹²) = σ(90²). The second of these does not count, since 90 is not prime.

## What remains open

- Q1 for n > 10¹⁸.
- Q2 for p^m > 10¹⁸ with n free of 2 and 3. For small bases we also checked p < 1000, m ≤ 400: σ(p^m) is a perfect power only for 3⁴ and 7³.

## Validation

[`writeup/code/p542_verify.py`](code/p542_verify.py) uses sympy and gmpy2 only and runs in about 15 s. It checks the claims by a different route from the C search: a direct enumeration of every n = m² and 2m² up to 2·10¹⁰.

```python
import gmpy2
from sympy import divisor_sigma, primerange, isprime, perfect_power

def odd_prime_power(s):
    """(q, k) if s = q^k with q an odd prime, else None."""
    if s % 2 == 0:
        return None
    if isprime(s):
        return (s, 1)
    pp = perfect_power(s)
    if pp and isprime(pp[0]):
        return pp
    return None

# 1. Direct: sigma(n) is odd only for n = m^2 or 2m^2. Check all of them up to 2*10^10.
hits = []
for m in range(1, 100001):
    for n in (m*m, 2*m*m):
        r = odd_prime_power(int(divisor_sigma(n)))
        if r and r[1] > 1:
            hits.append(n)
assert sorted(hits) == [81, 400], hits

# 2. sigma(2^a) = 2^(a+1) - 1 is never q^j with j >= 2 (a <= 200).
assert all(not (odd_prime_power(2**(a+1) - 1) or (0, 1))[1] > 1 for a in range(1, 201))

# 3. Q2 with q = 2: sigma(p^m) is never a power of 2 for m >= 2 (p < 1000, m <= 30).
assert not any(gmpy2.is_power(int(divisor_sigma(p**m))) and int(divisor_sigma(p**m)) & (int(divisor_sigma(p**m)) - 1) == 0
               for p in primerange(3, 1000) for m in range(2, 31))

# 4. Q2 for small p: (p^(m+1)-1)/(p-1) is a perfect power only for 3^4 and 7^3
#    (p < 1000, 2 <= m <= 400).
pw = [(p, m) for p in primerange(2, 1000) for m in range(2, 401)
      if gmpy2.is_power((p**(m+1) - 1)//(p - 1))]
assert pw == [(3, 4), (7, 3)], pw
print("all checks pass")
```
