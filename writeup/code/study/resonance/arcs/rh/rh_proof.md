## Verdict

**R_h is PROVED UP TO one quoted input whose primary source I could not open**: a zero-free region of
Vinogradov–Korobov/Chudakov type, with polylogarithmic bounds for L and 1/L inside it, for the Hecke L-functions
L(s, χλ^m) (χ a character mod h, λ^m the angular characters), uniformly in m (Hypothesis G_h, §3). For h = 1 this
input is in a refereed paper I read (Stucky, Lemmas 2.2–2.3, citing Coleman 1990); for h > 1 it is attributed to
Coleman (Mathematika 37 (1990)) by two opened papers, and its zero-free part (without the growth bounds) is stated
for every modulus in Duke (Acta Arith. 52 (1989), p. 222, citing Urbialis 1965). Given G_h, R_h holds for every
**θ < 1/(4 − 8δ)**, where δ > 0 is the absolute constant of Michel–Venkatesh (Publ. IHÉS 111 (2010), Theorem 1.1;
checked against the source text). The exponent as a function of a pointwise bound (2 + |k| + |t|)^{2κ} is
**θ < 1/(2 + 8κ)** (κ ∈ [1/8, 1/4]), which confirms the referee's formula; the derivation below does not use the
mean-value lemma of the caveat (it is false as stated, also for bounded coefficients) but a corrected version
(Lemma 5, proved), and it uses neither Coleman's hybrid large sieve nor Huxley's large-values estimate.

## 1. Theorem

Notation. O = ℤ[i], K = ℚ(i). For z ∈ O∖{0}: Λ(z) := Λ((z)), where Λ(𝔞) = log N𝔭 if 𝔞 = 𝔭^j (j ≥ 1), else 0;
arg z ∈ ℝ/2πℤ. q ∈ O∖{0}, Φ(q) := |(O/q)^*|. For an ideal 𝔞 = (α): cont(𝔞) := gcd(Re α, Im α) and
prim(𝔞) := (α/cont(𝔞)) (a primitive ideal: generated by a + bi with gcd(a, b) = 1).

**Hypothesis P_κ** (pointwise bound). For every q there is C_q such that for every primitive Grössencharacter ξ of K
of conductor dividing q and infinity type k (ξ((α)) = χ(α)(α/|α|)^k on α ≡ 1 mod^× conductor):
|L(1/2 + it, ξ)| ≤ C_q (2 + |k| + |t|)^{2κ} for all t ∈ ℝ.

**Hypothesis G_q** (zero-free region with growth). There are c_q > 0, B_q ≥ 0, a ∈ (0, 1) such that for every
Grössencharacter ξ ≠ 1 of K of modulus q, with infinity type k and V := |k| + |t| + 3, in the region
σ ≥ 1 − c_q (log V)^{−a}, σ ≤ 2: L(σ + it, ξ) ≠ 0 and (log V)^{−B_q} ≤ |L(σ + it, ξ)| ≤ (log V)^{B_q}.

**Theorem 1.** Assume P_κ with κ ∈ [1/8, 1/4) and G_q. Let θ < 1/(2 + 8κ) and ζ ∈ (O/q)^*. Then, as x → ∞,

    S(x; φ, ω) := Σ_{z ≡ ζ (mod q), N z ≤ x, arg z ∈ (φ, φ+ω]} Λ(z) = (2/π)·ω·x/Φ(q)·(1 + o(1)),

uniformly in φ ∈ ℝ and ω ∈ [x^{−θ}, 2π].

**Corollary (R_h).** By §3(e) (Michel–Venkatesh), P_κ holds with κ = max(1/4 − δ, 1/8). Hence, under G_h, Theorem 1
holds for every θ < 1/(4 − 8δ) (if δ ≤ 1/8; if δ > 1/8, for θ < 1/3). Since this is > 1/4, for fixed φ, c > 0 the
width ω = c x^{−1/4} is ≥ x^{−θ} for x ≥ x₀(c), and (φ − ω, φ] = (φ', φ' + ω] with φ' = φ − ω is covered by the
uniformity in φ. This is **Hypothesis R_h of arcs_theorem.md §2, word for word**: same sum (elements z, all
associates, Λ(z) = log N π on z = unit·π^k), same class condition z ≡ ζ (mod h), same normalisation
(2/π)|I_x|x/Φ(h). Nothing differs; Theorem 1 is stronger (any width ≥ x^{−θ}, uniform in φ, any modulus q ∈ O).
For h = 1 it reproves the input of Theorem A of the note without the mean-value lemma of the caveat.

## 2. Characters, units, infinity types (proved)

Let χ be a character of (O/q)^*. χ(i) is a 4th root of unity; let k_χ ∈ {0,1,2,3} with χ(i) = i^{−k_χ}. For k ∈ ℤ and
α coprime to q put e_k(α) := (α/|α|)^k. Then Σ_{ε∈{±1,±i}} χ(εα)e_k(εα) = χ(α)e_k(α)Σ_{j=0}^{3}(χ(i)i^k)^j, which is
4χ(α)e_k(α) if k ≡ k_χ (mod 4) and 0 otherwise. For k ≡ k_χ (4), ξ_{χ,k}((α)) := χ(α)e_k(α) does not depend on the
generator (χ(εα)e_k(εα) = (χ(i)i^k)^j·χ(α)e_k(α)): ξ_{χ,k} is a Grössencharacter of modulus q, infinity type k,
completely multiplicative on ideals prime to q (we set it 0 on the others). With λ(𝔞) := e_4(α) (Stucky's λ) and
ξ_χ := ξ_{χ,k_χ}: ξ_{χ,k_χ+4m} = ξ_χ λ^m, m ∈ ℤ, **both signs**. ξ_{χ,k} is trivial iff χ = χ₀ and k = 0.
(Computed: §H, Φ(2+i) = 4, Φ(5) = 16, Φ(3) = 8; the unit sum for all χ(i) ∈ μ₄, |k| ≤ 8.)

## 3. Quoted inputs, with the hypotheses as read in the sources

**(e) Michel–Venkatesh** (arXiv:0903.3591v2 = Publ. Math. IHÉS 111 (2010) 171–271; LaTeX source read). Theorem 1.1:
"There is an absolute constant δ > 0 such that: for π an automorphic representation of GL₁(𝔸) or GL₂(𝔸) (with unitary
central character), one has L(π, 1/2) ≪_F C(π)^{1/4−δ}." Remark after it: "this also includes … the t-aspect, because
L(π, 1/2 + it) = L(π ⊗ |.|^{it}, 1/2)". §5.1 theorem: "for χ a unitary (Hecke) character of F^×\𝔸_F^× … In particular,
L(χ, 1/2) ≪_F C(χ)^{1/4−δ}". Local analytic conductor (§ "The local analytic conductor"): at an archimedean place with
L-factor Π Γ_k(s + μ_i), C(π) = Π(2 + |μ_i|)^{deg k}; at a finite place q^{f(π)}; globally the product.
Hypotheses checked: F = ℚ(i) is fixed ✓. A Grössencharacter ξ (primitive, conductor f | q, infinity type k) is a
unitary idele class character ω; ω|·|^{it} is unitary ✓; its L-function is Σ_{(𝔞,f)=1}ξ(𝔞)N𝔞^{−1/2−it} ✓ (Tate). At the
complex place the L-factor is Γ_ℂ(s + |k|/2 + it), so C(ω|·|^{it}) = N(f)(2 + ||k|/2 + it|)² ≤ N(q)(2 + |k| + |t|)²
(up to a factor depending only on F). The bound is uniform in all aspects, in particular in the infinity type k
("frequency aspect"): C grows like k², and the exponent 1/4 − δ is subconvex in k. Hence P_κ with κ = 1/4 − δ
(imprimitive L-functions differ by Π_{𝔭|q}(1 − ξ*(𝔭)N𝔭^{−s}), of modulus ≤ 2^{ω(q)} on Re s = 1/2). δ is not explicit
("The value of δ is easily computable"), so the amount by which θ exceeds 1/4 is not explicit.

**(c) Zero-free region and growth (Hypothesis G_q).**
- q = 1. Stucky (arXiv:2008.11325 final version, read in full), Lemma 2.2: "Let V = (4m² + t²)^{1/2}. Then …
  L(σ + it, λ^m) ≪ V^{c(1−σ)^{3/2}}(log V)^{2/3}, uniformly for 1 − δ < σ < 1. … no zeros in σ ≥ 1 − C(log V)^{−2/3}
  (log log V)^{−1/3}" (from Coleman, Mathematika 37 (1990), Theorems 1 and 2); Lemma 2.3: "L'/L ≪ log V, 1/L ≪ log V"
  in that region (proof "follows closely Theorem 3.11 of Titchmarsh"). This is G₁ with any a ∈ (2/3, 1) for the
  characters λ^m (k ≡ 0 mod 4), which is all that q = 1 needs.
- q ≠ 1. Panidapu–Thorner (arXiv:2105.11093, relevant sections read), Lemma 3.3: zero-free region
  Re s ≥ 1 − c/((log(|Im s| + 3)M)^{2/3}(log log …)^{1/3}) for L(s, ξ_m), ξ_m primitive of conductor dividing a fixed
  𝔪 ≠ 1, "This follows from work of Coleman [Theorem 2]"; §4: "Lemmata ZFR and ZDE were proved in this level of
  generality in [Coleman 1990 (Proc. LMS), Coleman 1990 (Mathematika)]" (for twists by class-group characters).
  Järviniemi–Teräväinen (Rev. Mat. Iberoam. 40 (2024); text read in the relevant sections) apply "Theorems 1 and 6 in
  [Coleman, Mathematika 1990] (applied with f = 1 and V = O(m))", which indicates a modulus parameter f in Coleman's
  statements. Duke (Acta Arith. 52 (1989) 203–228, scanned pages read), p. 222: "Theorem (Urbialis). ζ(s, χλ^m) has no
  zeros for |Im s| ≤ T and Re s ≥ 1 − c₃ log^{−c₂} T if |m| ≤ T, T ≥ 2, and c₂ > 5/7. Here c₃ > 0 depends only on k, q,
  and c₂" — χ a narrow class character mod q, λ^m the torsion-free Hecke characters mod q, k any number field; it
  "follows in a standard way from Lemma 5 in [U]" (Urbialis, Liet. Mat. Sb. 5 (1965), not opened). This is the
  zero-free part of G_q (a = c₂). The polylog bounds for L^{±1} inside the region are what the proof needs in
  addition (Lemma 9); they come from a growth bound of the same type (Titchmarsh §3.11 argument) and are what I
  could not check for q ≠ 1. **This is the one step not closed against a primary source.**
- Why it is needed (not a weakness of the write-up): the Möbius factors of the Heath-Brown identity have length
  N ≥ x^{Δ/J} while the conductor is ≈ x^{2θ}; excluding their near-maximal values (σ > 1 − η) needs cancellation in
  Σ_{N𝔞~N} μ(𝔞)ξ(𝔞) for N ≥ V^c, c small. A zero-free region with only convexity growth gives
  |1/L| ≤ exp(O(η log V)) and fails exactly there (log N ≪ log V); a growth bound of Vinogradov/Chudakov type is
  required. The final saving x^{−Δ(1−σ)} beats the (log x)^B losses only if 1 − σ ≥ c(log x)^{−a} with a < 1.

## 4. Lemmas proved here

**Lemma 1 (angular cut-offs; proved, classical construction).** Let 0 < Δ_a < ω ≤ π, r ≥ 2. Let g be 1_{[φ,φ+ω]}
(on ℝ/2πℤ) convolved r times with the normalised indicator of [−Δ_a/2r, Δ_a/2r]. Then 0 ≤ g ≤ 1, g = 1 on
[φ + Δ_a/2, φ + ω − Δ_a/2], g = 0 outside [φ − Δ_a/2, φ + ω + Δ_a/2], ĝ(0) = ω/2π, and
|ĝ(k)| ≤ min(ω/2π, 1/(π|k|))·min(1, (2r/(|k|Δ_a))^r) (Fourier coefficients multiply: ĝ(k) = ĝ_ind(k)·sinc^r, and
|sinc(y)| ≤ min(1, 1/|y|)). ψ₊ := the same with [φ − Δ_a/2, φ + ω + Δ_a/2], ψ₋ := with [φ + Δ_a/2, φ + ω − Δ_a/2]:
ψ₋ ≤ 1_{(φ,φ+ω]} ≤ ψ₊, ψ̂_±(0) = (ω ± Δ_a)/2π, |ψ̂_±(k)| ≤ min(ω/π, 1/(π|k|))·min(1, (2r/(|k|Δ_a))^r).
(Computed: §E, bound for k ≤ 2000 and up to 10⁶; plateau/support by direct convolution.)

**Lemma 2 (lattice points in polar boxes; proved).** For r₁ ≥ 2, r₂ > r₁, 0 < ω' and y := r₂² − r₁²:
#{z ∈ ℤ²: r₁ ≤ |z| ≤ r₂, arg z ∈ [φ, φ + ω']} ≤ (ω'/2 + 1.12/r₁)(y + 2(r₁ + r₂)).
Proof: the unit squares centred at these z are disjoint and lie in {r₁ − 1 ≤ |w| ≤ r₂ + 1, arg w ∈ [φ − α, φ + ω' + α]}
with α = arcsin(1/(√2 r₁)) ≤ 1.111/r₁ (r₁ ≥ 2), of area ((ω' + 2α)/2)((r₂+1)² − (r₁−1)²). ∎ (Computed: §D, 150 random
boxes, max ratio 0.97.)

**Lemma 3 (log-Gaussian norm weight; proved).** For x, H > 0 let V(u) := P(Z ≥ H log(u/x)), Z standard normal. Then
0 ≤ V ≤ 1; |V(u) − 1_{u≤x}| ≤ exp(−H² log²(u/x)/2); and for Re s > 0, Ṽ(s) := ∫₀^∞ V(u)u^{s−1}du = x^s e^{s²/(2H²)}/s.
Proof: V(u) = E[1{u ≤ x e^{Z/H}}]; Fubini and ∫₀^Y u^{s−1}du = Y^s/s give E[(xe^{Z/H})^s]/s = x^s e^{s²/2H²}/s; the tail
bound is P(Z ≥ y) ≤ e^{−y²/2}. ∎ Hence |Ṽ(1/2 + it)| ≤ x^{1/2}e^{(1/4−t²)/(2H²)}/|1/2+it|, and for any finitely
supported c: Σ_𝔞 c(𝔞)V(N𝔞) = (1/2πi)∫_{(1/2)} Ṽ(s) Σ c(𝔞)N𝔞^{−s} ds (Mellin inversion; Ṽ is integrable on the line).
(Computed: §F, quadrature vs closed form, relative error ≤ 10⁻¹⁴.)

**Lemma 4 (Heath-Brown identity on ideals; proved; classical for ℤ, Heath-Brown 1982).** Let X ≥ 1, J ≥ 1, and
w: (0,∞) → ℂ bounded with w = 1 on (0, 1]. For every ideal 𝔞 with N𝔞 ≤ X^J and every completely multiplicative ξ,

    Λ(𝔞)ξ(𝔞) = Σ_{j=1}^{J} (−1)^{j−1} C(J, j) Σ_{𝔞₁⋯𝔞_{2j} = 𝔞} log(N𝔞₁) Π_{i=j+1}^{2j} μ(𝔞_i)w(N𝔞_i/X) · Π_{i=1}^{2j} ξ(𝔞_i).

Proof. With ζ = ζ_K and M(s) := Σ μ(𝔞)w(N𝔞/X)N𝔞^{−s} (Re s > 1): (1 − ζM)^J = Σ_j C(J,j)(−ζM)^j gives
−ζ'/ζ = −(ζ'/ζ)(1 − ζM)^J + Σ_{j=1}^J (−1)^{j−1}C(J,j)(−ζ')ζ^{j−1}M^j. The coefficient of 1 − ζM at 𝔞 is
[𝔞 = 1] − Σ_{𝔡|𝔞} μ(𝔡)w(N𝔡/X); it vanishes at 𝔞 = 1 and for 1 < N𝔞 ≤ X (all 𝔡 | 𝔞 have N𝔡 ≤ X, and
Σ_{𝔡|𝔞}μ(𝔡) = 0 in the Dedekind domain O). So (1 − ζM)^J, hence −(ζ'/ζ)(1 − ζM)^J, has coefficients supported on
N𝔞 > X^J. Comparing coefficients for N𝔞 ≤ X^J gives the identity for ξ = 1; multiply by ξ(𝔞) = Πξ(𝔞_i). ∎
(Computed: §G, exact check for X = 14, J = 2 and X = 6, J = 3, sharp and randomly smoothed w, all N𝔞 ≤ X^J.)
Smooth partition: let Φ₀ ∈ C^∞ be non-increasing, Φ₀ = 1 on (−∞, 1], 0 on [2, ∞), and W(u) := Φ₀(u) − Φ₀(2u).
Then W ≥ 0, supp W ⊂ [1/2, 2], Σ_{n≥0}W(2^n u) = Φ₀(u) (= 1 for u ≤ 1, ∈ [0,1] always); W(1) = 1, W = 0 on [2, ∞).
We take w(u) := Φ₀(u) = Σ_{n≥0} W(2^n u).

**Lemma 5 (mean value with content weight; proved; corrected form of "Ricci, Theorem C").** For M ≥ 1, T > 0,
N ≥ 1 and any complex c(𝔞) supported on N𝔞 ≤ N,

    Σ_{|m|≤M} ∫_{−T}^{T} |Σ_𝔞 c(𝔞)λ^m(𝔞)N𝔞^{−it}|² dt ≤ e²√π (√π M + πN/2) Σ_𝔞 |c(𝔞)|² (T + √π D(𝔞)),
    D(𝔞) := √(N / N prim(𝔞)) = cont(𝔞)√(N/N𝔞).

Proof. (i) Collapse. 𝔞 = (d)𝔞' with d = cont(𝔞) ∈ ℤ_{≥1}, 𝔞' = prim(𝔞); λ^m(𝔞) = λ^m(𝔞'), N𝔞 = d²N𝔞'. So the inner sum
is Σ_{𝔞'} λ^m(𝔞')N𝔞'^{−it}C_{𝔞'}(t), C_{𝔞'}(t) := Σ_d c((d)𝔞')d^{−2it}, the outer sum over primitive 𝔞' with N𝔞' ≤ N.
(ii) Spacing. Write λ^m(𝔞') = e(m x_{𝔞'}), x_{𝔞'} := (2/π)arg α' mod 1. For distinct primitive ideals (α'), (β') choose a
unit ε with ϑ := arg α' − arg(εβ') ∈ (−π/4, π/4]; Im(α'·conj(εβ')) is a nonzero integer (else εβ' would be a real
multiple of α', hence ±α' by primitivity), so |ϑ| ≥ |sin ϑ| ≥ 1/(|α'||β'|) ≥ 1/N and ‖x_{𝔞'} − x_{𝔟'}‖ ≥ 2/(πN) =: δ.
(iii) Large sieve with a Gaussian majorant. For δ-spaced x_r ∈ ℝ/ℤ and any b_r:
Σ_{|m|≤M}|Σ_r b_r e(m x_r)|² ≤ e Σ_m e^{−m²/M²}|…|² = e√πM Σ_{r,s} b_r b̄_s Σ_{k∈ℤ} e^{−π²M²(x_r−x_s+k)²} (Poisson;
the kernel is ≥ 0) ≤ e√πM Σ|b_r|² sup_r Σ_{s,k}e^{−π²M²(x_r−x_s+k)²} ≤ e(√πM + 1/δ)Σ|b_r|², because the lifts x_s − x_r + k
are δ-separated with one at 0, so the sum is ≤ 1 + 2Σ_{j≥1}e^{−π²M²j²δ²} ≤ 1 + 1/(√πMδ).
Applied at each t with b_{𝔞'} = C_{𝔞'}(t)N𝔞'^{−it}: Σ_m|…|² ≤ e(√πM + πN/2)Σ_{𝔞'}|C_{𝔞'}(t)|².
(iv) The t-integral. For d ≤ D_{𝔞'} := √(N/N𝔞'): ∫_{−T}^{T}|Σ_d b_d d^{−2it}|²dt ≤ e∫_ℝ e^{−t²/T²}|…|² =
e√πT Σ_{d,d'} b_d b̄_{d'} e^{−T²log²(d/d')} ≤ e√πT Σ|b_d|²·sup_d Σ_{d'≤D}e^{−T²(d−d')²/D²} ≤ e√π(T + √πD)Σ|b_d|²
(|log(d/d')| ≥ |d − d'|/D). Summing over 𝔞' and using D_{𝔞'} = D(𝔞) for 𝔞 = (d)𝔞' gives the claim. ∎
**On the caveat.** The form "≪ (MT + N min(M,T))Σ|c|²" (Stucky, Lemma 4.2, T ≤ M, arbitrary coefficients) fails for
c = 1 on the ideals (k), k ∈ ℤ (computed §B: ratio 75 at N = 2500, M = 5000, T = 1; 110 at M = 10⁵). These coefficients
are bounded, so **divisor-boundedness does not rescue that form**; what rescues the argument is the content weight:
for the coefficients that occur (Lemma 6) Σ|b(𝔞)|²cont(𝔞)/N𝔞 ≪ (log x)^B, and Lemma 5 then gives exactly
Stucky's estimate "R N^{g(2σ−1)} ≪ (MT + N^g(MT)^{(1−ℒ)/2})(log x)^B" (with T ≤ M). So Stucky's Theorem 1.1 (Theorem A
of the note) is not affected, up to a larger power of log. The same counterexample also disproves the box-shaped
large sieve that Duke conjectured (1989, p. 205), Σ(N(𝔞) + qMT)|c(𝔞)|² for |m| ≤ M, |t| ≤ T (computed: ratio 112).
(Computed: §B, Lemma 5 holds in 30 tests — six coefficient types including the counterexample, Möbius, d₂,
random phases — with LHS/bound ≤ 0.07; the spacing 2/(πN) and the collapse identity are checked.)

**Lemma 6 (divisor moments with the content weight; proved).** For g ≥ 1, Y ≥ 2:
Σ_{N𝔟≤Y} d_g(𝔟)² cont(𝔟)/N𝔟 ≤ (Σ_{d≤√Y} d_g(d)⁴/d)·(Σ_{N𝔞≤Y} 1/N𝔞)^{g²} ≪_g (log Y)^{g⁴+g²}.
Proof: d_g is submultiplicative on ideals (C(e+e'+g−1, g−1) ≤ C(e+g−1, g−1)C(e'+g−1, g−1)), so with 𝔟 = (d)𝔟':
d_g(𝔟) ≤ d_g((d))d_g(𝔟'); d_g((d)) ≤ d_g(d)² (split p: d_g(p^e)², inert: d_g(p^e), 2: C(2e+g−1, g−1) ≤ d_g(2^e)²);
cont·/N = d/(d²N𝔟'); d_g(d)⁴ ≤ d_{g⁴}(d), d_g(𝔟')² ≤ d_{g²}(𝔟'), and Σ_{n≤Y}d_m(n)/n ≤ (Σ_{n≤Y}1/n)^m. ∎
(Computed: §C, the product bound at Y ≤ 6·10⁴; the content weight costs a factor 4.5–8.3 there, ≤ 2 log Y.)

**Lemma 7 (Gallagher; proved).** If F is C¹ on [t₀ − 1/2, t₀ + 1/2]: |F(t₀)|² ≤ ∫_{|t−t₀|≤1/2}(|F|² + 2|F||F'|)dt
(write F(t₀)² = F(t)² + ∫_t^{t₀}2FF' and average over t). (Computed: §K.)

**Lemma 8 (pointwise bound for smooth factors; from P_κ).** Let W be as in Lemma 4, W* (u) := W(u)log u,
f(s) := Σ_𝔟 ξ(𝔟)W(N𝔟/N)N𝔟^{−s} with ξ ≠ 1 of modulus q and infinity type k. Then
|f(1/2+it)| ≤ C_{q,W}(2 + |k| + |t|)^{2κ}, and the same for W*.
Proof: f(1/2+it) = (1/2πi)∫_{(1)}L(1/2+it+s, ξ)W̃(s)N^s ds with W̃ entire, |W̃(s)| ≪_A (1+|s|)^{−A} on |Re s| ≤ 2

## 6. Proof of the Main Lemma (proved; Stucky's §4 scheme, with Lemmas 5–9 in place of his inputs)

Write ξ_k := ξ_{χ,k}, f_{i,k} := f_{i,ξ_k}; the family has ≤ K + 1 members, |k| < 2K, and k = k_χ + 4m with |m| ≤ K.

parity, so that within a class the t_{k,n} (fixed k) are 1-separated. Then ∫|F_k| ≤ (5 log x)^{2J}Z^{1/2}Σ_n|G_k(t_{k,n})|.
Levels: |f_{i,k}(1/2 + it_{k,n})| =: N_i^{σ(i,k,n)−1/2}(log x)^4 (i ∈ 𝔍_g). **Lemma 9 gives σ(i,k,n) ≤ 1 − η/2** for

## 7. Large values and the exponent (proved; computed)

In a class 𝒞(i, l), f := f_{i,·} has length N := N_i > x^{Δ/J} and coefficients a(𝔟) ∈ {μ, 1, log}·W(N𝔟/N), and
|f_k(1/2 + it_{k,n})| ≥ N^{σ−1/2}(log x)^4 on 𝒞. Write K = x^λ, λ ≤ θ + 2ε.

**Prop. 7.1 (large values, all g ≥ 1).** R ≤ C_{g,J,q}(K + (2N)^g)N^{g(1−2σ)}(log x)^{B_g}.
Proof. F_k := f_k^g = Σ_𝔟 β(𝔟)ξ_k(𝔟)N𝔟^{−s}, β := a^{∗g}, supported on N𝔟 ∈ [(N/2)^g, (2N)^g] =: [·, N_g],
|β| ≤ d_g(𝔟)(log x)^g. On 𝒞: R·N^{2g(σ−1/2)}(log x)^{8g} ≤ Σ_𝒞|F_k(1/2+it_{k,n})|². By Lemma 7 (per k and parity class)
this is ≤ 2(S₀ + 2√(S₀S₁)), S₀ := Σ_k∫_{|t|≤T₁+1}|F_k(1/2+it)|², S₁ the same with β log N𝔟. Since
ξ_k(𝔟) = ξ_χ(𝔟)λ^m(𝔟) with |m| ≤ K, Lemma 5 with c(𝔟) = β(𝔟)ξ_χ(𝔟)N𝔟^{−1/2} (|ξ_χ| ≤ 1: the fixed character is absorbed
in the coefficients; both signs of m are in the sum) gives
S₀ ≤ e²√π(√πK + πN_g/2)Σ|β|²N𝔟^{−1}(T₁ + 1 + √π 2^g cont(𝔟)) (D(𝔟) ≤ 2^g cont(𝔟) on the support)
≪ (K + N_g)(log x)^{3+2g}Σ_{N𝔟≤N_g}d_g(𝔟)²cont(𝔟)/N𝔟 ≪ (K + N_g)(log x)^{B'_g} (Lemma 6); S₁ ≤ (g log 2N)²·(same). ∎

**Prop. 7.2 (exclusion; from Lemma 8).** If N > X (then i ≤ j: a smooth 1/log factor) and 𝒞 ≠ ∅, then
N^{σ−1/2}(log x)^4 ≤ C(2 + 2K + T₁ + 1)^{2κ}log x ≤ C'K^{2κ}(log x)^{1+6κ}; as 1 + 6κ < 4, for x ≥ x₀ this forces
σ < 1/2 + 2κ/β, β := log N/log K (K ≥ 2; for K = 1, 𝒞 = ∅).

**Prop. 7.3 (trivial).** R ≤ (K + 1)(2T₁ + 2) ≪ K(log x)³.

**Prop. 7.4 (exponent).** In every case (R) holds.
- Short (N ≤ X). If N ≥ K: g = 1, R ≪ N^{2(1−σ)}(log x)^B ≤ x^{(2/J)(1−σ)}(log x)^B. If N < K: g := ⌈log K/log N⌉
  ≤ J/Δ + 1 (bounded), N^g ∈ [K, KN): R ≪ (KN)^{2(1−σ)}(log x)^B ≤ x^{2(λ+1/J)(1−σ)}(log x)^B. Both ≤ x^{(1−3Δ)(1−σ)} by (E2).
- Long (N > X), β = log N/log K. We show R ≪ K^{(2+8κ)(1−σ)}(log x)^B; (E1) then gives (R).
  (L1) β ≥ 1: g = 1 and Prop. 7.3: R ≪ K^{min(1, 2β(1−σ))}, and by Prop. 7.2 σ < 1/2 + 2κ/β. If β ≤ 1 + 4κ, use 2β ≤ 2 + 8κ.
  If β > 1 + 4κ, use 1/(1−σ) < 2β/(β − 4κ) ≤ 2 + 8κ (decreasing in β, equal at β = 1 + 4κ).
  (L2) 1/2 + 2κ ≤ β < 1 (note β > 4κ): g = 1, R ≪ K^{1−β(2σ−1)}, and (1 − β(2σ−1))/(1−σ) = 2β + (1−β)/(1−σ) is increasing
  in σ; at σ = 1/2 + 2κ/β it equals 2 − 8κ + 8κ(1−4κ)/(β − 4κ) ≤ 2 + 8κ (equality at β = 1/2 + 2κ).
  (L3) 1/2 ≤ β < 1/2 + 2κ: g = 2, R ≪ N^{4(1−σ)} = K^{4β(1−σ)}, 4β < 2 + 8κ.
  (L4) β < 1/2: g := ⌈1/β⌉ ≤ J(θ+2ε) + 1 (as N > X ⇒ β ≥ 1/(Jλ)), R ≪ K^{2gβ(1−σ)}, 2gβ < 2 + 2β < 3 ≤ 2 + 8κ (κ ≥ 1/8). ∎

Hence the exponent of the method is **A(κ) = 2 + 8κ** and the admissible widths are **θ < 1/(2 + 8κ)**: Weyl κ = 1/6 gives
3/10 (Ricci's exponent), convexity κ = 1/4 gives exactly 1/4 (not enough), any subconvexity κ < 1/4 gives θ > 1/4.
The worst case is a long smooth factor of length N = K^{1+4κ} at σ = 1/2 + 2κ/(1 + 4κ). (Computed, §A: the sup of
min{trivial, C′ with g ≤ 60}/(1−σ) under the exclusion, on a 1741 × 667 grid of (β, σ), equals 2 + 8κ to 0.004 for
κ = 1/8, 1/6, 0.2, 0.24, 0.249, 1/4, at the predicted (β, σ); without the exclusion the sup is not below 4; for
β ≤ 0.05 it is ≤ 2.07; it agrees with the referee's L = 1 values 3.3327, 3.9182, 3.9983 to 0.002.)

**Comparison with the referee.** The referee's formula 1/(2 + 8κ) is confirmed, and Weyl strength is indeed not needed.
Two differences: (1) the referee's scan used Stucky's estimate set, whose "Ricci C" is false as stated; here it is
replaced by Lemma 5, which is true and gives the same inequality for the coefficients that occur. (2) Stucky smooths the
norm cut-off on scale x^{1−ε}, so t runs to x^{ε}, ℒ < 1 occurs, and near σ = 1 his analysis needs Coleman's hybrid
large sieve and Huxley-type large values (the referee's scan, κ = 1/4: without Huxley A rises to 4.79 at ℒ = 0.6). The
log-Gaussian weight (Lemma 3) makes Ṽ decay like e^{−t²/2H²}, so t ≤ (log x)³ suffices, every t-factor is a power of
log x, and only Lemma 5, the trivial bound and the pointwise bound are needed. Coleman's Proc. LMS paper (not opened)
is therefore not used at all.

## 11. Classical vs derived here

Classical: the Heath-Brown identity (for ℤ; the ideal version is the same algebra), the large sieve (Lemma 5 (iii) is
a Gaussian-majorant variant of standard proofs), Gallagher's lemma, Stucky's §4 reduction scheme (Heath-Brown identity →
levels → classes → large values), the prime ideal theorem, the subconvexity bound (Michel–Venkatesh), the zero-free
regions (Coleman, Urbialis, Kubilius). Derived here: the corrected mean-value lemma with the content weight and its
counterexample-proof form; the observation that the coefficients of the method satisfy Σ|b|²cont/N ≪ (log x)^B so that
Stucky's (5.x) survives; the log-Gaussian norm weight that removes the t-aspect (t ≤ (log x)³) and with it Coleman's
large sieve and Huxley's estimate; the large-values case analysis with exponent 2 + 8κ under C′ + pointwise + trivial
bounds only; the extension to modulus q with ξ_χ in the coefficients.

## 12. Doubts and limits

1. G_q for q ≠ 1 rests on secondary sources. If Coleman's theorems were only for modulus 1, the gap is precisely the
   polylog bounds for L(s, χλ^m)^{±1} in a region 1 − c(log V)^{−a}, a < 1 (the zero-free part is in Duke/Urbialis).
2. δ of Michel–Venkatesh is not explicit, so θ − 1/4 is positive but not quantified.
3. The proof needs κ < 1/4 strictly for P_κ uniformly in k and t ≤ (log x)³ + 1; MV gives this. Convexity alone gives
   exactly θ = 1/4, which is not enough.
4. In Lemma 9 the truncation at |Im s| ≤ x uses V ≤ 3x; the constants in G_q must be uniform in k — as stated in the
   secondary sources (Coleman's region depends on V = |k| + |t| + 3 only).
5. The numerics test the main term at x = 10⁷ and every inequality of the lemmas on samples; they do not test the
   exponent θ > 1/4 (impossible at this height).
