A proof in Lean

A note published in November 2026 (remark.pdf) announced a proof of the Riemann hypothesis, and of the same statement for every Dirichlet L-function, written in the proof language Lean and found together with an AI model. The proof is a Lean project in 14 parts; a companion article (rh-short.pdf) explains its analytic steps and cites the deeper construction. We downloaded it and checked what can be checked without building it. This page shows what the theorem says, how large the project is, and what is still open.

Status: built and accepted by independent kernels, as reported by Andrew Sutherland (MIT) on 20–21 November 2026 (verification report; two of the slowest checks were still running). A Lean proof is only as good as two things: the statement (it is Mathlib's own RiemannHypothesis, see below) and the build (Lean's kernel must accept all 17.4 million lines, with no extra axioms). We checked the first ourselves; the second is the report's. The report used the same archive as we did (same SHA-256).

1. What the theorem says

The zeta function ζ(s) = 1 + 2−s + 3−s + … (a sum for Re s > 1, continued to every s ≠ 1) is zero at −2, −4, −6, … and at infinitely many points in the strip 0 < Re s < 1. The Riemann hypothesis says every zero in the strip lies on the line Re s = ½. In the picture dark means |ζ(s)| is small, and the darkest spots are the zeros (white rings); switch the colour to the direction of ζ(s) and a zero becomes a point where all colours meet. The white lines are the edges of the strip, the gold line is Re s = ½.

Right: Z(t), the real function with |Z(t)| = |ζ(½ + it)|. It changes sign where ζ has a zero on the line (all known zeros are simple), so every crossing is a zero (gold ticks). Computed with the Riemann–Siegel formula, as on the Prime Connection Laboratory page.

A picture can only show finitely many zeros. Computers have checked that the first 12.36 trillion zeros (all with 0 < t ≤ 3·1012) lie on the line (Platt and Trudgian, 2021). The Lean theorem proves it for all of them, and the same for every L(s, χ) of a Dirichlet character χ.

2. The same theorem, as a statement about the primes

Weil (1952) turned the Riemann hypothesis into a statement about the primes alone. Pick a test function φ: here a smooth bump of half-width a, tuned to a frequency ω. The explicit formula of Guinand and Weil says

Σ over the zeros ½ + iγ of h(γ)  =  h(i/2) + h(−i/2)  −  g(0)·log π  +  (1/2π)∫ h(r)·Re ψ(¼ + ir/2) dr  −  2·Σ Λ(n)/√n · g(log n)

with g = φ ∗ φ and h = φ̂2. Since g vanishes beyond 2a, the last sum runs over the prime powers n up to e2a only, each weighted by Λ(n) = log p. A zero on the line adds h(γ) = φ̂(γ)2 ≥ 0. So if RH holds, the right-hand side, computed from the primes without any zero, can never be negative; and Weil proved the converse: if it is never negative for any test function, RH holds. This is the sign the note says its proof wins ("Guinand–Weil had the sign").

The pink ticks are the heights of the zeros: W peaks where ω meets one, because φ̂ is then large at that zero. Between the peaks, and above all at ω = 0, the primes cancel the other terms almost exactly, and never overshoot. A picture of one family of test functions is not a proof: RH needs the sign for every test function, and that now follows from the Lean theorem. (The formal proof itself works with a related sign: an upper bound for a sum over the primes on selected ranges, as the companion article explains.)

3. The primes in a tube

The formal proof works with one sum over the primes. Give every prime power n = pk up to y the weight log p · (y/n − 1), add them up, and subtract y log y − (1 + γ)y, where γ = 0.5772… is Euler's constant. Call the result G(y). The Mellin transform of G in the companion article (its equation 2.3) gives, by the residue theorem, the exact formula

G(y)  =  log 2π  +  Σ over the zeros ρ of  yρ / (ρ(1 − ρ))  −  Σk≥1 y−2k / (2k(2k + 1))

On the line, ρ = ½ + iγρ and ρ(1 − ρ) = |ρ|2, so each zero adds a wave of height √y / |ρ|2, and these heights add up to √y · (2 + γ − log 4π) = 0.0461914… · √y. Now that RH is a theorem, the primes stay in a tube: G(y) − log 2π, plus the small last sum, never leaves ±0.0462 · √y. At y = 1 all the waves are in phase and the curve touches the edge; after that it never comes close. A zero off the line, at real part β > ½, would make the curve grow like yβ − ½ and leave every tube; the formal proof runs this argument backwards (Landau): an upper bound on selected ranges of y is enough to rule such zeros out.

(G(y) − log 2π + last sum) / √y, from the primesthe edge ±0.0462 that RH guaranteesthe same from the zeros

The page sieves the primes up to 107 itself (664,579 primes). Our separate check, a Python program with the primes up to 108, found the curve between −0.0227 and +0.0247 for every y from 100 to 108, and found the formula above equal to the sum over the first 400 zeros within the error of cutting that sum off. The overlay with all 79 zeros up to height 200 leaves out the rest of the zeros, worth up to about 0.006.

5. 203 layers of imports

A Lean file can only use what it imports. Give each file a layer: 0 if it imports no file of the project (only Mathlib or Lean itself), otherwise one more than the highest layer it imports. Main, the file with the final theorems, sits on top, in layer 202. Every one of the 175,187 files is imported by Main, directly or through other files. Imported is not the same as used: the archive also holds tooling and 195 files in folders named Counterexamples, and which of the million or so declarations the proof really needs only a build can tell.

    6. The last mile, in Lean

    The statement is not the project's own: RiemannHypothesis is defined in Mathlib, the community library of Lean (the pinned version says, above the definition, "constructing a term of this type is worth a million dollars"):

    def RiemannHypothesis : Prop :=
  ∀ (s : ℂ) (_ : riemannZeta s = 0) (_ : ¬∃ n : ℕ, s = -2 * (n + 1)) (_ : s ≠ 1), s.re = 1 / 2

    The project's file Main.lean in full:

    import Statements
import Supplements.Kernels.MainTheoremsAll

theorem riemannHypothesis : RiemannHypothesis := rhOfAll

theorem riemannZeta_eq_zero_re : RiemannZetaZerosOnLine := rhOfAll

theorem LFunction_ne_zero_of_half_lt_re : DirichletLNonvanishingRightOfHalf := allChi

theorem LFunction_eq_zero_re : DirichletLZerosOnLine := claimAll.2.1

theorem LFunction_eq_zero_re_of_isPrimitive : PrimitiveDirichletLZerosOnLine := critAll

    The steps just below are short and standard. The whole weight rests on one statement, EveryCharacter: no Dirichlet L-function vanishes where Re s > ½. The zeta function is the L-function of the character modulo 1, which gives ζ(s) ≠ 0 right of the line; the functional equation reflects a zero left of the line to the right, which gives the rest.

    theorem allChi : UpperTheory.EveryCharacter := UpperTheory.FinalTheorems.everyCharacter

theorem rhOfAll : RiemannHypothesis := Formalism.VW.rh_of_every allChi

theorem Formalism.VW.rh_of_every (h : UpperTheory.EveryCharacter) : RiemannHypothesis :=
  Formalism.VW.rh_of_right fun s hs hs1 => by
    have := h 1 (1 : DirichletCharacter ℂ 1) s hs (Or.inr hs1)
    rwa [LFunction_modOne_eq] at this
