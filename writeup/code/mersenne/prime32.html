Two-square tiles

Some numbers can be laid as two square tiles: 5 = 1² + 2², 13 = 2² + 3², 25 = 3² + 4², but 3, 7, 21 or 22 cannot. Fermat and Euler found the rule: a number is a sum of two squares exactly when every prime of the form 4k + 3 divides it an even number of times. Landau (1908) counted them: about K · x / √(ln x) up to x, with K = 0.7642 (the Landau–Ramanujan constant). The formula is right in the limit but approaches it painfully slowly; a second term found by Shanks brings it much closer, and two more terms closer still. Wieferich's needle: prime33, Euler's fountain: prime31, Euclid's orchard (also lattice points): prime25, overview: all pages.

Count against formula, up to 1016

The counts in the table are those of OEIS A164775 (computed by several contributors; see Shiu 1986 for a method); a separate program of ours sieved them up to 108 and agrees. Landau's formula is still 1.7 % short at 1016, because the next term of the expansion, C / ln x with C = 0.5819 (Shanks, 1964), shrinks only like 1 / ln x. With that term the error is 0.1 % at 1016 and falls like 1 / ln² x. Ramanujan wrote the count as K ∫ dt / √(ln t), which is better than Landau's but has the second term with 1/2 instead of C = 0.5819, so from 106 on it is worse than Shanks's form. The expansion goes on: by the Selberg–Delange method the next coefficients are 1.2910 / ln² x and 4.875 / ln³ x (computed), and with all four terms the formula is off by only 0.0018 % at 1016. The page and the sieve agree on the counts up to 106 and 107.
