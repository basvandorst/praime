Prime waterfall

Write the primes in a row: 2, 3, 5, 7, 11, 13, … Below it write the differences, without minus signs: 1, 2, 2, 4, 2, … Below that the differences of that row, and so on: a waterfall. Gilbreath noticed in 1958 that every row after the first starts with 1 (Proth had claimed a proof in 1878; it was wrong). It has been checked for the first 3.4 × 1011 primes (Odlyzko, 1993), and nobody has proved it. Is this about the primes, or would any sequence do? Try the fakes. Goldbach comet: prime10, turtle: prime8, Galton board: prime7, race: prime6.

Is the waterfall about the primes? Measured up to 5,000 and up to 1,000,000

Depth: the first row from which only 0s and 2s follow the leading 1. The fakes copy the true primes up to 100 and then take each number n that is not a multiple of the listed primes with the chance that makes their density match the primes. None of the 1,500 fakes up to 5,000 and none of the 500 fakes up to 1,000,000 broke Gilbreath's rule (fakes that are random from 3 on do break it: 70 of 200 odd fakes up to 5,000, and every fake that may also take even numbers). So the rule itself does not need the primes. What does single out the primes is how fast the waterfall settles: their depth is lower than for nearly all odd fakes, and fakes that also avoid 3, 5, 7, 11, 13 come closer, because the small primes make prime gaps more regular (the same reason the turtle of prime8 walks less far). The page and a separate program agree on the depth and the first column for the primes up to 1,000, 5,000, 100,000 and 1,000,000 and for the Mersenne exponents; the program also reproduces OEIS A036277 (where the first number above 2 sits in rows 0 to 51).
