Euler's fountain

In 1772 Euler noticed that n² + n + 41 is prime for every n from 0 to 39: 41, 43, 47, 53, 61, 71, … At n = 40 the fountain sputters (40² + 40 + 41 = 41²), but it keeps spouting primes far more often than other numbers of the same size. The reason: no prime below 41 ever divides n² + n + 41, because −163 is not a square modulo any of them. Bateman and Horn's conjecture turns this into a count: their constant C = 6.6395 says how much richer the fountain is than numbers picked at random. Spiral: the numbers 41, 42, 43, … wound outward, with the fountain's values on one diagonal. Counted up to ten million

Bateman and Horn's conjecture (1962) predicts that the number of n below N with n² + n + 41 prime is about C · Σ 1 / ln(n² + n + 41), where C is a product over all primes p of (1 − w(p)/p) / (1 − 1/p) and w(p) is the number of solutions of n² + n + 41 ≡ 0 mod p. Since w(p) = 1 + (−163 / p), and −163 is a non-square modulo every prime below 41, w(p) = 0 for those primes and each of them raises C. The class number formula for Q(√−163) turns the product into an absolutely convergent one: C = 6.6395464 (computed with the primes up to 107; with ln(n² + n + 41) ≈ 2 ln n the same prediction reads 3.3197732 · Σ 1 / ln n). A separate program sieved the values for n below 107 and a third counted them by a primality test below 106: both give the counts below. The conjecture is not proved for any polynomial of degree 2; it is not even known that n² + n + 41 is prime infinitely often.
