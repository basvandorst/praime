# Puzzle 61, Q7: why the GMN primes end in 1

> **In short:** M(a, p) = a^p − a + 1, and all known primes with two expressions have one with p = 2. The two expressions together force the last digit to be 1 or 7. It can only be 7 when the odd prime p ≡ 3 (mod 4), a ≡ 2 (mod 5) and the square-side base b ≡ 3 (mod 5). The number 7 = M(2, 3) = M(3, 2) is exactly that case. The other five primes cannot end in 7: three have p = 5 or p ≡ 1 (mod 4), and the other two have a ≡ 0 or 1 (mod 5).

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_061.htm)

**Status:** answered (Q7 only)

## The question

Jean Brette's "generalized Mersenne numbers" M(a, p) = a^p − a + 1 (p prime) with two expressions are 7, 31, 211, 241, 8191 and 78121, which are prime, and 2185 and 24299971, which are composite. Q7 asks: "Is there any special reason why, except the first GMN prime of this kind of numbers (7), all the other end in the decimal digit 'one'?" On the page, only A057896 is cited.

## The answer

N − 1 = a^p − a is always even, since a^p ≡ a (mod 2). So N ends in 1 exactly when 5 | a^p − a.

**The square expression.** For N = b² − b + 1, b(b − 1) mod 5 can only be 0, 1 or 2. So N mod 5 ∈ {1, 2, 3}, and since N is odd, N ends in 1, 7 or 3.

**The odd-p expression.**

- If p = 5 or p ≡ 1 (mod 4), then a^p ≡ a (mod 5) for every a, by Fermat. So 5 | N − 1 and **N ends in 1**.
- If p ≡ 3 (mod 4), then a^p − a ≡ a³ − a = (a − 1)·a·(a + 1) (mod 5). This is 0 for a ≡ 0, 1, 4, it is 1 for a ≡ 2, and it is 4 for a ≡ 3. So N mod 5 ∈ {1, 2, 0}, and 0 is impossible for a prime above 5.

**Both together.** For a prime N above 5, N mod 5 lies in {1, 2, 3} ∩ {1, 2, 0} = {1, 2}. So N ends in 1 or 7.

Ending in 7 means N ≡ 2 (mod 5). That needs p ≡ 3 (mod 4) and a ≡ 2 (mod 5) on one side, and b ≡ 3 (mod 5) on the other.

| N | odd expression | why it ends in 1 |
|---|---|---|
| 7 | M(2, 3) = M(3, 2) | ends in 7: p = 3, a = 2, b = 3 (the exceptional case) |
| 31 | M(2, 5) | p = 5 |
| 211 | M(6, 3) | a ≡ 1 (mod 5) |
| 241 | M(3, 5) | p = 5 |
| 8191 | M(2, 13) | p ≡ 1 (mod 4) |
| 78121 | M(5, 7) | a ≡ 0 (mod 5) |

So "1" is forced unless a rare congruence lines up, and only the smallest case, 7, has it.

The composite 2185 = M(3, 7) = M(13, 3) has no square expression and ends in 5. Ending in 5 is allowed when both p ≡ 3 (mod 4), and then 5 | N, as it does here.
