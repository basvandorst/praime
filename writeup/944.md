# Puzzle 944: Palprimes that stay palprimes when a digit is intertwined

> **In short:** Intertwining the digit D between all digits of a palprime P gives N_D = A + D·B with A = P spread with zeros and B = 1010…10, so the puzzle asks for a palprime whose spread starts a prime arithmetic progression with the fixed difference B; the record was D = 0 … 5 (a 13-digit P). (1) P must have an odd number n of digits (even-length palindromes are multiples of 11), and n ≡ 1 (mod 3) makes 3, 7, 13, 37, 101 and 9901 divide B, which lifts the chance of each term. (2) Among all 13-digit palprimes the record P is the only one with D = 0 … 5; among all 19-digit palprimes there are nine with D = 0 … 5 and none with D = 0 … 6, as a sieve against 38 small primes followed by primality tests shows. (3) The per-term probability of about 0.057 at 19 digits predicts 7.9 runs to 5 (9 found) and 0.45 runs to 6; runs to 6 should first appear in abundance among 25-digit palprimes (about 40 expected), beyond an exhaustive scan.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_944.htm)

**Status:** open · explained (D = 0 … 5 is the maximum for 13- and 19-digit palprimes, exhaustive; no D = 0 … 6 found; expected first at 25 digits)

## The question

Carlos Rivera: let P be a palprime and intertwine the digit D between all its digits; for P = 3273534353723 the results are palprimes for D = 0, 1, 2, 3, 4, 5 (3020703050304030503070203, …). Q: a palprime producing palprimes for D from 0 to k with 5 < k < 10. Paul Cleary found two 19-digit palprimes (7808765306035678087 and 7792235971795322977) that work for eight of the ten digits (D = 0, 1, 2, 3, 5, 6, 7, 9).

## How we found it

Writing P = Σ pᵢ·10^{n−1−i}, the intertwined number is Σ pᵢ·100^{n−1−i} + D·(10 + 1000 + … + 10^{2n−3}) = A + D·B. The ten candidates are an arithmetic progression with the fixed difference B, so the problem is the classical "primes in arithmetic progression" with the first term restricted to spreads of palprimes. Two consequences: n must be odd, since an even-length palindrome is divisible by 11; and for D = 0 … 5 to be prime, 3 and 5 must divide B (else three or five consecutive terms cover all residues), which holds exactly when 3 | n − 1; then 7, 13, 37, 101 and 9901 divide B as well. So n ∈ {13, 19, 25, …}. For n = 13 all 353701 palprimes were tested directly ([`code/p944_scan.py`](code/p944_scan.py)). For n = 19 a C program enumerates the 4·10⁹ palindromes, carries A modulo 38 primes q ∤ B (11 to 199) along the digits and keeps a palindrome only if A + D·B is coprime to all of them for D = 0 … 5, then tests P for primality ([`code/p944_sieve.c`](code/p944_sieve.c)); the 3998065 surviving palprimes were tested for the progression with gmpy2 ([`code/p944_ap.py`](code/p944_ap.py)).

## The math

**Step 1 (proved). The progression.** With A = spread(P) and B = 10·(100^{n−1} − 1)/99: N_D = A + D·B for D = 0 … 9, and N_D is a palindrome whenever P is. If q ∤ B and q ≤ k + 1, the k + 1 terms N₀ … N_k run through k + 1 distinct residues mod q and one of them is divisible by q; hence D = 0 … 5 requires 3 | B and 5 | B. Since 100 ≡ 1 (mod 3) and (100^{n−1} − 1)/99 ≡ n − 1 (mod 3), this means n ≡ 1 (mod 3). For such n, 100 has order 3 modulo 7, 13 and 37 and order 2 modulo 101, so these primes divide B too (and 9901, of order 6, when 6 | n − 1). The same argument shows that D = 0 … 6 and D = 0 … 9 need no further divisors (7 | B already), but D = 0 … 9 would need 11 ∤ B to be compensated by luck: with 11 ∤ B one of eleven consecutive terms is divisible by 11, but ten terms can avoid it (one residue class of A mod 11).

**Step 2 (computed). 13 digits.** All 353701 palprimes with 13 digits: the number with N₀ … N_k all prime is 22857 (k ≥ 0), 1977 (k ≥ 1), 195, 15, 2, 1 for k ≥ 2, 3, 4, 5. Only Rivera's 3273534353723 reaches k = 5; the k = 4 case is 3488975798843.

**Step 3 (computed). 19 digits.** Of the 4·10⁹ palindromes, 64734360 pass the sieve (A + D·B coprime to all primes 11 … 199 not dividing B, for D = 0 … 5), and 3998065 of those are prime. Among them the run lengths are: k = 0 for 302745, 1 for 33960, 2 for 4009, 3 for 445, 4 for 43, 5 for 9, and none with k ≥ 6. The nine palprimes with D = 0 … 5 are 1101973017103791011, 1751821346431281571, 3330451085801540333, 3410688833388860143, 3793877227227783973, 7803171488841713087, 7910913998993190197, 9394288609068824939 and 9863305824285033689 (all 37-digit terms proven prime with PARI). So no 19-digit palprime beats Rivera's record, and Cleary's examples are the best possible in the non-consecutive sense only.

**Step 4 (heuristic). Where k = 6 lives.** Each term is a 2n − 1 digit number coprime to 2, 3, 5, 7, 13, 37, 101 and 9901 when A is, so it is prime with probability about Π q/(q−1) / ln 10^{2n−1} ≈ 4.8/ln 10^{2n−1}: 0.084 at n = 13 and 0.056 at n = 19. The 13-digit ratios 1977/22857, 195/1977, 15/195 (0.087, 0.099, 0.077) agree. For n = 19 the model predicts 2.3·10⁸ palprimes, 7.9 with k ≥ 5 (9 found) and 0.45 with k ≥ 6 (none). For n = 25 there are about 1.7·10¹¹ palprimes and the per-term probability is 0.042, so about 40 palprimes with k ≥ 6 and 1.8 with k ≥ 7 are expected; finding one needs a scan of 4·10¹² palindromes, a thousand times ours.
