# Puzzle 189: Numbers in a row with prime sums and prime square sums

> **In short:** Arrange 1 … n so that every two neighbours have a prime sum, and their squares have a prime sum too. T. D. Noe left 22 values of n open. We settled all of them: a path exists for 52, 53, 56, 58 and every open value above, and none exists for 44, 45, 46, 47, 49, 51 and 54. With paths for every n from 58 to 200, the threshold asked for is n₀ = 57.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_189.htm)

**Status:** first answer (Task 2) · exhaustive search

## The question

Task 2 asks for an arrangement of 1, 2, …, n where, for every two neighbours a and b, both a + b and a² + b² are prime. Example for n = 10: 7, 10, 9, 4, 1, 6, 5, 8, 3, 2. Question 2 asks whether there is a solution for every n above some n₀, and what n₀ is.

| n₀ | "I think … n > 97, possibly less" | **57** |

## How we found it

Noe already turned it into a graph problem: join two numbers when both sums are prime, and look for a path through every number once (a Hamiltonian path). We added two rules that make an exhaustive search fast:

- **A number with only one free neighbour left must be the last one.** The path still has only one end to fill, so if two numbers are left with one free neighbour each, the branch is dead.
- **A number whose only free neighbour is the current end must come next.** Otherwise it is cut off for good.

With these rules, each "no path" case takes well under a second, and a path for every n from 58 to 200 comes out in a few seconds in total.

**Why 57 fails.** a + b can only be an odd prime if a and b have opposite parity, so the path alternates odd and even. For n = 57 there are 29 odd and 28 even numbers, so both ends must be odd. But the even number 54 has only one neighbour (25), so it must be an end. Contradiction.

## The math

```
neighbours a, b:   a + b prime  and  a² + b² prime
a + b odd prime  ⇒  a, b of opposite parity  ⇒  the path alternates odd/even
n = 57:   only neighbour of 54 is 25,   only neighbour of 47 is 20
          a degree-1 number must be an end, and both ends of an odd-length path are odd  ⇒  no path
```

## Verify it yourself

This script checks every path in the data file (each uses 1 … n once, and every pair of neighbours has a prime sum and a prime sum of squares), and checks the degree argument that rules out n = 57.

```python
from sympy import isprime

def good_pair(a, b):
    return isprime(a + b) and isprime(a * a + b * b)

paths = {}
for line in open("writeup/data/189.txt"):
    if line.startswith("#"):
        continue
    n, path = line.split(":")
    paths[int(n)] = list(map(int, path.split()))

assert sorted(paths) == list(range(58, 201))                 # a path for every n from 58 to 200
for n, path in paths.items():
    assert sorted(path) == list(range(1, n + 1))             # uses 1..n exactly once
    assert all(good_pair(a, b) for a, b in zip(path, path[1:]))

small = {12: "11 6 5 8 3 2 1 4 9 10 7 12",
         31: "7 12 17 2 27 20 3 8 23 18 5 24 19 10 21 26 11 6 31 16 1 4 9 14 15 22 25 28 13 30 29"}
for n, text in small.items():                               # the two Noe's greedy search missed
    path = list(map(int, text.split()))
    assert sorted(path) == list(range(1, n + 1)) and all(good_pair(a, b) for a, b in zip(path, path[1:]))

# n = 57: the even number 54 has a single neighbour, so it must be an end of the path,
# but a path of 57 alternating numbers starts and ends with odd numbers
n = 57
neighbours = {v: [w for w in range(1, n + 1) if w != v and good_pair(v, w)] for v in range(1, n + 1)}
assert neighbours[54] == [25] and neighbours[47] == [20]
print("paths verified for n = 58 .. 200; n = 57 is impossible")
```

The seven "no path" cases need the exhaustive search in C, [code/189.c](code/189.c). It takes n and a node limit, and prints a path or "NONE (exhaustive)":

```
gcc -O2 -o path writeup/code/189.c
for n in 44 45 46 47 49 51 54; do ./path $n 100000000000; done     # each: NONE (exhaustive), under a second
```
