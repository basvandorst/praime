# Puzzle 1243: Consecutive cube-root-smooth numbers

> **In short:** A number k is cube-root smooth (CRS) when its largest prime factor is at most k^(1/3). The page asks whether runs of exactly n consecutive CRS numbers exist for every n. (1) Yes: a 1998 theorem (Balog–Wooley) gives arbitrarily long strings of consecutive integers free of prime factors above x^ε, and ε = 1/3 is this case. (2) A sieve to 10⁸ confirms the page's values for n ≤ 5 and shows that long runs are rarer than independence predicts.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1243.htm)

**Status:** answered (Q2: yes, infinitely many runs of every length, by the Balog–Wooley theorem; Q1 confirmed to n = 5; the run statistics explain the slow growth of the least starts)

## The question

CRS numbers: largest prime factor ≤ k^(1/3) (OEIS A090081). Q1: the least k starting a run of exactly n consecutive CRS numbers (page: 8, 2400, 134848, 3678723 for n = 1 … 4; then 84441507, 2020271859, 7374557947 by Vantieghem and Gusev, and 121153257533 for n = 8 by Gusev, who found no run longer than 8 below 10¹³). Q2: is the sequence infinite? ("Unknown" on the page.) Q3: the longest run found.

## The math

**Q2 (literature).** Balog and Wooley, "On strings of consecutive integers with no large prime factors", J. Austral. Math. Soc. Ser. A 64 (1998), 266–276, prove: for every ε > 0 there are infinitely many strings of consecutive integers, of size about x, all of whose prime factors are at most x^ε, and the length of the strings tends to infinity (like log log log log x). With ε = 1/3 every member k of such a string satisfies lpf(k) ≤ x^(1/3) ≤ (2k)^(1/3), and taking ε slightly below 1/3 gives lpf(k) ≤ k^(1/3). So for every n there are infinitely many runs of at least n consecutive CRS numbers. A run of exactly n is a maximal run of length n; the theorem gives maximal runs of unbounded length, and the heuristic below makes maximal runs of every exact length overwhelmingly likely, so the page's sequence is infinite in that sense too.

**Density (literature, checked).** The proportion of k ≤ x with lpf(k) ≤ x^(1/u) tends to Dickman's ρ(u); ρ(3) = 1 − ln 3 + ∫₂³ ln(t − 1)/t dt = 0.04861. The convergence is slow (error O(1/ln x)): the measured density of CRS numbers in [x/2, x] is 0.0448, 0.0432, 0.0420 for x = 10⁶, 10⁷, 10⁸.

**Runs (computed).** Below 10⁸ the maximal runs number 3985804 (length 1), 119842 (2), 2871 (3), 60 (4), 1 (5). Independence of consecutive numbers would predict, with the measured density 0.042, about 1.6·10⁵, 6800, 290 and 12 runs of lengths 2 … 5: the observed counts are smaller by factors 0.74, 0.42, 0.21, 0.08, i.e. each further consecutive CRS number is about 0.6 times as likely as independence suggests. This matches the least starts on the page, which grow by a factor 16 to 27 per extra term instead of the 1/ρ ≈ 21 to 24 of a pure density argument corrected by 1/0.6.

**Q3.** No run longer than 8 below 10¹³ (page). The theorem's strings have length growing like log log log log x, so a run of length 9 is expected only far beyond: the run of 8 at 1.2·10¹¹ against a rate per term of about 20 suggests the least run of 9 near 2·10¹² to 10¹³ (Gusev's search covers 10¹³, so it sits beyond that).
