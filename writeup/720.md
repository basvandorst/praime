# Puzzle 720: x²&y² a square for consecutive x, y (partial answer)

> **In short:** Write the right-hand block as m², with k digits, and the left-hand block as s² with s = m ± 1. For even k there is no solution with m ≥ 2. A short inequality proves it: the square just above s·10^(k/2) is already too far away. For odd k a continued-fraction reduction rules out every k ≤ 91, so m² up to 91 digits. A heuristic count gives about 0.02 expected solutions over all odd k ≥ 3. So the two known examples 49 and 169 are very likely the only ones, but the odd case is not proved. This is an open attempt, not a full answer.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_720.htm)

**Status:** open · even k proved impossible; odd k proved impossible for k ≤ 91, heuristically for all k

## The question

Are there consecutive x, y > 3 such that the concatenation x²&y² (or y²&x²) is a square? The known examples are (2, 3) → 49 and (3, 4) → 169. On the page, Emmanuel Vantieghem gave a Pell-equation heuristic and wrote "I do not have a proof".

## Even k: impossible

We need Z² = s²·10^k + m², where k is the number of digits of m² and s = m ± 1.

1. Put T = 10^(k/2). Then m² < 10^k = T², so m < T.
2. Since Z > sT, write Z = sT + δ with δ ≥ 1. Then m² = Z² − s²T² = 2δsT + δ² ≥ 2sT.
3. But m² < mT ≤ 2sT, because s = m ± 1 ≥ m/2 whenever m ≥ 2.
4. That contradicts step 2.

## Odd k: reduced, checked, not proved

Put 10^k = 10·T² with T = 10^((k−1)/2). Then T ≤ m < √10·T, and

```
Z² − 10·(Ts)² = m²,    Z = √10·Ts + ε  with  0.16 < ε < 0.5.
```

So Z is the integer just above √10·Ts, and the remainder Z² − 10(Ts)² has to equal m² exactly. For a given s that happens with chance about 1/(2√10·Ts). Summed over the about 2.2·T values of s and both signs, that gives about 0.2/T per k. Summed over all odd k ≥ 3, the total is about 0.02 expected solutions; k = 1 gives the two known examples.

In Vantieghem's form this is the Pell-type equation X² − (10^k + 1)·Z² = −10^k with X = (10^k + 1)·s ∓ 1. A proof would need the solution classes of that equation, and the fundamental unit for odd k is huge. We did not find an elementary argument.

## Odd k: a continued-fraction reduction (k ≤ 91)

Write A = Z − m and B = Z + m. Then AB = 10^k·s², B − A = 2m, and gcd(m, s) = 1.

1. **Split.** An odd prime p ≠ 5 that divides s cannot divide both A and B, because then p | 2m. So A = 2^(a₁)5^(b₁)U² and B = 2^(a₂)5^(b₂)V², where UV is the part of s coprime to 10 and gcd(U, V) = 1.
2. **A good approximation.** Put R = 2^(a₁−a₂)5^(b₁−b₂). Then V²/U² = R·(1 + 2m/A), so

   0 < V/U − √R ≤ √R·m/A = m·UV/(10^(k/2)·s) · 1/U² ≤ (m/10^(k/2)) · 1/U² < 1/U².

3. **Fatou's theorem.** Because the error is below 1/U², V/U is a convergent of √R or one of its two neighbouring mediants.
4. **Parity.** 10^k·R must be a square, so a₁ − a₂ and b₁ − b₂ are odd. The bounds a₁ + a₂ = k + 2v₂(s) and b₁ + b₂ = k + 2v₅(s) cap |a₁ − a₂| and |b₁ − b₂|.
5. **Recover s.** Each candidate gives s exactly:

   s = 2ε / (2 − √(10^k/R)·(V² − R·U²)/(UV)),  where m = s − ε and ε = ±1.

So for each odd k there are finitely many R and O(k) candidate fractions per R. [`writeup/code/p720_cf.py`](code/p720_cf.py) runs through all of them. It finds 49 and 169 at k = 1 and nothing for 3 ≤ k ≤ 91 (29 minutes). This matches the exhaustive check for k ≤ 15. A proof for every k would need a uniform argument over all R, which we do not have.
