# Puzzle 463: k·P(k) + (k+1)·P(k+1)

> **In short:** T(k) = k·pₖ + (k+1)·pₖ₊₁, with pₖ the k-th prime; the record is 7 primes T(k) in a row (from k = 321150), and five such runs were known for k < 3.72·10⁸. A segmented sieve that carries the index k along, with T(k) tested on residues modulo 3 … 31 before any large number is formed, covers every prime below 10¹²: there are 17 runs of 7 below 2·10¹¹ and no run of 8 below 10¹² (k < 3.76·10¹⁰).

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_463.htm)

**Status:** open · no run of 8 for pₖ < 10¹² (computed); the list of runs of 7 extended from 5 to 17

## The question

6·13 + 7·17 = 197, 7·17 + 8·19 = 271, 8·19 + 9·23 = 359 are prime: three steps. The page has 7 steps from k = 321150 (p = 4580041) and asks for more than 7.

## How we found it

1. T(k) needs the index k, so the primes must be counted from the start. The search sieves the primes in segments and adds the count; a later start takes its index from π(x) (sympy.primepi, 16 seconds for 6·10¹¹).
2. T(k) modulo a small q depends only on k mod q and the two primes mod q. Positions where some q ≤ 31 divides T(k) are dropped with array operations; a run needs 7 or 8 surviving positions in a row, which leaves few candidates for the primality test.
3. A run of 7 continues with the chance that one more T is prime, roughly 0.05 near pₖ = 5·10¹¹ (T has 22 digits). So about one run of 8 per twenty runs of 7 is expected; with 17 runs of 7 below 2·10¹¹ and more beyond, finding none below 10¹² is mildly unlucky, not a sign of an obstruction.

## The math

**Parity (proved).** One of k, k + 1 is even, and for k ≥ 2 both primes are odd, so T(k) is odd.

**Modulo 3 (proved).** For primes above 3: if k ≡ 0, T ≡ pₖ₊₁ ≢ 0; if k ≡ 2, T ≡ 2pₖ ≢ 0; if k ≡ 1, T ≡ pₖ − pₖ₊₁, so the two primes must differ modulo 3. Every third step carries a condition modulo 3; similar conditions hold for each q. None of them forbids a run of 8: the residues of the primes can always be chosen to avoid 0.

**Ranges (computed).** [`code/p463_search.py`](code/p463_search.py): runs of at least 7 for 3 ≤ pₖ < 2·10¹¹ (two parts, split at 8·10¹⁰); runs of at least 8 for 2·10¹¹ ≤ pₖ < 10¹² (parts 2·10¹¹ … 6·10¹¹, 6·10¹¹ … 8.8·10¹¹ and 8·10¹¹ … 10¹²). π(10¹²) = 37607912018, so k < 3.76·10¹⁰.
