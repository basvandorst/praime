# Puzzle 211: The alternating sum of the primes (attempt)

> **In short:** The page asks to prove lim AS(p_n)/p_n = 1/2, where AS(p_n) = p_n − p_(n−1) + p_(n−2) − … ± 2. Joseph L. Pe refuted both proofs offered on the page, and the question is still open in the literature (OEIS A008347: "Does lim b(n) exist? If so, it must equal 1/2"; Meštrović 2018 states it as a conjecture). We prove an unconditional partial result: **1/64 ≤ liminf AS(p_n)/p_n ≤ limsup AS(p_n)/p_n ≤ 63/64.** So the ratio p_n/AS(p_n) stays between 64/63 and 64; the conjectured limit is 2. Numerically AS(p_n)/p_n − 1/2 = O(p_n^(−1/2)): |2AS(p_n) − p_n| < 8√p_n for all n ≤ 1.1·10⁷.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_211.htm)

**Status:** open · limit not proved; unconditional bounds 1/64 and 63/64 proved; numerics to n = 1.1·10⁷

## What the page has

Sebastián Martín Ruiz conjectured lim p_n/AS(p_n) = 2 and asked for a proof (Q1), and how good p_n ≈ 2·AS(p_(n−1)) is (Q2). Bruce Fleming's "outline proof" used an alternating-series argument. Joseph L. Pe showed it fails, because the terms p_(n−k)/p_n depend on n. Pe also showed the flaw in Martín Ruiz's own proof (replacing every p_(n−k) by its asymptotic). Fleming then wrote that one could at least show that if the ratio converges, the limit is 1/2. Hans Havermann's graph to 10⁶ "looks like the sequence now converges".

## The reformulation

AS(p_n) = (p_n − p_(n−1)) + (p_(n−2) − p_(n−3)) + … is the sum of every other prime gap, namely the gaps g_k = p_(k+1) − p_k with k ≡ n − 1 (mod 2), up to p_n. Equivalently, AS(p_n) is the measure of the set of x ≤ p_n where π(x) has a fixed parity. The conjecture says each parity class of gaps carries half the total length. That requires gaps at even and odd positions to have the same mean, and nothing known about prime gaps forces this.

## The partial result

| # | Claim | Why |
|---|---|---|
| 1 | #{p ≤ X : p + h prime} ≤ (4 + o(1))·S(h)·X/ln²X, uniformly in even h ≤ X, with S(h) = 2C₂∏_(q\|h, q>2)(q − 1)/(q − 2) | Selberg sieve; Halberstam–Richert, *Sieve Methods*, Theorem 3.11 |
| 2 | Σ_(0 < h ≤ H) S(h) = H + O(log H) | average of the singular series (classical) |
| 3 | at most (4δ + o(1))·π(X) primes p ≤ X have the next prime within δ·ln X | union bound over h ≤ δ ln X, claims 1–2 |
| 4 | in each parity class, at least (1/2 − 4δ − o(1))·π(X) gaps with p ∈ (X^(1−ε), X] are longer than δ·ln X | each class has about π(X)/2 gaps; claim 3 |
| 5 | each class of gaps up to X has total length ≥ (δ(1/2 − 4δ) − o(1))·X; at δ = 1/16 this is X/64 | claim 4, using π(X)·ln X ~ X |
| 6 | 1/64 − o(1) ≤ AS(p_n)/p_n ≤ 63/64 + o(1) | claim 5 for the class of AS(p_n) and for the other class, with X = p_n |

A better uniform constant than 4 in claim 1 would improve 1/64 directly. The limit 1/2 itself would follow from equidistribution of gap sizes across index parity, which seems as hard as the fine-scale gap questions it resembles.

**Numerics.** For 10⁶ ≤ n ≤ 1.1·10⁷, AS(p_n)/p_n lies in [0.49943, 0.50057], and |2·AS(p_n) − p_n| < 8√p_n for n ≥ 1000. That is the size of a random walk with steps of the size of a gap, consistent with a limit of 1/2 approached like p_n^(−1/2). For Q2, p_n ≈ 2·AS(p_(n−1)) is therefore off by O(√p_n), which is worse than li or Riemann's R(x) for estimating p_n.
