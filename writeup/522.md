# Puzzle 522: Three sets of k consecutive primes

> **In short:** We found two runs of 15 consecutive primes, x₁…x₁₅ and y₁…y₁₅, such that the i-th prime pᵢ (2, 3, 5, …, 47) divides xᵢ + yᵢ every time. The longest known before was 14.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_522.htm)

**Status:** beaten · proven primes

## The question

Take three sets of k consecutive primes, with no prime used twice. In the example the first set is {2, 3, 5, 7}, the second {17, 19, 23, 29} and the third {127, 131, 137, 139}, and each prime of the first set divides the sum of the matching primes of the other two:

```
2 | 17 + 127,   3 | 19 + 131,   5 | 23 + 137,   7 | 29 + 139
```

The puzzle asks for sets with more than four primes. We take the first set to be the first k primes, as the record holders did, and push k.

## Current record vs ours

| | Second set starts at | Third set starts at | k |
|---|---|---|---|
| Current record (F. Schneider) | 171145951 | 892667701 | 14 (divisors up to 43) |
| **Ours** | 3355845769 | 5130974053 | **15** (divisors up to 47) |

Our pair is the smallest one for k = 15: it has the smallest sum of starting primes among all solutions below 2·10¹⁰.

## How we found it

The direct approach compares every run of 15 primes with every other run, which is hopeless with a billion runs. But the condition pᵢ | xᵢ + yᵢ only depends on remainders: it says yᵢ ≡ −xᵢ (mod pᵢ) for every i.

So we gave each run a **key**: its 15 remainders xᵢ mod pᵢ. Two runs fit together exactly when one key is the negative of the other. Matching keys is a sorting problem, not a pairing problem, so we could handle every run of 15 consecutive primes below 2·10¹⁰ (about 880 million primes), split into chunks by remainder mod 47 to fit in memory. A simple random model predicted about 4 matching pairs below that bound; 7 turned up.

## The math

For runs x₁ < … < x_k and y₁ < … < y_k of consecutive primes, and p₁ = 2, …, p_k the first k primes:

```
p_i | x_i + y_i   for all i   ⇔   key(y) = −key(x),   key(x) = (x_1 mod p_1, …, x_k mod p_k)
```

The chance that two random runs match is ∏ 1/(pᵢ − 1) (each xᵢ is a prime not divisible by pᵢ, so it has pᵢ − 1 possible remainders). With M runs, the expected number of matching pairs is about M²/2 · ∏ 1/(pᵢ − 1). With about 880 million primes this predicted about 4.5 pairs for k = 15. For k = 16 the extra factor 1/52 (from p₁₆ = 53) means about √(52/4.5) ≈ 3.4 times as many primes, roughly 3·10⁹, to expect one pair.

## Validation

This script rebuilds both runs of 15 consecutive primes and checks that the i-th prime divides the i-th sum, for all seven pairs.

```python
from sympy import nextprime, isprime, prime

def run(start, k):
    # the k consecutive primes starting at `start`
    r = [start]
    while len(r) < k:
        r.append(nextprime(r[-1]))
    return r

k = 15
divisors = [prime(i) for i in range(1, k + 1)]        # 2, 3, 5, ..., 47

pairs = [(3355845769, 5130974053), (1978800407, 7379421781), (3518687563, 11898022561),
         (10679573911, 12240324973), (6227201249, 17034376213), (4986216821, 19768069171),
         (9522197759, 18828631421)]

for a, b in pairs:
    assert isprime(a) and isprime(b)
    x, y = run(a, k), run(b, k)
    assert not set(x) & set(y)                        # no prime used twice
    assert all((xi + yi) % p == 0 for xi, yi, p in zip(x, y, divisors))   # p_i divides x_i + y_i

print("7 pairs of 15 consecutive primes; p_i | x_i + y_i for i = 1..15")
```
