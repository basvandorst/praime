# Puzzle 336: σ(n) < prime(n)

> **In short:** A complete proof that σ(n) < p_n for every n > 4. The sum of divisors is less than n(1 + ln n). Dusart's 1999 bound puts the n-th prime above n(ln n + ln ln n − 1). The second is larger once ln ln n ≥ 2, i.e. n ≥ 1619, and a direct check covers 5 ≤ n ≤ 1618. The sketch on the page uses an inequality in the wrong direction.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_336.htm)

**Status:** answered · proof (complete)

## The question

Firoozbakht: how can we prove that σ(n) < prime(n) for n > 4? (The exceptions are n = 2, where σ(2) = 3 = p₂, and n = 4, where σ(4) = 7 = p₄.)

The only contribution, Dan Dima's sketch (4 Nov 2005), has two problems:

- It needs σ(n) < C·n·ln n < p_n with one constant C. But σ(n)/(n ln n) does not tend to 0 fast enough for a single C < 1 to work for all n beyond a small N, and with C ≥ 1 the second inequality fails.
- It "proves" π(n ln n) < n with π(x) < x/ln x. That is the reverse of the stated (and true) lower bound x/ln x < π(x).

## The math

**Lemma.** For n ≥ 2, σ(n) < n(1 + ln n).

*Proof.* σ(n)/n = Σ_(d|n) 1/d ≤ Σ_(d ≤ n) 1/d = H_n, and H_n < 1 + ln n for n ≥ 2, since H_n − 1 = Σ_(2≤k≤n) 1/k < ∫₁ⁿ dt/t. ∎

**Theorem (Dusart 1999).** p_n > n(ln n + ln ln n − 1) for n ≥ 2. *(FACTS.md fact 2012; literature)*

**Proof of the puzzle.** For n ≥ 2:

```
σ(n) < n(1 + ln n) ≤ n(ln n + ln ln n − 1) < p_n     as soon as  ln ln n ≥ 2,
```

that is n ≥ e^(e²) = 1618.17…. For 5 ≤ n ≤ 1618 we compare σ(n) with p_n directly. The check runs to n = 10⁵, and σ(n) ≥ p_n happens only for n = 2 and n = 4. ∎

Dusart's bound is used only for n ≥ 1619. The verification script also checks it numerically up to n = 10⁵. Even the older bound p_n > n ln n (Rosser 1938) would do, if combined with Robin's unconditional σ(n) < e^γ n ln ln n + 0.6483 n/ln ln n for n ≥ 3 (literature, 1984; the constant is reached at n = 12, which we checked for n < 2·10⁵). We use Dusart's bound because the argument is a single line.

## How we found it

The puzzle is a pure size comparison: σ(n)/n grows like ln ln n at most, while p_n/n grows like ln n. The work is in choosing explicit bounds whose crossover is small enough to check directly. With H_n and Dusart's bound the crossover is 1619.

## Verify it yourself

`writeup/code/p336_verify.py` (5 seconds):

```python
import math
from fractions import Fraction
from sympy import divisor_sigma, prime, primerange

# 1. The crossover: ln ln n >= 2 iff n >= e^(e^2) = 1618.17...
N0 = math.exp(math.exp(2))
assert 1618 < N0 < 1619 and math.log(math.log(1619)) >= 2

# 2. Lemma: sigma(n)/n <= H_n < 1 + ln n for n >= 2 (exact fractions for H_n, n <= 2000).
H = Fraction(0)
for n in range(1, 2001):
    H += Fraction(1, n)
    if n >= 2:
        assert Fraction(int(divisor_sigma(n)), n) <= H and float(H) < 1 + math.log(n)

# 3. Direct check up to 10^5, and the exceptions n = 2, 4.
P = list(primerange(2, 1300000))
fails = [n for n in range(1, 100001) if divisor_sigma(n) >= P[n - 1]]
assert fails == [2, 4], fails
assert divisor_sigma(2) == prime(2) == 3 and divisor_sigma(4) == prime(4) == 7

# 4. Dusart's bound holds on our range (sanity check of the cited theorem).
assert all(P[n - 1] > n * (math.log(n) + math.log(math.log(n)) - 1) for n in range(2, 100001))
print("all checks pass")
```
