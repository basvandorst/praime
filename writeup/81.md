# Puzzle 81: Three magic squares from one chain of primes

> **In short:** Question c asked for the least triplet of 3×3 magic squares of primes p, 2p + 1, 4p + 3 (or p, 2p − 1, 4p − 3); the page had only pairs. The method: (1) the maps p ↦ 2p ± 1 keep a square magic; (2) a 3×3 magic sum is three times the centre; (3) try centres in increasing order. This gives the least magic sums, 145060413 and 143168367.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_081.htm)

**Status:** first answer (c) · proven primes · proven least

## The question

A **Sophie Germain prime** p is one where 2p + 1 is prime too. The puzzle starts with pairs of 3×3 magic squares: one made of primes p, and a second whose cells are 2p + 1 of the matching cell. Question c goes one step further and asks for the **least triplet** of 3×3 magic squares with primes

- p, 2p + 1 and 4p + 3 (first order), or
- p, 2p − 1 and 4p − 3 (second order).

## What the page had vs ours

| | First order (p, 2p+1, 4p+3) | Second order (p, 2p−1, 4p−3) |
|---|---|---|
| On the page | only pairs of squares, no triplets | only pairs of squares, no triplets |
| **Ours** | **magic sum 145060413** (least) | **magic sum 143168367** (least) |

## How we found it

**Doubling keeps the square magic.** If p runs through a magic square, then 2p + 1 does too: every line just becomes twice its sum plus 3. The same holds for 4p + 3. So we need only one magic square of primes p, where every cell is the start of a chain p, 2p + 1, 4p + 3 of three primes. Notice that 4p + 3 = 2(2p + 1) + 1, so it really is a chain. Call these primes **starters**.

**Every 3×3 magic square has the same shape.** Édouard Lucas showed that every 3×3 magic square is a centre c with eight cells c ± x, c ± y, c ± (x + y), c ± (x − y) placed in a fixed pattern. Its magic sum is 3c. So "least magic sum" means "least centre".

**The search.** For each starter c, in increasing order, we listed the distances x for which both c − x and c + x are starters. A square needs four such distances of the form x, y, x + y and x − y. The first centre that has them gives the least triplet, and nothing is skipped along the way.

## The math

With centre c and 0 < y < x, x ≠ 2y (so all nine cells differ), the square is

```
c + x        c − x − y    c + y
c − x + y    c            c + x − y
c − y        c + x + y    c − x
```

Every row, column and diagonal adds up to 3c. If every cell p is a starter, the squares with cells 2p + s and 4p + 3s (s = +1 or −1) are magic too, with sums 2·3c + 3s and 4·3c + 9s.

## Validation

This script sieves the primes up to about 10⁸, keeps the starters, and walks through the centres in increasing order until a magic square of starters appears. It then builds all three squares for each order and checks them. It takes about half a minute and 200 MB.

```python
import numpy as np
from sympy import isprime

def primes_upto(n):
    sieve = np.ones(n // 2 + 1, dtype=bool)          # sieve[k] stands for 2k + 1
    sieve[0] = False
    for i in range(3, int(n ** 0.5) + 1, 2):
        if sieve[i // 2]:
            sieve[i * i // 2::i] = False
    return 2 * np.flatnonzero(sieve) + 1

def least_square(s, limit):
    # starters: primes p with 2p + s and 4p + 3s prime as well
    starters = [int(p) for p in primes_upto(2 * limit) if isprime(2 * p + s) and isprime(4 * p + 3 * s)]
    st = np.array(starters, dtype=np.int64)
    is_starter = np.zeros(2 * limit + 1, dtype=bool)
    is_starter[st] = True
    for i, c in enumerate(starters):                  # centres in increasing order
        if c >= limit:
            return None
        below = st[:i]
        D = set((c - below[is_starter[2 * c - below]]).tolist())   # x with c - x and c + x starters
        for x in D:
            for y in D:
                if y < x and x != 2 * y and x + y in D and x - y in D:
                    return c, x, y

def square(c, x, y):
    return [[c + x, c - x - y, c + y], [c - x + y, c, c + x - y], [c - y, c + x + y, c - x]]

def is_magic(sq):
    lines = [row for row in sq] + [list(col) for col in zip(*sq)]
    lines += [[sq[0][0], sq[1][1], sq[2][2]], [sq[0][2], sq[1][1], sq[2][0]]]
    return len({sum(line) for line in lines}) == 1

for s, expected in [(1, 145060413), (-1, 143168367)]:
    c, x, y = least_square(s, 48_400_000)
    base = square(c, x, y)
    for k in range(3):                                # p, then 2p + s, then 4p + 3s
        sq = [[2**k * p + s * (2**k - 1) for p in row] for row in base]
        cells = [p for row in sq for p in row]
        assert is_magic(sq) and len(set(cells)) == 9 and all(isprime(p) for p in cells)
    assert 3 * c == expected                          # magic sum of the least square
    print("order", 1 if s == 1 else 2, ": centre", c, "magic sum", 3 * c)
```
