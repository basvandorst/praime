# Puzzle 419: Divisor sum as a perfect power

> **In short:** We built a product N of 336 different primes whose divisor sum σ(N) equals (sum of N's primes × number of N's divisors) raised to the power 47. The best known before was the power 31.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_419.htm)

**Status:** beaten (Q4) · PRP (the larger primes are BPSW probable primes)

## The question

For a number N write SOPF(N) for the sum of its prime factors, ND(N) for its number of divisors and σ(N) for the sum of its divisors. For example N = 35 = 5·7 has SOPF = 12, ND = 4 and σ = 48 = 12·4.

Question 4 asks for N with

```
σ(N) = (SOPF(N) · ND(N))^P      for an exponent P > 3
```

and the larger P, the better.

## Current record vs ours

| | N | P |
|---|---|---|
| On the page (J. Wroblewski) | solutions for P = 3 to 7 | 7 |
| Best known (J. Wroblewski, [his linked files](http://www.math.uni.wroc.pl/~jwr/pp419/)) | 215 primes, SOPF = 3²⁸·5¹⁶ | 31 |
| **Ours** | 336 primes, SOPF = 3⁴²·5²⁵ (in [data/419.txt](data/419.txt)) | **47** |

## How we found it

If N is a product of m different primes q₁, …, q_m, everything becomes simple: ND(N) = 2^m and σ(N) = (q₁ + 1)·…·(q_m + 1). So the equation only involves the numbers q + 1.

We chose every prime so that q + 1 has no prime factors other than 2, 3 and 5, and aimed for a sum of primes S = 3ˣ·5ʸ. Then both sides only contain the primes 2, 3 and 5, and the equation turns into bookkeeping: count how many factors 2, 3 and 5 the primes supply, and make the counts come out exactly.

Wroblewski's own solution showed the pattern: each next prime is roughly a fifth of what is still needed to reach the target sum. We followed that, walking down through primes of shrinking size and always picking one that keeps the three factor counts on track. Near the end, when the remaining sum is small, an exact search finishes the job.

## The math

Write q_i + 1 = 2^(a_i)·3^(b_i)·5^(c_i) and S = Σ q_i = 3ˣ·5ʸ. With ND(N) = 2^m:

```
σ(N) = ∏ (q_i + 1) = 2^(Σa_i) · 3^(Σb_i) · 5^(Σc_i)
(S · ND(N))^P      = 3^(Px) · 5^(Py) · 2^(Pm)
```

So the condition is exactly four equations:

```
Σ a_i = P·m,     Σ b_i = P·x,     Σ c_i = P·y,     Σ q_i = 3^x · 5^y
```

Ours: P = 47, m = 336 primes, x = 42, y = 25:

```
S = 3^42 · 5^25 = 32609399894330608609020709991455078125
σ(N) = (S · 2^336)^47
```

## The numbers

The 336 primes are in [data/419.txt](data/419.txt), largest first. The largest has 37 digits; the smallest are 3 and 2.

## Verify it yourself

This script reads the 336 primes, checks they are different primes with sum 3⁴²·5²⁵, and checks σ(N) = (SOPF(N)·ND(N))⁴⁷ exactly (N is never built; the product of all q + 1 is enough).

```python
import math
from sympy import isprime

# read the primes (skip the comment line)
q = [int(x) for x in open("writeup/data/419.txt") if not x.startswith("#") and x.strip()]
m, P = len(q), 47

assert m == 336
assert len(set(q)) == m                         # all different, so N is squarefree
assert all(isprime(p) for p in q)               # all prime: exact below 2^64, BPSW probable primes above

S = sum(q)                                      # SOPF(N)
assert S == 3**42 * 5**25

ND = 2 ** m                                     # a squarefree N with m prime factors has 2^m divisors
sigma = math.prod(p + 1 for p in q)             # divisor sum of a squarefree N

assert sigma == (S * ND) ** P                   # the puzzle's equation with P = 47
print("sigma(N) = (SOPF(N) * ND(N))^47 with 336 primes")
```

Run it from the repository root, so the relative path [`writeup/data/419.txt`](data/419.txt) resolves.
