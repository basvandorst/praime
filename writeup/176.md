# Puzzle 176: Primes in a circle

> **In short:** Place 1 … n around a circle so that neighbours and opposite numbers add to primes (only n ≡ 2 mod 4); the page had examples for n = 10 and 202 but no strategy. (1) A zigzag 1, n, 3, n − 2, … and its rotation work whenever four fixed linear expressions in n are prime, but no formula covers every n. (2) A depth-first search that places each number together with its opposite builds every n ≡ 2 (mod 4) from 10 to 402, and 750 and 1002, in seconds. (3) A strategy proved for every n would prove the open prime circle conjecture.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_176.htm)

**Status:** answered (Q1: two closed-form families, proved, and a general construction; Q2 re-solved; a universal proof is out of reach, it contains the prime circle conjecture)

## The question

Distribute 1, 2, …, n around a circle so that every integer is used once, the sum of every two neighbours is prime and the sum of every two opposite numbers is prime. Solutions need n even and not divisible by 4. The page gives n = 10:

```
4 9 2 1 10 3 8 5 6 7   (around the circle; neighbour sums 11, 13 alternating, 7 at the join; opposite sums 7, 17, 7, 7, 17)
```

- Q1: find a strategy to build such arrangements ("nobody has found/sent any strategy").
- Q2: a solution for n = 202 (found by Jud McCranie by exhaustive search).
- Q3: why none for n = 6 (solved: 3 has only two prime-sum partners, 2 and 4, but needs three).

## How we found it

The n = 10 example has only four different sums, 7, 11, 13, 17, so it had to be a rigid pattern: odd numbers increasing on the odd positions, even numbers decreasing on the even positions. Writing the pattern with a free rotation c of the even numbers and computing all sums that can occur gave the two families. For the general case the opposite condition makes the usual insertion tricks for prime circles useless (inserting a number shifts every opposite pair), so the circle is built position by position together with its opposite.

## The math

Let n = 2m with m odd, positions 1 … n around the circle, position j opposite to j + m.

**Parity (proved).** All sums are at least 3, hence odd, so neighbours have opposite parity: the parities alternate around the circle, which needs n even. Opposite positions j and j + m then have opposite parity iff m is odd, i.e. n ≡ 2 (mod 4).

**Family 1 (proved).** Put the value j at every odd position j and the value n + 2 − j at every even position j: the circle reads 1, n, 3, n−2, 5, …, n−1, 2. Neighbour sums: j + (n + 2 − (j+1)) = n + 1 for j odd, (n + 2 − j) + (j + 1) = n + 3 for j even, and 2 + 1 = 3 at the join. Opposite sums: for odd j ≤ m the opposite position j + m is even with value n + 2 − j − m = m + 2 − j, sum m + 2; for odd j > m the opposite position is j − m with value n + 2 − j + m = 3m + 2 − j, sum 3m + 2. So the arrangement is valid iff n + 1, n + 3, m + 2 and 3m + 2 are prime. Below 3000: n = 10, 58, 70, 310, 1090, 1318, 1930. The page's n = 10 circle is this one, read from position 7.

**Family 2 (proved).** Even position j gets the value (4 − j) mod n (taken in 2 … n): the circle reads 1, 2, 3, n, 5, n−2, 7, n−4, …, n−1, 4. The sums are 3 (= 1 + 2), 5 (= 2 + 3), n + 3 and n + 5 for the other neighbours, and m + 4 and 3m + 4 for the opposites. Valid iff n + 3, n + 5, m + 4, 3m + 4 are prime: n = 26, 38, 98, 458, 878, 1286, 1298, 1478, 2378, 2546, 2726 below 3000.

**No other constant-sum pattern (proved).** If the odd positions carry j and the even positions carry (c − j) mod n for an even c, the neighbour sums are c − 1 or c − 1 + n and c + 1 or c + 1 + n, the opposite sums c ± m and c + m + n, whichever occur. For 4 < c < n + 2 both c − 1 and c + n − 1 occur, so c − 1, c + 1, c + n − 1, c + n + 1 must be prime: c ≡ 0 (mod 6) and n ≡ 0 (mod 6), but then m ≡ 0 (mod 3) and c + m is divisible by 3. Hence only c = 4 and c = n + 2 remain, the two families. Both need n ≡ 2 or 10 (mod 12), which excludes n = 202 (203 = 7·29, 205 = 5·41).

**General strategy (construction, checked).** Fill position i and its opposite i + m together as an oriented pair (xᵢ, yᵢ) with xᵢ + yᵢ prime, xᵢ + xᵢ₋₁ prime and yᵢ + yᵢ₋₁ prime; the last pair must also satisfy x_m + y₁ and y_m + x₁ prime. Position 1 holds 1 without loss of generality (rotate the circle). Candidates are ordered by the number of remaining prime-sum partners of x and y (fewest first, Warnsdorff's rule), ties broken randomly, and the search restarts with a new seed after a node budget. Every number has about 2n/ln n prime-sum partners, so the search almost never backtracks.

**Why a proof for all n is out of reach (proved).** Dropping the opposite condition leaves a prime circle (neighbour sums prime). Whether a prime circle exists for every even n is the prime circle conjecture (OEIS A051252), open since the 1980s. A strategy with a proof of success for every n ≡ 2 (mod 4) would prove it for those n.
