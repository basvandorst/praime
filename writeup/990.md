# Puzzle 990: Four numbers in arithmetic progression with the same σ

> **In short:** The page holds 34560288 + k·2138892 (k = 0..3), σ = 119508480, as the smallest known four-term progression with equal σ and asks to confirm it (Q1). (1) Since σ(m) > m, a sieve up to the σ value finds every such progression; there are eight below 1.84·10⁸. (2) The progression 37558049 + k·1032084 has σ = 41057280, the least possible. (3) The page's progression has the least first term. So Q1 holds for the first term but not for the σ value.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_990.htm)

**Status:** answered · Q1: least first term confirmed (exhaustive to the Robin bound), least σ is 41057280 (new set); Q2, Q3 untouched

## The question

K numbers in arithmetic progression with the same σ(n). For K = 4 the page gives 34560288, 36699180, 38838072, 40976964 (difference 2138892, σ = 119508480), from Gupta's "Can You Find" no. 35, "the smallest known solution". Q1: confirm this is the smallest answer for 4. (Q2: a smaller K = 5 solution than Wroblewski's 1666818506570911 + k·5777730; Q3: K ≥ 6.) No contribution is on the page.

On Gupta's page (CYF 35, 2007) Schneider found the set by a search "by divisor sum N" and called it "likely minimal"; Johnson called it "the smallest set of four numbers I found" and added a second set 435831146 + k·420 (σ = 653837184).

## How we found it

A divisor sieve gives σ(n) for all n ≤ N; sorting the indices by σ puts equal values together, and each group is scanned for four-term progressions (pairs (i, j), then binary search for the third and fourth term). This is exhaustive for progressions whose last term is ≤ N. Two facts turn it into proofs of minimality: σ(m) > m for m > 1 bounds the terms by the σ value, and Robin's inequality bounds the σ value by the first term.

## The math

**Exhaustiveness (proved).** Every progression n, n + d, n + 2d, n + 3d with n + 3d ≤ N and equal σ is found: its four terms are in the same σ-group, and the scan tests every pair (n, n + d) of a group.

**Least σ (proved).** σ(m) ≥ m + 1 for m > 1, so every term of a progression with common value σ = S is below S. The sieve to S₀ = 41057280 (independent numpy run) finds exactly two progressions with all terms ≤ S₀: ours (σ = S₀) and the page's (σ = 119508480, last term 40976964). A progression with σ < S₀ would have all terms < S₀ and would be in this list. So 41057280 is the least σ of a four-term progression, and 40654301 the least possible last term (the only other progression with last term ≤ S₀ ends at 40976964).

**Least first term (proved, computed).** Robin (1984): σ(n) < e^γ n ln ln n + 0.6483 n / ln ln n for n ≥ 3. For n < 34560288, ln ln n < 2.8543, so σ(n) < n·(1.7811·2.8543 + 0.2272) < 5.312·34560288 < 1.836·10^8. A progression with first term n < 34560288 has last term n + 3d < σ(n + 3d) = σ(n) < 1.836·10^8. The sieve to N = 1.84·10^8 finds eight progressions, none with first term below 34560288: it is the least first term.

**Why the two orderings differ (explained).** The page's set has even terms with σ/n ≈ 3.46; ours has odd squarefree terms, each a product of 3 or 4 primes, with σ/n ≈ 1.09. A search ordered by the σ value reaches sets of odd numbers much earlier than sets of even numbers, and the "smallest" set depends on which ordering is meant.
