# Puzzle 466: φ(m − n) = φ(m) = φ(m + n)

> **In short:** a(n) is the least m with φ(m − n) = φ(m) = φ(m + n). Firoozbakht and Resta left a(3), a(9) and a(10) open (none below 10¹³). We explain the whole table. A one-parameter family of solutions exists **iff 6 | n**, which is why multiples of 6 have thousands of solutions and everything else has a handful. Every other solution we know is a **pair shape**: two members are (small number)·(prime) and the third is a smooth number Z with Z − ρφ(Z) = K. Both known odd cases fit: 5187 for n = 1, and Resta's a(7) = 30057431145, which our search rediscovers. For **n = 10 we prove no pair shape exists**. For n = 3 and 9 every pair shape reduces to an odd, 3-free B′ with B′ − 2φ(B′) ∈ {1, 3, 5, 7, 9, 15, 17, 21, 51}, which needs at least seven prime factors ≥ 5; an exhaustive search finds **none below 10¹⁵**. Also a(9) ≤ 3·a(3). The three values stay open.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_466.htm)

**Status:** open · structure proved (families iff 6 | n; a(9) ≤ 3a(3); no pair-shape solution for n = 10); pair shapes for n = 3, 9 excluded below 10¹⁵ (exhaustive)

## The question

For n = 1 … 12 the page lists a(n) = 5187, 10, ?, 20, 25935, 78, ?, 40, ?, ?, 57057, 156. Resta (2014) computed φ below 10¹³: he found a(7) = 30057431145 and nothing for n = 3, 9, 10. Find a(3), a(7), a(9), a(10), or prove that one of them does not exist.

## How we found it

The only way three different numbers can share a φ-value for infinitely many m is through structure: each member is a fixed cofactor times a large prime, and the primes move together. We asked exactly when such structure can exist. The answer is a statement about radicals, and it explains the page's table at a glance. Where a full family is impossible, the next best structure fixes two members and leaves the third to satisfy a single "Lehmer-type" equation Z − ρφ(Z) = K, which a depth-first search over its prime factors solves completely.

## The math

**Step 1: scaling** (proved). φ(kX) = φ(k)φ(X)·d/φ(d) with d = gcd(k, X), and d/φ(d) depends only on the primes of d. So if every prime of k divides all three of A = m − n, B = m, C = m + n or none of them, then k·(A, B, C) is a solution for spacing kn. Consequences:

- Firoozbakht's 34889017254 = 2·3·7·13·19·1297·2593 is exactly rad(5186·5187·5188), so a(n) ≤ 5187n when gcd(n, 34889017254) = 1 (the page's remark).
- (8, 10, 12) gives a(2k) ≤ 10k when gcd(k, 15) = 1: the small even entries 20, 40, 70, 130, 140, … in the data.
- **a(9) ≤ 3·a(3)**: m − 3, m, m + 3 are all ≡ m (mod 3), so 3 divides all or none of them.
- Resta's a(7) = 7·4293918735 is a scaling with *unequal* factors: 4293918735 is only a φ-pair (φ(m) = φ(m + 1)), and 7 | m − 1 makes φ(7(m − 1)) = 7φ(m − 1) = 6φ(m).

**Step 2: the ratio lemma** (proved). X/φ(X) = ∏_{p|X} p/(p − 1) determines the set of primes of X. The largest prime P of the set divides the numerator once and divides no q − 1 (all q − 1 < P), so P is the largest prime of the reduced numerator; remove it and repeat.

**Step 3: families exist iff 6 | n** (proved). Call it a family if A = a₁p₁, B = a₂p₂, C = a₃p₃ with fixed aᵢ and primes pᵢ = N/φ(aᵢ) + 1 for a free parameter N = φ(B). Then A = (a₁/φ(a₁))N + a₁ and so on. The spacing is constant for all N only if a₁/φ(a₁) = a₂/φ(a₂) = a₃/φ(a₃), so by step 2 rad(a₁) = rad(a₂) = rad(a₃) =: R, and a₁, a₂, a₃ is an arithmetic progression with difference n. Every prime of R divides two of them, hence divides n.

- n odd: a₁ and a₂ have different parity, so 2 is in one radical and not the other.
- 3 ∤ n: a₁, a₂, a₃ are distinct mod 3, so 3 divides exactly one of them.
- 6 | n: (n, 2n, 3n) has a constant radical. With t = N/(6φ(n)) the primes are p₁ = 6t + 1, p₂ = 3t + 1, p₃ = 2t + 1, m = 2n(3t + 1). Example n = 6, t = 2: 13, 7, 5 give m = 84, the second solution in the data.

So for 6 | n solutions are plentiful (one for each prime triple 6t + 1, 3t + 1, 2t + 1, of which Dickson's conjecture predicts infinitely many), and for every other n they must be sporadic.

**Step 4: pair shapes** (definition, checked on the known solutions). Two members are linear, a·p and c·q with a/φ(a) = c/φ(c) = ρ (so rad(a) = rad(c), and c − a is the spacing between them), and the third member Z is free with φ(Z) = N. Then Z = ρN + K′ for a constant K′, so

```
Z − ρ·φ(Z) = K      (K = a + n for Z in the middle, K = b + n or b − n for Z at an end).
```

n = 1: 5186 = 2·2593, 5188 = 4·1297, (a, c) = (2, 4), Z = 5187 = 3·7·13·19 with 5187 − 2·2592 = 3 = a + n ✓.
n = 7: 30057431140 = 98·306708481, 30057431152 = 112·268369921, (a, c) = (98, 112) (both of radical {2, 7}), Z = 3·5·7·17·257·65521 with 3Z − 7φ(Z) = 315 = 3(a + n) ✓.

**Step 5: n = 10 has no pair shape** (proved). The pairs are (a, c) with c − a = 20 or 10 and equal radical R. Every prime of R divides the spacing, so R ⊆ {2, 5}, and the lists are complete by 2-adic and 5-adic splitting (consecutive {2, 5}-numbers are only 1, 2 and 4, 5): c − a = 20 gives (5, 25), (20, 40), (80, 100); c − a = 10 gives (10, 20), (40, 50). The free member Z is ≡ a member mod every p ∈ R, so R ⊆ rad(Z). Write Z = Z_R·s with s coprime to 10. Then ρφ(Z_R) = Z_R and

```
Z − ρφ(Z) = Z_R · (s − φ(s)).
```

s − φ(s) is 0 for s = 1, 1 for s prime and at least √s otherwise. The K values are 15, 30, 90 (Z in the middle), 30, 60 (Z after an adjacent pair) and 0, 30 (Z before one). K = 15, 30, 60, 90 are divisible by 3, so they are not {2, 5}-numbers and s cannot be prime; composite s forces Z ≤ K³, which a direct check rules out. K = 0 needs s = 1: Z = 10(p − 1) with p − 1 = 2ⁱ5ʲ, B = 10p, C = 20q, q = (p + 1)/2. If i + j is odd, 3 | p; if even, 3 | p + 1, so q = 3 and p = 5, which divides 10. **So every solution for n = 10 has at most one linear member.** That is why none turned up below 10¹³.

**Step 6: n = 3 and n = 9 reduce to one equation** (proved). The pair lists are complete by the same splitting plus Størmer's list of consecutive 3-smooth pairs (1,2), (2,3), (3,4), (8,9):

- n = 3 (c − a = 6): (2, 8), (3, 9), (6, 12), (12, 18), (18, 24), (48, 54).
- n = 9 (c − a = 18): (9, 27), (6, 24), (18, 36), (36, 54), (54, 72), (144, 162).
- adjacent pairs (difference 3 or 9) with equal radical: none.

(3, 9) and (9, 27) are impossible: A = 3p or 9p is odd, so Z = A + n is even and divisible by 3, so Z/φ(Z) ≥ 3, but it must be about ρ = 3/2. In all other shapes Z is odd. For (2, 8), 3 ∤ Z (else 3 | p); there Z − 2φ(Z) = 5. In the others ρ = 3 and 3 | Z: write Z = 3ᵉZ′ with 3 ∤ Z′. Then Z − 3φ(Z) = 3ᵉ(Z′ − 2φ(Z′)) = K. So in every case

```
B′ odd, 3 ∤ B′,  B′ − 2φ(B′) = K′,  K′ ∈ {1, 3, 5, 7, 9, 15, 17, 21, 51}.
```

B′/φ(B′) > 2 using primes ≥ 5 only needs **at least seven of them** (six give at most 5·7·11·13·17·19 → 1.949), so B′ ≥ 37182145. This is the real reason n = 3, 9 are hard: for n = 1 the middle term may use the prime 3 (5187 = 3·7·13·19 reaches 2.0012 with four primes), for n = 3, 9 the factor 3 is shared by all three members or by none.

**Step 7: the search** (exhaustive in the stated range). [code/p466_dfs.py](code/p466_dfs.py) lists every odd B ≤ X with βB − αφ(B) = βK by a Lehmer-style depth-first search: a skeleton S of small primes, then the last prime from a division, or the last two primes r < s from a factorisation of α²u² − D(αu + βK) with D = αu − βS, u = φ(S). A skeleton is cut when its ratio can no longer reach ρ within the size bound (taking the next primes greedily is optimal). It is complete: p² | B implies p | φ(B), hence p | K, so large primes appear to the first power; a skeleton prime above 10⁶ would force B > 10²⁵. Checks:

- 120 equations (ρ = 2 and 3, all odd K < 120) against a φ-sieve below 10⁷: 99 solutions, identical.
- n = 7, pair shapes up to 10¹¹: the only hit is 30057431145 = a(7), found from (98, 112).
- n = 3 and n = 9, all pair shapes, B ≤ 10¹⁵: **no solution of the B-equation at all**, so no pair-shape a(3) or a(9) below 10¹⁵.

What is left: solutions with at most one linear member (two or three members with several large prime factors). These are the only possibility for n = 10, and the only possibility below 10¹⁵ for n = 3 and 9. They need two independent φ-coincidences, and none is known for any n.

## Verify it yourself

[code/p466_triples.py](code/p466_triples.py) lists all triples below 10⁸ for n ≤ 36 (`p466_triples.py 100000000 36`, 15 s). [code/p466_dfs.py](code/p466_dfs.py) runs the checks (`validate`, `n7`, `n3n9 1e15`, `reduced X`). A quick check of the two pair shapes and of the n = 10 mod 3 argument:

```python
from sympy import totient as phi, factorint
for n, m, a, c in ((1, 5187, 2, 4), (7, 30057431145, 98, 112)):
    A, B, C = m - n, m, m + n
    assert phi(A) == phi(B) == phi(C)
    assert A % a == 0 and C % c == 0 and len(factorint(A // a)) == 1 and len(factorint(C // c)) == 1
    assert B * phi(a) - a * phi(B) == (a + n) * phi(a)
for i in range(1, 40):
    for j in range(0, 18):
        p = 2**i * 5**j + 1
        if p > 5 and p % 3:
            assert ((p + 1) // 2) % 3 == 0
print("both pair shapes check; the n = 10, K = 0 family always hits 3")
```
