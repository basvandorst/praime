# Puzzle 876: Prime tuples

> **In short:** In a prime tuple of order n every term after the n-th is the sum of the previous n, and k counts the terms before the first composite. Q3 asks for the maximal k for odd n. (1) Mod 3 the generated terms satisfy g_(j+1) ≡ (−1)^j·B_j, with B_j an alternating sum of the start terms. (2) For odd n ≢ 1 (mod 3) this forces a multiple of 3 by term 2n + 2, so k ≤ 2n + 1. (3) The table reaches 2n + 1 for n = 3, 5, 9, 11, 15, 17, so these lengths are maximal.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_876.htm)

**Status:** answered (Q3 for odd n ≢ 1 mod 3: k ≤ 2n + 1, proof; the table's lengths for n = 3, 5, 9, 11, 15, 17 are maximal) · open for n ≡ 1 (mod 6)

## The question

A prime tuple of order n (odd) and length k is a list (p₀, …, p_(k−1)) of distinct odd primes in which every term after the n-th is the sum of the previous n terms; k is the number of primes before a composite (or a repeat) appears. Kamenetsky's table:

| n | 3 | 5 | 7 | 9 | 11 | 13 | 15 | 17 | 19 |
|---|---|---|---|---|---|---|---|---|---|
| k | 7 | 11 | 25 | 19 | 23 | 34 | 31 | 35 | 43 |

Q1 and Q2 ask for improvements and extensions. Q3 asks, ignoring the weight, for the maximal k for each odd n. One contribution (C. Meller) observed for n = 3 that divisibility by 3 allows at most 3 generated primes, or 4 when the prime 3 is among the first three terms, so k ≤ 7. The editor wondered what this approach gives for n > 3.

## The math

**Step 1 (proved): the recurrence mod 3.** Let a₁, …, a_n be the first terms, S their sum, and g₁, g₂, … the generated terms. Then g₁ = S, g_(j+1) = g_j + g_j − a_j = 2g_j − a_j for j ≤ n (the window loses a_j), and g_(n+2) = 2g_(n+1) − g₁. With 2 ≡ −1 (mod 3) and B_j = S − Σ_(i≤j)(−1)^i a_i, induction gives

```
g_(j+1) ≡ (−1)^j B_j  (mod 3),   j = 0, …, n,   and   g_(n+2) ≡ −(g_(n+1) + g₁) ≡ −(S − B_n)  for odd n.
```

**Step 2 (proved): the bound.** Every generated term is the sum of n ≥ 3 primes, so it exceeds 3; a generated term ≡ 0 (mod 3) is composite. Among the first terms at most one is ≡ 0 (mod 3), namely the prime 3. Suppose g₁, …, g_(n+1) are all prime, so B₀, …, B_n ∈ {1, 2} (mod 3). Then B_j − B_(j−1) = −(−1)^j a_j. If a_j ≢ 0, the step is nonzero, so B_j = −B_(j−1), and the step equals B_(j−1). Hence a_j ≡ (−1)^(j+1)·B_(j−1).

- *No first term is 3.* Then B_j = (−1)^j B₀, every a_j ≡ B₀ = c, and S ≡ n·c must equal B₀ = c, so n ≡ 1 (mod 3).
- *a_(j₀) = 3.* Then B stays put at j₀ and alternates elsewhere. The terms before j₀ are ≡ c and those after are ≡ −c. S ≡ c gives j₀ ≡ 2n + 1 (mod 3), and B_n = (−1)^(n−1)·c = c = S. So g_(n+2) ≡ −(S − B_n) ≡ 0, a multiple of 3 and composite.

So for odd n ≢ 1 (mod 3) at most n + 1 terms can be generated, k ≤ 2n + 1, and k ≤ 2n without the prime 3. For n ≡ 1 (mod 3), first terms that are all ≡ c give generated terms that are all ≡ c (mod 3), and mod 3 gives no bound.

**Step 3 (computed): the table.** The script recomputes the length and weight of every tuple in the table. For n = 3, 5, 9, 11, 15, 17 the length is exactly 2n + 1, so these are the maxima asked for in Q3. They also show the residue pattern of the proof: 3 sits at a position j₀ ≡ 2n + 1 (mod 3), the earlier terms are ≡ S and the later ones ≡ −S (mod 3). An exhaustive check of all residue vectors mod 3 confirms the run length n + 1 for n = 3, 5, 9, 11 (and, with [code/p876_runs.c](code/p876_runs.c), for n = 15 and 17), and unbounded runs for n = 7, 13, 19.

**n ≡ 1 (mod 6) (open).** The same method with other small moduli gives much weaker bounds. Mod 5, n = 7 has an infinite zero-free run. Mod 7 caps the generated terms at 64 for n = 7, and mod 5 caps them at 53 for n = 13 (computed), far above the table's 18 and 21.
