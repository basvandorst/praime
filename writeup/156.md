# Puzzle 156: One million doors

> **In short:** Person k toggles every door that is a multiple of the k-th prime, so a door ends open iff its number has an odd number of distinct prime factors. Open were (CR) the share of open doors tends to 1/2, and (LI) M(n) = open − closed is zero infinitely often. (1) The series of (−1)^ω(n) is G(s)/ζ(s) with G analytic for Re s > 1/2. (2) The prime number theorem then gives M(n) = o(n), which proves (CR). (3) Landau's theorem and the first zeta zero force infinitely many sign changes of M(n), which proves (LI).

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_156.htm)

**Status:** answered · both conjectures proved (CR: open doors ~ n/2; LI: M(n) = 0 infinitely often) · counts to 10⁸ computed

## The question

One million doors d₁, d₂, … are closed. Person 1 opens all even doors, person 2 toggles every third door, person 3 every fifth door, and so on: person k toggles the multiples of the k-th prime. Which doors end open, and how many? The page settles that: door i is toggled ω(i) times, once per distinct prime factor, so it ends open iff ω(i) is odd; 500954 doors end open. With m(i) = +1 for an open door and −1 for a closed one, and M(n) = Σ_{i ≤ n} m(i), the page then asks about two conjectures:

- **CR:** the number of open doors among the first n is ~ n/2.
- **LI:** M(n) = 0 for infinitely many n.

The page records M(10⁶) = −1908 for closed − open; with the page's own sign convention (open = +1) it is M(10⁶) = +1908.

## How we found it

The function (−1)^ω(n) is a close relative of the Möbius and Liouville functions (the page mentions the Pólya conjecture). Its Dirichlet series factors through 1/ζ(s), which gives the mean value by the prime number theorem. For the sign changes the standard route for Möbius (Landau's theorem plus a zero of ζ) does not apply directly because the extra factor G(s) is singular at s = 1/2; the way around is to compare |F(σ + it₁)| with F(σ) along the real axis, which works because G(σ) → 0 there.

## The math

Throughout, ω(n) is the number of distinct prime factors, M_μ(x) = Σ_{n ≤ x} μ(n) is Mertens's function, and A(x) = Σ_{n ≤ x} (−1)^ω(n). Since m(n) = −(−1)^ω(n), M(n) = −A(n); every statement below about A holds for M with the sign flipped.

**Step 1 (proved): the Dirichlet series.** For Re s > 1,

```
F(s) = Σ (−1)^ω(n) n⁻ˢ = ∏ₚ (1 − p⁻ˢ − p⁻²ˢ − …) = ∏ₚ (1 − 2p⁻ˢ)/(1 − p⁻ˢ) = ζ(s) ∏ₚ (1 − 2p⁻ˢ).
```

Write (1 − 2x) = (1 − x)²·(1 − x²/(1 − x)²). Then F(s) = G(s)/ζ(s) with

```
G(s) = ∏ₚ (1 − 2p⁻ˢ)/(1 − p⁻ˢ)² = ∏ₚ (1 − p⁻²ˢ − 2p⁻³ˢ − 3p⁻⁴ˢ − …).
```

The factors are 1 + O(p^(−2σ)), so the product converges absolutely for Re s > 1/2: G is analytic there, and G(s) = 0 only where some p⁻ˢ = 1/2. Expanding the product gives G(s) = Σ g(n) n⁻ˢ with g multiplicative, g(p) = 0 and g(pᵏ) = −(k − 1) for k ≥ 2 (checked for all n ≤ 10⁵ in the script). Hence (−1)^ω = μ ∗ g, i.e.

```
A(x) = Σ_d g(d) M_μ(x/d),      Σ_d |g(d)|/d = ∏ₚ (1 + 1/(p − 1)²) = 2.83 < ∞.
```

**Step 2 (proved): CR.** M_μ(y) = o(y) is equivalent to the prime number theorem. Given ε > 0 choose D with Σ_{d > D} |g(d)|/d < ε; the finitely many terms d ≤ D contribute o(x), the rest at most εx. So A(x) = o(x), M(n) = o(n), and the open doors number n/2 + o(n). The same decomposition transfers the known bounds: M(n) = O(n·exp(−c (ln n)^{3/5}(ln ln n)^{−1/5})) unconditionally, and O(n^{1/2 + ε}) under the Riemann hypothesis. Data: M(n)/√n stays between −2.1 and +2.3 up to 10⁸.

**Step 3 (proved): LI.** Since m(n) = ±1, M(n) changes by one at every step, so if M(n) ≠ 0 for all n ≥ n₀ then M keeps one sign from n₀ on. We show that is impossible. Suppose A(x) ≥ 0 for x ≥ n₀ (the case A ≤ 0 is the same with −A). Partial summation gives, for Re s > 1,

```
F(s) = s ∫₁^∞ A(x) x^(−s−1) dx.
```

*Landau's theorem:* if the integrand is eventually non-negative, the integral converges for Re s > σ_c and the function it represents has a singularity at the real point s = σ_c. The function is F = G/ζ, which is analytic at every real s > 1/2: G is analytic there, ζ(s) ≠ 0 for real s > 1/2, and at s = 1 the pole of ζ gives F(1) = 0. Therefore σ_c ≤ 1/2: the integral converges, and represents F, for every s with Re s > 1/2. (In particular ζ has no zero with Re ρ > 1/2 under the assumption.)

*The comparison.* For σ > 1/2 and real t, using |x^(−s−1)| = x^(−σ−1) and A ≥ 0 beyond n₀,

```
|F(σ + it)| ≤ |σ + it| ( ∫₁^{n₀} |A(x)| x^(−σ−1) dx + ∫_{n₀}^∞ A(x) x^(−σ−1) dx )
           ≤ |σ + it| ( 2C + F(σ)/σ ),      C = ∫₁^{n₀} |A(x)| x^(−3/2) dx,
```

because the second integral equals F(σ)/σ minus the integral over [1, n₀], which is at most C in absolute value.

*The two sides at ρ₁.* Let ρ₁ = 1/2 + i t₁, t₁ = 14.1347…, the first zero of ζ, and let σ → 1/2⁺.

- Right side: F(σ) = G(σ)/ζ(σ) → 0, because ζ(1/2) = −1.4603… ≠ 0 and G(σ) → 0. Indeed G(s) = H(s)/ζ(2s) with H(s) = ∏ₚ (1 − 2p⁻ˢ)/((1 − p⁻ˢ)²(1 − p⁻²ˢ)), whose factors are 1 − 2p⁻³ˢ + O(p⁻⁴ˢ); H converges absolutely for Re s > 1/3, so H(σ) stays bounded (H(1/2) = 2.44) while ζ(2σ) → ∞. So the right side stays bounded.
- Left side: ζ(σ + it₁) → ζ(ρ₁) = 0 while G(σ + it₁) → G(ρ₁) = H(ρ₁)/ζ(2ρ₁) ≠ 0: a factor of H vanishes only where p⁻ˢ = 1/2, which needs p^(−1/2) = 1/2, i.e. p = 4; and ζ(1 + 2it₁) ≠ 0 since ζ has no zeros on Re s = 1. Numerically |G(ρ₁)| = 0.65. So |F(σ + it₁)| → ∞.

Contradiction. Hence A, and M, take both signs infinitely often, and M(n) = 0 for infinitely many n. ∎

(The argument is the one that proves sign changes of M_μ, with one extra step: for Möbius the real axis s > 0 is free of singularities, here s = 1/2 is singular for G, which is why the comparison at σ → 1/2⁺ is needed rather than Landau's theorem alone.)

**Data (computed):** below 10⁸, M(n) = 0 at 8883 values of n, the first 2, 40, 46, 48, 50, 7960, …, the last 40889722; M(n) > 0 for 30039953 of the n ≤ 10⁸, the last at 40889721; max M = 3905 at n = 7083297, min M = −11280 at n = 99833850. The long negative stretch from 4.1·10⁷ to 10⁸ is the same kind of behaviour as for Mertens's function; Step 3 guarantees it ends.
