# Puzzle 908: A long chain of prime remainders

> **In short:** We found two primes p and q for which a chain of repeated remainders gives 34 numbers in a row that are all prime (or 1, where the chain stops). The best before was 14. The trick is to pick q so that the first remainder is fixed in advance, then steer all the others with the Chinese remainder theorem.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_908.htm)

**Status:** beaten (Q2) · PRP (p and q are probable primes; the remainders are small proven primes)

## The question

Take primes p < q and N = p·q. Compute r₁ = N mod (p + q), then r₂ = N mod r₁, r₃ = N mod r₂, and so on until the remainder is 1. Example:

```
(11, 13):  143 mod 24 = 23,  143 mod 23 = 5,  143 mod 5 = 3,  143 mod 3 = 2,  143 mod 2 = 1
```

All five remainders are prime or 1. Question 2 asks for primes p, q (not necessarily consecutive) giving more than six remainders, all prime or 1.

## Current record vs ours

| | p, q | Remainders, all prime or 1 |
|---|---|---|
| Current record (F. Schneider, Jan 2018) | 3931787, 200611189 | 14 |
| **Ours** | a 65-digit p and q = p² − p + 199 (below) | **34** |

## How we found it

Schneider already used the Chinese remainder theorem on the page. Our extra idea is to make the **first** remainder free: choose q = p² − p + r₁ with r₁ a prime. Then p + q = p² + r₁ and

```
N = p·q = p³ − p² + r₁·p = (p² + r₁)(p − 1) + r₁
```

so N mod (p + q) = r₁ automatically, whatever p is. Every later step r_{i+1} = N mod rᵢ is a condition on p modulo the small prime rᵢ. We picked a descending chain of primes 199, 197, 193, …, 5, 2, solved each condition N ≡ r_{i+1} (mod rᵢ) for p (a cubic congruence, which has a solution about two times out of three), combined them with the Chinese remainder theorem, and then searched that one residue class for a p where both p and q are prime. It took 5985 tries.

## The math

```
q = p² − p + r₁                          (r₁ = 199)
N = p·q,   p + q = p² + r₁
N mod (p + q) = r₁                       (automatic)
N = p³ − p² + r₁·p ≡ r_{i+1}  (mod r_i)   for each step of the chosen chain
```

Each congruence fixes p modulo rᵢ (one of its roots), and the Chinese remainder theorem merges them into one class p ≡ p₀ (mod 199·197·…·5·2). Inside that class we tested p and q for primality.

## The numbers

```
p = 68516818704324257201795329467591133865835633315118443095966860117
q = p² − p + 199   (127 digits)

remainders: 199, 197, 193, 191, 181, 179, 173, 167, 163, 157, 149, 137, 127, 113, 109, 107, 101, 97,
            89, 83, 71, 67, 61, 53, 43, 41, 37, 31, 23, 17, 11, 5, 2, 1        (34 numbers)
```

p and q pass the BPSW test and 25 Miller-Rabin rounds: they are probable primes, not proven ones.

## Validation

This script rebuilds q from p, runs the chain of remainders and checks that every remainder is prime or 1.

```python
from sympy import isprime

p = 68516818704324257201795329467591133865835633315118443095966860117
q = p * p - p + 199                               # the first remainder is forced to be 199

assert isprime(p) and isprime(q)                  # both prime (BPSW probable primes at this size)
N = p * q

chain = [N % (p + q)]                             # r1 = N mod (p + q)
while chain[-1] > 1:
    chain.append(N % chain[-1])                   # r_(i+1) = N mod r_i

assert chain[0] == 199
assert chain[-1] == 1
assert all(r == 1 or isprime(r) for r in chain)   # every remainder is prime or 1
assert len(chain) == 34

print("34 descending remainders, all prime or 1:", chain)
```
