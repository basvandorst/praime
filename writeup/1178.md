# Puzzle 1178: ⌊(p_n + 1)² / (p_{n+1} − 1)⌋ is prime only for n = 30, up to 4·10¹⁸

> **In short:** F(n) = ⌊(p_n + 1)² / (p_{n+1} − 1)⌋ was found prime only for n = 30 (F = 103), with searches to n = 10¹⁰ and an argument on the page that reaches p_n < 4.28·10¹⁷. The proof: (1) with g = p_{n+1} − p_n, (p+1)² = (p − g + 3)(p + g − 1) + (g − 2)², so F(n) = p − g + 3 + ⌊(g−2)²/(p+g−1)⌋, and p − g + 3 is even; (2) F(n) is odd only if (g − 2)² ≥ p + g − 1, a gap of about √p or more; (3) every gap below 4·10¹⁸ is at most 1476, so only p_n < 2.2·10⁶ qualify, and a direct check there finds 103 alone. This proves that 103 is the only prime F(n) with p_n < 4·10¹⁸; beyond that a second prime would need a prime gap of merit above 4.7·10⁷ (the record is 42.5).

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1178.htm)

## The question

F(n) = ⌊(Prime[n] + 1)² / (Prime[n+1] − 1)⌋. The only prime value found is F(30) = ⌊114²/126⌋ = 103.

**Q.** Find other primes of this form, or prove there are none.

## What the page had vs ours

| | On the page | Ours |
|---|---|---|
| search | no other prime for n ≤ 10¹⁰ | — |
| argument | F(n) even unless the gap g satisfies g² − 5g + 5 ≥ p_n; checked against the known maximal gaps to p ≈ 4.28·10¹⁷; true in general if Oppermann's conjecture holds | the same identity; with the exhaustive gap table the proof reaches **p_n < 4·10¹⁸**, and beyond it a counterexample needs a gap of merit above 4.7·10⁷ |

## How we found it

Nothing new in the idea: it is the page's polynomial division. What was missing is the bookkeeping that turns it into a theorem with an explicit range: which gaps are large enough, how far all gaps are known, and a direct check below the threshold.

## The math

Write p = p_n and g = p_{n+1} − p.

**Step 1 (proved). The identity.** (p + 1)² = (p − g + 3)(p + g − 1) + (g − 2)². Dividing by p + g − 1 = p_{n+1} − 1 and taking floors, F(n) = p − g + 3 + ⌊(g − 2)² / (p + g − 1)⌋. For p > 2 both p and g − 3 are odd, so p − g + 3 is even.

**Step 2 (proved). When F(n) is odd.** F(n) is odd only if ⌊(g−2)²/(p+g−1)⌋ is odd, which needs (g − 2)² ≥ p + g − 1. For n = 30: p = 113, g = 14, (g−2)² = 144 ≥ 126, and ⌊144/126⌋ = 1 makes F = 102 + 1 = 103.

**Step 3 (theorem used).** Every prime gap below 4·10¹⁸ was computed by Oliveira e Silva, Herzog and Pardi (2014); the largest is 1476 (FACTS 3011, 3023).

**Step 4 (proved). The range p < 4·10¹⁸.** For g ≤ 1476 and p ≥ 2.2·10⁶, (g − 2)² ≤ 1474² = 2172676 < p + g − 1, so F(n) is even. For p < 2.2·10⁶ a direct computation of F(n) for all 162 thousand consecutive pairs finds exactly one prime, 103. Hence 103 is the only prime F(n) with p_n < 4·10¹⁸.

**Step 5 (explained). Beyond.** For p ≥ 4·10¹⁸ an odd F(n) needs g > √p − 1, a gap of merit g/ln p > 4.7·10⁷. The largest merit ever observed is 42.5, and the Cramér model puts gaps near (ln p)²: such a gap would contradict everything known about gaps, but no theorem excludes it (Oppermann's conjecture would).
