# Puzzle 128: Sum of consecutive squared primes a square

> **In short:** The page asks for a square sum of squares of consecutive primes starting at 2 or 3 (searched without success to 1.69·10¹²) and for two adjacent runs of consecutive primes with equal sums of squares (no contribution). (1) A sum N is a square with probability 1/(2√N); beyond the page's bound this leaves 2.5·10⁻⁷ expected solutions per start. (2) Adjacent runs mean 2Q(j) − Q(i) = Q(l) for prefix sums Q; all pairs i < j ≤ 100000 fail, where 0.34 solutions were expected, and 0.05 are expected beyond. (3) The same test on first powers finds 259 solutions against 294 expected.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_128.htm)

**Status:** open · attempted (a: probably no solution, heuristic; c: none with the first run ending below 1299709, about 0.05 expected beyond)

## The question

Find solutions of p₁² + … + pₙ² = A² over consecutive primes (a) with p₁ = 2 or 3, (b) with A prime, and (c) find two distinct but contiguous sets of consecutive primes with equal sums of squares; 131² + … + 647² = 941² + … + 1033² is an "almost-solution" whose sets are not contiguous. Giovanni Resta searched (a) without success up to 1693930336951 and found 2489647² = 355363² + … + 355951² (49 terms) for (b); Jim Fougeron added two solutions of (b) with 6913 and 10609 terms. Nothing is reported for (c).

## How we found it

Let Q(n) = p₁² + … + pₙ². Part (a) asks for a square Q(n) or Q(n) − 4. Part (c) asks for i < j < l with Q(j) − Q(i) = Q(l) − Q(j), that is, for a prefix sum equal to 2Q(j) − Q(i): for each j all i are tested at once by a binary search in the array Q ([`code/p128_search.py`](code/p128_search.py), 110 s, 50 MB).

## The math

**Step 1 (proved). Classes of n for (a).** For p > 3, p² ≡ 1 (mod 24), and the squares mod 24 are 0, 1, 4, 9, 12, 16. With p₁ = 2 and n terms the sum is ≡ 4 + 9 + (n − 2) = n + 11, so n ≡ 1, 5, 13, 14, 17, 22 (mod 24); with p₁ = 3 it is ≡ n + 8, so n ≡ 1, 4, 8, 16, 17, 20 (mod 24).

**Step 2 (heuristic). Expectation for (a).** A number near N is a square with probability 1/(2√N). The sum of the squares of the primes up to x is about x³/(3 ln x), and there are dx/ln x primes near x, so the expected number of solutions with last prime above B is ∫ √(3 ln x)/(2x^(3/2)) dx/ln x ≈ √3/√(B ln B). For B = 1693930336951 this is 2.5·10⁻⁷ for each start. Over the sums with last prime below 5·10⁶ the model gives 0.52 (start 2) and 0.39 (start 3), of which 0.40 and 0.28 come from the first ten sums; none of these 348512 and 348511 sums is a square (computed).

**Step 3 (computed). Search for (c).** With the primes below 3.6·10⁶, for every j ≤ 100000 (p_j ≤ 1299709) and every i < j the number 2Q(j) − Q(i) was looked up among the prefix sums: no match. So no solution exists whose first run ends at a prime below 1299709.

**Step 4 (heuristic). Expectation for (c).** Near Q(l) the prefix sums are p_l² apart, so a pair (i, j) has a matching l with probability 1/p_l². Summed over the tested pairs this gives 0.340. The sum over i is about j/p_j² up to a constant, and p_j ≈ j ln j makes it Σ 1/(j ln² j), with tail c/ln J; the range 50000 < j ≤ 100000 contributes 0.0030, which gives c = 0.541 and a tail of 0.047 beyond J = 100000. A solution of (c) is unlikely (about 5 %) and, if it exists, can be arbitrarily far out, because the tail decreases only like 1/ln J.

**Step 5 (computed). Check of the method on first powers.** The same search for adjacent runs with equal sums of the primes themselves, j ≤ 3000, finds 259 solutions (the first: 2 + 3 = 5; 5 + 7 + 11 + 13 = 17 + 19) where the model expects 293.9.
