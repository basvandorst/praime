# Puzzle 1139: Prime-producing irregular polynomials

> **In short:** Davide Rotondo's rule takes |n² − 108n + 2518| and halves it when n is even. That gives 109 primes in a row. We found out why it works. The rule only works for a narrow family of quadratics. In that family, the polynomial splits into the two quadratic forms of one discriminant, and 398 is a non-residue mod every prime up to 31. We then searched the whole family far beyond Rotondo's numbers: no quadratic beats 109. So his polynomial is very likely the best possible of its kind.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1139.htm)

**Status:** first answer · bounded search (109 not beaten; the searched ranges are listed below)

## The question

Rotondo's "irregular" polynomial: take |n² − 108n + 2518|, divide it by 2 when n is even (unless the value is 2). For n = 0 … 108 this gives 109 primes, 53 of them different. Can you find a better one?

## How we found it

**Step 1: find out what the rule needs.** Halving only makes sense if f(n) is even exactly when n is even, and f(n)/2 is then odd. Working mod 4 shows this holds for every n exactly when a is odd, b is even and c ≡ 2 (mod 4). With b even we can complete the square: Rotondo's polynomial is |N² − 398| with N = n − 54. The run N = −54 … 54 is symmetric, so most primes appear twice. That is why only 53 are different.

**Step 2: find out why 398 is good.** An odd prime p divides N² − 398 for some N only if 398 is a square mod p. 398 is a non-square mod 3, 5, 7, 11, 13, 17, 19, 23, 29 and 31, so none of these primes ever divides a value. The first primes that could divide a value are 37 and 43, and there the value is the prime itself (37 and 43 appear in the list). This is the trick behind Euler's n² + n + 41, and behind our [puzzle 1230](../results/1230.md): pick the constant so that small primes cannot divide any value.

**Step 3: turn that into a filter.** A run of 110 or more values covers 56 consecutive N, so it hits every residue mod each p ≤ 53. If D were a square mod one of those p, then p would divide some value. That value is then composite (it can only equal p itself when D ≤ 3200). So D must be a non-square mod all 15 odd primes up to 53. Only 1 in 2¹⁵ values of D passes. A CRT sieve lists just those, which lets the search reach D = 10¹³.

**Step 4: search.** Results, with the code in [code/](code/):

| Family (halved when n is even) | Range searched | Best run |
|---|---|---|
| \|N² − D\|, \|N² + D\|, every D ≡ 2 (mod 4) | D ≤ 2·10⁹ (N² − D) and D ≤ 10⁸ (N² + D), every window in −300 … 300 | **109 (D = 398 only)** |
| same, D passing the mod-53 filter | 3200 < D ≤ 10¹³ / 3 ≤ D ≤ 5·10¹² (N² + D) | 23 / 25 |
| \|a n² + b n + c\|, a = 3, 5, …, 51 | \|c\| ≤ 3·10⁶, every b, every window in −300 … 300 | 75 (5n² − 10n − 122) |
| \|N⁴ + B N² + G\| (even quartics) | −8000 ≤ B ≤ 400, \|G\| ≤ 3·10⁶, sieve p ≤ 23 | 57 |

Bigger D makes things worse, not better. The values grow with D, so each one is less likely to be prime. The best run for D > 3200 is 23 values, far below 109. Rotondo's D is small, so his values near the vertex are tiny primes.

## The math

**The rule only works for this family.** We need f(n) ≡ 2 (mod 4) for even n and f(n) odd for odd n. Both depend only on a, b, c mod 8 and n mod 8, and checking all cases gives exactly: a odd, b even, c ≡ 2 (mod 4). Integer-valued polynomials with half-integer coefficients reduce to this case too. (The check is in the script below.)

**Two forms of one discriminant.** For Rotondo's polynomial

```
n = 2m      :  f(n)/2 = |2(m − 27)² − 199|      the form 2x² − 199y²
n = 2m + 1  :  f(n)   = |(2m − 53)² − 398|      the form  x² − 398y²
```

Both forms have discriminant 4·398 = 1592. The odd-n values use the principal form and the even-n values use the "halved" form. The halving rule interleaves the two forms of the class group of Q(√398). Because 199 is prime and D = 2·199, the halved form is exactly 2x² − 199y².

**The 2-exception matters.** At n = 34 and 74 the raw value is 2. Halving it would give 1, which is not prime. Without the "unless it is 2" clause the run would end at n = 33.

**Why bigger is not better.** By the Hardy–Littlewood heuristic, the chance that a run of k values is all prime is about (C_D / ln D)ᵏ. Here C_D is the product over primes p of (1 − (D/p)/(p − 1)). It is large when D is a non-residue for many small p. For D near 10¹³, even the best C_D cannot make up for ln D ≈ 30, and the observed best runs (23, 25) match that.

This is a bounded search, not a proof. A larger D, a larger window or another degree could still win. The heuristic says this becomes less likely as D grows.

## Verify it yourself

This script checks Rotondo's run, the two forms, the parity lemma, the non-residue pattern of 398, and repeats a small version of the search independently. Run it after `pip install sympy`. The large searches are the C programs in [code/1139_monic.c](code/1139_monic.c), [code/1139_quadratic.c](code/1139_quadratic.c) and [code/1139_quartic.c](code/1139_quartic.c).

```python
from sympy import isprime, legendre_symbol, primerange, sieve

# Rotondo's rule: |f(n)|, divided by 2 when n is even (unless it is 2).
def v(a, b, c, n):
    x = abs(a*n*n + b*n + c)
    return x // 2 if n % 2 == 0 and x != 2 else x

# 1. Rotondo's polynomial: 109 primes for n = 0..108, 53 different, run ends on both sides.
vals = [v(1, -108, 2518, n) for n in range(109)]
assert all(isprime(x) for x in vals) and len(set(vals)) == 53
assert not isprime(v(1, -108, 2518, -1)) and not isprime(v(1, -108, 2518, 109))

# 2. It is |N^2 - 398| with N = n - 54, and its two halves are the two forms of discriminant 4*398.
assert all(v(1, -108, 2518, n) == v(1, 0, -398, n - 54) for n in range(109))
#    At n = 34 and 74 the raw value is 2: the "unless it is 2" clause keeps it (halving would give 1).
assert [2*m for m in range(55) if abs(2*(m - 27)**2 - 199) == 1] == [34, 74]
assert all(v(1, -108, 2518, 2*m) == abs(2*(m - 27)**2 - 199) for m in range(55) if m not in (17, 37))
assert all(v(1, -108, 2518, 2*m + 1) == abs((2*m - 53)**2 - 398) for m in range(54))

# 3. Parity lemma: the rule always gives odd numbers (or 2) iff a odd, b even, c = 2 mod 4.
#    Values mod 4 at n mod 8 depend only on a, b, c mod 8, so checking all residues is a proof.
for a in range(8):
    for b in range(8):
        for c in range(8):
            good = all(((a*n*n + b*n + c) % 4 == 2) if n % 2 == 0 else ((a*n*n + b*n + c) % 2 == 1)
                       for n in range(8))
            assert good == (a % 2 == 1 and b % 2 == 0 and c % 4 == 2)

# 4. Why 398 works: it is a non-residue mod every odd prime up to 31.
#    37 and 43 are the first exceptions, and there the value is the prime itself.
assert all(legendre_symbol(398, p) == -1 for p in primerange(3, 37))
assert legendre_symbol(398, 37) == 1 and legendre_symbol(398, 41) == -1 and legendre_symbol(398, 43) == 1
assert {x for x in vals if x in (37, 43)} == {37, 43}

# 5. Independent small scan of the monic family |N^2 - D| (D = 2 mod 4, both signs, |D| <= 20000),
#    windows inside N = -150..150: the longest run is 109, only for D = 398.
P = set(sieve.primerange(2, 200000))
best = {}
for D in range(-20000, 20001):
    if D % 4 != 2:
        continue
    run = longest = 0
    for N in range(-150, 151):
        if v(1, 0, -D, N) in P:
            run += 1
            longest = max(longest, run)
        else:
            run = 0
    best[D] = longest
top = max(best.values())
assert top == 109 and [D for D in best if best[D] == top] == [398]
print("all checks passed")
```
