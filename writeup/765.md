# Puzzle 765: p^a = q^b + r^c · s^d over {2, 3, 5, 7}

> **In short:** Of the 12 equations, exactly two have no solution: 2^a = 5^b + 3^c·7^d and 3^a = 2^b + 5^c·7^d. We prove both, using only congruences mod 3, 4, 5, 7 and 8 and the factorisation of a difference of two squares. The other ten have the solutions in Emmanuel Vantieghem's table, and none others with exponents up to 150. Each equation has only finitely many solutions (an S-unit equation).

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_765.htm)

**Status:** answered · Q1 proved; Q2 finiteness by theorem, lists complete up to exponent 150 (not proved beyond)

## The question

p, q, r, s are the primes 2, 3, 5, 7 in some order, and a, b, c, d ≥ 1. Swapping r and s gives the same equation, so there are 12 equations p^a = q^b + r^c·s^d.

- Q1 asks to show that at least 10 of them have a solution, and whether any has none.
- Q2 asks whether each solvable equation has finitely many solutions, and for the full lists.

On the page, Emmanuel Vantieghem gave a computer table ("I think that there are no more"), but no proofs.

## Q1: ten solvable, two impossible

Ten equations have the solutions in the table below, so at least 10 are solvable. The remaining two have none:

**(i) 2^a = 5^b + 3^c·7^d has no solution.**

1. Mod 3: (−1)^a ≡ (−1)^b, so a ≡ b (mod 2).
2. Mod 7: the powers of 2 are {1, 2, 4}, exactly the quadratic residues, and 5^b is a residue only for even b. So b is even, and so is a.
3. Write a = 2A and b = 2B. Then (2^A − 5^B)(2^A + 5^B) = 3^c·7^d. Both factors are odd and their gcd divides 2, so they are coprime.
4. If 2^A − 5^B = 1, then 2^A = 5^B + 1 ≡ 2 (mod 4), so A = 1 and 5^B = 1, i.e. B = 0. But b ≥ 1.
5. Otherwise the two factors are 3^c and 7^d in some order, so 3^c + 7^d = 2^(A+1).
   - Mod 8, 3^c + 7^d ≡ 0 forces c even and d odd.
   - Then 7^d = (2^m − 3^(c/2))(2^m + 3^(c/2)) with m = (A+1)/2. Mod 3, 2^(A+1) ≡ 1, so A + 1 is even and m is a whole number.
   - The two factors are coprime powers of 7, so 2^m − 3^(c/2) = 1. Its only solutions are 2 − 1 and 4 − 3, so c = 2, m = 2, d = 1 and A = 3.
   - Then 5^B = |2^A − 3^c| = 1, or the order of the factors makes it negative. Neither is allowed.

**(ii) 3^a = 2^b + 5^c·7^d has no solution.**

1. **b = 1.** Mod 7: 3^a ≡ 2 forces a ≡ 2 (mod 6), so a is even. Mod 5: 3^a ≡ 2 forces a ≡ 3 (mod 4), so a is odd. Contradiction.
2. **b ≥ 2.** The congruences give:
   - mod 7: 3^a ≡ 2^b, a quadratic residue, so a is even;
   - mod 4: (−1)^a ≡ (−1)^d, so d is even;
   - mod 5: 3 ≡ 2³, so b ≡ 3a (mod 4), and b is even;
   - mod 3: 0 ≡ (−1)^b + (−1)^c, so c is odd.
3. Factor: (3^A − 2^B)(3^A + 2^B) = 5^c·7^(2D). The factors are coprime.
   - 3^A − 2^B = 1 only for (A, B) = (1, 1) or (2, 3). The sums 5 and 17 are not of the form 5^c·7^(2D) with D ≥ 1.
   - 3^A ∓ 2^B = 5^c and 3^A ± 2^B = 7^(2D): then 2^(B+1) = ±(7^(2D) − 5^c) ≡ 4 (mod 8), because c is odd. So B = 1.
     - In the first order, 49^D − 4 = 5^c, which is impossible mod 3: 0 ≠ 2.
     - In the other order, 5^c − 49^D = 4 needs 5^c ≡ 4 (mod 7), so c ≡ 2 (mod 6). That makes c even, a contradiction.

## Q2: the solutions

| p, q, r, s | (a, b, c, d) |
|---|---|
| 2, 3, 5, 7 | (8, 4, 2, 1) |
| 2, 7, 3, 5 | (6, 2, 1, 1) |
| 3, 5, 2, 7 | (4, 2, 3, 1) |
| 3, 7, 2, 5 | (3, 1, 2, 1) |
| 5, 2, 3, 7 | (2, 2, 1, 1) |
| 5, 3, 2, 7 | (3, 3, 1, 2) |
| 5, 7, 2, 3 | (2, 1, 1, 2), (4, 2, 6, 2) |
| 7, 2, 3, 5 | (2, 2, 2, 1) |
| 7, 3, 2, 5 | (2, 2, 3, 1), (3, 5, 2, 2) |
| 7, 5, 2, 3 | (2, 2, 3, 1) |
| 2, 5, 3, 7 and 3, 2, 5, 7 | none (proved above) |

Every equation is an S-unit equation x + y = z with S = {2, 3, 5, 7}, so it has finitely many solutions. This is a theorem of Mahler (1933), made effective by Baker's method. An exhaustive check of all exponents up to 150 finds exactly the solutions listed above.

A proof that the lists are complete needs Baker-type bounds plus lattice reduction, which we did not carry out. De Weger's work on S-unit equations over {2, 3, 5, 7} should settle it, but we did not check that source.
