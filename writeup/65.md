# Puzzle 65: Equal power sums with consecutive primes

> **In short:** The record multigrade relation (equal power sums) between consecutive primes had degree 3, with 8 primes. The construction: (1) double a degree 5 Prouhet–Tarry–Escott solution to get 12 even offsets; (2) the offsets are admissible mod 3, 5 and 7; (3) sieve for a start c where all 12 are consecutive primes. This gives degree 5 with 12 consecutive primes from 19765897565467.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_065.htm)

**Status:** beaten · proven primes

## The question

A multigrade relation is two lists of numbers with the same sum, the same sum of squares, and so on up to some power (the degree). For example 1, 6, 8 and 2, 4, 9 both sum to 15, and their squares both sum to 101. The puzzle asks for larger and more interesting relations made of primes. Here we use only **consecutive** primes (no prime in between is skipped) and push the degree as high as we can.

## Current record vs ours

| | Relation | Result |
|---|---|---|
| Current record (A. Stinchcombe, 2021) | 17, 29, 31, 43 = 19, 23, 37, 41 | degree 3 with 8 consecutive primes |
| **Ours** | 12 consecutive primes from 19765897565467 to 19765897565543 (below) | **degree 5** |

Stinchcombe found no degree 4 relation with consecutive primes up to 1.6·10⁹. We also give one: 10 consecutive primes starting at 835589088973 (below).

## How we found it

Mathematicians have long known small sets of whole numbers with equal power sums, called Prouhet-Tarry-Escott solutions. Equal power sums survive two moves: adding the same number to every entry, and multiplying every entry by the same number. So we took a known degree 5 solution, doubled it (so all offsets are even, as gaps between odd primes must be), and looked for a starting prime c where the 12 numbers c + offset are prime and no other prime falls between them. The doubled offsets never cover every remainder class of a small prime, so such c can exist. A wheel and a sieve over c then found one.

## The math

The ideal degree 5 Prouhet-Tarry-Escott solution:

```
[0, 8, 11, 27, 30, 38] = [2, 3, 18, 20, 35, 36]   (equal sums of k-th powers, k = 1..5)
```

If Σaᵏ = Σbᵏ for k = 1..5, then also Σ(c + 2a)ᵏ = Σ(c + 2b)ᵏ for k = 1..5 (expand with the binomial theorem: every term only uses power sums of degree ≤ 5).

The 12 doubled offsets are

```
0, 4, 6, 16, 22, 36, 40, 54, 60, 70, 72, 76
```

Modulo 3 they only hit the classes 0 and 1, modulo 5 only 0, 1, 2, 4, modulo 7 only 0, 1, 2, 4, 5, 6. So no small prime is forced to divide one of the 12 numbers, and the pattern is admissible.

With c = 19765897565467:

```
A = c + 2·{0, 8, 11, 27, 30, 38}
B = c + 2·{2, 3, 18, 20, 35, 36}
```

The 6th power sums differ (by 1045094400), so the degree is exactly 5.

Degree 4 uses the same idea with c = 835589088973:

```
A = c + 2·{0, 18, 23, 57, 59}
B = c + 2·{3, 9, 32, 50, 63}
```

## Validation

This script rebuilds both runs of consecutive primes, checks every number is prime, and compares the power sums of the two sides.

```python
from sympy import isprime, nextprime, prevprime

# degree 5: the base prime and the two offset sets (offsets doubled from the PTE solution)
c = 19765897565467
A = [c + 2*x for x in (0, 8, 11, 27, 30, 38)]
B = [c + 2*x for x in (2, 3, 18, 20, 35, 36)]

# list the 12 primes that follow one another, starting at c
run = [c]
while len(run) < 12:
    run.append(nextprime(run[-1]))

# the two sides together are exactly those 12 consecutive primes
assert sorted(A + B) == run
# all 12 are proven prime (below 2^64 sympy's test is a proof)
assert all(isprime(p) for p in run)
# the sums of 1st..5th powers agree on both sides
assert all(sum(a**k for a in A) == sum(b**k for b in B) for k in range(1, 6))
# the 6th powers differ, so degree 5 is exactly what we get
assert sum(a**6 for a in A) != sum(b**6 for b in B)

# degree 4: same check with 10 consecutive primes
c4 = 835589088973
A4 = [c4 + 2*x for x in (0, 18, 23, 57, 59)]
B4 = [c4 + 2*x for x in (3, 9, 32, 50, 63)]
run4 = [c4]
while len(run4) < 10:
    run4.append(nextprime(run4[-1]))
assert sorted(A4 + B4) == run4
assert all(sum(a**k for a in A4) == sum(b**k for b in B4) for k in range(1, 5))

print("degree 5 with 12 consecutive primes, degree 4 with 10: both check out")
```
