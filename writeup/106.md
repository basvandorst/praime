# Puzzle 106: Prime magic squares that add up to 2000

> **In short:** The page asked for the least and largest number k of 3×3 prime magic squares that add up to the square full of 2000, and for k = 3 with 2001; none was given. The proof: (1) a square plus its half-turned copy is constant; (2) k is even for 2000; (3) a full check of the centres bounds k. This proves least k = 4 and largest k = 26 for 2000, and 3 and 27 for 2001.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_106.htm)

**Status:** first answer (Q1, Q2, Q3) · proven primes · proven least and largest k

## The question

John Everett found two 4×4 magic squares of primes that add up, cell by cell, to a 4×4 square filled with 2000. He could not find such a pair of 3×3 squares. For 3×3 magic squares of distinct primes A₁, …, A_k (all different squares) with A₁ + A₂ + … + A_k equal to the 3×3 square full of 2000, the puzzle asks:

1. a solution with the least k,
2. a solution with the largest k,
3. a solution with k = 3 for 2001, if any exists.

## What the page had vs ours

| | On the page | Ours |
|---|---|---|
| Least k for 2000 | "Solution" heading, nothing below | **k = 4** (k = 2 is impossible) |
| Largest k for 2000 | nothing | **k = 26** (k = 28 and more are impossible) |
| 2001 with k = 3 | nothing | **exists**; the least k is 3, the largest 27 |

## How we found it

**Turning a square upside down.** Every 3×3 magic square is its centre c plus a pattern of offsets that add up to zero along every line. Turning the square half a turn flips every offset to minus itself. So a square plus its half-turned copy is the constant square 2c. That gives k = 4 at once: take two squares whose centres add up to 1000, and add each to its own half-turned copy.

**The general rule.** A 3×3 magic square is fully fixed by three numbers: its centre and its two top corners. So squares add up to a constant square exactly when their centres add up to 2000 and their corner offsets cancel. This turns the puzzle into a small bookkeeping search.

**Why k must be even, and why it cannot be 2.** The prime 2 never fits in a 3×3 prime magic square, so every entry is odd. An odd number of odd entries cannot add up to 2000, so k is even. For k = 2, the second square would be 2000 minus the first, cell by cell, and checking all 647 prime magic squares with entries below 2000 shows this never gives primes everywhere.

**Why at most 26.** The least centre of a 3×3 prime magic square is 59, and only a few squares exist with small centres: just 8 orientations of one square at centre 59, 8 at 71, 8 at 73, and so on. The centres must add up to 2000, so many squares means many small centres, and those run out. Checking every way to choose the centres shows that 28 or more squares never balance, while 26 do. For 2001 (odd, so k is odd) the same search gives 3 at least and 27 at most.

## The math

With centre c and offsets x, y, every 3×3 magic square is

```
c + x        c − x − y    c + y
c − x + y    c            c + x − y
c − y        c + x + y    c − x
```

The half-turned square has offsets −x, −y, so the two add up to the constant square 2c. A sum of squares is again of this form, with centre Σc and offsets Σx, Σy. It is constant exactly when Σx = Σy = 0, and then every cell equals Σc. So the conditions are

```
sum of the centres = 2000,    sum of the corner offsets = (0, 0)
```

## Validation

This script lists every 3×3 magic square of distinct primes below the target, in all eight orientations, grouped by centre. For each k up to the least one, and from the largest one up to the bound total / 59, it tries every way to choose the centres, then checks whether the corner offsets can cancel. It runs in about a second.

```python
from itertools import combinations
from sympy import isprime, primerange

def square(c, x, y):
    return ((c + x, c - x - y, c + y), (c - x + y, c, c + x - y), (c - y, c + x + y, c - x))

def orientations(sq):
    out = set()
    for _ in range(4):
        sq = tuple(zip(*sq[::-1]))                 # quarter turn
        out.add(sq)
        out.add(tuple(row[::-1] for row in sq))    # and its mirror image
    return out

def prime_magic_squares(limit):
    # every 3x3 magic square of distinct primes below limit, grouped by centre
    P = set(primerange(2, limit))
    by_centre = {}
    for c in sorted(P):
        D = {d for d in range(1, c) if c - d in P and c + d in P}
        for x in D:
            for y in D:
                if y < x and x != 2 * y and x + y in D and x - y in D:
                    by_centre.setdefault(c, set()).update(orientations(square(c, x, y)))
    return {c: sorted(v) for c, v in by_centre.items()}

def offsets(sq):
    c = sq[1][1]
    return (sq[0][0] - c, sq[0][2] - c)            # the two top corners fix the whole square

def find(k, total, by_centre):
    # k different squares whose centres sum to total and whose offsets cancel, or None
    centres = sorted(by_centre)
    def choose_centres(i, left, rem, chosen):
        if left == 0:
            if rem == 0:
                yield dict(chosen)
            return
        if i == len(centres) or centres[i] * left > rem:
            return
        c = centres[i]
        for n in range(min(len(by_centre[c]), left, rem // c), -1, -1):
            chosen[c] = n
            yield from choose_centres(i + 1, left - n, rem - n * c, chosen)
            del chosen[c]
    for counts in choose_centres(0, k, total, {}):
        reach = {(0, 0): ()}                       # offset sum -> squares that give it
        for c, n in counts.items():
            if n == 0:
                continue
            options = {}
            for group in combinations(by_centre[c], n):
                options.setdefault(tuple(map(sum, zip(*map(offsets, group)))), group)
            reach = {(a[0] + b[0], a[1] + b[1]): g + h for a, g in reach.items() for b, h in options.items()}
        if (0, 0) in reach:
            return reach[(0, 0)]
    return None

def check(squares, total):
    for sq in squares:
        cells = [p for row in sq for p in row]
        assert all(isprime(p) for p in cells) and len(set(cells)) == 9
    assert len(set(squares)) == len(squares)
    assert all(sum(sq[i][j] for sq in squares) == total for i in range(3) for j in range(3))

for total, k_min, k_max in [(2000, 4, 26), (2001, 3, 27)]:
    squares = prime_magic_squares(total)
    assert min(squares) == 59                      # the least prime magic square has centre 59
    k_top = total // 59                            # centres are at least 59, so k <= total / 59
    for k in list(range(1, k_min + 1)) + list(range(k_max, k_top + 1)):
        found = find(k, total, squares)
        assert (found is not None) == (k in (k_min, k_max))   # nothing below k_min or above k_max
        if found:
            check(found, total)
    print(total, ": least k =", k_min, ", largest k =", k_max)
```
