# Puzzles 1249 and 1250: Cycles of p ↦ GPD(2p + 3) and p ↦ GPD(3p + 2)

> **In short:** Under p ↦ GPD(2p + 3) and p ↦ GPD(3p + 2) every prime tested falls into one of two known cycles; the page asks whether others exist. (1) On a cycle p_1 … p_L with a·p_i + b = s_i·p_(i+1), the cofactors multiply to an odd integer S = ∏(a + b/p_i) just above a^L, which rules out short cycles among large primes. (2) Every prime below 2·10⁸ ends in a known cycle, so a new cycle has length ≥ 23 (2p + 3) or ≥ 16 (3p + 2); with the page's searches, ≥ 28 or ≥ 25. A proof that no other cycle exists is open.

**Puzzles:** [1249](https://www.primepuzzles.net/puzzles/puzz_1249.htm), [1250](https://www.primepuzzles.net/puzzles/puzz_1250.htm)

**Status:** open · explained: no new cycle has its least prime below 2·10⁸ (exhaustive); any new cycle has length ≥ 23 (1249) or ≥ 16 (1250), and ≥ 28 or ≥ 25 given the page's searches; no proof that none exists

## The question

Puzzle 1249: A(p) = GPD(2p + 3). Every prime ≥ 5 tested falls into the cycle 5 → 13 → 29 → 61 → 5 or into 43 → 89 → 181 → 73 → 149 → 43. Are there other cycles? On the page: none below 10¹⁰ (J. Heleen) and none below 1.4·10¹⁰ (V. F. Izquierdo).

Puzzle 1250: A(p) = GPD(3p + 2). Every prime ≥ 3 tested falls into the cycle of 5 (19 terms) or 167 → 503 → 1511 → 907 → 389 → 167. Q1: are there more cycles? Q2: is a formal proof possible, for this map and for 1249? On the page: any other cycle starts above 6.1·10¹² (E. Vantieghem).

## The math

**Step 1 (proved): the cofactor product.** Let p_1, …, p_L be a cycle (p_(L+1) = p_1) and a·p_i + b = s_i·p_(i+1) with integers s_i ≥ 1. Since ∏ p_(i+1) = ∏ p_i,

```
S = ∏ s_i = ∏ (a·p_i + b)/p_(i+1) = ∏ (a + b/p_i),     so a^L < S ≤ (a + b/m)^L,   m = min p_i.
```

**Step 2 (proved): S is not just any number.** a·p + b is odd for odd p (2p + 3 and 3p + 2), so every s_i is odd. For a = 3, b = 2 also 3p + 2 ≡ 2 (mod 3), so 3 ∤ s_i. Hence S ≥ 2^L + 1 for the first map. For the second, S ≥ 3^L + 2, since 3^L + 1 is even.

**Step 3 (proved): the length bound.** If every prime below X ends in a known cycle, a new cycle has m > X. Then Step 1 and Step 2 give

```
2^L·((1 + 3/(2X))^L − 1) ≥ 1     (map 2p + 3),        3^L·((1 + 2/(3X))^L − 1) ≥ 2     (map 3p + 2).
```

The left sides are about 1.5·L·2^L/X and (2/3)·L·3^L/X, so short cycles are impossible:

| X (all primes below X checked) | new cycle of 2p + 3 needs L ≥ | new cycle of 3p + 2 needs L ≥ |
|---|---|---|
| 2·10⁸ (our check, Step 4) | 23 | 16 |
| 10¹⁰ (1249) / 6.1·10¹² (1250), page searches | 28 | 25 |

**Step 4 (computed): every prime below 2·10⁸ ends in a known cycle.** The primes are taken in increasing order, and the map is iterated from each until it reaches a smaller prime (already settled) or a member of a known cycle. Trial division by all primes below 2·10⁶ factors every value met: the largest values are 3.8·10¹⁰ (2p + 3) and 4.3·10¹¹ (3p + 2), both below 4·10¹².

**Step 5 (computed): the known cycles.** Their cofactors and S:

| map | cycle | cofactors s_i | S − a^L |
|---|---|---|---|
| 2p + 3 | 5, 13, 29, 61 | 1, 1, 1, 25 | 25 − 2⁴ = 9 |
| 2p + 3 | 43, 89, 181, 73, 149 | 1, 1, 5, 1, 7 | 35 − 2⁵ = 3 |
| 3p + 2 | 5, 17, …, 41 (19 terms) | 1, 1, 7, 1, 5, 1, 5, 1, 1, 17, 1, 1, 5, 25, 1, 5, 35, 1, 25 | 1626953125 − 3¹⁹ |
| 3p + 2 | 167, 503, 1511, 907, 389 | 1, 1, 5, 7, 7 | 245 − 3⁵ = 2 |

The cycle of 167 has the smallest possible excess (2), and that is why its primes are large. By Step 1 the least element of any cycle is at most b/(a·((1 + (S − a^L)/a^L)^(1/L) − 1)), so large cycles need S extremely close to a^L.

**Step 6 (heuristic): why no further cycle is expected.** A new cycle of 2p + 3 with least prime above 10¹⁰ needs L ≥ 28 and S − 2^L ≤ 1.5·L·2^L/10¹⁰. For L = 28 the only possibility is S = 2²⁸ + 1 = 17·15790321. Then at most two cofactors exceed 1, and 26 of the 28 steps are p_(i+1) = 2p_i + 3 with every value prime, near 10¹⁰. A random set of 28 such numbers is all prime with probability about (1.5·2/ln 10¹⁰)²⁸ ≈ 10⁻²⁵. Longer cycles allow more values of S but cost a further factor of about 0.13 per extra prime, so the expected number of new cycles stays far below 1. The same holds for 3p + 2.

**Q2 (can it be proved?).** Steps 1 to 3 give a proof for all short cycles. A complete proof would have to exclude cycles of every length L. Each L is a finite problem (S lies in a bounded window and determines the cycle), but the window grows like a^L, and nothing like it is known even for the Collatz map, where the analogous statement (no nontrivial cycle) is proved only for bounded lengths.
