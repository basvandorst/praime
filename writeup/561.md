# Puzzle 561: Squares of consecutive primes plus squares of consecutive even numbers

> **In short:** The record was 12 consecutive primes pᵢ with pᵢ² + (k + 2i)² prime for i = 0 … 11. The search: (1) a prime q ≡ 1 (mod 4) divides the i-th sum only for two residues of k, and a prime q ≡ 3 (mod 4) never; (2) modulo 5, 13, 17, 29, 37, 41 only 0.43 % of all runs leave a residue free; (3) the free residues are combined by the Chinese remainder theorem, so only these k are tested. This gives two runs of 13, one more than the record; all sums proved prime.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_561.htm)

**Status:** beaten · proven primes

## The question

5² + 16² = 281, 7² + 18² = 373, 11² + 20² = 521 and 13² + 22² = 653 are prime: consecutive primes squared plus consecutive even numbers squared. Find a longer run.

## How we found it

1. A plain search over (p₀, k) is hopeless: about 10¹⁸ pairs are needed for one run of 13.
2. The sums pᵢ² + (k + 2i)² can only have prime factors q ≡ 1 (mod 4). For such a q, each of the 13 sums forbids two residues of k. Modulo 5 that is 26 forbidden residues on 5 places, so almost every run of primes is dead for every k.
3. The same holds modulo 13, 17, 29, 37 and 41. Of the 50847534 runs below 10⁹, 217576 (0.43 %) keep a free residue for all six primes. For these, the free residues are combined into the allowed k modulo 2·5·13·17·29·37·41 = 97224530: on average 26000 values of k per run instead of 48 million.
4. These are sieved with the primes q ≡ 1 (mod 4) from 53 to 997 (one table lookup per q), and the few survivors are tested for primality.
5. Before the long run, a density estimate (below) said: about 2 runs of 13 for p₀ < 10⁹. The search found 2.

## The math

**Divisors (proved).** Let q be an odd prime, p a prime ≠ q and N = p² + m². If q | N then (m/p)² ≡ −1 (mod q), so −1 is a square modulo q and q ≡ 1 (mod 4). For q ≡ 1 (mod 4) let s² ≡ −1 (mod q). Then q | p² + m² exactly when m ≡ ±s·p (mod q). With m = k + 2i: q | Nᵢ exactly when k ≡ −2i ± s·pᵢ (mod q). N is odd because p is odd and m is even. The search starts at p₀ > 1000 and sieves with q < 1000, so pᵢ ≠ q always, and Nᵢ > 10⁶ > q.

**Wheel (proved).** Let F(q) be the set of residues k mod q not of the form −2i ± s·pᵢ for any i < L. If F(q) is empty for some q, no k works for this run (every k makes some Nᵢ divisible by q, and Nᵢ > q). Otherwise k must lie in F(q) for q = 5, 13, 17, 29, 37, 41 and be even; the Chinese remainder theorem lists these k modulo M = 97224530. The search covers exactly one period, 0 < k ≤ M.

**Expected number (heuristic, Bateman–Horn).** For a run and an even k that passed the wheel, the chance that all L sums are prime is taken as

C / ∏ ln Nᵢ, with C = 2^L · ∏ over odd primes q of c(q) / (1 − 1/q)^L,

where c(q) = 1 for q ≡ 3 (mod 4) and for the wheel primes, and c(q) = 1 − ν(q)/q for the other q ≡ 1 (mod 4), ν(q) = q − |F(q)| the number of forbidden residues. The factor 2^L stands for q = 2 (all Nᵢ are odd). The script uses the true ν(q) for q < 1000, ν(q) = 2L for 1000 < q < 10⁷, and ln Nᵢ ≈ ln(p₀² + k²).
