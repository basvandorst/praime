# Puzzle 342: A die of squares with prime corners

> **In short:** We put six different square numbers on the faces of a die so that the three faces meeting at each of the 8 corners always add up to a different prime. Our faces add up to 658, half of the 1330 on the page, and a full check shows nothing smaller is possible.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_342.htm)

**Status:** beaten (Q3) · proven minimal

## The question

Question 3: write a different square number on each of the 6 faces of a die so that the 3 faces around each of the 8 corners add up to 8 different primes. Make the total of the six squares as small as possible.

On a die, each corner touches exactly one face from each pair of opposite faces. So if the opposite pairs are (a, a'), (b, b'), (c, c'), the 8 corner sums are all the sums x + y + z with x from the first pair, y from the second and z from the third.

## How we found it

Two small facts cut the search down to almost nothing. First, the total of the six faces is what we minimize, so every face is at most the total: below 658 only the squares 1² to 25² can occur. Second, the corner sums only depend on how the six squares split into three opposite pairs, and six numbers split into pairs in just 15 ways.

So we tried every set of six different squares from 1² to 25² with total at most 658, and every way to pair them up. The only arrangement that gives 8 different primes is the one above, at exactly 658. Allowing 0 as a square (0 = 0²) gives a smaller answer, 286, with pairs (0, 144), (4, 64), (25, 49).

## The math

With opposite pairs (a, a'), (b, b'), (c, c'), the corner sums are

```
x + y + z,   x ∈ {a, a'},  y ∈ {b, b'},  z ∈ {c, c'}      (8 sums)
```

For ours:

```
pairs:   (4, 64), (36, 144), (49, 361)
corners: 4+36+49 = 89    4+36+361 = 401    4+144+49 = 197    4+144+361 = 509
         64+36+49 = 149  64+36+361 = 461   64+144+49 = 257   64+144+361 = 569
total:   4 + 64 + 36 + 144 + 49 + 361 = 658
```

All 8 corner sums are different primes.

## Validation

This script checks our die, then repeats the full search over every set of six positive squares with total at most 658 to confirm that 658 is the smallest possible.

```python
from itertools import combinations
from sympy import isprime

def corners(pairs):
    # the 8 corner sums: one face from each pair of opposite faces
    (a, a2), (b, b2), (c, c2) = pairs
    return [x + y + z for x in (a, a2) for y in (b, b2) for z in (c, c2)]

def good(pairs):
    s = corners(pairs)
    return len(set(s)) == 8 and all(isprime(v) for v in s)   # 8 different primes

ours = [(4, 64), (36, 144), (49, 361)]
assert good(ours) and sum(sum(p) for p in ours) == 658

def pairings(six):
    # all 15 ways to split six numbers into three pairs
    a, rest = six[0], six[1:]
    for b in rest:
        r = [x for x in rest if x != b]
        for d in r[1:]:
            e, f = [x for x in r if x not in (r[0], d)]
            yield [(a, b), (r[0], d), (e, f)]

# every face is at most the total, so with total <= 658 only 1^2 .. 25^2 can appear
best = min(sum(six) for six in combinations([k * k for k in range(1, 26)], 6)
           if sum(six) <= 658 and any(good(p) for p in pairings(six)))
assert best == 658                                         # nothing smaller exists

print("die with corner primes, total 658, proven minimal")
```
