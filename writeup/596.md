# Puzzle 596: Why 12n(n+2)+1 is so often prime or semiprime

> **In short:** 12n(n+2)+1 is mostly prime or semiprime for small n; the page asked why. The explanation: (1) with m = n + 1 it is 12m² − 11, so a prime q divides some value only if (q/33) = 1, and 2, 3, 5, 7, 13, 19, 23 never do; (2) this raises the prime rate by a factor 4.81. A model built on this matches all counts and predicts that the exceptions become the majority near n ≈ 4·10⁶.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_596.htm)

**Status:** answered (Q2) · the divisibility rules proved; the counts explained by a calibrated heuristic model

## The question

12·n·(n + 2) + 1 "produces mainly primes or semiprimes": for 0 ≤ n ≤ 100 the only exceptions are n = 21, 38, 71, 76, 96.

**Q1.** Study this statistic a little more. **Q2.** Explain it.

## How we found it

Shifting n by one turns the polynomial into 12m² − 11, a quadratic without a linear term. A prime q divides some value exactly when 11/12 is a square mod q, which is a Legendre-symbol condition. That is the same mechanism that makes Euler's n² + n + 41 prime-rich: half of all primes, among them most of the smallest ones, can never divide a value. From the list of possible prime factors, the counts follow from the Hardy–Littlewood local factors (as in [puzzle 1204](1204.md)).

## The math

Write f(n) = 12n(n + 2) + 1 = 12m² − 11 with m = n + 1.

**Step 1 (proved). Which primes divide some value.**
- f is odd, and f ≡ −11 ≡ 1 (mod 3), so 2 and 3 never divide it.
- 11 | f iff 11 | 12m², i.e. 11 | m. Then f = 11·(132k² − 1) with 132k² − 1 ≡ −1 (mod 11), so 11 ∥ f.
- For a prime q ∤ 66: q | f ⇔ 12m² ≡ 11 ⇔ (6m)² ≡ 33 (mod q) (multiply by 3). So some value is divisible by q iff (33/q) = 1, and then for exactly 2 residues of m mod q.
- Quadratic reciprocity gives (3/q)(11/q) = (q/3)(q/11)·(−1)^((q−1)/2·(1+5)) = (q/33). So q can divide f iff q mod 33 lies in the 10 classes with Jacobi symbol (q/33) = 1.

The primes below 200 that can divide a value are 11, 17, 29, 31, 37, 41, 67, 83, 97, 101, 103, 107, 131, 149, 157, 163, 167, 173, 181, 197, 199. The ones that never can start with 2, 3, 5, 7, 13, 19, 23, 43, 47, 53, 59.

**Step 2 (proved). Small n.** A value with three prime factors (counted with multiplicity) is at least 11·17² = 3179. The factor 11 occurs only once, and 17 is the smallest other possible factor; 17² does occur, because the roots of f mod 17 lift to mod 17². Since f(15) = 3061 < 3179, every n ≤ 15 gives a prime or a semiprime. The first exception is n = 21: f(21) = 5797 = 11·17·31.

**Step 3 (heuristic, calibrated). The counts.** Let ω(q) ∈ {0, 1, 2} be the number of roots of f mod q. The Hardy–Littlewood constant is

```
C = ∏_q (1 − ω(q)/q) / (1 − 1/q) = 4.81   (product over q < 10⁶)
```

A random number of the same size has C = 1. Here C is large because the factors (1 − 1/q)⁻¹ of the never-dividing primes 2, 3, 5, 7, 13, … are not cancelled. The model:

```
P(f(n) prime)      ≈ C / ln f(n)
P(f(n) semiprime)  ≈ Σ_(p allowed, p ≤ √f) (ω(p)/p) · (C / c_p) / ln(f/p),   c_p = (1 − ω(p)/p)/(1 − 1/p)
P(3 or more factors) = 1 − the two above
```

The semiprime term is "p divides f, and the cofactor f/p is prime": the cofactor carries the constant C without the local factor at p.

**Step 4 (heuristic). The trend.** Both probabilities fall like 1/ln f(n), so the exceptions slowly take over: the model gives a 3+ factor share of 0.47 at n = 10⁶, 0.52 at n = 10⁷ and 0.62 at n = 10¹⁰. The share passes one half near n ≈ 4·10⁶. "Mainly primes or semiprimes" holds below that, and the reason is the constant 4.81.
