# Puzzle 1238: Puzzle 1236, revisited (rules for the reversed period of 1/p)

> **In short:** Read backwards, the period of 1/p is the 10-adic number −1/p, with carries running forward. From that we prove a one-line criterion: Rotondo's reverse rule a(n) = a(n−J) + a(n−N) works **exactly when p divides 10^N + 10^J − 1**. The forward rules of Puzzle 1236 satisfy the mirror condition 10^(−J) + 10^(−N) ≡ 1 (mod p). So reverse lags are forward lags negated mod the period, which answers Q2. A rule exists for 154 of the 165 primes 7 ≤ p < 1000; for the other 11 we prove none exists (Q1). The reverse rules are Marsaglia and Zaman's add-with-carry random number generators in base 10 (Q3).

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1238.htm) (forward rules: [Puzzle 1236](https://www.primepuzzles.net/puzzles/puzz_1236.htm))

**Status:** answered (Q1, Q2, Q3) · proof, plus a table for all p < 1000

## The question

1/7 = 0.142857…; backwards the period reads 7, 5, 8, 2, 4, 1. Rotondo starts from 7, 5, 8 and uses a(n) = a(n−2) + a(n−3), carrying into the next term: 7, 5, 8, 12 → 2 (carry 1), 13 + 1 → 4, 10 + 1 → 1, 6 + 1 → 7, …

- **Q1.** Is there such a rule for the reversed period of every prime? (List the prime, the rule and the starting values.)
- **Q2.** Are the reverse rules related to the forward rules of Puzzle 1236?
- **Q3.** Are the reverse rules useful for anything?

The page has no contributions. On Puzzle 1236, Oscar Volpatti showed that a forward rule with lags J < N needs 10^N ≡ 10^(N−J) + 1 (mod p), subject to conditions on the carry cascade. Giorgos Kalogeropoulos listed forward rules for 208 primes up to 7639, and Oscar listed them for more.

## The math

Let T = ord_p(10), with p ≠ 2, 3, 5. Write b(1), b(2), … for the period of 1/p read backwards and repeated, so b = 7, 5, 8, 2, 4, 1, 7, … for p = 7.

**Lemma (backwards = −1/p).** In the 10-adic integers, Σ b(n)·10^(n−1) = −1/p.

*Proof.* One block gives Σ_(n≤T) b(n)·10^(n−1) = Σ a(m)·10^(T−m) = (10^T − 1)/p, the period read as an integer. Repeating it multiplies by 1 + 10^T + 10^(2T) + … = 1/(1 − 10^T). So the sum is (10^T − 1)/(p(1 − 10^T)) = −1/p. ∎

So the reversed digits are the 10-adic expansion of Y = −1/p, where carries move toward later digits. That is exactly the direction Rotondo's reverse process carries.

**Theorem (reverse rules).** For lags 1 ≤ J < N, start from b(1..N) with carry 0. Then a(n) = a(n−J) + a(n−N) + carry, keeping the last digit and carrying the rest, reproduces every b(n) **if and only if p | 10^N + 10^J − 1.**

*Proof.* Put D = 10^N + 10^J − 1.

**(⇐)** G = D/p is an integer with 0 < G < 10^N, and Y·(1 − 10^J − 10^N) = D/p = G, so

```
Y = G + 10^J·Y + 10^N·Y.
```

Let U_n = G + 10^J·(Y mod 10^(n−J)) + 10^N·(Y mod 10^(n−N)) for n ≥ N. Then U_n ≡ Y (mod 10^n). Going from U_n to U_(n+1) adds 10^n·(b(n+1−J) + b(n+1−N)). So digit n+1 of Y is (c_n + b(n+1−J) + b(n+1−N)) mod 10, where c_n = ⌊U_n / 10^n⌋ is the carry. That is Rotondo's step, and the carry is 0 or 1. It only remains to show that the starting carry c_N is 0. Write M = N − J and k = 10^(−M) mod p ∈ [1, p−1]. Then Y mod 10^M = (k·10^M − 1)/p, and

```
U_N = (10^N + 10^J − 1)/p + 10^J·(k·10^M − 1)/p = ((k + 1)·10^N − 1)/p < 10^N,   since k + 1 ≤ p.
```

**(⇒)** Suppose the process reproduces b, with starting carry 0. Let V = (Y mod 10^N) − 10^J·(Y mod 10^M). Induction gives Y·(1 − 10^J − 10^N) ≡ V (mod 10^n) for every n. Hence D/p = V is an ordinary integer, and p | D. ∎

Unlike the forward direction, no extra carry condition ever appears: every solution of the congruence is a working reverse rule. For p = 7: 10³ + 10² − 1 = 1099 = 7·157, so lags {2, 3} work. That is Rotondo's rule.

**Duality with the forward rules (Q2).** Multiply Oscar's forward condition 10^N ≡ 10^(N−J) + 1 by 10^(−N):

```
forward rule, lags {J, N}:   10^(−J) + 10^(−N) ≡ 1   (mod p)
reverse rule, lags {J, N}:   10^J    + 10^N    ≡ 1   (mod p)
```

Both conditions are symmetric in the two lags. Exponents only matter mod T, so:

> **lags {J, N} satisfy the forward congruence ⟺ lags {−J, −N} (mod T) give a reverse rule.**

The reverse rules for 10 are exactly the forward congruences for 10⁻¹ mod p. Equivalently, both say that the subgroup ⟨10⟩ of (ℤ/p)* contains u and v with u + v = 1, read in the two directions. So a prime has a 2-lag forward congruence exactly when it has a 2-lag reverse rule.

- **p = 7** (T = 6): reverse lags {2, 3} ↦ {4, 3}, Rotondo's own forward rule a(n−3) + a(n−4).
- **All 208 forward rules** in Kalogeropoulos's file (up to p = 7639) satisfy the forward congruence. Negating their lags gives reverse rules, and every one of them reproduces the reversed period (checked).

The forward direction can still fail because of its backward-moving carries (Oscar's cascade conditions). Below 1000, Oscar's forward list lacks 13, 53 and 757, although all three have reverse rules. Giorgos does give a forward rule for 13. We did not check whether Oscar's search bounds or a real obstruction explain the other two.

**Which primes have a rule (Q1).** A 2-lag rule exists iff some u ∈ ⟨10⟩ has 1 − u ∈ ⟨10⟩. If it does, a rule with N ≤ 2T exists: take J ∈ [1, T] and N ∈ [J + 1, J + T]. Below 1000 the answer is no exactly for

```
p    3  11  37  41  73  101  137  239  271  281  641  859
T    1   2   3   5   8    4    8    7    5   28   32   26
```

For these primes, neither a forward nor a reverse rule of the form a(n−J) + a(n−N) exists at all. Every other prime 7 ≤ p < 1000 (154 primes) has a reverse rule. The least one for each is in [`writeup/data/1238_reverse_rules.txt`](data/1238_reverse_rules.txt) (p, T, N, J, starting digits). Some examples:

**Usefulness (Q3).** The reverse process x_n = x_(n−J) + x_(n−N) + c (mod b), with a carry of 0 or 1, is the **add-with-carry generator** of Marsaglia and Zaman ("A new class of random number generators", *Ann. Appl. Probab.* 1, 1991; literature, not in our archive). Its theory says the output is the reversed base-b expansion of a fraction with denominator m = b^N + b^J − 1, which is our theorem in base 10. Large lags with m prime and b of large order mod m give fast generators with huge periods. So the reverse rules are not useless: they are a standard random number generator, and the theorem shows which ones produce 1/p.

## How we found it

The forward rules were explained on page 1236 with generating functions in x = 1/10. Reading digits backwards swaps x = 1/10 for x = 10, and power series in 10 converge 10-adically. That suggested the lemma. We then tested the criterion against Rotondo's process directly. For all primes 7 ≤ p < 1500 and 1 ≤ J < N ≤ 40 (184,080 cases, simulated over 3 periods), the process works exactly when p | 10^N + 10^J − 1. That run included the carry condition, which the proof then showed is always true. Code: `writeup/code/p1238_criterion.py`, `writeup/code/p1238_table.py`.

## Verify it yourself

`writeup/code/p1238_verify.py` gets the reversed digits from plain long division, not from the 10-adic formula. It checks: Rotondo's example; the criterion for all p < 400 and N ≤ 30; every row of the table, including that "none" occurs exactly when u + v = 1 has no solution in ⟨10⟩; and the duality on all 208 forward rules in the archived file `references/Pu 1236 GK.txt.txt`. It runs in 2 seconds.

```python
import re
from sympy import n_order, primerange

def period(p):
    """Digits of one period of 1/p by long division."""
    r, out = 1, []
    while True:
        out.append(10 * r // p); r = 10 * r % p
        if r == 1: return out

def reverse_rule_ok(p, N, J, terms):
    """Rotondo's process: start with the first N reversed digits, a(n) = a(n-J) + a(n-N) + carry."""
    rev = period(p)[::-1]
    want = [rev[k % len(rev)] for k in range(terms)]
    d, c = want[:N], 0
    for n in range(N, terms):
        v = d[n - J] + d[n - N] + c
        d.append(v % 10); c = v // 10
    return d == want

# 1. Rotondo's example.
assert period(7)[::-1] == [7, 5, 8, 2, 4, 1] and reverse_rule_ok(7, 3, 2, 60)

# 2. Criterion: the rule works iff p | 10^N + 10^J - 1.
for p in primerange(7, 400):
    T = n_order(10, p)
    for N in range(2, 31):
        for J in range(1, N):
            assert reverse_rule_ok(p, N, J, 3 * T + N) == ((10**N + 10**J - 1) % p == 0), (p, N, J)

# 3. The table.
for line in open('writeup/data/1238_reverse_rules.txt'):
    if line.startswith('#'): continue
    t = line.split(); p, T = int(t[0]), int(t[1])
    H = {pow(10, k, p) for k in range(T)}
    solvable = any((1 - u) % p in H for u in H)
    if t[2] == 'none':
        assert not solvable, p
    else:
        N, J = int(t[2]), int(t[3])
        assert solvable and reverse_rule_ok(p, N, J, 3 * T + N) and t[4] == ''.join(map(str, period(p)[::-1][:N]))

# 4. Duality with the forward rules of page 1236.
gk = re.findall(r"For 1/(\d+), using.*?a\(n\) = a\(n-(\d+)\)\s*\+ a\(n-(\d+)\)",
                open("references/Pu 1236 GK.txt.txt").read(), re.S)
for p, j, n in gk:
    p, j, n = int(p), int(j), int(n)
    assert (pow(10, -j, p) + pow(10, -n, p) - 1) % p == 0
    T = n_order(10, p); J2, N2 = sorted(((-j) % T or T, (-n) % T or T))
    if J2 == N2: N2 += T
    assert (10**N2 + 10**J2 - 1) % p == 0 and reverse_rule_ok(p, N2, J2, 3 * T + N2)
print("all checks pass")
```
