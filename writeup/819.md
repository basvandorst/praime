# Puzzle 819: All functions with g(g(n)) = p(n)

> **In short:** Q2 asked whether f with f(f(n)) = p(n), the n-th prime, is unique; a second solution was known, but not all. The proof: (1) put the integers in rows starting at the non-primes, each step applying p; (2) any solution commutes with p, so it maps rows into rows; (3) it must pair the rows. This proves the solutions are exactly the row pairings with orientations: 2^ℵ₀ of them.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_819.htm)

**Status:** answered (Q2 in full) · complete description of all solutions (proof); a random third solution checked numerically

## The question

[Puzzle 314](https://www.primepuzzles.net/puzzles/puzz_314.htm) asked for f with f(f(n)) = p(n). Luke Pebody built one from the array Z(m, n): Z(m, 1) is the m-th non-prime (1, 4, 6, 8, 9, …) and Z(m, n + 1) = p(Z(m, n)). He set f(Z(2m+1, k)) = Z(2m+2, k) and f(Z(2m+2, k)) = Z(2m+1, k + 1). Puzzle 819 asks: Q1 compute f(2016); Q2 "is there another function g such that g(g(n)) = p(n)? Or is f unique? Prove your answer"; Q3 compute g(2016).

On the page, Emmanuel Vantieghem computed f(2016) = 2018 and gave a second solution g by reversing the arrows within each pair (g(2016) = 17551). That answers Q2 with "not unique", but does not say what all solutions are.

## The math

Every n is Z(a, b) for exactly one row a and position b (Pebody). Let g be any function with g(g(n)) = p(n).

| # | Claim | Why |
|---|---|---|
| 1 | g is injective | g(x) = g(y) ⇒ p(x) = p(y) ⇒ x = y |
| 2 | g commutes with p | g(p(n)) = g(g(g(n))) = p(g(n)) |
| 3 | g(Z(a, k + 1)) = p(g(Z(a, k))), so g maps a whole row into a single row, shifting positions by a constant | claim 2 applied repeatedly |
| 4 | no row is mapped into itself | g(Z(a, 1)) = Z(a, j) gives Z(a, 2) = g(g(Z(a, 1))) = Z(a, 2j − 1), so j = 3/2 |
| 5 | if g(Z(a, 1)) = Z(b, j), then g maps row b back into row a and j ∈ {1, 2} | g(Z(b, j)) = Z(a, 2) by g∘g = p. If j ≥ 2, claim 3 gives g(Z(b, j − 1)) = Z(a, 1), and if j ≥ 3 also g(Z(b, j − 2)) = Z(a, 0), impossible, because Z(a, 1) is a non-prime and so not a value of p |
| 6 | j = 1: Z(a, k) → Z(b, k) → Z(a, k + 1); j = 2: Z(b, k) → Z(a, k) → Z(b, k + 1) | claims 3 and 5 |
| 7 | conversely, any perfect matching of {1, 2, 3, …} with any orientation of each pair defines a g with g∘g = p | each pair interleaves its two rows into one chain, and g steps along it |

There are 2^ℵ₀ perfect matchings of a countable set, and 2^ℵ₀ orientations even for a fixed matching. So the solutions form a set of the size of the continuum. Pebody's f uses the matching {1, 2}, {3, 4}, … with the odd row first. Vantieghem's g uses the same matching with the even row first.
