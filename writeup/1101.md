# Puzzle 1101: Primes p that divide the concatenation of σ(p−1) and σ(p+1)

> **In short:** 4793 divides 9000‖10368, the concatenation of σ(4792) and σ(4794); the page asks whether it is the only such prime, and a search found only 2 besides it below 1.1·10¹⁰. (1) The concatenation C = σ(p−1)·10^d + σ(p+1) is about p²·polylog, and p | C is a 1-in-p event with no structure forcing or forbidding it. (2) The expected count below X is Σ 1/p = ln ln X + 0.26: 3.4 below 1.1·10¹⁰ (2 found). So more such primes are expected, infinitely many, but the next one only near 10²⁷.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1101.htm)

**Status:** open · explained (2 and 4793 are the only solutions below 2·10⁷, direct, and below 1.1·10¹⁰ on the page; heuristic: infinitely many, growing like ln ln X)

## The question

Giorgos Kalogeropoulos notes that 4793 divides 900010368 = σ(4792)‖σ(4794) = 2⁷·3²·163·4793 and asks: is this the only prime with this property? Michael Branicky writes that 2 is also a solution (σ(1)‖σ(3) = 14) and that there is no other prime below 1.1·10¹⁰.

## How we found it

The concatenation is C = σ(p−1)·10^d + σ(p+1), with d the number of digits of σ(p+1). Nothing ties C to p modulo p: σ(p−1) and σ(p+1) depend on the factorisations of p ± 1, which are independent of p's residue behaviour. So p | C behaves like a random event of probability 1/p.

## The math

**Step 1 (proved). Size and form.** σ(n) < n·(e^γ ln ln n + 0.65/ln ln n) for n ≥ 3 (Robin's unconditional bound), so C < 10^d·σ(p−1) + σ(p+1) is at most about 10·σ(p+1)·σ(p−1) = O(p²(ln ln p)²). The condition p | C has no trivial solutions: for p = 3, 5, 7 the concatenations are 37, 712, 1215 (remainders 1, 2, 4).

**Step 2 (computed). Direct check.** A sieve of σ(n) for n < 2·10⁷ gives C mod p for every prime p < 2·10⁷: exactly 2 and 4793 divide their concatenation.

**Step 3 (heuristic). Expected count.** With probability 1/p per prime, the expected number of solutions with p ≤ X is Σ_{p≤X} 1/p = ln ln X + M, M = 0.2615: 3.40 below 1.1·10¹⁰, where 2 were found (Poisson probability of at most 2: 0.34). One more solution is expected only when ln ln X grows by 1 from 3.14 (the value at 1.1·10¹⁰): X ≈ 10²⁷. The expected number between 1.1·10¹⁰ and 10¹⁵ is 0.40. So the answer to the page's question is heuristically no, but a search cannot settle it.
