# Puzzle 882: Prime sequence type A(Z)ᵢB

> **In short:** Our run 95773717 (6)ᵢ 1 is prime for every i = 0..10. That is 11 primes (k = 10), one more than Taneja's 10 primes (k = 9). We found it with a sieve that runs over A instead of testing numbers one by one. For each prime q, the "bad" values of A form at most 11 residue classes mod q, so the whole space below 2⁶⁴ took 75 seconds.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_882.htm)

**Status:** beaten · proven primes (all 11 below 2⁶⁴)

## The question

A(Z)ᵢB is A, then the block Z written i times, then B. Taneja found 29 cases with A(Z)ᵢB prime for i = 0..9, for example 291234(3)ᵢ73. The puzzle asks for runs with k > 9, i.e. prime for i = 0..10 or longer. The page has no contributions.

## How we found it

With a one-digit Z and b = len(B), the i-th number is

```
N_i = A·10^(i+b) + Z·(10^i − 1)/9·10^b + B.
```

**Z must be 0, 3, 6 or 9.** The digit sum of N_i is s(A) + s(B) + iZ. If 3 ∤ Z, one of i = 0, 1, 2 gives a multiple of 3. This is the "fixed class" rule for affine chains (fact 6201): N_(i+1) = 10·N_i − c, and the class mod 3 stays fixed only when Z ≡ 0.

**Sieve over A, not over N.** For fixed Z and B and a prime q ∉ {2, 3, 5}, q | N_i is a linear condition on A:

```
A ≡ −(Z·(10^i − 1)/9·10^b + B) · 10^−(i+b)   (mod q).
```

Over i = 0..10 these are at most min(11, ord_q(10)) classes. For q = 11 there are only 2, for q = 37 only 3. We cross out those classes in a byte array of A values, for the first 600 odd primes q ≠ 5 (up to 4409). Then we run a deterministic 64-bit Miller–Rabin test on N₀, N₁, … of the survivors and stop at the first composite.

**The searched space** ([`writeup/code/p882_search64.c`](code/p882_search64.c), 75 s):

- Z ∈ {0, 3, 6, 9}
- B with 1 to 4 digits, odd, not divisible by 5, not starting with Z
- A not ending in Z (so A and B do not absorb copies of Z)
- every N_i < 1.8·10¹⁹ (below 2⁶⁴), which bounds A by 1.8·10¹⁹ / 10^(10+b)

About 10¹⁰ pairs (A, B) in all. The search reproduces Taneja's 291234(3)ᵢ73 and finds **exactly one run of 11 primes**, ours, and no longer run.

**Past 2⁶⁴.** [`writeup/code/p882_search128.c`](code/p882_search128.c) covers A from the 2⁶⁴ limit up to 10 times that, about 9·10¹⁰ more pairs, in 6 minutes on 2 cores. It uses 128-bit arithmetic and GMP's probable-prime test. It finds four more runs of 10 primes and none of 11 or more:

```
794583 (6)ᵢ 8867      651250363 (0)ᵢ 7
1766194519 (6)ᵢ 9     1052572 (0)ᵢ 2527
```

A run of 12 would need a much larger search.

A pitfall we hit: the first version of the 128-bit search sieved 14 terms (i = 0..13) while looking for runs of 12. That silently rejects every A where N₁₂ or N₁₃ has a small factor, and survivors dropped by a factor of 30. Sieve only the terms the target run needs.

## The math

- Mod 3 forces Z ∈ {0, 3, 6, 9} (see above). With Z = 0 the numbers are A·10^(i+b) + B.
- For q with small ord_q(10), the 11 numbers fall into few classes mod q: 11 (order 2), 37 (order 3), 101 (order 4), 41 and 271 (order 5), 7 and 13 (order 6). Such q rule out far fewer A than an unrelated 11-tuple would. That is why runs like this are much more common than 11 random numbers of the same size all being prime.
- All 11 numbers are below 2⁶⁴, so `sympy.isprime` is deterministic there and gives a proof.

## Verify it yourself

[`writeup/code/p882_verify.py`](code/p882_verify.py):

```python
from sympy import isprime, factorint

N = lambda A, Z, B, i: int(str(A) + str(Z) * i + str(B))

# Our run: 11 primes, all below 2^64, so sympy.isprime is a proof.
run = [N(95773717, 6, 1, i) for i in range(11)]
assert all(isprime(x) for x in run) and max(run) < 2**64

# It stops at i = 11.
n11 = N(95773717, 6, 1, 11)
assert not isprime(n11)
print('i = 11:', n11, '=', factorint(n11))

# Taneja's example from the page: 291234(3)_i73, i = 0..9, and i = 10 composite.
assert all(isprime(N(291234, 3, 73, i)) for i in range(10)) and not isprime(N(291234, 3, 73, 10))

# Mod 3: Z not = 0 mod 3 puts a multiple of 3 among i = 0, 1, 2.
for Z in range(10):
    for A in range(1, 300):
        for B in (1, 3, 7, 9):
            res = [N(A, Z, B, i) % 3 for i in range(3)]
            if Z % 3:
                assert 0 in res
print("all checks pass")
```
