# Puzzle 307: Record Smith numbers

> **In short:** The record Smith number of the form P·Q·10^M (Q a Mersenne prime) had 7,820,865 digits. The construction: (1) 10^M adds 7M to the factors' digit sum only; (2) take Q = 2¹³⁶²⁷⁹⁸⁴¹ − 1; (3) P = 7 balances with M = 2192. This gives a Smith number with 41,026,513 digits, beating 7,820,865; proven primes.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_307.htm)

**Status:** beaten (P·Q·10^M method) · proven primes

## The question

A **Smith number** is a composite number whose digit sum equals the sum of the digit sums of its prime factors (counted with repetition). Example: 22 = 2 · 11, digit sum 2 + 2 = 4, and the factors give 2 + (1 + 1) = 4.

The puzzle lists five known recipes for huge Smith numbers, each with its own record, and asks to improve any of them in its own recipe. We take P. Costello's recipe N = P · Q · 10^M, where Q is a Mersenne prime and P a small prime.

## Current record vs ours

| | Number | Digits |
|---|---|---|
| Current record (L. Soule, 2005) | 127 · (2²⁵⁹⁶⁴⁹⁵¹ − 1) · 10^M | 7,820,865 (as stated) |
| **Ours** | 7 · (2¹³⁶²⁷⁹⁸⁴¹ − 1) · 10²¹⁹² | **41,026,513** |

## How we found it

The recipe has one moving part. Multiplying by 10^M does not change the digit sum of N, but it adds M copies of the factors 2 and 5, which add 7 to the factors' side for every unit of M. So once P and Q are fixed, M is simply whatever makes the two sides equal, provided the gap is a non-negative multiple of 7.

So the size of the record is set by Q. We used the largest known Mersenne prime, 2¹³⁶²⁷⁹⁸⁴¹ − 1 (found by GIMPS in 2024, proven prime), and tried small primes P in order. P = 2, 3 and 5 fail (the gap is not a non-negative multiple of 7); P = 7 works with M = 2192.

## The math

Write S(n) for the digit sum and Q = 2¹³⁶²⁷⁹⁸⁴¹ − 1. With N = P · Q · 10^M = P · Q · 2^M · 5^M:

```
digit sum of N        = S(P · Q)                       (trailing zeros add nothing)
digit sum of factors  = S(P) + S(Q) + M·(2 + 5)
Smith condition:        S(P · Q) = S(P) + S(Q) + 7M
```

For P = 7:

```
S(Q)     = 184,595,719
S(7·Q)   = 184,611,070
7M       = 184,611,070 − 184,595,719 − 7 = 15,344   →   M = 2192
```

A note on the listed record: Soule gives S(127 · Q₄₂) = 35,175,028 with S(Q₄₂) = 35,170,384, so 7M = 35,175,028 − 35,170,384 − (1 + 2 + 7) = 4634 and M = 662. The page prints 10⁴⁶³⁴, which is 7M, not M. The script below checks this too.

## The number

```
N = 7 · (2^136279841 − 1) · 10^2192        (41,026,513 digits)
```

The Mersenne prime is proven (GIMPS). 7 and the factors 2 and 5 are trivially prime, so the factorization is complete and the Smith property is exact.

## Validation

This script computes the digit sums of the 41-million-digit numbers and checks the Smith condition; it also re-derives the correct M for Soule's number. It needs about 1 GB of memory and up to a minute.

```python
import gmpy2

S = lambda n: sum(int(d) for d in gmpy2.digits(n))     # digit sum of a (big) integer

# our number: N = 7 * Q * 10^2192 with Q = 2^136279841 - 1 (proven Mersenne prime, GIMPS 2024)
Q = gmpy2.mpz(2) ** 136279841 - 1
SQ, S7Q = S(Q), S(7 * Q)
assert SQ == 184595719 and S7Q == 184611070
assert S7Q == S(7) + SQ + 2192 * (2 + 5)               # the Smith condition holds with M = 2192
print("digits of N:", len(gmpy2.digits(7 * Q)) + 2192)  # 41,026,513

# Soule's number on the page: P = 127, Q = 2^25964951 - 1; solve for M
Q42 = gmpy2.mpz(2) ** 25964951 - 1
seven_M = S(127 * Q42) - S(127) - S(Q42)
assert seven_M == 4634 and seven_M % 7 == 0
print("Soule's correct exponent is M =", seven_M // 7)  # 662, not 4634

# not checked here: primality of the Mersenne primes (proven by GIMPS)
print("7 * (2^136279841 - 1) * 10^2192 is a Smith number")
```
