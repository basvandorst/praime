# Puzzle 1230: Even-period primes

> **In short:** The record was 29 primes in a row with an even decimal period. The construction: (1) the period is even when (10/p) = −1; (2) every p ≡ 17 (mod 40) has (10/p) = −1; (3) a quartic with all values ≡ 17 (mod 40) is prime for n = 0 … 29. This gives 30 primes in a row, beating the record by one; proven primes.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1230.htm)

**Status:** beaten · proven primes

## The question

1/7 = 0.142857 142857 …, a repeating block of 6 digits. Find a formula that gives as many different primes in a row as possible, where every prime's repeating block has **even** length.

## Current record vs ours

| | Formula | Result |
|---|---|---|
| Current record (J. M. Rebert, 2025) | 740n² − 100n + 3943, n = −9..19 | 29 primes |
| **Ours** | 5n⁴ − 330n³ + 9395n² − 130510n + 709337, n = 0..29 | **30 primes** |

## How we found it

Checking the block length of every prime is slow, so we looked for a shortcut. A prime that leaves remainder 17 when divided by 40 always has an even block length. So we only searched formulas whose outputs *always* leave remainder 17. The "even block" rule then takes care of itself, and the only job left is finding a long run of primes.

## The math

The block length of 1/p is the order of 10 modulo p: the smallest t with 10ᵗ ≡ 1 (mod p).

By Euler's criterion, 10^((p−1)/2) ≡ (10/p) (mod p). If (10/p) = −1, the order cannot divide (p−1)/2, so it is even.

```
(10/p) = (2/p) · (5/p)
p ≡ 17 (mod 40):  17 ≡ 1 (mod 8)  →  (2/p) = +1
                  17 ≡ 2 (mod 5)  →  (5/p) = −1
                  →  (10/p) = −1  →  even period
```

The formula is built to stay at remainder 17:

```
P(n) = 40 · Q(n) + 17,   Q(n) = (n⁴ − 66n³ + 1879n² − 26102n + 141864) / 8
```

Q(n) is a whole number for every whole n, so P(n) ≡ 17 (mod 40) always.

## Validation

This script rebuilds the 30 values and checks every claim: prime, distinct, remainder 17 mod 40, and an even repeating block. Run it after `pip install sympy`.

```python
from sympy import isprime, n_order

# The formula from the table above.
P = lambda n: 5*n**4 - 330*n**3 + 9395*n**2 - 130510*n + 709337

# The 30 values for n = 0, 1, ..., 29.
vals = [P(n) for n in range(30)]

# Every value is prime.
assert all(isprime(v) for v in vals)

# No value repeats, so these are 30 different primes.
assert len(set(vals)) == 30

# Every value leaves remainder 17 when divided by 40 (the shortcut).
assert all(v % 40 == 17 for v in vals)

# The repeating block of 1/p has length ord_p(10); check it is even for each prime.
assert all(n_order(10, v) % 2 == 0 for v in vals)

# The run stops exactly at 30: the neighbours on both sides are composite.
assert not isprime(P(-1)) and not isprime(P(30))

print("30 primes in a row, all with an even-length repeating block")
```
