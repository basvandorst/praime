# Puzzle 325: A Zeisel number with 10,008 digits

> **In short:** Q4 asked for a Zeisel number with at least 10,000 digits; none was known. The construction: (1) two chosen primes p₁, p₂ fix A and B; (2) p₂ = k·7723# + 1 is proved prime by Pocklington; (3) only p₃ = A·p₂ + B is left to chance. This gives a 10,008-digit Zeisel number; p₁ and p₂ are proven, p₃ is PRP.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_325.htm)

**Status:** first answer (Q4) · p₁, p₂ proven prime, p₃ probable prime (PRP)

## The question

J. K. Andersen's definition: a **Zeisel number** is a product of n ≥ 3 distinct primes p₁·p₂·…·p_n, where p₀ = 1 and p_i = A·p_(i−1) + B for fixed integers A and B. For example 105 = 3·5·7 with (A, B) = (1, 2). Question 4 asks for a Zeisel number with at least 10,000 digits, and how large one can go.

## How we found it

With p₀ = 1, the rule gives p₁ = A + B and p₂ = A·p₁ + B. Turned around: pick any two primes p₁ and p₂ with p₁ − 1 dividing p₂ − 1, and

```
A = (p₂ − 1)/(p₁ − 1) − 1,     B = p₁ − A
```

reproduce them exactly. Then p₃ = A·p₂ + B is forced, and it is the only number left to the luck of being prime.

We wanted p₂ to be huge and still **provably** prime. Numbers of the form k·7723# + 1 (7723# is the product of all primes up to 7723) are ideal: p₂ − 1 is almost completely factored, which is exactly what the Pocklington test needs to prove primality. With p₁ = 12487, p₁ − 1 = 12486 = 2·3·2081 divides 7723#, so the divisibility condition holds automatically. We then tried values of k until both p₂ and p₃ passed, and k = 10²¹ + 1245 worked.

## The math

**The chain.** With d = p₁ − 1, A = (p₂ − 1)/d − 1 and B = p₁ − A:

```
p₁ = A·1 + B                      ✓ by the choice of B
p₂ = A·p₁ + B = A·(p₁ − 1) + p₁ = (p₂ − 1 − d) + d + 1 = p₂   ✓
p₃ = A·p₂ + B
```

B comes out negative here. The definition only asks for constant integers A and B, so that is allowed.

**Pocklington's test.** If F divides N − 1, F > √N, and some a satisfies a^(N−1) ≡ 1 (mod N) and gcd(a^((N−1)/q) − 1, N) = 1 for every prime q dividing F, then N is prime. For N = p₂ we take F as the product of the 445 largest primes up to 7723 (1671 digits, more than half of p₂'s 3336 digits) and a = 3.

## The numbers

```
p₁ = 12487                                     (5 digits, prime)
p₂ = (10^21 + 1245) · 7723# + 1                (3336 digits, proven prime by Pocklington)
A  = (p₂ − 1)/12486 − 1,   B = 12487 − A
p₃ = A·p₂ + B                                  (6668 digits, probable prime)
Z  = p₁ · p₂ · p₃                              (10,008 digits)
```

p₃ passes the BPSW test and extra strong probable-prime tests, but has not been formally proven prime: a probable prime (PRP).

## Validation

This script rebuilds the three primes, checks the Zeisel rule, proves p₂ prime with Pocklington's test, and runs probable-prime tests on p₃. It uses gmpy2 for fast big-number arithmetic and takes about a minute.

```python
import gmpy2
from gmpy2 import mpz, powmod, gcd

primes = []                                  # all primes up to 7723
p = 2
while p <= 7723:
    primes.append(p)
    p = int(gmpy2.next_prime(p))
primorial = mpz(1)
for q in primes:
    primorial *= q

p1 = mpz(12487)
p2 = (10**21 + 1245) * primorial + 1
assert (p2 - 1) % (p1 - 1) == 0              # 12486 = 2*3*2081 divides 7723#
A = (p2 - 1) // (p1 - 1) - 1
B = p1 - A
p3 = A * p2 + B

chain = [mpz(1)]
for _ in range(3):
    chain.append(A * chain[-1] + B)          # p_i = A * p_(i-1) + B, starting from p_0 = 1
assert chain[1:] == [p1, p2, p3]

# Pocklington: F | p2 - 1 with F > sqrt(p2), and a = 3 passes for every prime q | F
F, F_primes = mpz(1), []
for q in reversed(primes):
    F *= q
    F_primes.append(q)
    if F * F > p2:
        break
a = 3
assert powmod(a, p2 - 1, p2) == 1
base = powmod(a, (p2 - 1) // F, p2)
assert all(gcd(powmod(base, F // q, p2) - 1, p2) == 1 for q in F_primes)   # p2 is proven prime

assert gmpy2.is_prime(p1)
assert gmpy2.is_bpsw_prp(p3) and all(gmpy2.is_strong_prp(p3, b) for b in (2, 5, 7))   # p3: PRP

Z = p1 * p2 * p3
print("digits:", len(str(p1)), len(str(p2)), len(str(p3)), "-> Zeisel number with", len(str(Z)), "digits")
```
