# Puzzle 1166: Products of prime pairs equal to (p_n#/2)^4

> **In short:** The page lists, for n = 6, 8, 9, 11, 13, 14, 15, sets X of even distances with ∏_{x∈X} P_n(x) = (p_n#/2)^4, where P_n(x) multiplies p(p + x) over the odd prime pairs up to p_n, and asks about n > 15. (1) The identity says every odd prime ≤ p_n has exactly four partners at distances in X. (2) An exact 0/1 search (CP-SAT for n ≤ 138, HiGHS as well for n ≤ 100) finds the page's seven sets as the only solutions for n ≤ 15 and none for 16 ≤ n ≤ 138. Heuristically none exists beyond.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1166.htm)

**Status:** answered (computed) · no set exists for 16 ≤ n ≤ 138 (CP-SAT, confirmed by HiGHS to n = 100); the seven sets on the page are the only ones for n ≤ 15

## The question

(Definition from puzzle 1165.) P_n(x) is the product of all p(p + x) over pairs of odd primes p, p + x with p + x ≤ p_n. Nomoto found sets X of even numbers with ∏_{x∈X} P_n(x) = (p_n#/2)^4 for n = 6, 8, 9, 11, 13, 14, 15, for example n = 6, X = {2, 4, 6, 8, 10} and n = 15, X = {6, 12, 16, 32, 34, 38, 44}. Is it possible for n larger than 15? No contribution is on the page.

## Record vs ours

| | Answer |
|---|---|
| Page | seven sets, n ≤ 15; open beyond |
| **Ours** | **no set for any 16 ≤ n ≤ 138** (exact); the page's sets are the only ones for n ≤ 15, one per n |

## How we found it

Taking the exponent of each prime q in the product turns the identity into a degree condition, one linear equation per odd prime ≤ p_n in the 0/1 unknowns "is x in X". That is a tiny exact feasibility problem: for n = 138 it has 137 equations in 392 unknowns. OR-Tools CP-SAT enumerates all solutions for each n (under a second for n ≤ 60, minutes near n = 138); HiGHS (scipy's `milp`) independently confirms feasibility or infeasibility for n ≤ 100.

## The math

**Reduction (proved).** Fix n and let S be the set of odd primes ≤ p_n. For x even, P_n(x) = ∏_{p, p+x ∈ S} p(p + x). The prime q ∈ S divides P_n(x) exactly once for each of the two numbers q − x, q + x that lies in S (both can, for different pairs). P_n(x) is squarefree apart from this, and no prime outside S occurs. Hence

```
v_q( ∏_{x∈X} P_n(x) ) = #{ x ∈ X : q − x ∈ S } + #{ x ∈ X : q + x ∈ S } =: deg_X(q),
```

and ∏_{x∈X} P_n(x) = (p_n#/2)^4 = ∏_{q∈S} q^4 holds if and only if deg_X(q) = 4 for every q ∈ S. In words: in the graph on S whose edges join primes at a distance in X, every vertex has degree exactly 4. (X may contain only distances up to p_n − 3, so X ⊆ {2, 4, …, p_n − 3}.)

**Check on the page's data (computed).** For each of the seven (n, X) on the page the product ∏ P_n(x) was formed literally and equals (p_n#/2)^4; the degree condition holds for every odd prime ≤ p_n.

**Exact search (computed).** For each n = 3 … 138 the system "deg_X(q) = 4 for all q ∈ S" over X ⊆ {2, 4, …, p_n − 3} was given to CP-SAT with full solution enumeration. Solutions exist only for n = 6, 8, 9, 11, 13, 14, 15, and for each of these there is exactly one X, the one on the page. HiGHS (branch-and-cut on the same 0/1 program) gives the same feasible set for n = 3 … 100 and returns the same X.

| n | p_n | all solutions X |
|---|---|---|
| 6 | 13 | 2, 4, 6, 8, 10 |
| 8 | 19 | 2, 4, 6, 14, 16 |
| 9 | 23 | 4, 8, 10, 12, 14, 18 |
| 11 | 31 | 6, 8, 14, 16, 22, 24, 28 |
| 13 | 41 | 6, 14, 16, 22, 26, 28, 30, 36 |
| 14 | 43 | 6, 12, 16, 28, 32, 34, 38 |
| 15 | 47 | 6, 12, 16, 32, 34, 38, 44 |
| 3–5, 7, 10, 12, 16–138 | | none |

**Why none is expected for larger n (heuristic).** A prime q ∈ S has about n − 2 possible partners (every other odd prime, at a distance that is one of the ≈ p_n/2 candidate values of x). For a random X of density 1/2, deg_X(q) is roughly binomial with n − 2 trials and chance 1/2, so P(deg = 4) ≈ C(n−2, 4)/2^(n−2). The expected number of solutions is then about 2^(p_n/2) · (C(n−2, 4)/2^(n−2))^(n−1) ≈ 2^(n ln n / 2 − n²) · n^(4n), which is about 10^(−26) at n = 20 and decreases like 2^(−n²). The exact search to n = 138 agrees: the equation count (n − 1) outruns the free choices as soon as n passes 15.
