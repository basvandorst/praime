# Puzzle 830: Add one to every factor, multiply by K

> **In short:** We want N written as a product of factors (each at least 2) so that adding 1 to every factor multiplies the product by exactly K. For K = 2012 and K = 2013 we found much smaller N than the published ones (13.6 and 2.2 times smaller), by letting the largest prime that still needs to cancel decide the next factor.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_830.htm)

**Status:** beaten (Q2, K = 2012 and 2013)

## The question

Write N = a₁·a₂·…·a_n with every factor aᵢ ≥ 2 (not necessarily prime). Add 1 to each factor: M = (a₁ + 1)·(a₂ + 1)·…·(a_n + 1). We want M = K·N. Example for K = 2016 (from the page):

```
N = 2^12 · 3^9 · 6,      M = 3^12 · 4^9 · 7 = 2016 · N
```

Question 2 asks for the smallest such N for K = 2012, …, 2017.

## Current record vs ours

| K | Current record (E. Vantieghem, "not 100% sure N is minimal") | **Ours** |
|---|---|---|
| 2012 | 485664325632000 | **35757277839360** |
| 2013 | 386983526400 | **174142586880** |
| 2014–2017 | listed values | the same values (our search finds nothing smaller) |

## How we found it

The condition is a product of fractions:

```
(a₁+1)/a₁ · (a₂+1)/a₂ · … · (a_n+1)/a_n = K
```

Factors 2 and 3 are the cheap way to build up K: each 2 multiplies N by 2 and the ratio by 1.5, each 3 multiplies N by 3 and the ratio by 1.33. But K also contains awkward primes (2012 = 4 · 503, 2013 = 3 · 11 · 61), and those must come from some a + 1. So we kept track of the fraction still needed and always looked at its **largest prime**: if that prime P must appear in a numerator, the next factor has to be a = j·P − 1 for some j; if it must disappear from a denominator, a = j·P. That leaves very few choices per step, and a lower bound on the remaining cost lets the search throw away bad branches early. The whole search takes well under a second per K.

## The math

For K = 2012 = 2² · 503 the prime 503 must come from a factor a with 503 | a + 1. The cheapest route found uses a = 3520 (3521 = 7 · 503), then cancels the 7 with 21 (22/21) and the leftover 5 with 4 (5/4):

```
N = 3520 · 21 · 4 · 2^11 · 3^10 = 35757277839360
M/N = (3521/3520)(22/21)(5/4)(3/2)^11(4/3)^10 = 2012
```

For K = 2013 = 3 · 11 · 61, the factors 60 and 54 bring in 61 and 55 = 5 · 11:

```
N = 60 · 54 · 2^13 · 3^8 = 174142586880
M/N = (61/60)(55/54)(3/2)^13(4/3)^8 = 2013
```

## The numbers

```
K = 2012:   N = 3520 · 21 · 4 · 2^11 · 3^10 = 35757277839360     (listed: 485664325632000)
K = 2013:   N = 60 · 54 · 2^13 · 3^8        = 174142586880       (listed: 386983526400)
```

## Validation

This script checks that adding 1 to every factor multiplies the product by exactly K, for our two solutions, and that both are smaller than the listed ones.

```python
import math

def check(K, factors):
    # factors: list of (a, how many times); returns N, after checking prod(a+1) == K * prod(a)
    N = math.prod(a ** e for a, e in factors)
    M = math.prod((a + 1) ** e for a, e in factors)
    assert all(a >= 2 for a, e in factors)        # no unit factors allowed
    assert M == K * N                              # the puzzle's condition
    return N

N2012 = check(2012, [(3520, 1), (21, 1), (4, 1), (2, 11), (3, 10)])
N2013 = check(2013, [(60, 1), (54, 1), (2, 13), (3, 8)])

assert N2012 == 35757277839360 < 485664325632000       # 13.6 times smaller than listed
assert N2013 == 174142586880 < 386983526400            # 2.2 times smaller than listed
# not checked here: minimality (that comes from the exhaustive search described above)
print("K = 2012:", N2012, "  K = 2013:", N2013)
```
