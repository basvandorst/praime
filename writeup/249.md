# Puzzle 249: A magic square of pandigital primes

> **In short:** The record 3×3 magic square of pandigital primes with a pandigital sum had magic sum 1530758629047. The construction: (1) entries c, c ± a, c ± b, …; (2) the top and bottom halves each use a fixed set of five digits; (3) a = 3·10⁶ and b = 4554 each move one half only. This gives magic sum 961547036829, beating 1530758629047; proven primes.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_249.htm)

**Status:** beaten · proven primes

## The question

A number is **pandigital** if it uses all ten digits 0 to 9 at least once (and does not start with 0). Question 2 asks for a 3×3 magic square (every row, column and both diagonals have the same sum) made of nine different **primes** that are each pandigital, with a magic sum that is pandigital too. Smaller is better.

## Current record vs ours

| | Square | Magic sum |
|---|---|---|
| Current record (J. C. Rosa, May 2005) | 12-digit pandigital primes, "probably not the smallest" | 1530758629047 |
| **Ours** | 12-digit pandigital primes (below) | **961547036829** |

## How we found it

Making a number pandigital by trial and error is wasteful, because most numbers miss a digit. So we split each 12-digit entry into a 6-digit top half and a 6-digit bottom half, and made the top half use one fixed set of five digits and the bottom half the other five. Then every entry is pandigital automatically, whatever the exact digits are.

A 3×3 magic square can always be written with a centre c and two step sizes a and b. We put the step a in the top half and the step b in the bottom half, so the halves never mix. That leaves only one real job: find c, a, b so that all nine entries are prime and the magic sum (3c) is pandigital.

## The math

Every 3×3 magic square has the form

```
c − b       c + a + b   c − a
c − a + b   c           c + a − b
c + a       c − a − b   c + b
```

with magic sum 3c. Ours uses

```
c = 320515678943,   a = 3000000,   b = 4554
```

The step a = 3·10⁶ only changes the top six digits and b = 4554 only the bottom six, so each half moves inside its own block and keeps its own digit set. The magic sum is

```
3c = 961547036829     (pandigital: uses 0..9)
```

## The square

```
320515674389  320518683497  320512678943
320512683497  320515678943  320518674389
320518678943  320512674389  320515683497
```

All nine entries are different, all are pandigital, and all are prime (proven: these numbers are below 2⁶⁴, where the test used is exact). The magic sum 961547036829 is pandigital and composite, as the puzzle asks.

## Validation

This script checks that the square is magic, that every entry is a different pandigital prime, and that the magic sum is pandigital.

```python
from sympy import isprime

S = [[320515674389, 320518683497, 320512678943],
     [320512683497, 320515678943, 320518674389],
     [320518678943, 320512674389, 320515683497]]

pandigital = lambda n: set(str(n)) == set("0123456789")   # uses every digit 0..9

# all row, column and diagonal sums
lines = [sum(r) for r in S] + [sum(c) for c in zip(*S)]
lines += [S[0][0] + S[1][1] + S[2][2], S[0][2] + S[1][1] + S[2][0]]
assert len(set(lines)) == 1                       # the square is magic
magic_sum = lines[0]

cells = [x for row in S for x in row]
assert len(set(cells)) == 9                       # nine different numbers
assert all(isprime(x) for x in cells)             # all prime (sympy is exact below 2^64)
assert all(pandigital(x) for x in cells)          # each entry uses all ten digits
assert pandigital(magic_sum) and not isprime(magic_sum)   # sum is pandigital and composite
assert magic_sum < 1530758629047                  # smaller than Rosa's published square

print("pandigital prime magic square with magic sum", magic_sum)
```
