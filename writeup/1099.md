# Puzzle 1099: A floor-function formula for many distinct primes

> **In short:** We extended a formula with floor divisions ⌊n/k⌋ so that it produces 570 different primes for n = 0 to 569, against 120 on the page. The formula is built from blocks of ten primes in arithmetic progression, and there are plenty of such blocks to add.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_1099.htm)

**Status:** beaten · proven primes

## The question

Using only n, whole-number constants and floor divisions ⌊n/k⌋, write a formula f(n) that is prime for n = 0, 1, 2, … for as long as possible. The starting example (S. Cavegn) gives 103 primes, many of them repeated. The best on the page gives 120 **distinct** primes.

## Current record vs ours

| | Formula | Distinct primes |
|---|---|---|
| Current record (E. Vantieghem, 2022) | 12 blocks, floor terms up to ⌊n/110⌋ | 120 (n = 0 … 119) |
| **Ours** | 57 blocks, floor terms up to ⌊n/560⌋ (in [data/1099.txt](data/1099.txt)) | **570** (n = 0 … 569) |

## How we found it

Vantieghem explains on the page that his 120 primes come in 12 groups of 10, each group an arithmetic progression with difference 9699690 = 2·3·5·7·11·13·17·19 (written 19#). The floor terms only make the formula jump from one group to the next.

That difference is the natural one for long prime progressions: since it contains every prime up to 19, the numbers a, a + d, …, a + 9d can never be divisible by any of them. Progressions of 10 primes with this difference are common: we found 76 starting values below 6·10⁷. So we simply added more groups. Each new group adds 10 new primes and one new floor term. We stopped at 57 groups, 570 primes; the construction can keep going.

## The math

A block is ten primes I_m, I_m + d, …, I_m + 9d with d = 19# = 9699690. The formula

```
H(n) = I₀ + d·n + Σ_{j=1..56} c_j · ⌊n / (10j)⌋
```

must equal I_m + d·(n − 10m) on block m (10m ≤ n ≤ 10m + 9). At each block boundary n = 10m the floor terms ⌊n/(10j)⌋ with j | m jump by 1, so matching the jump gives the coefficients one at a time:

```
c_m = (I_m − I_{m−1} − 10·d) − Σ_{j | m, j < m} c_j
```

Because the blocks have different starting values modulo d, no prime appears twice.

## The numbers

```
H(n) = 35969 + 9699690·n − 96801340·⌊n/10⌋ − 9796·⌊n/20⌋ − 22722·⌊n/30⌋ + 1492548·⌊n/40⌋ + …
```

The first 11 floor coefficients are exactly Vantieghem's; the full list of 56 is in [data/1099.txt](data/1099.txt). The 570 values are all below 2⁶⁴, where sympy's primality test is exact, so they are proven primes.

## Validation

This script reads the formula from the data file, evaluates it for n = 0 … 569 and checks that all 570 values are prime and different.

```python
from sympy import isprime

# read the floor terms "k c" from the data file (lines starting with # are comments)
terms = [tuple(map(int, line.split())) for line in open("writeup/data/1099.txt")
         if line.strip() and not line.startswith("#")]
assert len(terms) == 56

def H(n):
    return 35969 + 9699690 * n + sum(c * (n // k) for k, c in terms)

values = [H(n) for n in range(570)]
assert all(isprime(v) for v in values)       # all prime (exact below 2^64)
assert len(set(values)) == 570               # all different

# the first 120 values are exactly Vantieghem's 12 blocks
assert values[:3] == [35969, 9735659, 19435349] and values[119] == 96444217

print("570 different primes for n = 0..569")
```

Run it from the repository root, so the relative path [`writeup/data/1099.txt`](data/1099.txt) resolves.
