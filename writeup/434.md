# Puzzle 434: σ(σ(x)) = σ(x) + x

> **In short:** Firoozbakht noted that every Mersenne prime q satisfies σ(σ(q)) = σ(q) + q and asked whether these are the only solutions. We prove the equation says exactly that y = σ(x) has aliquot sum x, so y must be deficient. For prime x it is then *equivalent* to "x + 1 is almost perfect" (σ(n) = 2n − 1), a classical open problem, and we pin down what a non-Mersenne prime solution would have to look like. For composite x we derive strong necessary conditions, show that a whole family (σ(x) = 2·prime) dies on an algebraic factorisation, and check every x ≤ 5·10⁷: only the Mersenne primes. A near-miss count suggests composite solutions should exist, but far beyond any sieve.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_434.htm)

**Status:** open · prime case reduced to almost perfect numbers (proof); necessary conditions for composite x (proof); no composite solution ≤ 5·10⁷ (computed); heuristic

## The question

If q = 2ᵖ − 1 is a Mersenne prime, σ(σ(q)) = σ(2ᵖ) = 2ᵖ⁺¹ − 1 = σ(q) + q. Are the Mersenne primes the only solutions of σ(σ(x)) = σ(x) + x?

## Record vs ours

| | On the page | Ours |
|---|---|---|
| Prime x | question only | equivalent to "x + 1 almost perfect"; a non-Mersenne prime solution needs x = 2ᵃm² − 1 with a odd, m with ≥ 2 primes all > 2ᵃ⁺¹ (proof) |
| Composite x | no contributions | none ≤ 5·10⁷; necessary conditions; the family σ(x) = 2·prime is impossible below 10⁸ and its main branch impossible always |

## How we found it

Write y = σ(x). Then σ(y) = y + x says the proper divisors of y add up to x, so y is a number whose aliquot sum is x. Measured by abundancy A(n) = σ(n)/n, this reads A(y) = 1 + 1/A(x), which is below 2. So everything hinges on y being *deficient*, and deficient numbers are rigid: they cannot be multiples of 6, of 20, of 28 or of any other perfect or abundant number. That turns into congruences on x.

## The math

**Step 1: the reformulation** (proved). With y = σ(x), the equation is σ(y) − y = x, i.e. s(y) = x where s is the aliquot sum. Divide by y: A(y) = 1 + x/σ(x) = 1 + 1/A(x). For x > 1, A(x) > 1, so **A(y) < 2: y is deficient**.

**Step 2: prime x** (proved). For x = p prime, y = p + 1 and the equation becomes σ(p + 1) = 2(p + 1) − 1: p + 1 is *almost perfect*. Every power of 2 is almost perfect, giving the Mersenne primes. No other almost perfect number is known, and none has been proved impossible. So "only Mersenne primes" for prime x is equivalent to: no almost perfect n other than 2ᵏ has n − 1 prime. What such an n must look like:

1. σ(n) = 2n − 1 is odd, so n is a square or twice a square: n = 2ᵃm² with m odd. n − 1 = p is odd, so a ≥ 1, and m > 1 when n is not a power of 2.
2. For any prime q ≤ 2ᵃ⁺¹ − 1, A(2ᵃq) = (2 − 2⁻ᵃ)(1 + 1/q) ≥ (2 − 2⁻ᵃ) · 2ᵃ⁺¹/(2ᵃ⁺¹ − 1) = 2. So q | m would make A(n) > 2, but A(n) = 2 − 1/n. Hence **every prime of m exceeds 2ᵃ⁺¹**.
3. Dividing σ(n) = (2ᵃ⁺¹ − 1)σ(m²) = 2ᵃ⁺¹m² − 1 gives A(m²) = 1 + (1 − 1/m²)/(2ᵃ⁺¹ − 1), and reducing mod 2ᵃ⁺¹ − 1 gives (2ᵃ⁺¹ − 1) | m² − 1.
4. If m were a prime power q^j, then A(m²) < 1 + 1/(q − 1) ≤ 1 + 2⁻⁽ᵃ⁺¹⁾, which is below the value in 3 because m² > 2ᵃ⁺¹. So **m has at least two distinct prime factors**.
5. 3 ∤ m by 2, so m² ≡ 1 (mod 3) and p = 2ᵃm² − 1 ≡ 2ᵃ − 1 (mod 3). If a were even, 3 | p. Hence **a is odd**.

**Step 3: composite x, necessary conditions** (proved). Let a = v₂(y).

- 6 ∤ y, since A(6k) ≥ A(6) = 2. More generally y is not a multiple of 6, 20, 28, 70, 88, 104, … (any perfect or abundant number).
- If y is odd, then x = m² or 2m² (σ(x) is odd exactly for squares and twice-squares).
- If y is even: by the argument of step 2.2, y has no odd prime factor below 2ᵃ⁺¹; and A(y) ≥ 2 − 2⁻ᵃ in step 1 gives **A(x) ≤ 2ᵃ/(2ᵃ − 1)**. Since 3 ∤ y and σ(pᵉ) ≡ 0 (mod 3) when p ≡ 2 (mod 3) and e is odd (and σ(2ᵇ) = 2ᵇ⁺¹ − 1 ≡ 0 when b is odd): **every prime p ≡ 2 (mod 3) divides x to an even power, the power of 2 in x is even, and primes p ≡ 1 (mod 3) appear with exponent ≢ 2 (mod 3)**.
- If x is even: x = 2ᵇu with b ≥ 2 even, so A(x) ≥ 7/4. That forces a = 1. Each odd prime with odd exponent adds at least one factor 2 to y, so x has **exactly one** odd prime to an odd power, and it is ≡ 1 (mod 12) when that power is 1.

**Step 4: the family σ(x) = 2·prime** (proved). If y = 2P with P prime, then σ(y) = 3(P + 1), so x = σ(y) − y = P + 3 and σ(x) = 2P = 2x − 6. Conversely, **any even x with σ(x) = 2x − 6 and x − 3 prime is a solution.** For x = 2ᵏq the deficiency-6 condition gives q = 2ᵏ⁺¹ + 5, and then, with t = 2ᵏ,

```
x − 3 = 2t² + 5t − 3 = (2t − 1)(t + 3),
```

always composite. The sieve below finds exactly three even deficiency-6 numbers below 10⁸: 52, 592 and 2102272, which are k = 2, 4, 10 of this family. So there is no solution with σ(x) = 2·prime below 10⁸, and none at all of the shape 2ᵏq.

**Step 5: one-unknown families** (exhaustive in the stated range). Take x = Q·p with p = c·r − 1, p and r prime, Q a fixed cofactor. Then y = σ(Q)·c·r, and with M = σ(Q)·c,

```
F := σ(y) − y − x = L·r + σ(M) + Q,   L = σ(M) − M − Q·c.
```

F = 0 forces r = (σ(M) + Q)/(M + Q·c − σ(M)): one candidate per (Q, c). This explains the closest misses in the data. For example x = 15633 = 3⁴·193 has 194 = 2·97 and F = −5·97 + 480 = −5; it would need r = 96. Over every Q ≤ 10⁴ and even c with σ(Q)·c ≤ 10⁸ (x up to about 10¹⁶), only 27 pairs give an integer r, and none gives r and p both prime. The family is thin because L < 0 needs M deficient, which with c even requires 3 ∤ σ(Q).

**Step 6: the search** (computed). A σ-sieve to 10⁸ checks every x ≤ 5·10⁷ with σ(x) ≤ 10⁸. By step 3 that covers every solution with y even, since then A(x) ≤ 2ᵃ/(2ᵃ − 1) ≤ 2. The rest (y odd) are squares and twice-squares, and the ones among them with σ(x) > 10⁸ are checked one by one (about 12000 numbers). The only solutions are 3, 7, 31, 127, 8191, 131071 and 524287. The previous check (ours, at the start of this attack) went to 2·10⁶. The page had no contributions.

**Step 7: how many to expect** (heuristic). Count composite x with |F| ≤ 100: 9, 7, 9 and 9 in [10⁴, 10⁵), [10⁵, 10⁶), [10⁶, 10⁷) and [10⁷, 5·10⁷). That is about 8.5 per decade, spread over the 201 values of F with no visible congruence gap: F takes both parities and all classes mod 3 among the near misses. If F = 0 is as likely as any nearby value, the exact-hit rate is about 8.5/201 = 0.04 per decade, so 0.16 hits were expected between 10⁴ and 5·10⁷, and the observed zero is not surprising. At a constant rate per decade, composite solutions exist and are infinitely many, but the first one is expected only after about 16 more decades (beyond 10²³). This rests on four decades of data and on F behaving like a smooth random variable near 0, so it is a guess, not a forecast.

What is left: a proof either way. The prime case is as hard as the almost perfect number problem. For composite x, every surviving shape needs a near-coincidence of abundancies, which is the same kind of open problem.

from sympy import divisor_sigma as sigma, isprime
for x in range(2, 300000):
    y = int(sigma(x))
    if sigma(y) == y + x:
        assert isprime(x) and (x + 1) & x == 0
for k in range(1, 60):
    t = 2**k
    assert t * (2 * t + 5) - 3 == (2 * t - 1) * (t + 3)
print("only Mersenne primes below 3e5; the 2^k(2^(k+1)+5) family always fails")
