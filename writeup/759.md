# Puzzle 759: At most 10 palindromic primes in arithmetic progression

> **In short:** It was claimed, but not proved, that at most 10 palindromic primes can lie in arithmetic progression (10 are known since 1999). The proof: (1) with 6 or more prime terms the common difference d is a multiple of 10, so all terms have the same last digit, the same first digit and the same length; (2) the lowest nonzero digit e of d makes one digit of the terms step by e (mod 10), while every digit below it stays fixed; (3) by symmetry that digit reappears near the front of each term, where it cannot decrease while the terms increase, so it takes at most 10 values. This proves the claim: at most 10 terms, and exactly 10 only when that digit runs through 0, 1, …, 9.

**Puzzle:** [primepuzzles.net](https://www.primepuzzles.net/puzzles/puzz_759.htm)

**Status:** answered · proof (complete)

## The question

Abhiram R. Devesh found palindromic primes in arithmetic progression (AP) of length 3 and 4, e.g. 10301, 13331, 16361, 19391.

**Q.** Does there exist a pair (p, d) that generates palindromic primes in AP of length 5 or above, or can we prove that it cannot exist?

## How we found it

Andersen's remark "any 10 palindromes in AP must contain a digit which goes from 0 to 9" already names the mechanism. The lowest digits of the terms never change, so neither do the highest ones. The first digit position that does change is driven by the lowest nonzero digit of d, without any carry from below. In a palindrome that digit is mirrored near the front of the number, where it decides the order of the terms. A digit that steps by e (mod 10) and must not decrease can take at most 10 values.

## The math

Let P_k = p + k·d (k = 0, 1, …, N − 1, d > 0) be N palindromic primes.

**Step 1 (proved). For N ≥ 6, 10 divides d.**

- If d is odd, every second term is even, so it is 2. Then N ≤ 2.
- If 5 ∤ d, then among P₁, …, P₅ one term is ≡ 0 (mod 5), so it equals 5. That forces p ∈ {2, 3}. With p = 2 every term is even (d is even by the first point); with p = 3, d = 2 the run is 3, 5, 7 and then 9.

So N ≥ 6 needs 2 | d and 5 | d.

**Step 2 (proved). All terms have the same last digit, the same first digit c, and (for N ≥ 4) the same length.** The last digit is the same because 10 | d. In a palindrome the first digit equals the last, so all terms start with the same digit c ≥ 1.

Suppose two consecutive terms have lengths L < L′. Both start with c, so d > c·10^(L′−1) − (c+1)·10^(L−1) ≥ (9c − 1)·10^(L′−2) ≥ 8·10^(L′−2). All terms of one length lie in an interval of width 10^(length−1), which gives two consequences:

- A length that is followed by a longer one holds only 1 term, because two terms in it would make d < 10^(L−1).
- After the first change of length at most 1 + 10^(L′−1)/(8·10^(L′−2)) < 3 terms fit into the new length.

A second change of length would need d ≥ (9c − 1)·10^(L′−1). But d < (c + 1)·10^(L′−1), since d is the difference of a term of length L and one of length L′, and 9c − 1 < c + 1 is false. So an AP whose length changes has at most 3 terms. For N ≥ 4 all terms have the same length L.

**Step 3 (proved). The stepping digit.** Write 10^j ∥ d (j ≥ 1 by step 1) and let e ∈ {1, …, 9} be the digit of d at position j (positions counted from 0 at the right). Since d ≡ 0 (mod 10^j),

```
P_k mod 10^j = p mod 10^j            (digits 0 … j−1 never change)
⌊P_k / 10^j⌋ = ⌊p / 10^j⌋ + k·d/10^j  ⇒  digit j of P_k = (p_j + k·e) mod 10
```

There is no carry into position j, because nothing below it changes.

**Step 4 (proved). At most 10 terms.** The terms are palindromes of length L, so the digit at position i equals the digit at position L − 1 − i.

- If j > L − 1 − j, the mirror of position j is one of the constant positions 0 … j − 1. Then digit j is constant, but it changes by e ≢ 0 (mod 10) from P₀ to P₁. Contradiction (N ≥ 2).
- Otherwise L − 1 − j ≥ j. Let T_k = ⌊P_k / 10^(L−1−j)⌋, the number formed by the top j + 1 digits of P_k. Its top j digits mirror positions 0 … j − 1, so they are a constant C. Its last digit, at position L − 1 − j, mirrors position j (or is position j itself when it is the middle digit). So

```
T_k = 10·C + a_k,   a_k = (p_j + k·e) mod 10 ∈ {0, …, 9}
```

Since P_k increases, T_k cannot decrease, so a_(k+1) ≥ a_k. But a_(k+1) ≡ a_k + e (mod 10) with 1 ≤ e ≤ 9, so a_(k+1) = a_k + e: a wrap-around (a_k + e − 10 < a_k) is forbidden. Therefore a_(N−1) = a_0 + (N − 1)·e ≤ 9, and

```
N ≤ 1 + 9/e ≤ 10,   with N = 10 only if e = 1 and a_k = k (the digit runs 0, 1, …, 9)
```

Steps 1–4 hold for every N ≥ 6, so **no 11 palindromic primes are in AP**, in base 10. The 1999 record (p, d) = (742950290870000078092059247, 1010100000000000) is the extremal case: d = 10101·10¹¹, so j = 11, e = 1, and digit 11 of the ten 27-digit terms runs 0, 1, …, 9. All ten terms are proven primes (PARI).

The proof uses primality only in step 1, to force 10 | d. For palindromes in general (not prime) the same steps give at most 10 terms whenever 10 | d.
