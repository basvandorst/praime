Puzzle 1104 Sum of powers of primitive roots

Hope you like the following puzzle from Giorgos Kalogeropoulos

The primitive roots of prime number 43 are 3, 5, 12, 18, 19, 20, 26, 28, 29, 30, 33 and 34.

3 + 5 + 12 + 18 + 19 + 20 + 26 + 28 + 29 + 30 + 33 + 34 = 257 (prime)

3^2 + 5^2 + 12^2 + 18^2 + 19^2 + 20^2 + 26^2 + 28^2 + 29^2 + 30^2 + 33^2 + 34^2 = 6709 (prime)

3^3 + 5^3 + 12^3 + 18^3 + 19^3 + 20^3 + 26^3 + 28^3 + 29^3 + 30^3 + 33^3 + 34^3 = 188729 (prime)

3^4 + 5^4 + 12^4 + 18^4 + 19^4 + 20^4 + 26^4 + 28^4 + 29^4 + 30^4 + 33^4 + 34^4 = 5527909 (prime)

3^5 + 5^5 + 12^5 + 18^5 + 19^5 + 20^5 + 26^5 + 28^5 + 29^5 + 30^5 + 33^5 + 34^5 = 166291577 (prime)

3^6 + 5^6 + 12^6 + 18^6 + 19^6 + 20^6 + 26^6 + 28^6 + 29^6 + 30^6 + 33^6 + 34^6 = 5098962229 (composite)

If we raise all the primitive roots of 43 to the first 5 powers, the sums of these powers are prime numbers. For any prime p we always use all the primitive roots < p.

Q1. Can you find another prime with the same property?

Q2. Can you find a prime whose sums of the first six powers (or more) of its primitive roots are primes?
