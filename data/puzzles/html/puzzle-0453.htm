Puzzle 453. DPFP

Michel Marcus sent the following puzzle:

Only one Deficient Primitive Friendly Pair (a,b) is known such that abundancy(a) = abundancy(b), having a & b the same set of prime factors.

(a, b) = (451737, 1401543)
abundancy 6832/3861

Q1. Is it possible to find other deficient friendly pairs with the same property?
Q2. Is it possible to find abundant friendly pairs with the same property ?
