Problem 68. More on Brier numbers.

Arkadiusz Wesolowski sent the following puzzle proposal, related to Brier numbers. Regarding this issue, see previous Problems 29, 49, 52 & 58.

A Brier number is an integer k such that both k.2^n+1 and k.2^n-1 are composite for any value of n.

Let k be a Brier number. Let A be a covering set for the Sierpinski number k and let B be a covering set for the Riesel number k, then A U B = S = {p(1), p(2), ..., p(s)} a set of primes and P = product[p(i)](i = 1...s).

Number of primes used in both sets A & B | Discoverer | P value
